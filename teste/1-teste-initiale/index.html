Teste Fizică - Evaluări inițiale

Lista testelor disponibile pentru elevi, pentru programa de 3 ore/săptămână:

Clasa a IX-a

  • Test Inițial - Clasa a IX-a (3 ore)
    Evaluarea inițială a cunoștințelor pentru programa de 3 ore/săptămână.
    Concepte de bază, cinematică, măsurare, dinamică, statica fluidelor, lucru mecanic, mecanisme simple, echilibrul corpurilor, investigație experimentală.

Clasa a X-a

  • Test Inițial - Clasa a X-a (3 ore)
    Evaluarea inițială a cunoștințelor din clasa a IX-a, pentru programa de 3 ore/săptămână.
    Mecanică (recapitulare), legea atracției universale, impulsul mecanic și energia mecanică.

Clasa a XI-a

  • Test Inițial - Clasa a XI-a (3 ore)
    Evaluarea inițială a cunoștințelor din clasa a X-a, pentru programa de 3 ore/săptămână.
    Termodinamică (temperatură, căldură, calorimetrie), gazul ideal, curent electric, circuite electrice.
