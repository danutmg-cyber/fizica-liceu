1. Identificarea elevului

Clasa și numărul din catalog determină setul experimental. Pentru fiecare elev este generată reproductibil o combinație de inductanță, capacitate, tensiune inițială și pierderi.

2. Securitatea în laborator

Circuitul real se realizează numai cu tensiuni mici. Un condensator poate rămâne încărcat și după deconectarea sursei. Înaintea modificării montajului, acesta trebuie descărcat printr-o rezistență adecvată.
  • Alimentarea se oprește înaintea modificării circuitului.
  • Nu scurtcircuita direct un condensator încărcat.
  • Respectă polaritatea condensatorului dacă acesta este electrolitic.
  • Respectă tensiunea nominală maximă a condensatorului.
  • Nu conecta montajul la rețeaua de 230 V.

4. Modelul fizic și predicțiile

Un condensator încărcat este conectat la o bobină. Câmpul electric al condensatorului și câmpul magnetic al bobinei își transferă periodic energia.

q(t) = Qmax cos(ω₀t)

i(t) = −ω₀Qmax sin(ω₀t)
ω₀ = 1/√(LC)

T₀ = 2π√(LC)

f₀ = 1/(2π√(LC))
WE = C UC² / 2

WB = L I² / 2
