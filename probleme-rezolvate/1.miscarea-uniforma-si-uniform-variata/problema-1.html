Mișcare uniformă și uniform variată › Problema 1

Problema 1

Două autocamioane pleacă în același moment din București, din dreptul bornei kilometrice zero, pe șoseaua București–Craiova, cu viteze diferite și constante.

Ideea lecției: poziția unui mobil în mișcare uniformă se scrie x(t) = v·t. Din această relație simplă putem afla orice moment sau orice bornă cerută de problemă.

1. Enunțul problemei

Un autocamion are viteza v₁ = 30 km/h, iar celălalt viteza v₂ = 25 km/h. Să se determine:

  1. după cât timp punctul unde se află borna kilometrică 66 se găsește la mijlocul distanței dintre cele două autocamioane;
  2. care este borna kilometrică prin fața căreia al doilea autocamion trece la o oră după primul.
Date: v₁ = 30 km/h  ·  v₂ = 25 km/h  ·  start comun în borna 0

2. Schiță grafică

Ambele autocamioane pornesc din același punct și merg în același sens. Poziția fiecăruia, măsurată de la borna 0, este x = v·t. Mijlocul distanței dintre ele, la momentul t, este media celor două poziții.

x_mij(t) = (v₁ + v₂) · t / 2

3. Rezolvare — cerința 1°

  1. Poziția fiecărui autocamion la momentul t: x₁(t) = v₁·t  ;  x₂(t) = v₂·t
  2. Mijlocul distanței dintre ele: x_mij(t) = (x₁ + x₂) / 2 = (v₁ + v₂)·t / 2
  3. Punem condiția x_mij(t) = 66: (v₁ + v₂)·t / 2 = 66  →  t = 132 / 55
t = 2,4 h  (2 h 24 min)
Verificare: la t = 2,4 h → x₁ = 30 · 2,4 = 72 km; x₂ = 25 · 2,4 = 60 km. Mijlocul: (72 + 60) / 2 = 66 km ✓

4. Rezolvare — cerința 2°

  1. Timpul fiecăruia până la borna x: t₁ = x / v₁  ;  t₂ = x / v₂
  2. Condiția din enunț: t₂ − t₁ = 1  →  x·(v₁ − v₂) / (v₁·v₂) = 1
  3. Rezolvăm pentru x: x = v₁·v₂ / (v₁ − v₂) = (30·25) / (30−25) = 750/5
x = 150 km
Verificare: primul ajunge la km 150 după t₁ = 150/30 = 5 h; al doilea ajunge după t₂ = 150/25 = 6 h. Diferența: 6 − 5 = 1 h ✓

5. Reține esențialul

  • În mișcare uniformă, poziția este liniară în timp: x(t) = v·t.
  • Mijlocul distanței dintre două mobile pornite din același punct: t = 2d / (v₁ + v₂), unde d este borna-reper.
  • Borna la care diferența de timp de trecere este fixată: x = v₁v₂ / (v₁ − v₂).
  • Ambele rezultate — 2,4 h și 150 km — se verifică exact.

Ai terminat problema.
