Relatii magice in trigonometrie

Din triunghi în formulă și din formulă în triunghi.

Alege o latură egală cu 1 și lasă teorema lui Pitagora să dezvăluie relațiile.

Ce vei învăța să vezi

O expresie precum √(1 + t²) poate reprezenta ipotenuza unui triunghi dreptunghic. O expresie precum √(1 − u²) poate reprezenta o catetă.

Scopul lecției este să reconstruiești relațiile trigonometrice prin desen, astfel încât să le recunoști mai ușor în calculele de la Analiză matematică.

În toate triunghiurile lecției, 0° < x < 90°. Funcțiile trigonometrice sunt pozitive. Desenele fixe sunt schematice.

Metoda: alegi latura unitară → identifici celelalte laturi → aplici Pitagora → citești rapoartele.

1. Ipotenuza este 1

Față de unghiul x:

sin x = cateta opusă / ipotenuză

cos x = cateta alăturată / ipotenuză

Dacă ipotenuza este 1, catetele au lungimile sin x și cos x.

Aplicăm teorema lui Pitagora:

sin²x + cos²x = 1

Izolăm fiecare catetă și extragem rădăcina pozitivă:

sin x = √(1 − cos²x)
cos x = √(1 − sin²x)
Imaginează-ți înainte să calculezi

Ipotenuza rămâne 1. Unghiul x crește. Ce se întâmplă cu cele două catete?

Cateta opusă crește, iar cea alăturată scade. Suma pătratelor lor rămâne egală cu 1.

Imagine algebrică: dacă ipotenuza este 1, iar o catetă este u, cu 0 < u < 1, cealaltă catetă este √(1 − u²).

2. Cateta alăturată este 1

tan x = cateta opusă / cateta alăturată

sec x = 1 / cos x = ipotenuză / cateta alăturată

Când cateta alăturată este 1, cateta opusă este tan x, iar ipotenuza este sec x.

1 + tan²x = sec²x
sec x = √(1 + tan²x)
tan x = √(sec²x − 1)

Din același desen citim:

sin x = tan x / √(1 + tan²x)
cos x = 1 / √(1 + tan²x)
Dacă t = tan x > 0, desenează catetele 1 și t. Ipotenuza este √(1 + t²).
De ce secanta este mai mare decât 1?

În acest desen, sec x este ipotenuza, iar una dintre catete este 1. Ipotenuza este mai mare decât fiecare catetă, deci sec x > 1.

3. Cateta opusă este 1

cot x = cateta alăturată / cateta opusă

csc x = 1 / sin x = ipotenuză / cateta opusă

Când cateta opusă este 1, celelalte laturi sunt cot x și csc x.

Cosecanta se notează și cosec x.

1 + cot²x = csc²x
csc x = √(1 + cot²x)
cot x = √(csc²x − 1)
sin x = 1 / √(1 + cot²x)
cos x = cot x / √(1 + cot²x)
Descoperă legătura dintre tangentă și cotangentă

În orice triunghi dreptunghic:

tan x = cateta opusă / cateta alăturată, iar cot x = cateta alăturată / cateta opusă.

Prin urmare, tan x · cot x = 1.

4. Explorează unghiul

Desenul de mai jos are ipotenuza 1. Modifică unghiul și urmărește cele două catete. Valorile tuturor funcțiilor se actualizează.

Valorile sunt aproximative, rotunjite la trei zecimale.

Ce observi la x = 45°?

Catetele sunt egale, deci sin x = cos x = √2/2. Tangenta și cotangenta sunt 1, iar secanta și cosecanta sunt √2.

5. Recunoaște triunghiul ascuns într-un radical

Expresie Triunghiul pe care îl construiești O alegere posibilă
√(1 − u²), 0 < u < 1 Ipotenuza 1; catetele u și √(1 − u²) u = sin x ⇒ radicalul este cos x
√(1 + u²), u > 0 Catetele 1 și u; ipotenuza √(1 + u²) u = tan x ⇒ radicalul este sec x
√(u² − 1), u > 1 Ipotenuza u; catetele 1 și √(u² − 1) u = sec x ⇒ radicalul este tan x

Exemplu pentru Analiză

Pentru t > 0, cum interpretezi expresia t / √(1 + t²)?

Desenezi un triunghi cu cateta opusă t și cateta alăturată 1. Ipotenuza este √(1 + t²). Raportul cerut este sinusul unghiului x, unde tan x = t.

Dacă t = tan x, atunci t / √(1 + t²) = sin x.
Extinde ideea: √(a² − u²)

Pentru a > 0 și 0 < u < a, alegi ipotenuza a și o catetă u. Cealaltă catetă este √(a² − u²).

Dacă u = a sin x, atunci √(a² − u²) = a cos x.

6. Atelier de imaginație

La fiecare exercițiu, începe printr-un desen. Deschide răspunsul numai după ce ai scris laturile triunghiului.

Provocarea 1

sin x = 3/5. Alege ipotenuza 1 și determină celelalte cinci funcții.

Verifică

Catetele sunt 3/5 și 4/5.

cos x = 4/5; tan x = 3/4; cot x = 4/3; sec x = 5/4; csc x = 5/3.

Provocarea 2

tan x = 2. Determină sin x, cos x și sec x.

Verifică

Catetele sunt 1 și 2, iar ipotenuza este √5.

sin x = 2/√5; cos x = 1/√5; sec x = √5.

Provocarea 3

cot x = 3. Ce latură alegi egală cu 1? Determină sin x, cos x și csc x.

Verifică

Cateta opusă este 1, cateta alăturată este 3, iar ipotenuza este √10.

sin x = 1/√10; cos x = 3/√10; csc x = √10.

Provocarea 4

sec x = u > 1. Exprimă tan x și sin x în funcție de u.

Verifică

Cateta alăturată este 1, ipotenuza este u, iar cateta opusă este √(u² − 1).

tan x = √(u² − 1); sin x = √(u² − 1)/u.

Provocarea 5

csc x = v > 1. Exprimă cot x și cos x în funcție de v.

Verifică

Cateta opusă este 1, ipotenuza este v, iar cateta alăturată este √(v² − 1).

cot x = √(v² − 1); cos x = √(v² − 1)/v.

Provocarea 6

Pentru 0 < u < 1, construiește un triunghi în care √(1 − u²)/u să reprezinte cotangenta unui unghi.

Verifică

Alege ipotenuza 1 și cateta opusă u. Cateta alăturată este √(1 − u²).

Atunci sin x = u și cot x = √(1 − u²)/u.

7. Atenție la semn când treci la Analiză

Radicalul pătrat este nenegativ. Pentru unghiuri generale, trebuie să ținem cont de modul:

√(1 − cos²x) = |sin x|
√(1 − sin²x) = |cos x|
√(1 + tan²x) = |sec x|
√(1 + cot²x) = |csc x|

Ultimele două relații se folosesc acolo unde funcțiile sunt definite. Pentru unghiurile ascuțite din lecție, valorile sunt pozitive și modulele pot fi eliminate.

Bilet de ieșire: desenează din memorie cele trei triunghiuri cu o latură egală cu 1. Scrie pentru fiecare relația lui Pitagora și dedu o formulă cu radical.
