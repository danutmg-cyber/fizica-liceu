LECȚIA 11 · Aprofundare · XII

Radicali și domenii: factorul Lorentz

Înainte să calculezi un radical sau un raport, verifică domeniul și sensul fizic.

Privește și reconstruiește

β = v/c   ;   γ = 1/√(1 − β²)

Raportul β este fără unitate. Pentru un corp cu masă de repaus nenulă, viteza sa într-un reper inerțial satisface 0 ≤ v < c, deci 0 ≤ β < 1. Radicalul este pozitiv și numitorul nu se anulează.

Poți folosi un triunghi cu ipotenuza 1 și catetele β și √(1 − β²), pentru 0 < β < 1. Dacă β = sin x, atunci γ = 1/cos x = sec x. Triunghiul este un instrument algebric de vizualizare.

Exemplu rezolvat

Pentru v = 0,6c, β = 0,6. Cealaltă catetă este √(1 − 0,36) = 0,8, deci γ = 1/0,8 = 1,25.

În relația de dilatare temporală Δt = γΔτ, Δτ este timpul propriu dintre două evenimente care se produc în același loc în reperul ceasului. Pentru Δτ = 4 μs, celălalt reper inerțial măsoară Δt = 5 μs.

Când β se apropie de 1 din stânga, γ crește fără limită. Nu înlocui v = c pentru un corp cu masă și nu atribui fotonului un reper propriu de repaus.

Încearcă singur

Calculează γ pentru v = 0,8c. De ce γ nu poate fi mai mic decât 1 în acest model?

Desenează situația, precizează condițiile formulei și verifică unitățile rezultatului.

Deschide explicația

√(1 − 0,8²) = 0,6, deci γ = 5/3 ≈ 1,667. Numitorul este pozitiv și cel mult 1, astfel încât inversul său este cel puțin 1.
