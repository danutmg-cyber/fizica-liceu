Notații și condiții de aplicare

Reflexie și refracție: unghiurile se măsoară față de normală. n este indicele absolut, v viteza de fază în mediu, c viteza luminii în vid. La trecerea între medii staționare frecvența ν se conservă. Reflexia totală cere trecere spre indice mai mic și incidență peste unghiul critic.

Lentile: p > 0 pentru obiect real, p < 0 pentru obiect virtual; q > 0 pentru imagine reală, q < 0 pentru imagine virtuală. f > 0 la lentile convergente, f < 0 la divergente. Se folosesc 1/f = 1/p + 1/q, β = −q/p și C = 1/f. Înălțimile sunt algebrice; β < 0 înseamnă imagine răsturnată. Se lucrează cu lentile subțiri și raze paraxiale.

În formula constructorului, razele de curbură sunt carteziene, pozitive când centrul este spre dreapta, lumina mergând spre dreapta: C = (n_lentilă/n_mediu − 1)(1/R₁ − 1/R₂). Pentru două lentile separate, convergența echivalentă este C_eq = C₁ + C₂ − dC₁C₂; focala echivalentă se referă la planele principale, nu automat la una dintre lentile. La calcul succesiv, p₂ = d − q₁.

Interferență: δ este diferența de drum optic; formulele cu δ optic folosesc λ_vac. În aer, n ≈ 1 și λ ≈ λ_vac. La Young, d este distanța dintre fante, D distanța până la ecran și i interfranja; se presupun D ≫ d și |x| ≪ D. Sursele sunt coerente și inițial în fază, dacă enunțul nu spune altfel. I în formulele interferenței este iradianță, în W/m².

Ordinul algebric k al unei franje rămâne același în toate variantele aceleiași întrebări. Nu se schimbă numerotarea pentru a transforma o condiție de interferență în alta. Numărul de intervale este cu unul mai mic decât numărul maximelor consecutive între care se măsoară o distanță. La o lamelă introdusă în mediu, drumul optic suplimentar este (n_lamelă − n_mediu)e.

Fotoni și fotoemisie: h: constanta lui Planck; W_e: lucrul de extracție; K_max: energia cinetică maximă; U_s: modulul pozitiv al tensiunii de stopare; e > 0: modulul sarcinii electronului; λ_pr și ν_pr: pragurile fotoelectrice. Se folosește modelul monofotonic, în regim nerelativist. Randamentul cuantic η_q este raport de numere de particule, nu randament energetic.

Constante și conversii: folosește valorile precizate în fiecare enunț. În aplicațiile cu energie în eV și lungime în nm se indică hc ≈ 1240 eV·nm. Alte aplicații indică h ≈ 6,63 × 10⁻³⁴ J·s, c = 3 × 10⁸ m/s, e ≈ 1,6 × 10⁻¹⁹ C și m_e ≈ 9,1 × 10⁻³¹ kg. La determinarea experimentală a lui h, folosește măsurătorile din problemă. Nu combina aproximații diferite într-un singur calcul.

Numitorii sunt nenuli. Dacă se împarte la ordinul k, atunci k ≠ 0. Păstrează semnele și convertește lungimile în unități compatibile. Rotunjește numai rezultatul final, la cel mult trei zecimale. Poți folosi hârtie și un calculator simplu. Geometria suplimentară necesară aplicațiilor de sinteză este precizată în enunț sau explicație.
