Notații și convenții

Optică geometrică: unghiurile de incidență, reflexie și refracție se măsoară față de normală. c este viteza luminii în vid, n indicele absolut, v viteza de fază în mediu. Se folosesc lentile subțiri și raze paraxiale.

Lentile: p > 0 pentru obiect real și p < 0 pentru obiect virtual; q > 0 pentru imagine reală și q < 0 pentru imagine virtuală; f > 0 pentru lentilă convergentă și f < 0 pentru divergentă. Se folosește 1/f = 1/p + 1/q și β = −q/p. În formula constructorului, razele de curbură au semne carteziene, precizate în întrebare. C este convergența, măsurată în m⁻¹.

Interferență: δ este diferența de drum optic; formulele cu δ optic folosesc λ_vac, lungimea de undă în vid. În montajul Young în aer, n ≈ 1 și se folosește λ ≈ λ_vac. d este distanța dintre fante, D distanța până la ecran, i interfranja. Sursele sunt coerente, inițial în fază, dacă nu se precizează altfel. I din formula interferenței este iradianță (W/m²).

Efect fotoelectric: ν este frecvența, h constanta lui Planck, W_e lucrul de extracție, K_max energia cinetică maximă, e modulul sarcinii electronului. U_s este modulul pozitiv al tensiunii de stopare. λ_pr și ν_pr sunt pragurile fotoelectrice. Se folosesc modelul monofotonic și regimul nerelativist de liceu.

Numitorii sunt nenuli; relațiile se cer în forma lor generală. Ordinele k sunt întregi, iar formulele care împart la k se aplică pentru k ≠ 0. Argumentele logice și semnele trebuie interpretate în contextul fiecărei întrebări.
