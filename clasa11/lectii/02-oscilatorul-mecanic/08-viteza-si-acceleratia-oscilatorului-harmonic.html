Viteza și accelerația oscilatorului armonic

Poziție • Viteză • Accelerație • Fază • Reprezentări grafice

Prof. Dănuț Andronie e-Mail: danutmg@gmail.com

Unde se mișcă cel mai repede oscilatorul?

În Lecția 7 am obținut:

\[ x(t)=A\cos(\omega t+\varphi_0). \]

Această relație ne spune unde se află corpul.

Acum vrem să aflăm:

  • cât de repede se deplasează;
  • în ce sens se deplasează;
  • unde accelerația este maximă;
  • de ce accelerația este orientată mereu spre echilibru.

Metoda folosită

Nu vom deriva funcția \(x(t)\).

Vom folosi din nou modelul geometric al mișcării circulare uniforme.

\[ \boxed{ \text{viteza tangențială pe cerc} \longrightarrow \text{proiecție} \longrightarrow v_x } \] \[ \boxed{ \text{accelerația centripetă} \longrightarrow \text{proiecție} \longrightarrow a_x } \]

La finalul lecției vei putea:

  • să scrii relația vitezei oscilatorului armonic;
  • să determini viteza maximă;
  • să scrii relația accelerației;
  • să determini accelerația maximă;
  • să explici de ce \(a=-\omega^2x\);
  • să identifici sensul vitezei și accelerației;
  • să compari graficele \(x(t)\), \(v(t)\) și \(a(t)\);
  • să rezolvi aplicații numerice.
Pagina 1 din 9
1. Viteza oscilatorului armonic

Pornim de la cercul de referință

Punctul \(P\) se deplasează uniform pe un cerc de rază \(A\).

Proiecția sa \(M\) pe axa orizontală efectuează oscilația armonică.

Modulul vitezei punctului pe cerc

În mișcarea circulară uniformă:

\[ v_P=\omega A. \]

Proiecția pe axa oscilației

Componenta orizontală a vitezei tangențiale este:

\[ \boxed{ v= -\omega A\sin\varphi } \]

iar:

\[ \varphi= \omega t+\varphi_0. \]

Prin urmare:

\[ \boxed{ v(t)= -\omega A \sin(\omega t+\varphi_0) } \]

Viteza maximă

Valoarea maximă a lui \(|\sin\varphi|\) este 1.

\[ \boxed{ v_{\max}=\omega A } \]

Unde este viteza maximă?

În poziția de echilibru:

\[ x=0. \]

Atunci:

\[ |\sin\varphi|=1 \] și: \[ \boxed{ |v|=v_{\max} }. \]

Unde este viteza zero?

În pozițiile extreme:

\[ x=\pm A, \] avem: \[ \boxed{ v=0 }. \]

Nu confunda viteza cu poziția

În extrema mișcării corpul este cel mai departe de echilibru, dar viteza sa este momentan zero.

În echilibru, elongația este zero, dar modulul vitezei este maxim.

Unde este maxim modulul vitezei?

Pagina 2 din 9
2. Accelerația oscilatorului armonic

Din nou folosim cercul de referință

Punctul aflat în mișcare circulară uniformă are accelerație centripetă.

\[ a_c= \omega^2 A. \]

Această accelerație este orientată permanent spre centrul cercului.

Proiecția accelerației

Componenta accelerației pe axa oscilației este:

\[ a= -\omega^2A\cos\varphi. \]

Dar:

\[ x= A\cos\varphi. \]

Prin urmare:

\[ \boxed{ a=-\omega^2x } \]

Semnificația fizică

Accelerația are întotdeauna sens opus elongației.

\[ \boxed{ \vec a \text{ este orientată spre poziția de echilibru} } \]

Accelerația maximă

Pentru:

\[ |x|=A, \] rezultă: \[ |a|= \omega^2A. \]
\[ \boxed{ a_{\max}= \omega^2A } \]

Unde este accelerația zero?

În poziția de echilibru:

\[ x=0, \] deci: \[ \boxed{ a=0 }. \]

Echilibru nu înseamnă repaus

Când corpul trece prin \(x=0\), accelerația este momentan zero, dar viteza are modul maxim.

De aceea corpul trece mai departe prin poziția de echilibru.

Corpul se află la \(x>0\). Care este semnul accelerației?

Un ciclu complet

\(3\pi/2\) \(0\) \(+v_{\max}\) \(0\) trece spre dreapta

În extreme

\[ |x|=A \] \[ v=0 \] \[ |a|=a_{\max} \]

În echilibru

\[ x=0 \] \[ |v|=v_{\max} \] \[ a=0 \]
\[ \boxed{ v_{\max}=\omega A } \] \[ \boxed{ a_{\max}=\omega^2A } \]

Cauză–efect

Cu cât corpul este mai departe de echilibru:

\[ |x|\uparrow \quad\Rightarrow\quad |a|\uparrow. \]

Apropiindu-se de echilibru:

\[ |x|\downarrow \quad\Rightarrow\quad |a|\downarrow, \] în timp ce modulul vitezei crește.

Accelerația și viteza pot avea sensuri diferite

Corpul se poate deplasa spre dreapta, dar accelerația sa poate fi spre stânga.

În acest caz viteza scade.

Dacă viteza și accelerația au același sens, modulul vitezei crește.

Exemplu conceptual

Corpul se află la dreapta echilibrului:

\[ x>0. \]

Se deplasează spre dreapta:

\[ v>0. \]

Dar:

\[ a=-\omega^2x<0. \]

Accelerația este opusă vitezei, deci corpul încetinește în timp ce se apropie de extrema pozitivă.

Corpul trece prin echilibru. Care afirmație este corectă?

5. Aplicații

Exemplu complet

Oscilația este descrisă prin:

\[ x(t)= 0{,}05\cos(\pi t)\ \mathrm m. \]

Identificăm:

\[ A=0{,}05\,\mathrm m, \] \[ \omega=\pi\,\mathrm{rad/s}, \] \[ \varphi_0=0. \]

Viteza

\[ v(t)= -\omega A\sin(\omega t+\varphi_0). \]

Deci:

\[ \boxed{ v(t)= -0{,}05\pi\sin(\pi t) \ \mathrm{m/s} }. \]

Accelerația

\[ a(t)= -\omega^2x(t). \]

Deci:

\[ \boxed{ a(t)= -0{,}05\pi^2\cos(\pi t) \ \mathrm{m/s^2} }. \]

La \(t=0\)

\[ x=+0{,}05\,\mathrm m, \] \[ v=0, \] \[ a= -0{,}05\pi^2 \approx -0{,}493\,\mathrm{m/s^2}. \]

La \(t=0{,}5\,\mathrm s\)

Faza este:

\[ \varphi= \pi\cdot0{,}5 = \frac{\pi}{2}. \]

Prin urmare:

\[ x=0, \] \[ v= -0{,}05\pi \approx -0{,}157\,\mathrm{m/s}, \] \[ a=0. \]

La \(t=1\,\mathrm s\)

\[ x=-0{,}05\,\mathrm m, \] \[ v=0, \] \[ a= +0{,}05\pi^2 \approx +0{,}493\,\mathrm{m/s^2}. \]

Observație

Accelerația și elongația au semne opuse:

\[ \boxed{ a=-\omega^2x }. \]

6. Relațiile de fază

Trei mărimi, aceeași perioadă

\[ x= A\cos\varphi \] \[ v= -\omega A\sin\varphi \] \[ a= -\omega^2A\cos\varphi \]

Elongația și accelerația

Comparăm:

\[ x= A\cos\varphi \] și: \[ a= -\omega^2A\cos\varphi. \]

Rezultă:

\[ \boxed{ a=-\omega^2x } \]

Când elongația este pozitivă, accelerația este negativă.

Când elongația este negativă, accelerația este pozitivă.

Elongația și accelerația sunt în opoziție de fază

Maximele pozitive ale uneia corespund maximelor negative ale celeilalte.

Diferența lor de fază este:

\[ \boxed{ \Delta\varphi=\pi }. \]

Elongația și viteza

Putem scrie:

\[ -\sin\varphi = \cos \left( \varphi+\frac{\pi}{2} \right). \]

Astfel:

\[ v= \omega A \cos \left( \varphi+\frac{\pi}{2} \right). \]

Viteza și elongația sunt decalate cu:

\[ \boxed{ \frac{\pi}{2} }. \]

De aceea, atunci când elongația este extremă, viteza este zero, iar când elongația este zero, modulul vitezei este maxim.

Toate au aceeași perioadă

Pentru oscilația armonică ideală:

\[ \boxed{ T_x=T_v=T_a=T }. \]
Mărime Valoare maximă Unde apare?
\(|x|\) \(A\) în extreme
\(|v|\) \(\omega A\) în echilibru
\(|a|\) \(\omega^2A\) în extreme

Ce se întâmplă dacă perioada se înjumătățește?

Deoarece:

\[ \omega= \frac{2\pi}{T}, \]

dacă:

\[ T'= \frac{T}{2}, \] atunci: \[ \omega'=2\omega. \]

Pentru aceeași amplitudine:

\[ v'_{\max} = 2v_{\max}, \] iar: \[ a'_{\max} = 4a_{\max}. \]

Dacă perioada se înjumătățește, iar amplitudinea rămâne constantă, accelerația maximă:

Viteza:

\[ \boxed{ a= -\omega^2A \cos(\omega t+\varphi_0) } \] \[ \boxed{ a=-\omega^2x } \]
\[ \boxed{ v_{\max}=\omega A } \] \[ \boxed{ a_{\max}=\omega^2A } \]

Accelerația oscilatorului armonic este orientată permanent spre poziția de echilibru.

Cu cât corpul este mai departe de echilibru, cu atât modulul accelerației este mai mare.

Cum am obținut relațiile?

Fără calcul diferențial:

\[ \boxed{ \text{MCU} \rightarrow \text{proiecția vitezei tangențiale} \rightarrow v } \] \[ \boxed{ \text{MCU} \rightarrow \text{proiecția accelerației centripete} \rightarrow a } \]

Pasul următor: energia

Acum știm cum variază:

\[ x,\qquad v,\qquad a. \]

energia cinetică, energia potențială elastică și energia mecanică.
