Compunerea oscilațiilor paralele

Superpoziție • Diferență de fază • Fazori • Oscilație rezultantă • Bătăi

Prof. Dănuț Andronie e-Mail: danutmg@gmail.com

Ce se întâmplă când două oscilații acționează simultan?

Un punct material poate fi solicitat simultan de mai multe cauze care tind să îl pună în oscilație.

De exemplu, o structură poate fi solicitată simultan de vibrații produse de trafic și de alte surse mecanice.

Situația studiată

Considerăm două oscilații care se desfășoară:

  • pe aceeași direcție;
  • în jurul aceleiași poziții de echilibru;
  • simultan.

Acestea sunt oscilații paralele.

\[ \boxed{ x(t)=x_1(t)+x_2(t) } \]

Relația exprimă principiul superpoziției pentru un sistem liniar.

Oscilația 1

\[ x_1= A_1 \cos(\omega t+\varphi_1) \]

Oscilația 2

\[ x_2= A_2 \cos(\omega t+\varphi_2) \]

La finalul lecției vei putea:

  • să explici principiul superpoziției;
  • să compui două oscilații armonice paralele de aceeași frecvență;
  • să folosești reprezentarea fazorială;
  • să calculezi amplitudinea oscilației rezultante;
  • să explici rolul diferenței de fază;
  • să recunoști oscilațiile în fază, în opoziție de fază și în cvadratură;
  • să interpretezi fenomenul de bătăi;
  • să rezolvi aplicații numerice.

1. Principiul superpoziției

Elongațiile se adună algebric

Considerăm două oscilații produse pe aceeași axă.

Dacă la un anumit moment:

\[ x_1=+3\,\mathrm{cm} \] și: \[ x_2=+2\,\mathrm{cm}, \] atunci: \[ x=x_1+x_2=+5\,\mathrm{cm}. \]

Dar dacă sensurile sunt opuse?

Dacă:

\[ x_1=+3\,\mathrm{cm}, \qquad x_2=-2\,\mathrm{cm}, \] atunci: \[ x=+1\,\mathrm{cm}. \]

Două oscilații armonice

Pentru aceeași pulsație:

\[ x_1= A_1\cos(\omega t+\varphi_1) \] și: \[ x_2= A_2\cos(\omega t+\varphi_2). \]
\[ \boxed{ x= A_1\cos(\omega t+\varphi_1) + A_2\cos(\omega t+\varphi_2) } \]

Pentru două oscilații de aceeași frecvență, rezultanta este tot o oscilație armonică de aceeași frecvență:

\[ \boxed{ x= A\cos(\omega t+\varphi) } \]

Ce se poate schimba?

Pulsația rămâne \(\omega\), dar amplitudinea \(A\) și faza inițială \(\varphi\) depind de cele două oscilații componente.

La un moment dat: \(x_1=4\,\mathrm{cm}\) și \(x_2=-3\,\mathrm{cm}\). Care este elongația rezultantă?

2. Reprezentarea fazorială

Un vector pentru fiecare oscilație

Din Lecția 7 știm că o oscilație armonică poate fi asociată proiecției unei mișcări circulare uniforme.

Putem reprezenta oscilația:

\[ x=A\cos(\omega t+\varphi_0) \] printr-un vector rotitor numit fazor.

Fazorul

  • are modulul egal cu amplitudinea \(A\);
  • formează un unghi egal cu faza oscilației;
  • se rotește cu viteza unghiulară \(\omega\).

Fazorii celor două oscilații au aceeași viteză unghiulară \(\omega\), deci unghiul dintre ei rămâne constant:

\[ \boxed{ \Delta\varphi= \varphi_2-\varphi_1 } \]

Fazorul rezultant se obține prin adunare vectorială.

Aplicând teorema cosinusului:

\[ \boxed{ A= \sqrt{ A_1^2+ A_2^2+ 2A_1A_2 \cos\Delta\varphi } } \]

Concluzie importantă

Amplitudinea rezultantă nu depinde numai de \(A_1\) și \(A_2\).

Ea depinde și de diferența de fază dintre oscilații.

Faza oscilației rezultante

Dacă folosim forma cu cosinus:

\[ x=A\cos(\omega t+\varphi), \] atunci: \[ \tan\varphi= \frac{ A_1\sin\varphi_1+ A_2\sin\varphi_2 }{ A_1\cos\varphi_1+ A_2\cos\varphi_2 }. \]

Pentru problemele obișnuite

Determinarea amplitudinii este de multe ori suficientă.

Dacă trebuie determinată și faza, trebuie ales corect cadranul în care se află fazorul rezultant.

De ce diferența de fază rămâne constantă dacă cele două oscilații au aceeași pulsație?

4. Cazuri particulare

1. Oscilații în fază

Dacă:

\[ \Delta\varphi=0 \quad \text{sau, mai general, } 2k\pi, \] atunci: \[ \cos\Delta\varphi=1. \]
\[ \boxed{ A=A_1+A_2 } \]

Amplitudinea rezultantă este maximă.

2. Oscilații în opoziție de fază

Dacă:

\[ \Delta\varphi=\pi \quad \text{sau, mai general, } (2k+1)\pi, \] atunci: \[ \cos\Delta\varphi=-1. \]
\[ \boxed{ A= |A_1-A_2| } \]

Anulare completă

Dacă:

\[ A_1=A_2 \] și: \[ \Delta\varphi=\pi, \] atunci: \[ \boxed{ A=0 }. \]

Cele două oscilații se anulează reciproc.

3. Oscilații în cvadratură

Pentru:

\[ \Delta\varphi= \frac{\pi}{2} \] sau un multiplu impar de \(\pi/2\): \[ \cos\Delta\varphi=0. \]
\[ \boxed{ A= \sqrt{ A_1^2+A_2^2 } } \]
Diferența de fază Situație Amplitudinea rezultantă
\(0\) în fază \(A_1+A_2\)
\(\pi/2\) cvadratură \(\sqrt{A_1^2+A_2^2}\)
\(\pi\) opoziție de fază \(|A_1-A_2|\)

Problema 1

Două oscilații de aceeași frecvență au:

\[ A_1=4\,\mathrm{cm}, \qquad A_2=3\,\mathrm{cm}, \] și sunt în fază.

\[ A=A_1+A_2. \] \[ \boxed{ A=7\,\mathrm{cm} }. \]

Introdu amplitudinea rezultantă.

Două oscilații au:

\[ A_1=5\,\mathrm{cm}, \qquad A_2=3\,\mathrm{cm}, \] și: \[ \Delta\varphi=\pi. \]

Atunci:

\[ A= |5-3|. \] \[ \boxed{ A=2\,\mathrm{cm} }. \]

5. Aplicații generale

Problema 1 – amplitudinea rezultantă

Se compun:

\[ x_1= 4\cos(10t)\ \mathrm{cm} \] și: \[ x_2= 2\cos \left( 10t+\frac{\pi}{3} \right) \mathrm{cm}. \]

Identificăm:

\[ A_1=4\,\mathrm{cm}, \] \[ A_2=2\,\mathrm{cm}, \] \[ \Delta\varphi= \frac{\pi}{3}. \]

Amplitudinea:

\[ A^2= 4^2+ 2^2+ 2\cdot4\cdot2 \cos\frac{\pi}{3}. \] \[ A^2= 16+4+8. \] \[ A^2=28. \] \[ \boxed{ A= 2\sqrt7 \approx 5{,}29\,\mathrm{cm} }. \]

Introdu amplitudinea rezultantă.

cm

Faza rezultantei

În problema de mai sus:

\[ \varphi_1=0, \qquad \varphi_2= \frac{\pi}{3}. \]

Atunci:

\[ \tan\varphi= \frac{ A_2\sin(\pi/3) }{ A_1+ A_2\cos(\pi/3) }. \] \[ \tan\varphi= \frac{ 2\cdot\sqrt3/2 }{ 4+2\cdot1/2 }. \] \[ \tan\varphi= \frac{\sqrt3}{5}. \]

Numeric:

\[ \varphi\approx0{,}333\,\mathrm{rad}. \]
\[ \boxed{ x\approx 5{,}29 \cos(10t+0{,}333) \ \mathrm{cm} } \]

Verificare rapidă

Amplitudinea trebuie să satisfacă:

\[ |A_1-A_2| \le A \le A_1+A_2. \]

Pentru valorile problemei:

\[ 2 \le 5{,}29 \le 6. \]

Rezultatul este fizic posibil.

6. Extensie – fenomenul bătăilor

Frecvențe apropiate, dar nu egale

Ce se întâmplă dacă cele două oscilații paralele nu au exact aceeași frecvență?

Dacă frecvențele sunt apropiate, rezultanta prezintă alternanțe periodice de amplitudine mare și mică.

Fenomenul se numește bătăi.

Considerăm, pentru simplitate, amplitudini egale:

\[ x_1= A\cos(2\pi f_1t) \] și: \[ x_2= A\cos(2\pi f_2t). \]

Prin adunare:

\[ x= 2A \cos \left[ \pi(f_1-f_2)t \right] \cos \left[ 2\pi \frac{f_1+f_2}{2} t \right]. \]

Oscilația rapidă are aproximativ frecvența medie:

\[ \boxed{ f_{\mathrm{med}} = \frac{f_1+f_2}{2} }. \]

Amplitudinea aparentă variază lent:

\[ A_{\mathrm{env}} = 2A \left| \cos \left[ \pi(f_1-f_2)t \right] \right|. \]

Frecvența bătăilor

\[ \boxed{ f_b= |f_1-f_2| } \] și: \[ \boxed{ T_b= \frac{1}{ |f_1-f_2| } }. \]

Frecvența medie

4,25 Hz

Frecvența bătăilor

0,50 Hz

Perioada bătăilor

2,00 s

Pentru 4,00 Hz și 4,50 Hz apare o bătaie la fiecare 2,00 s.

Exemplu

Două diapazoane produc:

\[ f_1=440\,\mathrm{Hz}, \qquad f_2=443\,\mathrm{Hz}. \]

Frecvența bătăilor este:

\[ f_b= |443-440|. \] \[ \boxed{ f_b=3\,\mathrm{Hz} }. \]

Intensitatea sunetului crește și scade de aproximativ 3 ori pe secundă.

Două surse au frecvențele 50 Hz și 53 Hz. Determină frecvența bătăilor.

Sinteză

Compunerea oscilațiilor paralele

Principiul superpoziției:

\[ \boxed{ x=x_1+x_2 } \]

Pentru:

\[ x_1= A_1\cos(\omega t+\varphi_1) \] și: \[ x_2= A_2\cos(\omega t+\varphi_2), \] rezultanta este: \[ \boxed{ x= A\cos(\omega t+\varphi) }. \]
\[ \boxed{ A= \sqrt{ A_1^2+ A_2^2+ 2A_1A_2 \cos\Delta\varphi } } \] \[ \boxed{ \Delta\varphi= \varphi_2-\varphi_1 } \]
Diferența de fază Tip Amplitudinea
\(0\) în fază \(A_1+A_2\)
\(\pi/2\) cvadratură \(\sqrt{A_1^2+A_2^2}\)
\(\pi\) opoziție de fază \(|A_1-A_2|\)

Limitele amplitudinii rezultante

\[ \boxed{ |A_1-A_2| \le A \le A_1+A_2 } \]

Diferența de fază stabilește unde se află amplitudinea rezultantă între aceste două limite.

Pentru două frecvențe apropiate:

\[ \boxed{ f_b= |f_1-f_2| } \] \[ \boxed{ T_b= \frac{1}{f_b} } \]

Nu confunda două situații

Aceeași frecvență: rezultanta este o oscilație armonică de aceeași frecvență și amplitudine constantă.

Frecvențe apropiate, dar diferite: amplitudinea aparentă a rezultantei variază periodic și apar bătăile.

Pasul următor

În această lecție oscilațiile au avut aceeași direcție.
