Energia oscilatorului armonic

Energie cinetică • Energie potențială elastică • Energie mecanică • Transformări energetice

Prof. Dănuț Andronie e-Mail: danutmg@gmail.com

Unde este „stocată” energia oscilatorului?

Când masa se află într-o extremă, ea se oprește pentru o clipă.

În acel moment:

\[ v=0. \]

Totuși, corpul pornește din nou spre echilibru.

De unde provine energia mișcării?

În extreme

\[ v=0 \]

energia cinetică este zero

resortul este cel mai deformat

În echilibru

\[ x=0 \]

deformarea față de echilibru este nulă

modulul vitezei este maxim

\[ \boxed{ E_p \rightleftarrows E_c } \]

În timpul oscilației ideale, energia se transformă continuu între forma potențială elastică și forma cinetică.

Întrebarea centrală

Dacă \(E_c\) și \(E_p\) se modifică permanent, ce se întâmplă cu energia mecanică totală?

La finalul lecției vei putea:

  • să calculezi energia potențială elastică;
  • să calculezi energia cinetică;
  • să explici transformarea dintre \(E_c\) și \(E_p\);
  • să demonstrezi algebric conservarea energiei mecanice;
  • să calculezi energia mecanică totală;
  • să identifici pozițiile în care \(E_c\) și \(E_p\) sunt maxime;
  • să interpretezi graficele energetice;
  • să compari oscilatorul ideal cu unul amortizat.

1. Energia potențială elastică

Energia resortului deformat

Pentru un resort ideal:

\[ F_e=-kx. \]

Modulul forței elastice crește liniar cu deformarea:

\[ F=k|x|. \]

Cum obținem energia potențială?

Pentru a deplasa lent corpul de la \(x=0\) la \(x\), forța aplicată crește de la \(0\) la \(kx\).

Pe graficul \(F(x)\), lucrul mecanic corespunde ariei triunghiului:

Aria este:

\[ E_p= \frac{1}{2} \cdot x \cdot kx. \]
\[ \boxed{ E_p= \frac{1}{2}kx^2 } \]

Ce observăm?

Energia potențială elastică depinde de pătratul elongației.

De aceea:

\[ E_p(+x)=E_p(-x). \]

Valoarea maximă

În extreme:

\[ |x|=A. \]

Prin urmare:

\[ \boxed{ E_{p,\max} = \frac{1}{2}kA^2 } \]

În echilibru

\[ x=0 \] și: \[ \boxed{ E_p=0 }. \]

Atenție la reper

În această lecție considerăm energia potențială elastică nulă pentru poziția de echilibru a oscilației.

Un resort are \(k=50\,\mathrm{N/m}\). Corpul este deplasat cu \(x=0{,}10\,\mathrm m\). Calculează energia potențială elastică.

2. Energia cinetică

Energia asociată mișcării

Energia cinetică este:

\[ \boxed{ E_c= \frac{1}{2}mv^2 } \]

Din Lecția 8:

\[ v= -\omega A\sin\varphi. \]

Ridicând la pătrat:

\[ v^2= \omega^2A^2\sin^2\varphi. \]

Legătura dintre \(k\), \(m\) și \(\omega\)

Pentru sistemul masă–resort ideal:

\[ F_e=-kx. \]

Din principiul fundamental al dinamicii:

\[ F=ma. \]

Iar pentru oscilația armonică:

\[ a=-\omega^2x. \]

Rezultă:

\[ -kx= -m\omega^2x. \]
\[ \boxed{ k=m\omega^2 } \]

sau:

\[ \boxed{ \omega= \sqrt{\frac{k}{m}} } \]

Energia cinetică în funcție de fază

\[ E_c= \frac{1}{2} m\omega^2A^2 \sin^2\varphi. \]

Deoarece:

\[ m\omega^2=k, \] obținem: \[ \boxed{ E_c= \frac{1}{2} kA^2 \sin^2\varphi }. \]

Energia cinetică în funcție de poziție

Avem:

\[ x=A\cos\varphi. \]

Din:

\[ \sin^2\varphi+ \cos^2\varphi=1, \] rezultă: \[ \sin^2\varphi= 1-\frac{x^2}{A^2}. \]

Prin urmare:

\[ \boxed{ E_c= \frac{1}{2} k(A^2-x^2) } \]

În extreme

\[ x=\pm A \] \[ v=0 \] \[ \boxed{ E_c=0 } \]

În echilibru

\[ x=0 \] \[ |v|=v_{\max} \] \[ \boxed{ E_c=E_{c,\max} } \]
\[ \boxed{ E_{c,\max} = \frac{1}{2}kA^2 } \]

În ce poziție este maximă energia cinetică?

3. Energia mecanică

Adunăm cele două forme de energie

Energia mecanică este:

\[ E_m= E_c+E_p. \]

Folosim:

\[ E_c= \frac{1}{2} k(A^2-x^2) \] și: \[ E_p= \frac{1}{2}kx^2. \]

Atunci:

\[ E_m= \frac{1}{2}k(A^2-x^2) + \frac{1}{2}kx^2. \]

Termenii cu \(x^2\) se reduc:

\[ \boxed{ E_m= \frac{1}{2}kA^2 } \]

Pentru oscilatorul armonic ideal

\[ \boxed{ E_m= E_c+E_p= \text{constantă} } \]

Energia nu dispare și nu apare din nimic.

Ea se transformă continuu între forma cinetică și forma potențială elastică.

Un ciclu energetic

Poziție \(E_c\) \(E_p\) \(E_m\)
\(x=+A\) 0 \(E_m\) \(E_m\)
\(x=0\) \(E_m\) 0 \(E_m\)
\(x=-A\) 0 \(E_m\) \(E_m\)
\(x=0\) \(E_m\) 0 \(E_m\)
\[ \boxed{ +A \rightarrow 0 \rightarrow -A \rightarrow 0 \rightarrow +A } \] \[ E_p \rightarrow E_c \rightarrow E_p \rightarrow E_c \rightarrow E_p \]

Când sunt egale \(E_c\) și \(E_p\)?

Dacă:

\[ E_c=E_p, \] atunci fiecare reprezintă jumătate din energia mecanică: \[ E_p= \frac{E_m}{2}. \]

Dar:

\[ \frac{1}{2}kx^2= \frac{1}{2} \left( \frac{1}{2}kA^2 \right). \]

Rezultă:

\[ x^2= \frac{A^2}{2}. \]
\[ \boxed{ |x|= \frac{A}{\sqrt2} } \]

Un oscilator are \(k=100\,\mathrm{N/m}\) și \(A=0{,}10\,\mathrm m\). Calculează energia mecanică.

5. Aplicații

Problema 1 – energia totală

Un corp oscilează pe un resort cu:

\[ k=50\,\mathrm{N/m} \] și: \[ A=10\,\mathrm{cm} = 0{,}10\,\mathrm m. \]

Energia mecanică este:

\[ E_m= \frac12kA^2. \] \[ E_m= \frac12 \cdot50 \cdot (0{,}10)^2. \] \[ \boxed{ E_m=0{,}25\,\mathrm J }. \]

Problema 2 – energia într-o poziție intermediară

Pentru același oscilator, corpul se află la:

\[ x=6\,\mathrm{cm} = 0{,}06\,\mathrm m. \]

Energia potențială:

\[ E_p= \frac12kx^2 = \frac12 \cdot50 \cdot (0{,}06)^2. \] \[ \boxed{ E_p=0{,}09\,\mathrm J }. \]

Din conservarea energiei:

\[ E_c= E_m-E_p. \] \[ E_c= 0{,}25-0{,}09. \] \[ \boxed{ E_c=0{,}16\,\mathrm J }. \]

Metodă eficientă

Nu este întotdeauna necesar să calculăm mai întâi viteza.

Dacă știm \(A\), \(k\) și \(x\):

\[ \boxed{ E_m= \frac12kA^2 } \] \[ \boxed{ E_p= \frac12kx^2 } \] \[ \boxed{ E_c= E_m-E_p }. \]

Raporturi energetice

Împărțim energia potențială la energia totală:

\[ \frac{E_p}{E_m} = \frac{x^2}{A^2}. \]
\[ \boxed{ \frac{E_p}{E_m} = \left( \frac{x}{A} \right)^2 } \] \[ \boxed{ \frac{E_c}{E_m} = 1- \left( \frac{x}{A} \right)^2 } \]

Exemplu rapid

Dacă:

\[ |x|=\frac{A}{2}, \] atunci: \[ \frac{E_p}{E_m} = \frac14. \]

Deci:

\[ \boxed{ E_p=25\%\,E_m } \] și: \[ \boxed{ E_c=75\%\,E_m }. \]

Corpul se află la \(|x|=A/2\). Ce procent din energia mecanică este energie cinetică?

6. Energia și faza oscilației

Cum variază energiile în timp?

Pentru:

\[ x= A\cos\varphi, \] energia potențială este: \[ E_p= \frac12kA^2 \cos^2\varphi. \]

Dar:

\[ E_m= \frac12kA^2. \]

Deci:

\[ \boxed{ E_p= E_m\cos^2\varphi } \] \[ \boxed{ E_c= E_m\sin^2\varphi } \]

Energia mecanică rămâne constantă

\[ E_c+E_p= E_m \left( \sin^2\varphi+ \cos^2\varphi \right). \]

Deoarece:

\[ \sin^2\varphi+ \cos^2\varphi=1, \] rezultă: \[ \boxed{ E_c+E_p=E_m }. \]

Un rezultat interesant

Mișcarea corpului are perioada \(T\).

Dar funcțiile:

\[ \sin^2\varphi \quad\text{și}\quad \cos^2\varphi \] se repetă după o variație de fază de \(\pi\), nu de \(2\pi\).

Prin urmare, variația fiecărei forme de energie se repetă după:

\[ \boxed{ T_E= \frac{T}{2} }. \]

De ce?

Corpul are energie potențială maximă atât la:

\[ x=+A, \] cât și la: \[ x=-A. \]

Aceste poziții sunt separate prin:

\[ \frac{T}{2}. \]
Moment Poziție \(E_p\) \(E_c\)
\(0\) \(+A\) \(E_m\) 0
\(T/4\) 0 0 \(E_m\)
\(T/2\) \(-A\) \(E_m\) 0
\(3T/4\) 0 0 \(E_m\)
\(T\) \(+A\) \(E_m\) 0

Ce se întâmplă într-un oscilator amortizat?

În Lecțiile 5 și 6 am observat că amplitudinea scade:

\[ A\downarrow. \]

Deoarece:

\[ E_m= \frac12kA^2, \] rezultă: \[ \boxed{ A\downarrow \Rightarrow E_m\downarrow }. \]

Conservarea energiei mecanice

Relația:

\[ E_m= \text{constantă} \]

este valabilă pentru oscilatorul ideal neamortizat.

Pentru un oscilator real amortizat, energia mecanică a oscilatorului scade deoarece energia este transferată către mediul exterior.

Sinteză

Energia oscilatorului armonic

Energia potențială elastică:

\[ \boxed{ E_p= \frac12kx^2 } \]

Energia cinetică:

\[ \boxed{ E_c= \frac12mv^2 } \]

Pentru oscilatorul armonic:

\[ \boxed{ E_c= \frac12k(A^2-x^2) } \]

Energia mecanică:

\[ \boxed{ E_m= E_c+E_p= \frac12kA^2 } \]
Poziție Viteză \(E_c\) \(E_p\)
\(x=\pm A\) 0 0 maximă
\(x=0\) maximă în modul maximă 0
\(|x|=A/\sqrt2\) intermediară \(E_m/2\) \(E_m/2\)
\[ \boxed{ E_p= E_m\cos^2\varphi } \] \[ \boxed{ E_c= E_m\sin^2\varphi } \]

Ideea esențială

\[ \boxed{ E_p \rightleftarrows E_c } \]

În oscilatorul armonic ideal, cele două forme de energie se transformă continuu una în cealaltă, în timp ce:

\[ \boxed{ E_m=\text{constantă} }. \]

Ideal versus real

Pentru modelul ideal neamortizat:

\[ E_m= \text{constantă}. \]

Pentru un oscilator amortizat:

\[ A\downarrow \quad\Rightarrow\quad E_m\downarrow. \]

Energia mecanică nu dispare, ci este transferată către alte forme de energie și către mediul exterior.
