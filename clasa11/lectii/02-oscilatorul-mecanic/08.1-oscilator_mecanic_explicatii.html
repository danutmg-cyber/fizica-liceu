Partea I. Formulele complete, fără derivate

Un corp oscilează când se mișcă repetat de o parte și de alta a unei poziții de echilibru. Elongația este coordonata sa față de echilibru: poate fi pozitivă, negativă sau zero. Amplitudinea A este cea mai mare distanță față de echilibru, deci A > 0.

În modelul ideal, fără frecare, perioada T este durata unei oscilații complete, iar frecvența f arată câte oscilații se efectuează într-o secundă. Pulsația ω arată cât de repede crește faza.

f=1T,ω=2πT=2πf

Unități: x, y și A în metri; T în secunde; f în hertzi; ω în radiani pe secundă. Unghiurile din formule sunt exprimate în radiani.

Faza și faza inițială

θ(t) = ωt + φ₀

φ₀ este faza inițială: unghiul pe care OP îl face cu sensul pozitiv al axei Ox la t = 0. Ea stabilește de unde începe mișcarea. Nu este obligatoriu ca la t = 0 corpul să fie la extremitate.

Pentru același punct P care se rotește în sens trigonometric, formulele complete sunt:

Proiecția pe OxProiecția pe Oy
x(t) = A cos(ωt + φ₀)y(t) = A sin(ωt + φ₀)
vₓ(t) = −ωA sin(ωt + φ₀)vᵧ(t) = ωA cos(ωt + φ₀)
aₓ(t) = −ω²A cos(ωt + φ₀)aᵧ(t) = −ω²A sin(ωt + φ₀)

Componentele vₓ, vᵧ, aₓ și aᵧ au semn: acesta indică sensul pe axă. Modulele vitezelor proiecțiilor sunt |vₓ| și |vᵧ|. Ambele proiecții sunt oscilații armonice, cu aceeași amplitudine și perioadă.

aₓ = −ω²x    și    aᵧ = −ω²y

De reținut: pe Ox pornim de la cosinus, iar pe Oy de la sinus, fiind proiecțiile aceluiași punct P. Relația y = A sin(ωt + φ₀) se poate scrie și y = A cos(ωt + φ₀ − π/2). Dacă folosim cosinusul pentru ambele axe, fazele lor diferă cu π/2.

Cum interpretăm φ₀?

x(0) = A cos φ₀    ·    vₓ(0) = −ωA sin φ₀

y(0) = A sin φ₀    ·    vᵧ(0) = ωA cos φ₀

  • φ₀ = 0: x(0) = A, vₓ(0) = 0; urmează mișcarea spre stânga.
  • φ₀ = π/2: x(0) = 0, vₓ(0) = −ωA; trece prin echilibru spre stânga.
  • φ₀ = π: x(0) = −A, vₓ(0) = 0; urmează mișcarea spre dreapta.

Poziția inițială singură nu stabilește întotdeauna faza; trebuie cunoscut și sensul mișcării. Faze care diferă cu 2π descriu aceeași stare.

Schema interactivă: faza inițială și proiecțiile

Punctul P se rotește uniform în sens trigonometric. Proiecția Q pe Ox oscilează orizontal, iar proiecția R pe Oy oscilează vertical. Modifică faza inițială și timpul independent, apoi urmărește vectorii și componentele lor.

Vectori:
Proiecții:

Albastru: poziție și elongații · Verde: viteză · Roșu: accelerație. Liniile punctate arată construcția proiecțiilor.

OP este vectorul de poziție pe cerc; elongația pe Ox este x, reprezentată de OQ. Pentru Oy, elongația este y, reprezentată de OR. Viteza și accelerația au scări grafice proprii: lungimile lor nu se compară cu raza sau între ele, fiind mărimi cu unități diferite. Animația reprezintă o perioadă în 8 secunde de vizualizare.

Valorile sunt raportate la A, ωA și ω²A. Butonul de revenire păstrează faza inițială aleasă și readuce timpul la zero.

1. Elongația: proiecția razei

La momentul t, raza OP face unghiul θ = ωt + φ₀ cu Ox. Din trigonometrie:

x(t) = A cos θ = A cos(ωt + φ₀)

y(t) = A sin θ = A sin(ωt + φ₀)

În primul cadran, relațiile rezultă din definițiile cosinusului și sinusului în triunghiul dreptunghic. Pe întregul cerc, semnele sunt date de cadran. Proiecțiile se mișcă între −A și +A. Cercul este un model geometric; fiecare proiecție se deplasează pe o dreaptă.

2. Viteza: proiecția vectorului tangent

Într-o rotație, P parcurge 2πA în timpul T. Modulul vitezei pe cerc este constant:

vc=2πAT=ωA

Vectorul viteză este tangent la cerc, perpendicular pe OP, în sensul mișcării. El face unghiul θ + π/2 cu Ox. Viteza unei proiecții este componenta corespunzătoare a vitezei lui P, deoarece deplasările pe acea axă sunt identice pe același interval de timp.

vₓ = ωA cos(θ + π/2) = −ωA sin(ωt + φ₀)

vᵧ = ωA sin(θ + π/2) = ωA cos(ωt + φ₀)

Am folosit cos(θ + π/2) = −sin θ și sin(θ + π/2) = cos θ. Pentru fiecare proiecție, modulul vitezei este maxim la echilibrul propriu, vmax = ωA, și este zero la extremități.

3. Accelerația: proiecția vectorului spre centru

Pe cerc, modulul vitezei rămâne constant, dar direcția sa se schimbă. Accelerația centripetă este orientată spre O. Folosim relația cunoscută pentru mișcarea circulară uniformă:

ac=vc2A=ω2A

aₓ = −ω²A cos(ωt + φ₀) = −ω²x

aᵧ = −ω²A sin(ωt + φ₀) = −ω²y

Accelerația este opusă lui OP, de aceea componentele au semn opus coordonatelor. Fiecare proiecție are accelerația orientată spre poziția sa de echilibru. Modulul acesteia este maxim la extremități, amax = ω²A, și zero la echilibru.

Accelerația nu indică sensul mișcării. Corpul își mărește modulul vitezei când se apropie de echilibru și îl micșorează când se îndepărtează. La extremități, viteza este zero, dar accelerația este nenulă.

4. Exemplu particular: φ₀ = 0, pe Ox

5. Două sisteme fizice cu aceeași lege de oscilație

A. Oscilatorul elastic: corpul legat de resort

Pentru un corp de masă m legat de un resort ideal de constantă elastică k, elongația x se măsoară față de echilibru. Pe orizontală, fără frecare, F = −kx. Din F = maₓ:

ax=−kmx,ω=km,T=2πmk

Regăsim aₓ = −ω²x, deci x(t) = A cos(ωt + φ₀). O masă mai mare duce la o perioadă mai mare, iar un resort mai rigid duce la o perioadă mai mică. Pentru un resort vertical ideal, aceleași relații se aplică elongației măsurate față de noua poziție de echilibru.

B. Oscilatorul gravitațional: pendulul simplu

Modelul este un corp mic de masă m, suspendat de un fir inextensibil, de masă neglijabilă, cu lungimea ℓ. Neglijăm frecarea și rezistența aerului. Unghiul α se măsoară față de verticala poziției de echilibru.

Greutatea are o componentă tangentă la traiectorie, orientată spre echilibru:

Fₜ = −mg sin α

Deplasarea cu semn pe arcul de cerc este s = ℓα, pentru α exprimat în radiani. Componenta tangențială a accelerației este aₜ = Fₜ/m.

Pentru unghiuri mici, sin α ≈ α. De exemplu, pentru amplitudini unghiulare de cel mult aproximativ 10°, aproximația este bună pentru această lecție. Astfel:

at=−gsinα≈−gα=−gℓs

Regăsim forma a = −ω² · elongație. Pendulul efectuează, aproximativ, o oscilație armonică:

ω=gℓ,T=2πℓg

s(t) = As cos(ωt + φ₀)

vₜ(t) = −ωAs sin(ωt + φ₀)

aₜ(t) = −ω²As cos(ωt + φ₀)

α(t) = αmax cos(ωt + φ₀),   As = ℓαmax

Relațiile de mai sus sunt cele ale modelului armonic aproximativ. As este amplitudinea pe arc, în metri, iar αmax este amplitudinea unghiulară, în radiani. Un fir mai lung înseamnă o perioadă mai mare. În acest model, perioada nu depinde de masă și este aproximativ independentă de amplitudine.

Aici aₜ este numai componenta tangențială a accelerației. Pendulul are și o componentă normală, v²/ℓ, spre punctul de suspensie. La trecerea prin echilibru aₜ = 0, dar accelerația totală nu este zero. Cercul pendulului este traiectoria sa reală; cercul din schema de sus este o construcție auxiliară pentru oscilația armonică.

Verifică ce ai înțeles

1. La x = 0, viteza proiecției Q este zero? 2. Dacă x < 0, ce semn are aₓ? 3. Ce schimbă faza inițială? 4. Dacă lungimea pendulului se înmulțește cu 4, ce se întâmplă cu perioada?

Vezi răspunsurile

1. Nu; |vₓ| = ωA. 2. aₓ > 0. 3. Starea de la t = 0, fără a modifica amplitudinea sau perioada. 4. Perioada se dublează, în aproximația oscilațiilor mici.

Partea a II-a. Pentru mai târziu: limite și derivate

Această parte presupune că ai studiat limitele, limita sin u / u când u → 0 și derivarea funcțiilor compuse. Partea I poate fi înțeleasă independent de ea. Păstrăm faza inițială în toate formulele.

A. Viteza instantanee ca limită

Viteza medie pe Ox este variația coordonatei împărțită la intervalul de timp. Viteza instantanee este limita acestui raport:

vx(t)=limΔt→0x(t+Δt)−x(t)Δt=x′(t)

Punem θ = ωt + φ₀ și h = ωΔt. Folosim cos(θ + h) − cos θ = −2 sin(θ + h/2) sin(h/2). Raportul devine:

x(t+Δt)−x(t)Δt=−Aωsin(θ+h2)sin(h/2)h/2

Când Δt → 0, h → 0, sin(h/2)/(h/2) → 1 și sin(θ + h/2) → sin θ. Rezultă vₓ(t) = −ωA sin(ωt + φ₀). Limita trigonometrică folosită este valabilă pentru unghiuri în radiani.

B. Accelerația instantanee ca limită

Accelerația instantanee este limita accelerației medii:

ax(t)=limΔt→0vx(t+Δt)−vx(t)Δt=x″(t)

Din sin(θ + h) − sin θ = 2 cos(θ + h/2) sin(h/2), raportul variației vitezei este −ω²A cos(θ + h/2) · sin(h/2)/(h/2). Trecând la limită rezultă aₓ(t) = −ω²A cos(ωt + φ₀).

C. Derivare directă pe ambele axe

OxOy
x = A cos(ωt + φ₀)y = A sin(ωt + φ₀)
vₓ = x′ = −ωA sin(ωt + φ₀)vᵧ = y′ = ωA cos(ωt + φ₀)
aₓ = x″ = −ω²A cos(ωt + φ₀)aᵧ = y″ = −ω²A sin(ωt + φ₀)

La fiecare derivare apare factorul ω din regula funcției compuse. Faza inițială φ₀ este constantă, deci derivata ei este zero.

D. Ecuațiile celor două oscilatoare

Resort: x″ + (k/m)x = 0

Pendul, ecuația exactă: α″ + (g/ℓ) sin α = 0

Pendul, unghiuri mici: α″ + (g/ℓ)α ≈ 0

În modelul liniarizat al pendulului, soluția este α(t) = αmax cos(√(g/ℓ) · t + φ₀). Pentru unghiuri mari, mișcarea pendulului nu mai este armonică și perioada depinde de amplitudine.
