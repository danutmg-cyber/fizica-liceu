Oscilatorul armonic: elongație, viteză și accelerație

De la proiecția unei mișcări circulare uniforme la mișcarea oscilatorie.

Partea I. Explicații fără derivate

Un corp oscilează când se mișcă repetat de o parte și de alta a poziției de echilibru. Elongația x este coordonata sa față de această poziție; poate fi pozitivă, negativă sau zero. Amplitudinea A este cea mai mare distanță față de echilibru, deci A > 0.

În modelul ideal, fără frecare, perioada T este durata unei oscilații complete, iar frecvența f arată câte oscilații se efectuează într-o secundă. Pulsația ω arată cât de repede crește faza.

f=1T,ω=2πT=2πf

Unități: x și A în metri, T în secunde, f în hertzi și ω în radiani pe secundă. Unghiurile din formule sunt exprimate în radiani.

Alegerea momentului inițial

Alegem t = 0 când corpul se află în extremitatea pozitivă: x = A și v = 0. În această situație:

x(t) = A cos(ωt)

v(t) = −ωA sin(ωt)

a(t) = −ω²A cos(ωt) = −ω²x(t)

În aceste relații, v și a sunt componentele cu semn pe Ox. Modulul vitezei este |v|, iar modulul accelerației este |a|. Semnul arată sensul pe axă.

Schema interactivă: cercul și proiecțiile

Punctul P se rotește uniform în sens trigonometric. Proiecția Q pe Ox oscilează orizontal, iar proiecția R pe Oy oscilează vertical. Activează vectorii și proiecțiile pe care dorești să le urmărești.

Vectori:
Proiecții:

Albastru: poziție și elongații · Verde: viteză · Roșu: accelerație. Liniile punctate sunt linii de construcție; săgețile arată sensul componentelor.

OP este vectorul de poziție al punctului de pe cerc. Elongația oscilatorului pe Ox este componenta x, reprezentată de OQ. Vectorii viteză și accelerație au scări grafice proprii; lungimile lor nu se compară cu raza sau între ele, fiind mărimi cu unități diferite.

Valorile afișate sunt raportate la A, ωA și ω²A. Pentru Ox: x = A cos θ, vₓ = −ωA sin θ, aₓ = −ω²A cos θ. Pentru Oy: y = A sin θ, vᵧ = ωA cos θ, aᵧ = −ω²A sin θ.

1. Elongația: proiecția razei pe Ox

Pe cercul de rază A, unghiul dintre OP și sensul pozitiv al axei Ox este θ = ωt. Din trigonometrie, coordonatele punctului sunt:

x = A cos θ

y = A sin θ

În primul cadran, relațiile rezultă din definițiile cosinusului și sinusului în triunghiul dreptunghic. Pe întregul cerc, semnele sunt date de cadran. Proiecția Q se mișcă între −A și +A: aceasta este mișcarea oscilatorie armonică.

Cercul este un model geometric; corpul care oscilează pe Ox se deplasează pe o dreaptă.

2. Viteza: proiecția vectorului tangent

La o rotație completă, P parcurge distanța 2πA în timpul T. Modulul vitezei sale pe cerc este constant:

vc=2πAT=ωA

Vectorul viteză este tangent la cerc, perpendicular pe OP, în sensul mișcării. El face unghiul θ + π/2 cu Ox. Componenta sa pe Ox este viteza lui Q: în același interval de timp, deplasarea orizontală a lui P este exact deplasarea lui Q.

vₓ = ωA cos(θ + π/2) = −ωA sin θ

v(t) = −ωA sin(ωt)

Am folosit identitatea cos(θ + π/2) = −sin θ. Imediat după plecarea din x = A, corpul merge spre stânga, deci v < 0. La echilibru, modulul vitezei este maxim: vmax = ωA. La extremități, v = 0.

3. Accelerația: proiecția vectorului spre centru

Pe cerc, modulul vitezei rămâne constant, dar direcția sa se schimbă. Există astfel o accelerație centripetă, orientată spre O. Folosim relația cunoscută pentru mișcarea circulară uniformă:

ac=vc2A=ω2A

aₓ = −ω²A cos θ = −ω²x

Accelerația este opusă vectorului OP, de aceea proiecția are semnul minus. Componenta pe Ox este accelerația lui Q. Dacă x > 0, atunci a < 0; dacă x < 0, atunci a > 0. Accelerația este orientată spre echilibru.

Modulul accelerației este maxim la extremități: amax = ω²A. La echilibru, a = 0.

Accelerația nu indică sensul mișcării. Corpul își mărește modulul vitezei când se apropie de echilibru și îl micșorează când se îndepărtează. La extremități, viteza este zero, dar accelerația este nenulă.

Legătura cu resortul

Pentru un corp de masă m legat de un resort ideal, forța elastică este F = −kx. Din F = ma rezultă a = −(k/m)x. Comparând cu a = −ω²x, obținem:

ω=km,T=2πmk

Verifică ce ai înțeles

1. La x = 0, viteza este zero? 2. Dacă x este negativ, ce semn are accelerația? 3. Poate viteza să fie zero, iar accelerația nenulă?

Vezi răspunsurile

1. Nu, modulul vitezei este maxim, ωA. 2. Accelerația este pozitivă. 3. Da, la extremități: v = 0, iar |a| = ω²A.

Partea a II-a. Pentru mai târziu: limite și derivate

Această parte presupune că ai studiat limitele, limita sin u / u când u → 0 și derivarea funcțiilor compuse. Nu este necesară pentru înțelegerea părții I.

A. Viteza instantanee ca limită

Viteza medie pe Ox este variația coordonatei împărțită la intervalul de timp. Viteza instantanee este limita acestui raport:

v(t)=limΔt→0x(t+Δt)−x(t)Δt=x′(t)

Punem θ = ωt și h = ωΔt. Identitatea cos(θ + h) − cos θ = −2 sin(θ + h/2) sin(h/2) transformă raportul în:

x(t+Δt)−x(t)Δt=−Aωsin(θ+h2)sin(h/2)h/2

Când Δt → 0, avem h → 0. Atunci sin(h/2)/(h/2) → 1, iar sin(θ + h/2) → sin θ. Rezultă v(t) = −ωA sin(ωt). Limita trigonometrică folosită este valabilă pentru unghiuri în radiani.

B. Accelerația instantanee ca limită

Accelerația medie este variația vitezei împărțită la intervalul de timp. Accelerația instantanee este limita accelerației medii:

a(t)=limΔt→0v(t+Δt)−v(t)Δt=v′(t)=x″(t)

Folosim sin(θ + h) − sin θ = 2 cos(θ + h/2) sin(h/2). Raportul variației vitezei devine:

v(t+Δt)−v(t)Δt=−ω2Acos(θ+h2)sin(h/2)h/2

Trecând la limită, obținem a(t) = −ω²A cos(ωt).

C. Calcul direct cu derivate

x(t) = A cos(ωt)

v(t) = x′(t) = A · [−sin(ωt)] · ω = −ωA sin(ωt)

a(t) = v′(t) = −ωA · cos(ωt) · ω = −ω²A cos(ωt)

La fiecare derivare apare un factor ω din regula funcției compuse. Pentru o fază inițială oarecare φ₀, înlocuim ωt cu ωt + φ₀ în toate cele trei formule. Ecuația diferențială a oscilatorului este x″(t) + ω²x(t) = 0.
