Două oscilatoare pot oscila foarte diferit

Unul se poate deplasa mai mult și mai lent.

Altul se poate deplasa mai puțin, dar mai rapid.

Pentru a compara mișcările avem nevoie de mărimi fizice măsurabile.

\[ \boxed{ x,\qquad A,\qquad T,\qquad f,\qquad N } \]

\(x\)

Unde se află oscilatorul față de poziția echilibru?

\(A\)

Care este deplasarea maximă față de poziția echilibru?

\(T\)

Cât durează o oscilație completă?

\(f\)

Câte oscilații efectuează într-o secundă?

La finalul lecției vei putea:

  • să definești elongația;
  • să identifici semnul elongației;
  • să definești amplitudinea;
  • să diferențiezi amplitudinea de distanța parcursă;
  • să definești perioada unei oscilații;
  • să definești frecvența și unitatea hertz;
  • să folosești relația \(f=1/T\);
  • să determini experimental perioada prin cronometrarea mai multor oscilații;
  • să interpretezi un grafic simplu \(x(t)\).

1. Elongația

Unde se află oscilatorul față de poziția de echilibru?

Elongația este mărimea fizică ce exprimă deplasarea oscilatorului față de poziția de echilibru, la un moment dat.

Pentru o oscilație rectilinie alegem originea axei în poziția de echilibru:

\[ O:\quad x=0. \]

Elongația este o mărime algebrică

\(x>0\)

oscilatorul se află în partea pozitivă a axei

\(x=0\)

oscilatorul se află în poziția de echilibru

\(x<0\)

oscilatorul se află în partea negativă a axei

Unitatea SI a elongației liniare este:

\[ \boxed{ [x]=\mathrm m } \]

Elongația nu este distanța parcursă

Elongația arată poziția instantanee față de echilibru.

Distanța parcursă depinde de întregul traseu efectuat de corp.

Un oscilator se află exact în poziția de echilibru. Elongația sa este:

2. Amplitudinea

Cea mai mare îndepărtare de echilibru

Amplitudinea oscilației este valoarea maximă a modulului elongației.
\[ \boxed{ A=\max |x| } \]

Pentru o oscilație rectilinie simetrică, pozițiile extreme sunt:

\[ x=-A \qquad\text{și}\qquad x=+A. \]
\[ \boxed{ -A\le x\le A } \]

Amplitudinea este o mărime pozitivă:

\[ A\ge0. \]

Unitatea SI:

\[ \boxed{ [A]=\mathrm m }. \]

Exemplu

Un corp oscilează între pozițiile:

\[ x_{\min}=-6\,\mathrm{cm} \] și: \[ x_{\max}=+6\,\mathrm{cm}. \]

Amplitudinea este:

\[ \boxed{ A=6\,\mathrm{cm} }. \]

Amplitudinea nu este distanța dintre extreme

Distanța dintre cele două poziții extreme este:

\[ (+A)-(-A)=2A. \]

Deci, pentru \(A=6\,\mathrm{cm}\):

\[ 2A=12\,\mathrm{cm}. \]
Într-o oscilație completă rectilinie între extremele \(-A\) și \(+A\), corpul parcurge în total: \[ \boxed{ s=4A }. \]

Un corp oscilează între \(-4\,\mathrm{cm}\) și \(+4\,\mathrm{cm}\). Care este amplitudinea în metri?

m

3. Perioada

Cât durează o oscilație completă?

Perioada este durata unei oscilații complete.
\[ \boxed{ T=\text{durata unei oscilații complete} } \]

Unitatea SI este secunda:

\[ \boxed{ [T]=\mathrm s }. \]

Ce înseamnă „oscilație completă”?

Sistemul trebuie să revină în aceeași stare de mișcare:

  • aceeași poziție;
  • același sens al mișcării.
\[ +A \rightarrow 0 \rightarrow -A \rightarrow 0 \rightarrow +A \]

reprezintă o oscilație completă dacă sistemul revine în starea din care a pornit.

Cum determinăm experimental perioada?

Cronometrarea unei singure oscilații poate avea o eroare relativ mare din cauza timpului de reacție.

Este mai bine să măsurăm timpul pentru mai multe oscilații:

\[ \boxed{ T= \frac{\Delta t}{N} } \]

unde:

  • \(\Delta t\) = timpul măsurat;
  • \(N\) = numărul de oscilații complete.

Exemplu

Pentru \(10\) oscilații se măsoară:

\[ \Delta t=16\,\mathrm s. \]

Atunci:

\[ T= \frac{16}{10} = 1{,}6\,\mathrm s. \] \[ \boxed{ T=1{,}6\,\mathrm s }. \]

Un pendul efectuează \(15\) oscilații în \(30\,\mathrm s\). Care este perioada?

s

4. Frecvența

Câte oscilații se produc într-o secundă?

Frecvența este numărul de oscilații complete efectuate în unitatea de timp.
\[ \boxed{ f= \frac{N}{\Delta t} } \]

În unele manuale, frecvența este notată și cu \(\nu\). În această lecție folosim simbolul \(f\).

Unitatea de măsură

\[ [f]=\mathrm{s^{-1}}. \]

Unitatea are numele:

\[ \boxed{ 1\,\mathrm{Hz} = 1\,\mathrm{s^{-1}} } \]

O frecvență de:

\[ f=5\,\mathrm{Hz} \]

înseamnă că sistemul efectuează:

\[ 5 \]

oscilații complete în fiecare secundă.

Legătura dintre perioadă și frecvență

Dacă o oscilație durează \(T\), într-o secundă au loc:

\[ \frac{1}{T} \] oscilații.

\[ \boxed{ f= \frac{1}{T} } \] \[ \boxed{ T= \frac{1}{f} } \]

perioadă mai mică

\[ T\downarrow \] \[ \Downarrow \]

oscilații mai rapide

\[ \Downarrow \] \[ f\uparrow \]

Exemplu

\[ T=0{,}25\,\mathrm s. \]

Frecvența:

\[ f= \frac{1}{0{,}25} = 4\,\mathrm{Hz}. \]

Un oscilator are perioada \(T=0{,}2\,\mathrm s\). Determină frecvența.

Hz

5. Activitate practică

Determină perioada unui oscilator

Materiale

Un pendul simplu sau o masă prinsă de un resort și un cronometru.

1. Pregătește oscilatorul

Deplasează puțin sistemul față de poziția de echilibru.

Eliberează-l fără impuls suplimentar.

2. Alege un reper

Poți folosi trecerea prin poziția de echilibru într-un anumit sens.

Numără o oscilație numai când sistemul revine la reper în aceeași stare de mișcare.

3. Cronometrează 10 oscilații

Notează în caiet timpul:

\[ \Delta t. \]

Folosește apoi:

\[ T= \frac{\Delta t}{10}. \]

4. Calculează frecvența

\[ f= \frac{1}{T}. \]

De ce 10 oscilații și nu una singură?

Eroarea produsă de timpul de reacție la pornirea și oprirea cronometrului are o influență relativ mai mică atunci când măsurăm un interval de timp mai mare.

Exersează calculul

Pentru \(10\) oscilații ai măsurat \(\Delta t=18\,\mathrm s\). Determină perioada.

s

Pentru \(T=1{,}8\,\mathrm s\), determină frecvența.

Hz

6. Citirea graficului unei oscilații

Elongația în funcție de timp

Mișcarea oscilatorie poate fi reprezentată printr-un grafic:

\[ x=x(t). \]

Echilibru

\[ x=0 \]

Extremă pozitivă

\[ x=+A \]

Extremă negativă

\[ x=-A \]

Repetarea graficului

are loc după o perioadă \(T\)

\[ \boxed{ x(t+T)=x(t) } \]

pentru o mișcare strict periodică.

Graficul \(x(t)\) nu este traiectoria corpului

Pe axa orizontală este reprezentat timpul, nu poziția în spațiu.

Curba arată cum se modifică elongația în timp.

O relație utilă

Dacă într-un timp \(\Delta t\) se efectuează \(N\) oscilații:

\[ \boxed{ N=f\Delta t } \] sau: \[ \boxed{ N= \frac{\Delta t}{T} }. \]

Un oscilator are frecvența \(f=3\,\mathrm{Hz}\). Câte oscilații efectuează în \(4\,\mathrm s\)?

Sinteză

Mărimile caracteristice ale oscilației

Mărime Simbol Definiție / relație Unitate SI
elongație \(x\) deplasarea față de echilibru m
amplitudine \(A\) \(A=\max|x|\) m
perioadă \(T\) \(T=\Delta t/N\) s
frecvență \(f\) \(f=N/\Delta t\) Hz
număr de oscilații \(N\) \(N=f\Delta t=\Delta t/T\) fără unitate
\[ \boxed{ f=\frac{1}{T} } \] \[ \boxed{ T=\frac{1}{f} } \]
\[ \boxed{ -A\le x\le A } \]

Cum descriem acum o oscilație?

Exemplu:

„Oscilatorul are amplitudinea \(A=4\,\mathrm{cm}\) și perioada \(T=0{,}5\,\mathrm s\).”

Putem determina imediat:

\[ f= \frac{1}{0{,}5} = 2\,\mathrm{Hz}. \]

Confuzii de evitat

Nu confunda Cu
elongația \(x\) distanța totală parcursă
amplitudinea \(A\) distanța dintre extreme \(2A\)
perioada \(T\) frecvența \(f\)
\(1/T\) \(T\)
graficul \(x(t)\) traiectoria corpului

Pasul următor

Avem acum instrumentele cantitative de bază:

\[ x,\quad A,\quad T,\quad f,\quad N. \]

Următoarea lecție este dedicată aplicațiilor și problemelor cu aceste mărimi.
