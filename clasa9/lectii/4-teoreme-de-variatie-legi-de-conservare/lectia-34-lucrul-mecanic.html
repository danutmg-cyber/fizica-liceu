Lucrul mecanic

Forță • Deplasare • Unghi • Joule • Lucru pozitiv, negativ și nul

Prof. Dănuț Andronie e-Mail: danutmg@gmail.com

Este suficient să aplicăm o forță pentru a efectua lucru mecanic?

Împingi un perete cu o forță mare.

Peretele nu se deplasează.

Din punct de vedere fizic, lucrul mecanic al forței asupra peretelui este:

\[ \boxed{ L=0 }. \]

Forță + deplasare

Forța poate efectua lucru mecanic.

Forță fără deplasare

Lucrul mecanic este nul.

Deplasare perpendiculară pe forță

Lucrul mecanic al acelei forțe este nul.

forță + deplasare + orientarea dintre ele → lucru mecanic

Ideea centrală

Lucrul mecanic caracterizează efectul unei forțe pe parcursul unei deplasări.

Nu depinde numai de modulul forței și de lungimea deplasării, ci și de unghiul dintre forță și deplasare.

La final vei putea:

  • să definești lucrul mecanic;
  • să utilizezi relația \(L=Fs\cos\alpha\);
  • să identifici corect unghiul \(\alpha\);
  • să stabilești semnul lucrului mecanic;
  • să utilizezi unitatea joule;
  • să explici situațiile în care lucrul este nul;
  • să calculezi lucrul mai multor forțe constante.

1. Definiția lucrului mecanic

O forță constantă produce o deplasare rectilinie

Considerăm o forță constantă de modul \(F\), iar corpul se deplasează rectiliniu pe distanța \(s\).

Unghiul dintre vectorul forță și vectorul deplasare este:

\[ \alpha. \]

Lucrul mecanic al forței constante

\[ \boxed{ L= Fs\cos\alpha } \]

\(F\)

Modulul forței.

\[ [F]=\mathrm N \]

\(s\)

Modulul deplasării rectilinii.

\[ [s]=\mathrm m \]

\(\alpha\)

Unghiul dintre forță și deplasare.

Componenta care contează

Componenta forței pe direcția deplasării este:

\[ F_{\parallel} = F\cos\alpha. \]

Prin urmare:

\[ L= F_{\parallel}s. \]

Unghiul \(\alpha\)

Este întotdeauna unghiul dintre vectorul forță și vectorul deplasare.

Nu este automat unghiul față de verticală sau față de orizontală.

O forță de \(50\,\mathrm N\) produce o deplasare de \(4\,\mathrm m\), iar unghiul dintre forță și deplasare este \(60^\circ\). Determină lucrul mecanic.

2. Joule. Semnul lucrului mecanic

Unitatea de măsură

Din relația:

\[ L= Fs\cos\alpha \]

rezultă:

\[ [L] = \mathrm{N\,m}. \]
\[ \boxed{ 1\,\mathrm J = 1\,\mathrm{N\,m} } \]

Unitatea SI pentru lucrul mecanic se numește joule, cu simbolul:

\[ \mathrm J. \]

Lucrul mecanic este o mărime scalară

Lucrul mecanic nu are direcție și sens, dar poate avea:

\[ L>0, \qquad L=0, \qquad L<0. \]

\(0^\circ\le\alpha<90^\circ\)

\[ \cos\alpha>0 \] \[ \boxed{ L>0 } \]

Forța are componentă în sensul deplasării.

\(\alpha=90^\circ\)

\[ \cos90^\circ=0 \] \[ \boxed{ L=0 } \]

Forța este perpendiculară pe deplasare.

\(90^\circ<\alpha\le180^\circ\)

\[ \cos\alpha<0 \] \[ \boxed{ L<0 } \]

Forța are componentă opusă deplasării.

Terminologie

Un lucru mecanic pozitiv este numit uneori lucru motor.

Un lucru mecanic negativ este numit uneori lucru rezistent.

Lucrul mecanic negativ nu înseamnă „lucru inexistent”

Semnul negativ arată că acea forță are o componentă orientată opus deplasării.

3. Cazuri particulare

Trei situații pe care trebuie să le recunoști imediat

Forță în sensul deplasării

\[ \alpha=0^\circ \] \[ \cos0^\circ=1 \]
\[ \boxed{ L=Fs } \]

Forță perpendiculară

\[ \alpha=90^\circ \] \[ \cos90^\circ=0 \]
\[ \boxed{ L=0 } \]

Forță opusă deplasării

\[ \alpha=180^\circ \] \[ \cos180^\circ=-1 \]
\[ \boxed{ L=-Fs } \]

Când mai este lucrul mecanic nul?

Din:

\[ L= Fs\cos\alpha \]

rezultă că lucrul este nul dacă:

\(F=0\)

Forța nu acționează.

\(s=0\)

Corpul nu se deplasează.

\(\alpha=90^\circ\)

Forța este perpendiculară pe deplasare.

Situație conceptuală

Ții un ghiozdan în mână și mergi cu viteză constantă pe un coridor orizontal.

Forța exercitată de mână asupra ghiozdanului este aproximativ verticală, iar deplasarea este orizontală.

Unghiul este:

\[ 90^\circ. \]

Lucrul mecanic al acestei forțe, în modelul idealizat, este:

\[ \boxed{ L=0 }. \]

Limbajul cotidian și limbajul fizicii

În viața de zi cu zi putem spune că „facem efort” când ținem un obiect greu.

În fizică, însă, lucrul mecanic al unei forțe are o definiție precisă și poate fi nul chiar dacă persoana obosește.

O forță de \(20\,\mathrm N\) este orientată opus deplasării de \(3\,\mathrm m\). Determină lucrul mecanic al forței.

4. Lucrul mai multor forțe

Fiecare forță are propriul lucru mecanic

Dacă asupra unui corp acționează mai multe forțe constante, putem calcula separat lucrul fiecărei forțe.

Lucrul mecanic total este suma algebrică:

\[ \boxed{ L_{\mathrm{total}} = L_1+ L_2+ \cdots+ L_n } \]

Pentru o deplasare rectilinie, acesta este și lucrul mecanic al rezultantei forțelor:

\[ \boxed{ L_{\mathrm{rez}} = L_{\mathrm{total}} } \]
Exemplu

Un corp se deplasează \(5\,\mathrm m\) spre dreapta.

Acționează două forțe orizontale:

\[ F_1= 30\,\mathrm N \]

în sensul deplasării și:

\[ F_2= 10\,\mathrm N \]

în sens opus.

Lucrul lui \(F_1\):

\[ L_1= 30\cdot5= 150\,\mathrm J. \]

Lucrul lui \(F_2\):

\[ L_2= -10\cdot5= -50\,\mathrm J. \]

Lucrul total:

\[ L_{\mathrm{total}} = 150-50. \] \[ \boxed{ L_{\mathrm{total}} = 100\,\mathrm J }. \]

Verificare prin rezultantă

Rezultanta:

\[ F_{\mathrm{rez}} = 30-10= 20\,\mathrm N. \]

Este în sensul deplasării, deci:

\[ L_{\mathrm{rez}} = 20\cdot5= 100\,\mathrm J. \]

Același rezultat

\[ \boxed{ L_{\mathrm{rez}} = L_1+L_2 }. \]

Interpretare grafică pentru o forță constantă paralelă

Dacă forța este paralelă cu deplasarea:

\[ L=Fs. \]

Pe graficul \(F(s)\), lucrul mecanic este numeric egal cu aria dreptunghiului de sub grafic.

Deocamdată: forțe constante

În această lecție lucrăm în principal cu forțe constante.

Pentru o forță care variază cu poziția, situația necesită o analiză mai atentă.

Două forțe paralele cu deplasarea de \(5\,\mathrm m\) au modulele \(30\,\mathrm N\) în sensul mișcării și \(10\,\mathrm N\) în sens opus. Determină lucrul total.

6. Activitate practică

Verifică relația \(L=Fs\) pentru o forță aproximativ constantă

Materiale

Un corp mic sau o cutie, un dinamometru, o ruletă ori o riglă lungă și o suprafață orizontală.

Scopul activității

Nu determinăm aici lucrul frecării.

Exersăm relația dintre forța aplicată, deplasare și lucrul mecanic al forței de tracțiune.

1. Montaj Leagă dinamometrul de corp.
2. Marchează traseul Stabilește o deplasare de exemplu de \(0{,}50\,\mathrm m\).
3. Trage orizontal Menține dinamometrul aproximativ paralel cu deplasarea.
4. Măsoară Citește valoarea aproximativ constantă a forței.
5. Notează Scrie \(F\) și \(s\) în tabel.
6. Calculează Pentru \(\alpha\approx0^\circ\): \[ L\approx Fs. \]

Relația cauză–efect

Dacă forța rămâne aproximativ constantă și paralelă cu deplasarea:

\[ L= Fs. \]

Dublarea deplasării conduce la dublarea lucrului mecanic al forței.

Problemă de sinteză

O forță constantă de \(24\,\mathrm N\) acționează asupra unui corp care se deplasează \(5\,\mathrm m\).

Unghiul dintre forță și deplasare este \(60^\circ\).

Calculăm:

\[ L= 24\cdot5\cdot\cos60^\circ. \] \[ L= 24\cdot5\cdot0{,}5. \] \[ \boxed{ L= 60\,\mathrm J }. \]

Pagina 8 din 9
Sinteză

Ce trebuie să reții

Formula generală

\[ \boxed{ L= Fs\cos\alpha } \]

Forță paralelă

\[ \alpha=0^\circ \] \[ \boxed{ L=Fs } \]

Forță perpendiculară

\[ \alpha=90^\circ \] \[ \boxed{ L=0 } \]

Forță opusă

\[ \alpha=180^\circ \] \[ \boxed{ L=-Fs } \]

Unitatea SI

\[ \boxed{ 1\,\mathrm J = 1\,\mathrm{N\,m} } \]

Lucrul total

\[ \boxed{ L_{\mathrm{total}} = \sum_i L_i } \]

\(L>0\)

Forța are componentă în sensul deplasării.

\(L=0\)

Forța este perpendiculară pe deplasare sau deplasarea este nulă.

\(L<0\)

Forța are componentă opusă deplasării.

identific forța → identific deplasarea → determin \(\alpha\) → calculez \(\cos\alpha\) → \(L=Fs\cos\alpha\)

Patru greșeli de evitat

1. Nu calcula \(L=Fs\) dacă forța nu este paralelă cu deplasarea.

2. Nu uita că unghiul este cel dintre \(\vec F\) și deplasare.

3. Nu elimina semnul negativ al lucrului rezistent.

4. Nu confunda joule \((\mathrm J)\) cu watt \((\mathrm W)\).

Algoritm rapid

  1. desenează sensul deplasării;
  2. desenează vectorul forță;
  3. stabilește unghiul dintre ele;
  4. scrie \(L=Fs\cos\alpha\);
  5. verifică semnul rezultatului;
  6. exprimă rezultatul în jouli.
