Puterea mecanică. Randamentul

Lucru mecanic • Timp • Watt • Putere utilă • Randament

Același lucru mecanic. Timpi diferiți.

Doi elevi urcă același obiect la aceeași înălțime.

Amândoi efectuează același lucru mecanic util.

Primul termină în:

\[ 4\,\mathrm s, \]

iar al doilea în:

\[ 12\,\mathrm s. \]

Cine efectuează lucrul mecanic mai repede?

Elevul A

\[ L= 600\,\mathrm J \] \[ t= 4\,\mathrm s \] \[ P= 150\,\mathrm W \]

Elevul B

\[ L= 600\,\mathrm J \] \[ t= 12\,\mathrm s \] \[ P= 50\,\mathrm W \]

Prima idee a lecției

Puterea mecanică nu arată cât lucru mecanic s-a efectuat, ci cât de repede este efectuat.

lucru mecanic + interval de timp → putere → rapiditatea efectuării lucrului

A doua întrebare

O mașină primește lucru mecanic din exterior, dar nu tot lucrul consumat devine lucru util.

Cum caracterizăm această eficiență?

Prin: randament.

La final vei putea:

  • să definești puterea mecanică;
  • să utilizezi relația \(P=L/\Delta t\);
  • să utilizezi unitatea watt;
  • să utilizezi relația \(P=Fv\cos\alpha\) în situații simple;
  • să definești randamentul;
  • să calculezi randamentul în procente;
  • să diferențiezi lucrul util de lucrul consumat;
  • să pregătești experimentul de determinare a randamentului unui plan înclinat.

1. Puterea mecanică

Cât lucru mecanic se efectuează într-o unitate de timp?

Definiție

Puterea mecanică medie este raportul dintre lucrul mecanic efectuat și intervalul de timp în care acesta este efectuat.

\[ \boxed{ P= \frac{ L }{ \Delta t } } \]

\(P\)

puterea mecanică

\(L\)

lucrul mecanic

\[ [L]=\mathrm J \]

\(\Delta t\)

intervalul de timp

\[ [t]=\mathrm s \]

Unitatea de măsură

Din definiție:

\[ [P] = \frac{ \mathrm J }{ \mathrm s }. \]
\[ \boxed{ 1\,\mathrm W = 1\,\frac{\mathrm J}{\mathrm s} } \]

Unitatea SI a puterii se numește watt, cu simbolul:

\[ \boxed{ \mathrm W }. \]

kilowatt

\[ 1\,\mathrm{kW} = 1000\,\mathrm W \]

megawatt

\[ 1\,\mathrm{MW} = 10^6\,\mathrm W \]
Exemplu

O mașină efectuează un lucru mecanic de:

\[ L= 3600\,\mathrm J \]

în:

\[ \Delta t= 12\,\mathrm s. \]

Puterea:

\[ P= \frac{ 3600 }{ 12 }. \] \[ \boxed{ P= 300\,\mathrm W }. \]

Comparație

Pentru același lucru mecanic:

\[ P= \frac{L}{\Delta t}. \]

Un interval de timp mai mic înseamnă o putere mai mare.

Puterea nu este lucru mecanic

Lucrul mecanic se măsoară în:

\[ \mathrm J, \]

iar puterea în:

\[ \mathrm W. \]

Sunt mărimi fizice diferite.

Un motor efectuează un lucru mecanic de \(1000\,\mathrm J\) în \(5\,\mathrm s\). Determină puterea medie.

2. Puterea unei forțe

Legătura dintre putere, forță și viteză

Considerăm o forță constantă \(F\), care formează un unghi \(\alpha\) cu deplasarea.

Lucrul mecanic:

\[ L= Fs\cos\alpha. \]

Puterea:

\[ P= \frac{ Fs\cos\alpha }{ \Delta t }. \]

Dacă mișcarea este uniformă în intervalul analizat:

\[ v= \frac{ s }{ \Delta t }. \]

Obținem:

\[ \boxed{ P= Fv\cos\alpha } \]

Forță paralelă cu viteza

Pentru:

\[ \alpha= 0^\circ, \]

avem:

\[ \cos0^\circ= 1. \]
\[ \boxed{ P= Fv } \]

Forța în sensul mișcării

\[ \alpha<90^\circ \] \[ P>0 \]

Forța perpendiculară

\[ \alpha=90^\circ \] \[ P=0 \]

Forța opusă mișcării

\[ \alpha>90^\circ \] \[ P<0 \]

Domeniul relației folosite aici

La nivelul acestei lecții utilizăm:

\[ P= Fv\cos\alpha \]

în situații în care forța, viteza și unghiul pot fi considerate constante în intervalul analizat.

Exemplu

Un tractor exercită o forță de tracțiune:

\[ F= 2000\,\mathrm N \]

în sensul mișcării și se deplasează uniform cu:

\[ v= 3\,\mathrm{m/s}. \]

Atunci:

\[ P= Fv. \] \[ P= 2000\cdot3. \] \[ \boxed{ P= 6000\,\mathrm W= 6\,\mathrm{kW} }. \]

O forță de \(500\,\mathrm N\) acționează în sensul mișcării unui corp care se deplasează uniform cu \(3\,\mathrm{m/s}\). Determină puterea acestei forțe.

3. Randamentul

Nu tot lucrul mecanic consumat devine lucru mecanic util

O mașină primește din exterior un lucru mecanic:

\[ L_c, \]

pe care îl numim lucru mecanic consumat.

Doar o parte este valorificată în scopul urmărit:

\[ L_u, \]

numit lucru mecanic util.

Lucru consumat
\(L_c\)
→
Lucru util
\(L_u\)

Randamentul

\[ \boxed{ \eta= \frac{ L_u }{ L_c } } \]

De obicei îl exprimăm în procente:

\[ \boxed{ \eta= \frac{ L_u }{ L_c } \cdot100\% } \]

Cu ajutorul puterilor

Pentru același interval de funcționare:

\[ P_u= \frac{ L_u }{ \Delta t }, \] \[ P_c= \frac{ L_c }{ \Delta t }. \]

Rezultă:

\[ \boxed{ \eta= \frac{ P_u }{ P_c } } \]

Pentru o mașină reală

În mod obișnuit:

\[ 0< \eta< 1, \]

sau:

\[ 0\%< \eta< 100\%. \]

O parte din lucrul consumat este asociată efectelor nedorite, de exemplu frecării, deformărilor sau încălzirii.

Randamentul nu poate depăși 100%

Dacă dintr-un calcul obții:

\[ \eta> 100\%, \]

trebuie să verifici datele, formulele sau identificarea lucrului util și a celui consumat.

O mașină primește un lucru mecanic de \(500\,\mathrm J\) și furnizează un lucru util de \(400\,\mathrm J\). Determină randamentul în procente.

4. Aplicații

Putere și randament în probleme

Problema 1 – ridicarea unei sarcini

Un elevator ridică o sarcină cu masa:

\[ m= 200\,\mathrm{kg} \]

la înălțimea:

\[ h= 5\,\mathrm m \]

în:

\[ t= 10\,\mathrm s. \]

Considerăm:

\[ g= 10\,\mathrm{N/kg}. \]

Lucrul util:

\[ L_u= mgh. \] \[ L_u= 200\cdot10\cdot5= 10000\,\mathrm J. \]

Puterea utilă:

\[ P_u= \frac{ 10000 }{ 10 }. \] \[ \boxed{ P_u= 1000\,\mathrm W= 1\,\mathrm{kW} }. \]
Problema 2 – puterea consumată

Elevatorul din problema anterioară are randamentul:

\[ \eta= 80\%. \]

Scriem:

\[ \eta= \frac{ P_u }{ P_c }. \]

În formă zecimală:

\[ \eta= 0{,}80. \]

Rezultă:

\[ P_c= \frac{ P_u }{ \eta }. \] \[ P_c= \frac{ 1000 }{ 0{,}80 }. \] \[ \boxed{ P_c= 1250\,\mathrm W }. \]

Procentele trebuie transformate corect

\[ 80\%= 0{,}80. \]

În formule precum:

\[ P_u= \eta P_c, \]

folosim randamentul în formă zecimală.

Problema 3 – tracțiune

Un vehicul se deplasează uniform cu:

\[ v= 5\,\mathrm{m/s}. \]

Forța de tracțiune are modulul:

\[ F= 800\,\mathrm N \]

și este în sensul mișcării.

Puterea mecanică:

\[ P= Fv. \] \[ \boxed{ P= 4000\,\mathrm W= 4\,\mathrm{kW} }. \]

Două întrebări diferite

Puterea: cât de repede se efectuează lucrul mecanic?

\[ P= \frac{L}{t}. \]

Randamentul: ce fracție din lucrul consumat este valorificată util?

\[ \eta= \frac{L_u}{L_c}. \]

O mașină are puterea utilă \(P_u=1000\,\mathrm W\) și randamentul \(\eta=80\%\). Determină puterea consumată.

W

6. Activitate practică și pregătirea experimentului

Măsoară-ți puterea mecanică la urcarea scărilor

Materiale

Cronometru, ruletă sau metru, calculator și valoarea masei elevului.

1. Măsoară masa Notează: \[ m. \]
2. Măsoară o treaptă Determină înălțimea unei trepte.
3. Numără treptele Calculează înălțimea totală: \[ h. \]
4. Urcă în siguranță Fără alergare dacă spațiul nu permite activitatea în condiții sigure.
5. Cronometrează Măsoară: \[ t. \]
6. Calculează lucrul util \[ L_u= mgh. \]
7. Calculează puterea \[ P= \frac{mgh}{t}. \]
8. Compară Elevii pot efectua lucruri mecanice diferite, deci comparația trebuie făcută prin putere, nu doar prin timp.

Concluzie

Un elev poate urca mai repede, dar poate avea și altă masă.

De aceea comparăm:

\[ \boxed{ P= \frac{mgh}{t} } \]

și nu doar timpii de urcare.

Pregătirea Lecției 37 – planul înclinat

Pentru ridicarea unui corp pe planul înclinat:

lucrul mecanic util este:

\[ \boxed{ L_u= mgh } \]

iar dacă forța de tracțiune \(F\) este paralelă cu planul și aproximativ constantă:

\[ \boxed{ L_c= Fs } \]

Prin urmare:

\[ \boxed{ \eta= \frac{ mgh }{ Fs } } \]

sau:

\[ \boxed{ \eta= \frac{ mgh }{ Fs } \cdot100\% } \]

Exact aceasta va fi ideea experimentului următor

Vei măsura direct:

\[ m, \qquad h, \qquad F, \qquad s, \]

apoi vei calcula manual:

\[ L_u, \qquad L_c, \qquad \eta. \]

Pe un plan înclinat, lucrul util este \(300\,\mathrm J\), iar lucrul consumat este \(400\,\mathrm J\). Determină randamentul în procente.

Sinteză

Ce trebuie să reții

Puterea mecanică

\[ \boxed{ P= \frac{ L }{ \Delta t } } \]

Unitatea SI

\[ \boxed{ 1\,\mathrm W = 1\,\mathrm{J/s} } \]

Puterea unei forțe

\[ \boxed{ P= Fv\cos\alpha } \]

Forță în sensul mișcării

\[ \boxed{ P= Fv } \]

Randament

\[ \boxed{ \eta= \frac{ L_u }{ L_c } } \]

Randament prin puteri

\[ \boxed{ \eta= \frac{ P_u }{ P_c } } \]

Randament procentual

\[ \boxed{ \eta_{\%}= \frac{ L_u }{ L_c } \cdot100\% } \]

Plan înclinat

\[ \boxed{ \eta= \frac{ mgh }{ Fs } } \]

Puterea

Caracterizează rapiditatea efectuării lucrului mecanic.

\[ P= \frac{L}{t} \]

Randamentul

Compară lucrul util cu lucrul mecanic consumat.

\[ \eta= \frac{L_u}{L_c} \]
lucru mecanic ÷ timp → putere • util / consumat → randament

Patru greșeli de evitat

1. Nu confunda wattul cu joule-ul.

2. În formula randamentului, lucrul util este la numărător:

\[ \eta= \frac{L_u}{L_c}. \]

3. În calcule, transformă:

\[ 80\%=0{,}80. \]

4. Un randament mai mare de \(100\%\) indică o eroare de model, date sau calcul.

Pentru experimentul următor

Pe planul înclinat vei măsura:

\[ m, \qquad h, \qquad F, \qquad s. \]

Vei calcula:

\[ L_u= mgh, \] \[ L_c= Fs, \]

apoi:

\[ \boxed{ \eta= \frac{ mgh }{ Fs } \cdot100\% }. \]
