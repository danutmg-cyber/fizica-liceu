Energia mecanică. Conservarea energiei mecanice

Energie cinetică • Energie potențială • Transformări • Conservare

Prof. Dănuț Andronie e-Mail: danutmg@gmail.com

Energia își poate schimba forma fără ca energia mecanică să se schimbe

O bilă lăsată să cadă pierde energie potențială gravitațională și câștigă energie cinetică.

Un resort comprimat poate pierde energie potențială elastică și poate accelera un corp.

În anumite condiții, suma acestor forme de energie rămâne constantă.

Energie cinetică

\[ E_c= \frac{mv^2}{2} \]

Energie potențială gravitațională

\[ E_{p,g}=mgh \]

Energie potențială elastică

\[ E_{p,el} = \frac{kx^2}{2} \]

Energia mecanică

\[ \boxed{ E_m= E_c+ E_p } \]

Dacă sunt prezente simultan energia gravitațională și cea elastică:

\[ \boxed{ E_m= E_c+ E_{p,g}+ E_{p,el} }. \]
energie cinetică ↔ energie potențială → energie mecanică

Situația ideală

Dacă lucrul forțelor neconservative este nul:

\[ L_{nc}=0, \]

atunci:

\[ \boxed{ E_m=\text{constantă} }. \]

La final vei putea:

  • să definești energia mecanică;
  • să identifici formele de energie dintr-un sistem;
  • să formulezi legea conservării energiei mecanice;
  • să precizezi condițiile de conservare;
  • să utilizezi \(E_{m1}=E_{m2}\);
  • să utilizezi relația generală \(\Delta E_m=L_{nc}\);
  • să analizezi transformări gravitaționale și elastice;
  • să explici efectul frecării asupra energiei mecanice.

1. Energia mecanică

Energia asociată mișcării și configurației

Energia mecanică a unui sistem este suma dintre energia cinetică și energiile potențiale considerate:

\[ \boxed{ E_m= E_c+ E_p }. \]

Sistem corp–Pământ

Dacă avem numai interacțiunea gravitațională:

\[ E_m= \frac{mv^2}{2} + mgh. \]

Sistem corp–resort

Pentru un corp legat de un resort ideal, pe o suprafață orizontală fără frecare:

\[ E_m= \frac{mv^2}{2} + \frac{kx^2}{2}. \]

Sistem corp–Pământ–resort

Dacă ambele energii potențiale sunt relevante:

\[ E_m= \frac{mv^2}{2} + mgh + \frac{kx^2}{2}. \]

Trebuie precizat sistemul

Energia potențială este asociată unei interacțiuni.

De aceea este util să precizăm sistemul studiat: corp–Pământ, corp–resort sau corp–Pământ–resort.

Energia mecanică nu este o a treia energie independentă

Nu adăugăm o energie nouă peste energia cinetică și potențială.

Energia mecanică este chiar:

\[ \boxed{ E_m=E_c+E_p }. \]
Exemplu

Un corp de \(2\,\mathrm{kg}\) se deplasează cu \(4\,\mathrm{m/s}\) la înălțimea de \(3\,\mathrm m\). Considerăm:

\[ g=10\,\mathrm{N/kg}. \]

Energia cinetică:

\[ E_c= \frac{2\cdot4^2}{2} = 16\,\mathrm J. \]

Energia potențială:

\[ E_p= 2\cdot10\cdot3 = 60\,\mathrm J. \]

Energia mecanică:

\[ \boxed{ E_m= 76\,\mathrm J }. \]

Pentru exemplul de mai sus, determină energia mecanică.

2. Legea conservării energiei mecanice

Pornim de la teorema energiei cinetice

Din Lecția 38:

\[ \boxed{ \Delta E_c= L_{\mathrm{tot}} }. \]

Separăm lucrul total în:

\[ L_{\mathrm{tot}} = L_c+ L_{nc}, \]

unde:

  • \(L_c\) este lucrul forțelor conservative;
  • \(L_{nc}\) este lucrul forțelor neconservative.

Pentru forțele conservative:

\[ L_c= -\Delta E_p. \]

Înlocuim:

\[ \Delta E_c = -\Delta E_p + L_{nc}. \]

Rearanjăm:

\[ \Delta E_c+ \Delta E_p = L_{nc}. \]

Dar:

\[ \Delta E_m = \Delta E_c+ \Delta E_p. \]

Relația generală

\[ \boxed{ \Delta E_m= L_{nc} } \]

Cazul conservativ

Dacă:

\[ L_{nc}=0, \]

atunci:

\[ \Delta E_m=0. \]

Deci:

\[ \boxed{ E_{m1}=E_{m2} } \]

sau:

\[ \boxed{ E_m= \text{constantă} }. \]

Condiția trebuie precizată

Energia mecanică nu este conservată în orice situație.

Conservarea este valabilă atunci când lucrul forțelor neconservative este nul.

\(\Delta E_c=L_c+L_{nc}\) → \(L_c=-\Delta E_p\) → \(\Delta E_m=L_{nc}\) → dacă \(L_{nc}=0\), \(E_m=\) constantă

3. Transformarea gravitațională

Căderea fără rezistența aerului

Considerăm un corp și neglijăm rezistența aerului.

Energia mecanică:

\[ E_m= \frac{mv^2}{2} + mgh. \]
sus:
\(E_p\) mare
corpul coboară
\(E_p\downarrow\)
\(E_c\uparrow\)
\(E_m=\) constantă

Între două poziții

\[ \boxed{ \frac{mv_1^2}{2} + mgh_1 = \frac{mv_2^2}{2} + mgh_2 } \]
Problema 1 – cădere liberă

Un corp este lăsat din repaus de la:

\[ h_1= 5\,\mathrm m. \]

La sol:

\[ h_2=0. \]

Considerăm:

\[ g= 10\,\mathrm{N/kg}. \]

Conservarea energiei:

\[ mgh_1 = \frac{mv_2^2}{2}. \]

Masa se simplifică:

\[ gh_1 = \frac{v_2^2}{2}. \] \[ v_2= \sqrt{2gh_1}. \] \[ v_2= \sqrt{ 2\cdot10\cdot5 }. \] \[ \boxed{ v_2= 10\,\mathrm{m/s} }. \]

Observație

În acest model, viteza finală nu depinde de masa corpului.

Masa apare atât în energia potențială, cât și în energia cinetică și se simplifică.

Model idealizat

Rezultatul presupune că rezistența aerului poate fi neglijată.

Dacă rezistența aerului efectuează lucru mecanic nenul, energia mecanică nu mai rămâne constantă.

Un corp este lăsat din repaus de la \(5\,\mathrm m\). Neglijăm rezistența aerului și luăm \(g=10\,\mathrm{N/kg}\). Determină viteza la sol.

4. Transformarea elastică

Resort și corp pe suprafață fără frecare

Considerăm un corp legat de un resort ideal.

Suprafața este orizontală, iar frecarea este neglijabilă.

Energia mecanică:

\[ E_m= \frac{mv^2}{2} + \frac{kx^2}{2}. \]
\[ \boxed{ \frac{mv_1^2}{2} + \frac{kx_1^2}{2} = \frac{mv_2^2}{2} + \frac{kx_2^2}{2} } \]
resort deformat
\(E_{p,el}\) mare
eliberare
\(E_{p,el}\downarrow\)
\(E_c\uparrow\)
Problema 2 – resort comprimat

Avem:

\[ m= 0{,}50\,\mathrm{kg}, \] \[ k= 200\,\mathrm{N/m}, \] \[ x_1= 0{,}10\,\mathrm m, \] \[ v_1=0. \]

Când resortul ajunge nedeformat:

\[ x_2=0. \]

Energia elastică inițială:

\[ E_{p,el,1} = \frac{ 200\cdot0{,}10^2 }{ 2 } = 1\,\mathrm J. \]

Prin conservare:

\[ 1 = \frac{ 0{,}50v_2^2 }{ 2 }. \] \[ 1= 0{,}25v_2^2. \] \[ v_2^2=4. \] \[ \boxed{ v_2= 2\,\mathrm{m/s} }. \]

Unde este viteza maximă?

În modelul orizontal fără frecare, viteza este maximă atunci când energia potențială elastică este minimă:

\[ x=0. \]

Atunci:

\[ E_{p,el}=0 \]

și energia mecanică este integral cinetică.

Atenție la semnul deformării

Energia elastică depinde de:

\[ x^2. \]

Alungirea și comprimarea de aceeași mărime au aceeași energie potențială elastică.

Pentru \(m=0{,}50\,\mathrm{kg}\), \(k=200\,\mathrm{N/m}\), \(x=0{,}10\,\mathrm m\), corpul este eliberat din repaus. Determină viteza la \(x=0\).

Energia nu dispare

Când spunem că energia mecanică scade prin frecare, nu înseamnă că energia totală dispare.

O parte din energia mecanică este transformată în alte forme de energie, în special energie internă a corpurilor aflate în contact.

Problema 3 – coborâre cu frecare

Un corp de \(2\,\mathrm{kg}\) pornește din repaus de la:

\[ h= 3\,\mathrm m. \]

Considerăm:

\[ g= 10\,\mathrm{N/kg}. \]

Lucrul frecării pe traseu este:

\[ L_f= -20\,\mathrm J. \]

Energia mecanică inițială:

\[ E_{m1}= mgh= 60\,\mathrm J. \]

Energia mecanică finală:

\[ E_{m2} = E_{m1}+L_f. \] \[ E_{m2} = 60-20. \] \[ E_{m2} = 40\,\mathrm J. \]

La baza planului:

\[ E_p=0. \]

Deci:

\[ E_c= 40\,\mathrm J. \] \[ \frac{ 2v^2 }{ 2 } = 40. \] \[ v^2= 40. \] \[ \boxed{ v\approx 6{,}32\,\mathrm{m/s} }. \]

Fără frecare

\[ L_{nc}=0 \] \[ E_m=\text{constantă} \]

Cu frecare

\[ L_f<0 \] \[ E_m\downarrow \]

Sinteză

Ce trebuie să reții

Energia cinetică

\[ \boxed{ E_c= \frac{mv^2}{2} } \]

Potențială gravitațională

\[ \boxed{ E_{p,g}=mgh } \]

Potențială elastică

\[ \boxed{ E_{p,el} = \frac{kx^2}{2} } \]

Energia mecanică

\[ \boxed{ E_m= E_c+ E_p } \]

Relația generală

\[ \boxed{ \Delta E_m= L_{nc} } \]

Conservare

\[ \boxed{ L_{nc}=0 \Rightarrow E_{m1}=E_{m2} } \]
\(E_c\) ↔ \(E_p\) → \(E_c+E_p=E_m\) → fără lucru neconservativ: \(E_m\) constantă

Sistem conservativ

\[ L_{nc}=0 \] \[ \boxed{ E_{m1}=E_{m2} } \]

Energia se transformă între forme mecanice.

Forțe neconservative

\[ L_{nc}\ne0 \] \[ \boxed{ E_{m2} = E_{m1} + L_{nc} } \]

Șase greșeli de evitat

  • nu confunda energia mecanică cu energia cinetică;
  • nu presupune automat că energia mecanică se conservă;
  • verifică dacă există frecare sau alte forțe neconservative;
  • folosește aceeași referință pentru energia potențială în cele două stări;
  • nu spune că energia „dispare” prin frecare;
  • conservarea sumei \(E_c+E_p\) nu înseamnă că fiecare termen este constant separat.

Algoritm de rezolvare

  1. alege sistemul;
  2. identifică starea inițială și starea finală;
  3. identifică formele de energie relevante;
  4. verifică existența forțelor neconservative;
  5. dacă \(L_{nc}=0\), scrie \(E_{m1}=E_{m2}\);
  6. dacă \(L_{nc}\ne0\), scrie \(E_{m2}=E_{m1}+L_{nc}\);
  7. înlocuiește expresiile energiilor;
  8. rezolvă și verifică unitățile și semnele.
