Impulsul mecanic. Teorema variației impulsului

Masă • Viteză • Impuls mecanic • Impulsul forței • Interacțiune

Prof. Dănuț Andronie e-Mail: danutmg@gmail.com

De ce contează atât masa, cât și viteza unui corp?

Un cărucior ușor și un camion pot avea aceeași viteză, dar efectele opririi lor sunt foarte diferite.

Pentru a caracteriza mișcarea ținând seama simultan de masă și de viteză introducem:

\[ \boxed{ \vec p= m\vec v }. \]

Impuls mecanic

Caracterizează starea de mișcare a corpului.

\[ \boxed{ \vec p=m\vec v } \]

Impulsul forței

Caracterizează efectul unei forțe într-un interval de timp.

\[ \boxed{ \vec I_F= \vec F_{\mathrm{med}} \Delta t } \]

Două noțiuni diferite

Nu confundăm:

\[ \boxed{ \text{impulsul mecanic al corpului} } \]

cu:

\[ \boxed{ \text{impulsul forței} }. \]

Ele au aceeași unitate de măsură și sunt legate printr-o teoremă, dar reprezintă mărimi fizice diferite.

Teorema variației impulsului

\[ \boxed{ \Delta\vec p= \vec I_F } \]

Pentru rezultanta forțelor:

\[ \boxed{ \Delta\vec p = \vec F_{\mathrm{med}} \Delta t }. \]
forță + timp → impulsul forței → variația impulsului mecanic

La final vei putea:

  • să definești impulsul mecanic;
  • să explici caracterul vectorial al impulsului;
  • să calculezi \(\Delta\vec p\);
  • să definești impulsul unei forțe;
  • să aplici teorema variației impulsului;
  • să tratezi corect schimbarea sensului mișcării;
  • să explici relația dintre timpul de oprire și forța medie;
  • să diferențiezi impulsul mecanic de energia cinetică.

1. Impulsul mecanic

Masă și viteză într-o singură mărime fizică

\[ \boxed{ \vec p= m\vec v } \]

Impulsul mecanic este o mărime vectorială.

Modul

\[ p=mv \]

unde \(v\) este modulul vitezei.

Direcție

Aceeași cu direcția vitezei.

Sens

Același cu sensul vitezei.

Unitatea SI

\[ [p] = \mathrm{kg\cdot m/s}. \]

Deoarece:

\[ 1\,\mathrm N = 1\,\mathrm{kg\cdot m/s^2}, \]

rezultă:

\[ 1\,\mathrm{N\,s} = 1\,\mathrm{kg\cdot m/s}. \]

Pe o axă orientată

Dacă alegem sensul spre dreapta pozitiv:

\[ v>0 \Rightarrow p>0, \] \[ v<0 \Rightarrow p<0. \]

Semnul arată sensul vectorului pe axa aleasă.

Exemplu

Un corp cu masa:

\[ m=2\,\mathrm{kg} \]

se deplasează spre dreapta cu:

\[ v=3\,\mathrm{m/s}. \]

Impulsul mecanic:

\[ p= 2\cdot3. \] \[ \boxed{ p= 6\,\mathrm{kg\cdot m/s} } \]

orientat spre dreapta.

Impulsul mecanic nu este energia cinetică

Impulsul:

\[ \vec p=m\vec v \]

este vectorial și depinde liniar de viteză.

Energia cinetică:

\[ E_c= \frac{mv^2}{2} \]

este scalară și depinde de pătratul vitezei.

Un corp de \(2\,\mathrm{kg}\) are viteza \(3\,\mathrm{m/s}\). Determină modulul impulsului mecanic.

2. Variația impulsului

Final minus inițial

\[ \boxed{ \Delta\vec p = \vec p_2-\vec p_1 } \]

Pentru masă constantă:

\[ \vec p_1= m\vec v_1, \] \[ \vec p_2= m\vec v_2. \]

Deci:

\[ \boxed{ \Delta\vec p = m( \vec v_2-\vec v_1 ) }. \]

Mișcare pe o singură axă

Alegem dreapta ca sens pozitiv.

Situație \(v\) \(p=mv\)
spre dreapta pozitivă pozitiv
repaus 0 0
spre stânga negativă negativ
Exemplul 1 – încetinire

Pentru:

\[ m= 0{,}50\,\mathrm{kg}, \] \[ v_1= +4\,\mathrm{m/s}, \] \[ v_2= +1\,\mathrm{m/s}, \]

obținem:

\[ \Delta p = 0{,}50(1-4). \] \[ \boxed{ \Delta p = -1{,}50\,\mathrm{kg\cdot m/s} }. \]
Exemplul 2 – schimbarea sensului

Un corp de:

\[ m= 0{,}20\,\mathrm{kg} \]

se deplasează inițial spre dreapta:

\[ v_1= +5\,\mathrm{m/s}. \]

După interacțiune se deplasează spre stânga:

\[ v_2= -3\,\mathrm{m/s}. \]

Variația impulsului:

\[ \Delta p = 0{,}20(-3-5). \] \[ \boxed{ \Delta p= -1{,}60\,\mathrm{kg\cdot m/s} }. \]

Greșeală frecventă

La schimbarea sensului nu calculăm:

\[ m(5-3). \]

Trebuie să folosim componentele vitezelor cu semn:

\[ \boxed{ \Delta p= m(v_2-v_1) }. \]

Aceeași viteză ca modul

\[ v_1=+v, \qquad v_2=-v \]

Energia cinetică este aceeași.

Impulsul se schimbă

\[ p_1=+mv, \qquad p_2=-mv \] \[ \Delta p=-2mv. \]

Pentru \(m=0{,}20\,\mathrm{kg}\), \(v_1=+5\,\mathrm{m/s}\), \(v_2=-3\,\mathrm{m/s}\), determină \(\Delta p\).

3. Impulsul forței și teorema variației impulsului

Forța acționează într-un interval de timp

Pentru un corp cu masa constantă:

\[ \vec F_{\mathrm{rez}} = m\vec a. \]

Pentru un interval de timp \(\Delta t\), accelerația medie este:

\[ \vec a_{\mathrm{med}} = \frac{ \vec v_2-\vec v_1 }{ \Delta t }. \]

Atunci:

\[ \vec F_{\mathrm{med}} = m \frac{ \vec v_2-\vec v_1 }{ \Delta t }. \]

Înmulțim cu \(\Delta t\):

\[ \vec F_{\mathrm{med}} \Delta t = m( \vec v_2-\vec v_1 ). \]

Dar:

\[ m( \vec v_2-\vec v_1 ) = \Delta\vec p. \]

Teorema variației impulsului

\[ \boxed{ \Delta\vec p = \vec F_{\mathrm{med}} \Delta t } \]

Impulsul rezultantei forțelor

\[ \boxed{ \vec I_F = \vec F_{\mathrm{med}} \Delta t } \]

Prin urmare:

\[ \boxed{ \Delta\vec p = \vec I_F }. \]

Unitatea impulsului forței

\[ [I_F] = \mathrm{N\,s}. \]

Dar:

\[ 1\,\mathrm{N\,s} = 1\,\mathrm{kg\cdot m/s}. \]

Forță variabilă

Dacă forța se modifică în timp, folosim forța medie pentru intervalul analizat:

\[ \vec I_F = \vec F_{\mathrm{med}} \Delta t. \]

Pe un grafic \(F(t)\), impulsul forței este asociat ariei dintre grafic și axa timpului, cu semnul corespunzător.

Exemplu

O forță medie de:

\[ F_{\mathrm{med}}= 10\,\mathrm N \]

acționează timp de:

\[ \Delta t= 0{,}20\,\mathrm s. \]

Impulsul forței:

\[ I_F= 10\cdot0{,}20. \] \[ \boxed{ I_F= 2\,\mathrm{N\,s} }. \]

Corpul suferă aceeași variație a impulsului mecanic:

\[ \boxed{ \Delta p= 2\,\mathrm{kg\cdot m/s} }. \]

O forță medie de \(10\,\mathrm N\) acționează timp de \(0{,}20\,\mathrm s\). Determină impulsul forței.

4. Aplicații ale teoremei variației impulsului

Accelerare, oprire și revenire

Problema 1 – accelerare

Un corp de:

\[ m= 1\,\mathrm{kg} \]

are inițial:

\[ v_1= 2\,\mathrm{m/s}. \]

O forță de:

\[ F= 4\,\mathrm N \]

acționează în sensul mișcării timp de:

\[ \Delta t= 0{,}50\,\mathrm s. \]

Impulsul forței:

\[ I_F= 4\cdot0{,}50 = 2\,\mathrm{N\,s}. \]

Impulsul inițial:

\[ p_1= 1\cdot2 = 2\,\mathrm{kg\cdot m/s}. \]

Impulsul final:

\[ p_2= p_1+\Delta p = 2+2 = 4\,\mathrm{kg\cdot m/s}. \] \[ \boxed{ v_2= 4\,\mathrm{m/s} }. \]
Problema 2 – oprire

O minge cu masa:

\[ m= 0{,}20\,\mathrm{kg} \]

se deplasează spre dreapta cu:

\[ v_1= +10\,\mathrm{m/s}. \]

După oprire:

\[ v_2=0. \]

Variația impulsului:

\[ \Delta p = 0{,}20(0-10). \] \[ \boxed{ \Delta p= -2\,\mathrm{kg\cdot m/s} }. \]

Impulsul forței de oprire este:

\[ \boxed{ I_F=-2\,\mathrm{N\,s} }. \]
Problema 3 – ricoșeu

O minge de:

\[ m= 0{,}50\,\mathrm{kg} \]

lovește un perete cu:

\[ v_1= +2\,\mathrm{m/s} \]

și revine cu:

\[ v_2= -2\,\mathrm{m/s}. \]

Atunci:

\[ \Delta p = 0{,}50(-2-2). \] \[ \boxed{ \Delta p= -2\,\mathrm{kg\cdot m/s} }. \]

Oprirea și ricoșeul nu sunt echivalente

Pentru aceeași viteză inițială, un corp care ricoșează în sens opus poate avea o variație a impulsului mai mare decât un corp care doar se oprește.

Exemplu:

\[ +v\rightarrow0 \Rightarrow |\Delta p|=mv, \] \[ +v\rightarrow-v \Rightarrow |\Delta p|=2mv. \]

Timpul de oprire și forța medie

\[ \boxed{ F_{\mathrm{med}} = \frac{ |\Delta p| }{ \Delta t } } \]

pentru modulul forței medii într-o situație unidimensională.

aceeași variație
\(|\Delta p|\)
timp de oprire mai mare
\(\Delta t\uparrow\)
forță medie mai mică
\(F_{\mathrm{med}}\downarrow\)

Aplicații practice

Această idee explică rolul:

  • airbagului;
  • centurilor și zonelor deformabile ale automobilului;
  • saltelelor de protecție;
  • mișcării mâinilor înapoi atunci când prindem o minge.

Pentru aceeași schimbare de impuls, creșterea timpului interacțiunii reduce modulul forței medii.

Un corp de \(1\,\mathrm{kg}\) are inițial \(2\,\mathrm{m/s}\). O forță de \(4\,\mathrm N\) acționează în sensul mișcării timp de \(0{,}50\,\mathrm s\). Determină viteza finală.

De ce rezultatele nu vor fi perfect egale?

Într-un experiment simplu:

  • forța poate să nu fie perfect constantă;
  • există frecare;
  • vitezele și timpul au incertitudini de măsurare;
  • dinamometrul este citit cu rezoluție finită.

Căutăm concordanță rezonabilă:

\[ I_F\approx\Delta p. \]

Demonstrație cauză–efect

Minge moale

Prinde o minge moale în două moduri:

A. oprește mâinile aproape pe loc;

B. deplasează mâinile înapoi în timpul opririi mingii.

În ambele cazuri mingea trece aproximativ de la același impuls inițial la repaus.

În cazul B timpul de oprire este mai mare, deci:

\[ \boxed{ F_{\mathrm{med}} \text{ este mai mică} }. \]

Siguranță

Folosește numai mingi ușoare și moi pentru demonstrație. Activitatea nu se realizează cu obiecte dure sau grele.

Sinteză

Ce trebuie să reții

Impuls mecanic

\[ \boxed{ \vec p=m\vec v } \]

Variația impulsului

\[ \boxed{ \Delta\vec p = \vec p_2-\vec p_1 } \]

Masă constantă

\[ \boxed{ \Delta\vec p = m( \vec v_2-\vec v_1 ) } \]

Impulsul forței

\[ \boxed{ \vec I_F = \vec F_{\mathrm{med}} \Delta t } \]

Teorema variației impulsului

\[ \boxed{ \Delta\vec p = \vec I_F } \]

Forța medie

\[ \boxed{ \vec F_{\mathrm{med}} = \frac{ \Delta\vec p }{ \Delta t } } \]

Unitatea impulsului mecanic

\[ \boxed{ [p] = \mathrm{kg\,m/s} } \]

Echivalența unităților

\[ \boxed{ 1\,\mathrm{N\,s} = 1\,\mathrm{kg\,m/s} } \]

Impuls mecanic

\[ \vec p=m\vec v \]

Caracterizează starea de mișcare.

Impulsul forței

\[ \vec I_F = \vec F_{\mathrm{med}}\Delta t \]

Caracterizează acțiunea forței într-un interval.

\(\vec p_1\) + \(\vec I_F\) → \(\vec p_2\)

O formă foarte utilă

Din:

\[ \Delta\vec p= \vec I_F \]

rezultă:

\[ \boxed{ \vec p_2 = \vec p_1+ \vec I_F }. \]

Greșeli de evitat

  • nu confunda impulsul mecanic cu impulsul forței;
  • nu confunda impulsul mecanic cu energia cinetică;
  • impulsul mecanic este vectorial;
  • la mișcarea unidimensională folosește semne pentru sens;
  • variația se calculează final minus inițial;
  • la schimbarea sensului nu utiliza doar modulele vitezelor;
  • pentru aceeași \(|\Delta p|\), un timp mai mare înseamnă o forță medie mai mică.

Algoritm pentru probleme

  1. alege axa și sensul pozitiv;
  2. scrie vitezele cu semn;
  3. calculează \(p_1=mv_1\);
  4. calculează \(p_2=mv_2\) sau impulsul forței;
  5. aplică \(\Delta p=p_2-p_1\);
  6. utilizează \(\Delta p=F_{\mathrm{med}}\Delta t\);
  7. interpretează semnul rezultatului.

Urmează: impulsul unui sistem de corpuri

Până acum am studiat impulsul unui singur corp:
