Lecția 56 • Clasa a IX-a

Debitul. Ecuația de continuitate

Câtă apă trece printr-o conductă într-o secundă? De ce fluidul se deplasează mai repede într-o porțiune îngustă a aceleiași conducte? Răspunsul pornește de la conservarea masei.

🎯 Ce vei învăța

La final vei putea:

  • să definești debitul volumic;
  • să definești debitul masic;
  • să utilizezi unitățile SI pentru debit;
  • să deduci relația \(Q_v=Sv_{\text{med}}\);
  • să formulezi principiul continuității curgerii;
  • să utilizezi relația \(S_1v_1=S_2v_2\) pentru un fluid incompresibil;
  • să explici de ce viteza crește într-o secțiune mai îngustă;
  • să rezolvi probleme simple de debit și continuitate.

Ideea centrală

Într-o conductă fără ramificații, fluidul nu poate dispărea și nici nu poate apărea din nimic.

Pentru o curgere staționară, masa care intră într-o porțiune a conductei într-un interval de timp este egală cu masa care iese.

\[ \boxed{ \text{conservarea masei} } \]

Din această idee rezultă ecuația de continuitate.

🚿 Situație-problemă

Apa curge printr-un furtun. Strângem parțial capătul furtunului, micșorând secțiunea de ieșire.

Jetul care iese poate avea o viteză mai mare.

Întrebări:

De ce crește viteza într-o secțiune mai mică?

Se „produce” mai multă apă în partea îngustă?

Ce mărime trebuie să rămână aceeași într-o curgere staționară printr-o conductă fără ramificații?

1. Debitul volumic

Considerăm că printr-o secțiune a unei conducte trece volumul de fluid \(\Delta V\) în intervalul de timp \(\Delta t\).

Debitul volumic reprezintă volumul de fluid care traversează o secțiune în unitatea de timp.
\[ \boxed{ Q_v= \frac{\Delta V}{\Delta t} } \]

Într-o situație în care debitul este constant, putem scrie simplificat:

\[ \boxed{ Q_v= \frac{V}{t} } \]

2. Unitatea debitului volumic

Din definiție:
\[ [Q_v] = \frac{[V]}{[t]} \]
În Sistemul Internațional:
\[ \boxed{ [Q_v] = \mathrm{m^3/s} } \]

În aplicații sunt utilizate frecvent și:

Unitate Conversie
\(\mathrm{L/s}\) \[ 1\,\mathrm{L/s} = 10^{-3}\,\mathrm{m^3/s} \]
\(\mathrm{L/min}\) \[ 1\,\mathrm{L/min} = \frac{10^{-3}}{60}\,\mathrm{m^3/s} \]
\(\mathrm{m^3/h}\) \[ 1\,\mathrm{m^3/h} = \frac1{3600}\,\mathrm{m^3/s} \]

🧮 Exemplul 1 – Umplerea unui recipient

Un robinet umple un recipient cu:

\[ V=12\,\mathrm L \]
în:
\[ t=30\,\mathrm s \]
Debitul volumic este:
\[ Q_v= \frac{V}{t} \]
\[ Q_v= \frac{12}{30} = 0,40\,\mathrm{L/s} \]
În SI:
\[ 0,40\,\mathrm{L/s} = 0,40\cdot10^{-3}\,\mathrm{m^3/s} \]
\[ \boxed{ Q_v= 4,0\cdot10^{-4}\,\mathrm{m^3/s} } \]

3. Legătura dintre debit, secțiune și viteză

\(v_{\text{med}}\)
secțiunea \(S\)
în timpul \(\Delta t\), volumul transportat este \(\Delta V=S\,v_{\text{med}}\Delta t\)

Considerăm o conductă de secțiune constantă \(S\).

În intervalul \(\Delta t\), fluidul avansează în medie cu:

\[ \Delta x= v_{\text{med}}\Delta t \]
Volumul care traversează secțiunea este:
\[ \Delta V= S\Delta x \]
deci:
\[ \Delta V= Sv_{\text{med}}\Delta t \]
Împărțind la \(\Delta t\):
\[ \boxed{ Q_v= Sv_{\text{med}} } \]

4. De ce scriem \(v_{\text{med}}\)?

Într-un model foarte simplificat, putem reprezenta viteza ca fiind aceeași în întreaga secțiune.

Într-o conductă reală însă, viteza poate varia de la un punct la altul al secțiunii.

Relația: \[ \boxed{ Q_v= Sv_{\text{med}} } \] utilizează viteza medie pe secțiune.
Nu trebuie interpretat automat: \[ Q_v=Sv \] ca și cum fiecare particulă a fluidului ar avea exact aceeași viteză. Pentru problemele elementare, \(v\) reprezintă de regulă viteza medie a curgerii în secțiunea respectivă.

5. Verificarea dimensională

Din:
\[ Q_v=Sv \]
avem:
\[ [S] = \mathrm{m^2} \] și: \[ [v] = \mathrm{m/s} \]
Prin urmare:
\[ [Q_v] = \mathrm{m^2} \cdot \mathrm{\frac{m}{s}} \]
adică:
\[ \boxed{ [Q_v] = \mathrm{m^3/s} } \]
Verificarea unităților este o metodă rapidă pentru detectarea multor erori de calcul.

6. Debitul masic

Putem caracteriza curgerea nu numai prin volumul transportat, ci și prin masa transportată în unitatea de timp.

Debitul masic este masa de fluid care traversează o secțiune în unitatea de timp.
\[ \boxed{ Q_m= \frac{\Delta m}{\Delta t} } \]
Unitatea SI este:
\[ \boxed{ [Q_m] = \mathrm{kg/s} } \]
Dacă fluidul are densitatea \(\rho\):
\[ \Delta m= \rho\Delta V \]
deci:
\[ Q_m = \rho \frac{\Delta V}{\Delta t} \]
Prin urmare:
\[ \boxed{ Q_m= \rho Q_v } \]
și, folosind \(Q_v=Sv_{\text{med}}\):
\[ \boxed{ Q_m= \rho Sv_{\text{med}} } \]

🧮 Exemplul 2 – Debitul masic al apei

Prin conductă curge apă cu debitul volumic:

\[ Q_v= 2,5\,\mathrm{L/s} \]
Pentru apă:
\[ \rho= 1000\,\mathrm{kg/m^3} \]
Transformăm debitul:
\[ 2,5\,\mathrm{L/s} = 2,5\cdot10^{-3}\,\mathrm{m^3/s} \]
Aplicăm:
\[ Q_m= \rho Q_v \]
\[ Q_m= 1000 \cdot 2,5\cdot10^{-3} \]
\[ \boxed{ Q_m= 2,5\,\mathrm{kg/s} } \]

7. Conservarea masei într-o conductă

Considerăm o curgere staționară printr-o conductă fără ramificații.

Într-un anumit interval de timp, masa care intră în conductă trebuie să fie egală cu masa care iese.

\[ \boxed{ \Delta m_1= \Delta m_2 } \]
Împărțind la același interval de timp:
\[ \boxed{ Q_{m1} = Q_{m2} } \]
Ecuația de continuitate este o expresie a conservării masei pentru fluidul aflat în curgere.

8. Ecuația de continuitate

Pentru fiecare secțiune:
\[ Q_m= \rho Sv \]
Conservarea debitului masic impune:
\[ \boxed{ \rho_1S_1v_1 = \rho_2S_2v_2 } \]
Aceasta este forma utilă atunci când densitatea poate fi diferită în cele două secțiuni.

Pentru un fluid ideal incompresibil:

\[ \rho_1=\rho_2 \]
Densitatea se simplifică și obținem:
\[ \boxed{ S_1v_1= S_2v_2 } \]
sau:
\[ \boxed{ Q_v= Sv= \text{constant} } \]

9. Ce se întâmplă într-o porțiune îngustă?

\(S_1,\;v_1\)
\(S_2,\;v_2\)
\(S_1>S_2 \Rightarrow v_2>v_1\)
Pentru fluid incompresibil:
\[ S_1v_1= S_2v_2 \]
Dacă:
\[ S_2 atunci:
\[ \boxed{ v_2>v_1 } \]
Într-o secțiune mai îngustă, viteza medie a fluidului trebuie să fie mai mare pentru ca același debit volumic să fie transportat.

10. Relația dintre viteză și secțiune

Din:
\[ Sv= Q_v = \text{constant} \]
rezultă:
\[ \boxed{ v\sim\frac1S } \]

Dacă \(S\) se înjumătățește

\[ S_2= \frac{S_1}{2} \]
atunci:
\[ v_2= 2v_1 \]

Dacă \(S\) devine de 3 ori mai mică

\[ S_2= \frac{S_1}{3} \]
atunci:
\[ v_2= 3v_1 \]

Dacă \(S\) se dublează

\[ S_2= 2S_1 \]
atunci:
\[ v_2= \frac{v_1}{2} \]

🧮 Exemplul 3 – Conductă cu secțiune variabilă

Apa curge printr-o conductă. În secțiunea 1:

\[ S_1= 40\,\mathrm{cm^2} \] \[ v_1= 1,5\,\mathrm{m/s} \]
În secțiunea 2:
\[ S_2= 10\,\mathrm{cm^2} \]
Determinăm \(v_2\).

Aplicăm:
\[ S_1v_1= S_2v_2 \]
de unde:
\[ v_2= \frac{S_1v_1}{S_2} \]
Înlocuim:
\[ v_2= \frac{ 40\cdot1,5 }{ 10 } \]
\[ \boxed{ v_2= 6\,\mathrm{m/s} } \]
Nu este nevoie să transformăm ariile din \(\mathrm{cm^2}\) în \(\mathrm{m^2}\) atunci când ele apar numai într-un raport și sunt exprimate în aceeași unitate.

🧮 Exemplul 4 – Determinarea debitului

O conductă are secțiunea:

\[ S= 25\,\mathrm{cm^2} \]
iar viteza medie a apei este:
\[ v= 2\,\mathrm{m/s} \]
Transformăm aria:
\[ 25\,\mathrm{cm^2} = 25\cdot10^{-4}\,\mathrm{m^2} \]
\[ S= 2,5\cdot10^{-3}\,\mathrm{m^2} \]
Aplicăm:
\[ Q_v= Sv \]
\[ Q_v= 2,5\cdot10^{-3} \cdot 2 \]
\[ \boxed{ Q_v= 5,0\cdot10^{-3}\,\mathrm{m^3/s} } \]
adică:
\[ \boxed{ Q_v= 5\,\mathrm{L/s} } \]

11. Dacă problema oferă diametrul conductei

Pentru o conductă circulară:
\[ S= \pi r^2 \]
Cum:
\[ r= \frac D2 \]
rezultă:
\[ \boxed{ S= \frac{\pi D^2}{4} } \]
Ecuația de continuitate devine:
\[ \frac{\pi D_1^2}{4}v_1 = \frac{\pi D_2^2}{4}v_2 \]
Simplificăm:
\[ \boxed{ D_1^2v_1 = D_2^2v_2 } \]
Atenție: viteza nu este invers proporțională cu diametrul, ci cu pătratul diametrului pentru o conductă circulară: \[ v\sim\frac1{D^2} \]

🧮 Exemplul 5 – Diametrul se înjumătățește

Dacă:
\[ D_2= \frac{D_1}{2} \]
atunci:
\[ S_2= \frac{\pi D_2^2}{4} \]
și:
\[ S_2= \frac{S_1}{4} \]
Din continuitate:
\[ S_1v_1= S_2v_2 \]
deci:
\[ v_2= 4v_1 \]
\[ \boxed{ D\rightarrow\frac D2 \quad\Rightarrow\quad v\rightarrow4v } \]

12. Ce presupune ecuația simplă de continuitate?

Pentru relația:
\[ \boxed{ S_1v_1= S_2v_2 } \]
folosim un model în care:
  • curgerea este staționară;
  • conducta nu are ramificații între secțiunile analizate;
  • fluidul este incompresibil;
  • nu există acumulare de fluid între cele două secțiuni;
  • \(v_1\) și \(v_2\) reprezintă viteze medii pe secțiuni.
Pentru situații mai generale, conservarea masei rămâne principiul fundamental, dar forma matematică poate fi mai complexă.

13. Ce NU ne spune ecuația de continuitate?

Ecuația:
\[ S_1v_1= S_2v_2 \]
ne spune cum sunt legate secțiunea și viteza prin conservarea masei.

Ea nu determină singură:

  • presiunea fluidului;
  • energia pe unitatea de volum;
  • efectele diferențelor de înălțime;
  • pierderile prin vâscozitate.
Legătura dintre presiune, viteză și înălțime va fi studiată separat prin legea lui Bernoulli.

14. Unde întâlnim debitul?

🚰 Alimentarea cu apă

Consumul și transportul apei sunt descrise frecvent prin debite volumice.

🌊 Râuri

Debitul unui râu exprimă volumul de apă transportat pe unitatea de timp.

🏭 Instalații industriale

Conductele transportă lichide și gaze la debite controlate.

💨 Ventilație

Debitul volumic al aerului este important în sistemele de ventilație.

❤️ Circulația sângelui

Mișcarea sângelui poate fi analizată folosind concepte de mecanica fluidelor, cu limitele specifice unui sistem biologic real.

⛽ Alimentare și transport

Debitul poate fi monitorizat în instalațiile care transportă fluide.

Principiu

Măsurăm volumul colectat \(V\) într-un timp \(t\).

\[ \boxed{ Q_v= \frac Vt } \]
  1. Alege un interval de timp convenabil.
  2. Colectează fluidul într-un recipient gradat.
  3. Măsoară volumul.
  4. Notează timpul.
  5. Calculează raportul \(V/t\).
  6. Repetă măsurarea pentru a reduce influența erorilor aleatoare.

16. Algoritm pentru probleme

  1. Identifică mărimea cerută.

    Debit, viteză, secțiune sau timp?

  2. Transformă unitățile.
    \[ 1\,\mathrm L = 10^{-3}\,\mathrm{m^3} \] \[ 1\,\mathrm{cm^2} = 10^{-4}\,\mathrm{m^2} \]
  3. Pentru debit măsurat direct:
    \[ Q_v= \frac Vt \]
  4. Pentru o secțiune cunoscută:
    \[ Q_v= Sv \]
  5. Pentru două secțiuni ale aceleiași curgeri incompresibile:
    \[ S_1v_1= S_2v_2 \]
  6. Dacă sunt date diametrele:
    \[ S= \frac{\pi D^2}{4} \]
  7. Verifică sensul fizic.

    Secțiune mai mică \(\Rightarrow\) viteză mai mare, pentru același debit.

⚠️ Greșeli frecvente

1. Confuzia dintre volum și debit

Volumul se măsoară în:

\[ \mathrm{m^3} \]
Debitul volumic în:
\[ \mathrm{m^3/s} \]

2. Confuzia dintre debit și viteză

Debitul nu este viteza fluidului.

\[ Q_v= Sv \]

3. Uitarea conversiei \(L\rightarrow m^3\)

\[ 1\,L= 10^{-3}\,m^3 \]

4. Uitarea conversiei \(cm^2\rightarrow m^2\)

\[ 1\,cm^2= 10^{-4}\,m^2 \]

5. „Secțiune mai mică → viteză mai mică.”

Pentru același debit este invers:

\[ S\downarrow \Rightarrow v\uparrow \]

6. Confuzia dintre diametru și arie

Pentru o conductă circulară:

\[ S\sim D^2 \]

7. „Continuitatea conservă viteza.”

Nu.

Pentru fluid incompresibil se conservă debitul volumic:

\[ Sv= \text{constant} \]

8. „Ecuația de continuitate spune cum se schimbă presiunea.”

Nu direct. Ea exprimă conservarea masei.

Presiunea va fi legată de mișcare în lecția despre Bernoulli.

📌 De reținut

Debitul volumic

\[ \boxed{ Q_v= \frac{\Delta V}{\Delta t} } \]

Debit și viteză

\[ \boxed{ Q_v= Sv_{\text{med}} } \]

Debitul masic

\[ \boxed{ Q_m= \frac{\Delta m}{\Delta t} = \rho Q_v } \]

Continuitate generală

\[ \boxed{ \rho_1S_1v_1 = \rho_2S_2v_2 } \]

Fluid incompresibil

\[ \boxed{ S_1v_1= S_2v_2 } \]

Consecință

\[ \boxed{ S\downarrow \Rightarrow v\uparrow } \]

pentru același debit.

Ideea esențială: ecuația de continuitate este consecința conservării masei. Pentru un fluid incompresibil aflat în curgere staționară: \[ \boxed{ Q_v= S_1v_1= S_2v_2= \text{constant} } \] Prin urmare, o secțiune mai mică presupune o viteză medie mai mare.
