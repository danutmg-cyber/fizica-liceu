Două fire sunt trase cu aceeași forță. Se solicită la fel?

Imaginează-ți două fire realizate din același material.

Unul este gros, celălalt foarte subțire.

Aplicăm aceeași forță de întindere ambelor fire.

Firul subțire este mai intens solicitat, deși forța este aceeași.

Tensiunea în fir

Este o forță.

Simbol: \(T\)

Unitate: \(\mathrm N\)

Efortul unitar

Compară forța cu aria secțiunii transversale.

Simbol: \(\sigma\)

Unitate: \(\mathrm{Pa}\)

Deformația relativă

Compară modificarea lungimii cu lungimea inițială.

Simbol: \(\varepsilon\)

Este adimensională.

Atenție la terminologie

În această lecție, tensiunea în fir \(T\) și efortul unitar \(\sigma\) sunt mărimi fizice diferite.

\[ T \quad\text{se măsoară în N}, \]

în timp ce:

\[ \sigma \quad\text{se măsoară în Pa}. \]

La final vei putea:

  • să reprezinți tensiunea într-un fir ideal;
  • să aplici principiul fundamental unui corp legat de un fir;
  • să calculezi efortul unitar;
  • să calculezi deformația relativă;
  • să utilizezi forma \(\sigma=E\varepsilon\) a legii lui Hooke;
  • să explici diferența dintre constanta elastică \(k\) și modulul lui Young \(E\);
  • să pregătești experimentul pentru determinarea lui \(k\).

1. Tensiunea în fir

Un fir întins exercită forțe asupra corpurilor de care este legat

Tensiunea în fir

Tensiunea este forța exercitată de un fir întins asupra corpului de care este legat.

Vectorul tensiune este orientat de-a lungul firului.

Un fir flexibil poate trage, nu poate împinge

Tensiunea apare când firul este întins.

Dacă firul devine complet destins, tensiunea poate deveni:

\[ T=0. \]

Cazul corpului suspendat în repaus

Dacă obiectul este în echilibru:

\[ a=0. \]

Pe verticală:

\[ T-mg=0. \]

Deci:

\[ \boxed{ T=mg } \]

numai pentru această situație de echilibru.

\(T=mg\) nu este o lege generală

Dacă obiectul accelerează, tensiunea și greutatea nu mai sunt în general egale.

Corp care accelerează în sus

Alegem sensul pozitiv în sus:

\[ T-mg=ma. \] \[ \boxed{ T=m(g+a) }. \]

Corp care accelerează în jos

Dacă modulul accelerației în jos este \(a\):

\[ mg-T=ma. \] \[ \boxed{ T=m(g-a) }. \]

Un corp de \(2\,\mathrm{kg}\) este suspendat în repaus de un fir. Pentru \(g=10\,\mathrm{m/s^2}\), determină tensiunea.

2. Modelul firului ideal

Când putem considera tensiunea aceeași de-a lungul firului?

În multe probleme de clasa a IX-a folosim modelul unui fir ideal.

Masă neglijabilă

Masa firului este considerată mult mai mică decât masele corpurilor din problemă.

Inextensibil

Lungimea firului este considerată constantă.

Flexibil

Firul poate schimba direcția, de exemplu peste un scripete ideal.

Într-un fir ideal întins

În situațiile uzuale studiate aici, modulul tensiunii este același de-a lungul firului:

\[ \boxed{ T_1=T_2=T }. \]

Acțiune și reacțiune

Firul trage corpul A, iar corpul A trage firul.

Aceste două forțe formează o pereche acțiune–reacțiune.

La fel pentru corpul B și fir.

Într-un fir real

Dacă masa firului nu poate fi neglijată sau dacă există alte efecte importante, tensiunea poate să nu fie aceeași în toate punctele.

Egalitatea tensiunilor este o proprietate a modelului ideal folosit în probleme.

3. Efortul unitar

Aceeași forță poate solicita diferit două fire

Considerăm un fir sau o bară solicitată longitudinal de o forță de modul \(F\).

Secțiunea transversală are aria:

\[ S. \]

Efortul unitar

\[ \boxed{ \sigma= \frac{F}{S} } \]

Unitatea de măsură

\[ [\sigma] = \frac{\mathrm N}{\mathrm{m^2}}. \]

Această unitate se numește:

\[ \boxed{ 1\,\mathrm{Pa} = 1\,\mathrm{N/m^2} } \]

Exemplu comparativ

Firul A

\[ F= 100\,\mathrm N \] \[ S_A= 2\,\mathrm{mm^2} \]

Firul B

\[ F= 100\,\mathrm N \] \[ S_B= 1\,\mathrm{mm^2} \]

Deoarece:

\[ 1\,\mathrm{mm^2} = 10^{-6}\,\mathrm{m^2}, \]

pentru firul A:

\[ \sigma_A= \frac{100}{ 2\cdot10^{-6} } = 5\cdot10^7\,\mathrm{Pa}. \] \[ \boxed{ \sigma_A= 50\,\mathrm{MPa} }. \]

Pentru firul B:

\[ \sigma_B= \frac{100}{ 1\cdot10^{-6} } = 10^8\,\mathrm{Pa}. \] \[ \boxed{ \sigma_B= 100\,\mathrm{MPa} }. \]

Concluzie

La aceeași forță, o secțiune mai mică conduce la un efort unitar mai mare.

\[ \sigma= \frac{F}{S}. \]

Nu confunda tensiunea în fir cu efortul unitar

\[ T \quad\rightarrow\quad \mathrm N \]

în timp ce:

\[ \sigma \quad\rightarrow\quad \mathrm{Pa}. \]

Pentru un fir real întins, forța internă longitudinală poate fi legată de tensiunea \(T\), iar efortul unitar se estimează prin:

\[ \sigma= \frac{T}{S}. \]

O forță de \(100\,\mathrm N\) solicită un fir cu aria secțiunii \(2\,\mathrm{mm^2}\). Determină efortul unitar în MPa.

4. Deformația relativă

O alungire de 1 mm înseamnă același lucru pentru orice fir?

Nu.

O alungire de \(1\,\mathrm{mm}\) este importantă diferit pentru:

  • un fir de \(10\,\mathrm{mm}\);
  • un fir de \(1\,\mathrm m\).

Pentru a compara deformări ale corpurilor cu lungimi inițiale diferite folosim deformația relativă.

Deformația relativă

\[ \boxed{ \varepsilon= \frac{\Delta l}{l_0} } \]

Deoarece este raportul dintre două lungimi:

\[ [\varepsilon]=1. \]

Deformația relativă este adimensională.

Exemplu

Un fir are lungimea inițială:

\[ l_0= 2{,}00\,\mathrm m. \]

Se alungește cu:

\[ \Delta l= 2\,\mathrm{mm} = 0{,}002\,\mathrm m. \]

Deformația relativă:

\[ \varepsilon= \frac{0{,}002}{2{,}00}. \] \[ \boxed{ \varepsilon= 0{,}001 }. \]

Exprimare procentuală

Putem scrie:

\[ \varepsilon\cdot100\% = 0{,}1\%. \]

Interpretare

O deformație relativă:

\[ \varepsilon= 0{,}001 \]

înseamnă că variația lungimii reprezintă:

\[ 0{,}1\% \]

din lungimea inițială.

Deformație absolută

\[ \Delta l= l-l_0 \]

Unitate: m

Deformație relativă

\[ \varepsilon= \frac{\Delta l}{l_0} \]

Fără unitate.

Un fir de \(1{,}5\,\mathrm m\) se alungește cu \(3\,\mathrm{mm}\). Determină deformația relativă.

5. Efort – deformație

Forma legii lui Hooke pentru un fir sau o bară

Am definit:

\[ \sigma= \frac{F}{S} \]

și:

\[ \varepsilon= \frac{\Delta l}{l_0}. \]

În domeniul elastic liniar, pentru un material dat, efortul unitar este proporțional cu deformația relativă:

\[ \boxed{ \sigma= E\varepsilon } \]

Constanta:

\[ E \]

se numește modul longitudinal de elasticitate sau modulul lui Young.

\[ \boxed{ E= \frac{\sigma}{\varepsilon} } \]

Unitatea lui \(E\)

Deoarece \(\varepsilon\) este adimensională:

\[ [E]=[\sigma]. \] \[ \boxed{ [E]= \mathrm{Pa} }. \]

Semnificație

În domeniul liniar, un material cu \(E\) mai mare se deformează relativ mai puțin pentru același efort unitar.

Legătura cu \(F=k\Delta l\)

Înlocuim:

\[ \sigma= \frac{F}{S}, \qquad \varepsilon= \frac{\Delta l}{l_0} \] în: \[ \sigma= E\varepsilon. \]

Obținem:

\[ \frac{F}{S} = E \frac{\Delta l}{l_0}. \]

Deci:

\[ F= \frac{ES}{l_0} \Delta l. \]

Comparăm cu:

\[ F= k\Delta l. \]
\[ \boxed{ k= \frac{ES}{l_0} } \]

\(E\) – proprietate de material

Caracterizează răspunsul elastic longitudinal al materialului, în modelul studiat.

Unitate: \(\mathrm{Pa}\).

\(k\) – proprietate a corpului elastic

Depinde de material, dar și de geometria corpului.

Unitate: \(\mathrm{N/m}\).

\(E\) și \(k\) nu sunt aceeași mărime

\[ E \quad\text{se măsoară în Pa}, \]

iar:

\[ k \quad\text{se măsoară în N/m}. \]

Pentru un material, \(\sigma=200\,\mathrm{MPa}\) produce \(\varepsilon=0{,}002\). Determină \(E\) în GPa.

6. Explorează

Cum influențează forța, secțiunea, lungimea și materialul deformarea?

Simulatorul modelează un fir sau o bară solicitată longitudinal în domeniul elastic liniar.

Modifică parametrii și urmărește:

\[ \sigma, \qquad \varepsilon, \qquad \Delta l, \qquad k. \]
\(\sigma=F/S\) 100,0 MPa
\(\varepsilon=\sigma/E\) 0,001000
\(\Delta l=\varepsilon l_0\) 1,000 mm
\(k=ES/l_0\) 200000 N/m
Mărirea forței mărește efortul unitar și deformarea.

Experimentează

A. Dublează forța

Menține \(S\), \(l_0\) și \(E\) constante.

Observă cum se modifică \(\sigma\) și \(\Delta l\).

B. Mărește secțiunea

Pentru aceeași forță, observă scăderea efortului unitar.

C. Mărește lungimea

Pentru aceeași forță, secțiune și material, deformarea absolută crește.

D. Mărește \(E\)

Pentru același efort unitar, deformația relativă scade.

\[ \boxed{ \Delta l= \frac{Fl_0}{ES} } \]

Ce arată relația?

\[ \Delta l \sim F, \] \[ \Delta l \sim l_0, \] \[ \Delta l \sim \frac{1}{S}, \] \[ \Delta l \sim \frac{1}{E}. \]

Legătura cu experimentul următor

Pentru un corp elastic dat:

\[ F=k\Delta l. \]

Dacă măsurăm mai multe perechi:

\[ (F,\Delta l), \]

putem determina \(k\) din raportul:

\[ k= \frac{F}{\Delta l} \]

sau din panta graficului \(F(\Delta l)\).

Sinteză

Ce trebuie să reții

Tensiunea în fir

Este o forță orientată de-a lungul firului.

\[ [T]=\mathrm N \]

Efortul unitar

\[ \boxed{ \sigma= \frac{F}{S} } \] \[ [\sigma]=\mathrm{Pa} \]

Deformația absolută

\[ \boxed{ \Delta l= l-l_0 } \]

Deformația relativă

\[ \boxed{ \varepsilon= \frac{\Delta l}{l_0} } \]

Adimensională.

Legea lui Hooke

\[ \boxed{ \sigma= E\varepsilon } \]

Modulul lui Young

\[ \boxed{ E= \frac{\sigma}{\varepsilon} } \] \[ [E]=\mathrm{Pa} \]

Legătura cu \(k\)

\[ \boxed{ k= \frac{ES}{l_0} } \]

Alungirea

\[ \boxed{ \Delta l= \frac{Fl_0}{ES} } \]

\(T\)

Tensiune în fir.

Este o forță.

\[ [T]=\mathrm N \]

\(\sigma\)

Efort unitar.

Forță raportată la suprafață.

\[ [\sigma]=\mathrm{Pa} \]

\(\varepsilon\)

Deformație relativă.

Raport dintre două lungimi.

\[ [\varepsilon]=1 \]
forță \(F\) → \(\sigma=F/S\) → \(\sigma=E\varepsilon\) → \(\varepsilon=\Delta l/l_0\) → deformare \(\Delta l\)

Algoritm pentru probleme

  1. identifică forța care solicită firul sau bara;
  2. transformă aria secțiunii în \(\mathrm{m^2}\);
  3. calculează \(\sigma=F/S\);
  4. transformă alungirea și lungimea inițială în aceleași unități;
  5. calculează \(\varepsilon=\Delta l/l_0\);
  6. dacă materialul se află în domeniul elastic liniar, folosește \(\sigma=E\varepsilon\).

Două conversii care produc frecvent erori

\[ 1\,\mathrm{mm} = 10^{-3}\,\mathrm m \]

dar:

\[ 1\,\mathrm{mm^2} = 10^{-6}\,\mathrm{m^2}. \]

Nu transforma o arie ca pe o lungime.

Urmează experimentul

În Lecția 30 vei determina experimental constanta elastică a unui resort.

Vei măsura mai multe perechi:

\[ F,\quad \Delta l \]

și vei verifica relația:

\[ \boxed{ F=k\Delta l }. \]
