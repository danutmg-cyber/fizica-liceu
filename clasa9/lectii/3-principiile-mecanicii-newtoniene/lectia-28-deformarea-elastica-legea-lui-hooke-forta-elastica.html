De ce revine un resort la forma inițială?

Tragem ușor de un resort și îl eliberăm.

Resortul tinde să revină la lungimea inițială.

În timpul deformării apare o forță elastică orientată astfel încât să reducă deformarea.

Deformare elastică

După încetarea acțiunii deformatoare, corpul revine la forma și dimensiunile inițiale.

Deformare plastică

După încetarea acțiunii deformatoare, corpul nu revine complet la starea inițială.

Întrebările lecției

Cum măsurăm deformarea unui resort?

1. Deformarea corpurilor

O forță poate modifica forma sau dimensiunile unui corp

Prin deformare înțelegem modificarea formei și/sau a dimensiunilor unui corp sub acțiunea unor forțe.

Întindere

Lungimea corpului crește.

Comprimare

Lungimea corpului scade.

Încovoiere

Axa corpului se curbează.

Răsucire

Diferite secțiuni ale corpului se rotesc relativ.

Elastic sau plastic?

Deformare elastică

Dacă, după îndepărtarea forței deformatoare, corpul revine la forma și dimensiunile inițiale, deformarea este elastică.

Deformare plastică

Dacă rămâne o deformare permanentă după îndepărtarea forței, deformarea este plastică.

Atenție

Același corp poate avea comportare elastică pentru deformări mici și poate suferi deformări permanente dacă solicitarea devine prea mare.

2. Legea lui Hooke

Cum depinde forța elastică de deformare?

Pentru deformări suficient de mici ale unui resort ideal, experimentul arată că modulul forței elastice este proporțional cu modulul deformării.

Legea lui Hooke

\[ \boxed{ F_{el} = k|\Delta l| } \]

unde \(F_{el}\) reprezintă modulul forței elastice.

Constanta elastică

Mărimea:

\[ k \]

se numește constanta elastică a resortului.

\[ \boxed{ k= \frac{F_{el}}{|\Delta l|} } \]

Unitatea de măsură

\[ [k] = \frac{\mathrm N}{\mathrm m}. \]
\[ \boxed{ [k]_{\mathrm{SI}} = \mathrm{N/m} } \]

\(k\) mare

Resort mai rigid.

Este necesară o forță mai mare pentru aceeași deformare.

\(k\) mic

Resort mai puțin rigid.

Aceeași forță produce o deformare mai mare.

Legea lui Hooke are un domeniu de valabilitate

Faptul că un corp este elastic nu înseamnă că relația \(F_{el}=k|\Delta l|\) este valabilă pentru orice deformare.

Relația liniară se utilizează în domeniul de comportare hookeană.

Un resort se alungește cu \(0{,}05\,\mathrm m\) sub acțiunea unei forțe elastice de modul \(10\,\mathrm N\). Determină \(k\).

3. Forța elastică

Forța elastică se opune deformării

Să alegem o axă \(Ox\) și să notăm cu \(x\) deplasarea capătului resortului față de poziția nedeformată.

Dacă resortul este întins spre dreapta:

\[ x>0, \]

iar forța elastică este orientată spre stânga.

Dacă resortul este comprimat spre stânga:

\[ x<0, \]

forța elastică este orientată spre dreapta.

Forma algebrică pe axa resortului

\[ \boxed{ F_{el,x} = -kx } \]

Semnificația semnului minus

Semnul minus nu înseamnă că modulul forței este negativ.

El arată că forța elastică este orientată în sens opus deformării.

Modul

\[ F_{el} = k|x| \]

Componentă pe axă

\[ F_{el,x} = -kx \]

4. Reprezentarea grafică

Forța este proporțională cu deformarea

Pentru modulul deformării:

\[ F_{el}=k|\Delta l|. \]

Panta graficului

Pentru un grafic cu \(F\) pe axa verticală și \(\Delta l\) pe axa orizontală:

\[ k= \frac{\Delta F}{\Delta l}. \]

Panta dreptei reprezintă constanta elastică.

Exemplu dintr-un tabel

\(\Delta l\) (m) \(F\) (N) \(F/\Delta l\) (N/m)
0,01 2 200
0,02 4 200
0,03 6 200
0,04 8 200

Raportul rămâne constant:

\[ \frac{F}{\Delta l} = 200\,\mathrm{N/m}. \]

Deci:

\[ \boxed{ k= 200\,\mathrm{N/m} }. \]

Dacă graficul nu mai este drept

Proporționalitatea simplă dintre forță și deformare nu mai este respectată.

Nu mai putem folosi aceeași constantă \(k\) pentru întreaga zonă respectivă.

Un punct de pe grafic are coordonatele \(\Delta l=0{,}02\,\mathrm m\) și \(F=6\,\mathrm N\). Determină \(k\).

5. Explorează

Corp suspendat de un resort vertical

Suspendăm un corp de un resort vertical și așteptăm până când corpul ajunge în repaus.

În poziția de echilibru:

\[ F_{el}=G. \]
\(G=mg\) 5,00 N
\(\Delta l=mg/k\) 0,050 m
\(F_{el}\) 5,00 N
\(\sum F_y\) 0 N
În echilibru, forța elastică și greutatea au module egale și sensuri opuse.

Echilibru static

\[ F_{el}-G=0. \] \[ k\Delta l=mg. \] \[ \boxed{ \Delta l= \frac{mg}{k} }. \]

Atenție

Relația de mai sus descrie poziția de echilibru static.

Dacă masa este eliberată și oscilează, în alte poziții rezultanta forțelor nu mai este nulă.

Un corp de \(1\,\mathrm{kg}\) este suspendat de un resort cu \(k=100\,\mathrm{N/m}\). Pentru \(g=10\,\mathrm{m/s^2}\), determină alungirea de echilibru.

6. Aplicații și pregătire experimentală

Aplică legea lui Hooke

Aplicația 1

Un resort are:

\[ k= 250\,\mathrm{N/m}. \]

Este alungit cu:

\[ \Delta l= 4\,\mathrm{cm} = 0{,}04\,\mathrm m. \]

Modulul forței elastice:

\[ F_{el} = k\Delta l. \] \[ F_{el} = 250\cdot0{,}04. \] \[ \boxed{ F_{el} = 10\,\mathrm N }. \]
Aplicația 2

O forță de:

\[ F= 6\,\mathrm N \]

produce o alungire:

\[ \Delta l= 3\,\mathrm{cm} = 0{,}03\,\mathrm m. \]

Constanta elastică:

\[ k= \frac{6}{0{,}03}. \] \[ \boxed{ k= 200\,\mathrm{N/m} }. \]

Observație demonstrativă la clasă

1. Montaj Fixează vertical un resort și așază alături o riglă.
2. Măsurare inițială Măsoară lungimea nedeformată \(l_0\).
3. Acțiune Suspendă o masă cunoscută.
4. Măsurare După stabilirea echilibrului, măsoară noua lungime \(l\).
5. Tabel Notează \(m\), \(F=mg\), \(l\) și \(\Delta l=l-l_0\).
6. Repetare Adaugă o altă masă și repetă măsurarea.
7. Calcul Calculează: \[ k= \frac{F}{\Delta l}. \]
8. Concluzie Compară valorile lui \(k\).

Ce vom verifica ulterior experimental?

Dacă, pentru același resort și în domeniul hookean:

\[ \frac{F}{\Delta l} \approx \text{constant}. \]

Această constantă este \(k\).

Nu supraîncărca resortul

Masele trebuie adăugate progresiv.

Dacă deformarea devine permanentă, resortul nu mai este în regimul elastic studiat.

Legătura cu lecția următoare

Un resort este doar un exemplu particular de corp deformabil.

În lecția următoare vom introduce mărimi care permit descrierea deformării unui fir sau a unei bare:

\[ \text{efort unitar} \qquad\text{și}\qquad \text{deformație relativă}. \]

Un resort cu \(k=200\,\mathrm{N/m}\) este solicitat de o forță de \(6\,\mathrm N\). Determină alungirea.

Sinteză

Ce trebuie să reții

Deformarea

\[ \boxed{ \Delta l= l-l_0 } \]

Legea lui Hooke

\[ \boxed{ F_{el} = k|\Delta l| } \]

Forța de revenire

\[ \boxed{ F_{el,x} = -kx } \]

Constanta elastică

\[ \boxed{ k= \frac{F_{el}}{|\Delta l|} } \]

Unitatea SI

\[ \boxed{ [k]= \mathrm{N/m} } \]

Resort vertical în echilibru

\[ \boxed{ k\Delta l= mg } \]

Alungirea de echilibru

\[ \boxed{ \Delta l= \frac{mg}{k} } \]

Grafic \(F(\Delta l)\)

\[ \boxed{ k= \frac{\Delta F}{\Delta l} } \]
forță deformatoare → deformare → apare \(F_{el}\) → \(F_{el}=k|\Delta l|\) → revenire

Algoritm pentru probleme

  1. identifică lungimea inițială \(l_0\);
  2. determină deformarea \(\Delta l=l-l_0\);
  3. transformă centimetrii în metri;
  4. folosește \(F_{el}=k|\Delta l|\);
  5. dacă există mai multe forțe, construiește diagrama corpului;
  6. pentru echilibru aplică \(\sum\vec F=\vec0\).

Ideea de rigoare

„Elastic” și „hookean” nu sunt sinonime.

Deformarea elastică înseamnă revenirea corpului la starea inițială.

Legea lui Hooke descrie suplimentar un raport liniar între forță și deformare.
