Cum determinăm experimental \(k\)?

În Lecția 28 am folosit relația:

\[ F=k\Delta l. \]

În această lecție ne pregătim să răspundem experimental la întrebarea:

„Ce valoare are constanta elastică a resortului pe care îl studiez?”

\[ \boxed{ k= \frac{F}{\Delta l} } \]
măsurăm \(l_0\) → suspendăm masa \(m\) → măsurăm \(l\) → calculăm \(\Delta l\) → calculăm \(F=mg\) → determinăm \(k\)

1. Principiul metodei

De la greutatea masei la constanta elastică

Suspendăm o masă de un resort vertical.

După ce oscilațiile s-au redus suficient, corpul se află aproximativ în echilibru static.

Echilibrul masei suspendate

În poziția de echilibru:

\[ F_{el}=G. \]

Cum:

\[ G=mg, \]

rezultă:

\[ F=mg. \]

Relațiile experimentului

\[ \boxed{ F=mg } \] \[ \boxed{ \Delta l=l-l_0 } \] \[ \boxed{ F=k\Delta l } \] \[ \boxed{ k= \frac{F}{\Delta l} } \]

Ce reprezintă lungimile?

\(l_0\)

Lungimea resortului fără masa suspendată.

\(l\)

Lungimea resortului după suspendarea masei și stabilirea echilibrului.

\(\Delta l\)

Alungirea produsă de sarcină:

\[ \Delta l=l-l_0. \]

Greșeala principală

Nu folosim:

\[ k= \frac{F}{l}. \]

Legea lui Hooke utilizează alungirea:

\[ \boxed{ k= \frac{F}{l-l_0} }. \]

4. Citirea riglei

Exersează înainte de laborator

În Experimentul 5 va trebui să citești singur scala riglei.

Diviziunea este:

\[ 0{,}1\,\mathrm{cm}. \]

Ce valoare indică reperul roșu?

cm

Regula de citire

Identifică mai întâi două valori numerotate consecutive.

Apoi stabilește valoarea unei diviziuni și numără diviziunile până la reper.

Evită eroarea de paralaxă

La o riglă reală, privește reperul cât mai perpendicular pe scară.

O privire oblică poate deplasa aparent poziția reperului.

Lungimea trebuie citită în echilibru

Dacă resortul oscilează, capătul său trece succesiv prin mai multe poziții.

Pentru experiment ne interesează lungimea corespunzătoare poziției de echilibru.

Pagina 5 din 9
5. Prelucrarea datelor

Din valorile măsurate la \(k\)

1. Forța

\[ \boxed{ F_i=m_i g } \]

2. Alungirea în cm

\[ \Delta l_i= l_i-l_0 \]

3. Alungirea în metri

\[ \boxed{ \Delta l_i= \frac{ l_i-l_0 }{100} } \]

dacă \(l_i\) și \(l_0\) sunt în cm.

4. Constanta elastică

\[ \boxed{ k_i= \frac{F_i}{ \Delta l_i } } \]

Conversia critică

Dacă:

\[ \Delta l= 4{,}0\,\mathrm{cm}, \]

atunci:

\[ \Delta l= 0{,}040\,\mathrm m. \]

În relația:

\[ k= \frac{F}{\Delta l}, \]

alungirea trebuie introdusă în metri pentru a obține \(k\) în \(\mathrm{N/m}\).

Calculator de antrenament

Valorile de mai jos sunt doar pentru exercițiu. Nu reprezintă setul tău experimental.

\(F=mg\) 1,96 N
\(\Delta l\) 0,040 m
\(k\) 49,0 N/m
\(g=9{,}8\,\mathrm{N/kg}\).

După cele patru determinări

Vei obține:

\[ k_1,\quad k_2,\quad k_3,\quad k_4. \]

Valoarea medie

\[ \boxed{ \overline{k} = \frac{ k_1+k_2+k_3+k_4 }{ 4 } }. \]

Estimarea prin semidispersie

\[ \boxed{ \Delta k= \frac{ k_{\max}-k_{\min} }{ 2 } }. \]

Incertitudinea relativă

\[ \boxed{ u_{\mathrm{rel}} = \frac{ \Delta k }{ \overline{k} } \cdot100\% }. \]

De ce nu sunt toate valorile \(k_i\) identice?

Citirea riglei are o rezoluție finită, masele au toleranțe, reperul nu poate fi citit perfect și resortul poate oscila ușor.

Diferențele mici dintre determinări sunt firești într-un experiment.

Pentru \(m=0{,}20\,\mathrm{kg}\), \(l_0=12{,}0\,\mathrm{cm}\), \(l=16{,}0\,\mathrm{cm}\) și \(g=9{,}8\,\mathrm{N/kg}\), determină \(k\).

N/m

Sinteză

De la legea lui Hooke la experiment

Lungimea inițială

\[ l_0 \]

Se măsoară fără sarcină.

Lungimea sub sarcină

\[ l_i \]

Se măsoară după reducerea oscilațiilor.

Forța

\[ \boxed{ F_i=m_i g } \]

Alungirea

\[ \boxed{ \Delta l_i= l_i-l_0 } \]

Constanta elastică

\[ \boxed{ k_i= \frac{F_i}{ \Delta l_i } } \]

Media

\[ \boxed{ \overline{k} = \frac{ k_1+k_2+k_3+k_4 }{4} } \]

Semidispersia

\[ \boxed{ \Delta k= \frac{ k_{\max}-k_{\min} }{2} } \]

Incertitudinea relativă

\[ \boxed{ u_{\mathrm{rel}} = \frac{ \Delta k }{ \overline{k} } \cdot100\% } \]
montaj → \(l_0\) → masă → echilibru → citire \(l\) → tabel → calcule → concluzie

Trei erori de evitat

1. Nu folosi lungimea totală \(l\) în locul alungirii \(\Delta l\).

2. Nu introduce centimetri direct în \(k=F/\Delta l\) dacă dorești rezultatul în \(\mathrm{N/m}\).

3. Nu citi rigla cât timp resortul oscilează puternic.
