Dinamica mișcării circulare uniforme

Viteză tangentă • Accelerație centripetă • Rezultantă radială

Prof. Dănuț Andronie e-Mail: danutmg@gmail.com

Dacă modulul vitezei este constant, de ce există accelerație?

În mișcarea circulară uniformă, mobilul parcurge o circumferință cu modulul vitezei constant.

Totuși, vectorul viteză își schimbă permanent direcția.

Prin urmare:

\[ \boxed{ \vec a\neq\vec 0 }. \]

Modulul vitezei

\[ v=\text{constant} \]

Direcția vitezei

Se modifică permanent.

Accelerația

Este orientată spre centrul cercului.

traiectorie circulară → direcția lui \(\vec v\) se schimbă → există \(\vec a_c\) → există rezultantă radială

Întrebarea centrală

Ce forță face ca un corp să își schimbe continuu direcția vitezei și să rămână pe o traiectorie circulară?

La final vei putea:

  • să explici de ce mișcarea circulară uniformă este accelerată;
  • să reprezinți viteza și accelerația centripetă;
  • să utilizezi \(a_c=v^2/r\);
  • să utilizezi \(F_c=mv^2/r\);
  • să explici corect sensul expresiei „forță centripetă”;
  • să identifici forța reală care asigură mișcarea circulară;
  • să rezolvi aplicații cu tensiune, frecare și gravitație.

1. Accelerația centripetă

Viteza este tangentă, accelerația este radială

\[ \boxed{ a_c= \frac{v^2}{r} } \]

\(a_c\)

Accelerație centripetă

Unitate: \(\mathrm{m/s^2}\)

\(v\)

Modulul vitezei

Unitate: \(\mathrm{m/s}\)

\(r\)

Raza cercului

Unitate: \(\mathrm m\)

Direcția accelerației

În fiecare punct al traiectoriei, accelerația centripetă este orientată:

\[ \boxed{ \text{spre centrul cercului} }. \]

Dependențe

Dacă \(v\) se dublează

\[ a_c'= \frac{(2v)^2}{r} = 4a_c. \]

Accelerația devine de 4 ori mai mare.

Dacă \(r\) se dublează

\[ a_c'= \frac{v^2}{2r} = \frac{a_c}{2}. \]

Pentru aceeași viteză, accelerația se înjumătățește.

Legătura cu viteza unghiulară

Deoarece:

\[ v=\omega r, \]

avem:

\[ a_c= \frac{ (\omega r)^2 }{r}. \]
\[ \boxed{ a_c= \omega^2r } \]

Un corp se deplasează pe un cerc de rază \(r=2\,\mathrm m\) cu viteza \(v=4\,\mathrm{m/s}\). Determină accelerația centripetă.

m/s²

2. Principiul fundamental

Ce produce accelerația centripetă?

Conform principiului fundamental al dinamicii:

\[ \vec F_{\mathrm{rez}} = m\vec a. \]

În mișcarea circulară uniformă:

\[ \vec a= \vec a_c. \]

Prin urmare, rezultanta forțelor trebuie să fie orientată spre centrul cercului.

Rezultanta centripetă

\[ F_c= ma_c. \]

Folosind:

\[ a_c= \frac{v^2}{r}, \]

obținem:

\[ \boxed{ F_c= m\frac{v^2}{r} }. \]

Folosind:

\[ v=\omega r, \]

putem scrie și:

\[ \boxed{ F_c= m\omega^2r } \]

„Forța centripetă” nu este o forță nouă

Nu desenăm automat o forță suplimentară numită „forță centripetă” pe lângă toate celelalte forțe reale.

Expresia forță centripetă indică rolul dinamic al rezultantei radiale.

\[ \boxed{ \sum F_{\mathrm{radial}} = m\frac{v^2}{r} }. \]

Cum rezolvăm corect?

1. Aleg corpul Ce corp se deplasează pe cerc?
2. Desenez forțele reale Greutate, normală, tensiune, frecare etc.
3. Aleg direcția radială Pozitiv spre centrul traiectoriei.
4. Calculez rezultanta radială Adun algebric componentele radiale.
5. Aplic dinamica \[ \sum F_r= \frac{mv^2}{r}. \]

Care afirmație este corectă?

3. Forțe reale cu rol centripet

Nu există o singură „forță centripetă”

Tensiunea în fir

Pentru un corp rotit cu un fir pe un plan orizontal, tensiunea poate asigura rezultanta radială.

\[ T= \frac{mv^2}{r} \]

dacă aceasta este singura forță radială.

Frecarea statică

La un automobil care virează pe un drum orizontal, frecarea statică dintre pneuri și drum poate asigura rezultanta centripetă.

Forța gravitațională

Pentru un satelit pe orbită circulară idealizată, gravitația este orientată spre centrul orbitei.

Forța normală

În anumite trasee curbe, componenta normalei poate contribui la rezultanta radială.

Întrebarea corectă nu este:

„Care este forța centripetă?”

Ci:

„Care dintre forțele reale sau care rezultantă a lor este orientată spre centrul traiectoriei?”

Exemplu: bilă legată de un fir

Dacă tensiunea este singura forță orizontală radială:

\[ T= F_c. \]

Deci:

\[ \boxed{ T= \frac{mv^2}{r} } \]

Exemplu numeric

O bilă cu masa:

\[ m= 0{,}50\,\mathrm{kg} \]

se rotește cu:

\[ v= 4\,\mathrm{m/s} \]

pe un cerc de rază:

\[ r= 2\,\mathrm m. \]

Atunci:

\[ T= \frac{ 0{,}50\cdot4^2 }{ 2 }. \] \[ \boxed{ T= 4\,\mathrm N }. \]

Un automobil virează pe un drum orizontal fără să derapeze. Ce forță poate furniza componenta radială necesară virajului?

4. Automobilul în viraj

De ce contează frecarea statică?

Considerăm un automobil care descrie un cerc pe un drum orizontal.

Pe verticală:

\[ N=mg. \]

Pe direcție radială, spre centrul virajului:

\[ F_f= \frac{mv^2}{r}. \]

Frecarea este statică, nu la alunecare

Cât timp roata rulează fără să derapeze, punctul de contact nu alunecă pe carosabil.

De aceea utilizăm condiția:

\[ F_f \le \mu_sN. \]

Pentru a nu apărea deraparea:

\[ \frac{mv^2}{r} \le \mu_smg. \]

Se simplifică masa:

\[ \frac{v^2}{r} \le \mu_sg. \]

Rezultă viteza maximă în modelul simplificat:

\[ \boxed{ v_{\max} = \sqrt{ \mu_sgr } } \]

Ce observăm?

În acest model:

  • o aderență mai mare permite o viteză mai mare;
  • o rază mai mare permite o viteză mai mare;
  • masa automobilului se simplifică din relație.

Exemplu

Considerăm:

\[ \mu_s= 0{,}40, \qquad r= 25\,\mathrm m, \qquad g= 10\,\mathrm{m/s^2}. \]

Atunci:

\[ v_{\max} = \sqrt{ 0{,}40\cdot10\cdot25 }. \] \[ v_{\max} = \sqrt{100}. \] \[ \boxed{ v_{\max} = 10\,\mathrm{m/s} }. \]

Model simplificat

Relația de mai sus presupune drum orizontal, viraj circular, model simplificat al frecării și condiții uniforme.

Situațiile reale de trafic depind de mult mai mulți factori.

Pentru aceeași aderență și aceeași viteză, dacă raza virajului scade, forța centripetă necesară:

Experimentează cauză–efect

Menține \(m\) și \(r\) constante și dublează viteza.

Verifică dacă:

\[ F_c \rightarrow 4F_c. \]

Apoi menține \(m\) și \(v\) constante și dublează raza.

Verifică dacă:

\[ F_c \rightarrow \frac{F_c}{2}. \]

6. Aplicații

Probleme integrate

Problema 1 – tensiunea firului

Un corp de:

\[ m= 0{,}40\,\mathrm{kg} \]

se deplasează uniform pe un cerc orizontal de rază:

\[ r= 0{,}80\,\mathrm m \]

cu viteza:

\[ v= 2\,\mathrm{m/s}. \]

Firul furnizează rezultanta radială.

\[ T= \frac{mv^2}{r}. \] \[ T= \frac{ 0{,}40\cdot4 }{ 0{,}80 }. \] \[ \boxed{ T= 2\,\mathrm N }. \]
Problema 2 – determinarea vitezei

Un corp de:

\[ m= 2\,\mathrm{kg} \]

se deplasează pe un cerc cu:

\[ r= 8\,\mathrm m. \]

Rezultanta radială este:

\[ F_c= 9\,\mathrm N. \]

Din:

\[ F_c= \frac{mv^2}{r} \]

rezultă:

\[ v^2= \frac{F_cr}{m}. \] \[ v^2= \frac{ 9\cdot8 }{ 2 } = 36. \] \[ \boxed{ v= 6\,\mathrm{m/s} }. \]
Problema 3 – de la perioadă la dinamică

Un corp de:

\[ m= 1\,\mathrm{kg} \]

se deplasează pe un cerc de rază:

\[ r= 2\,\mathrm m \]

cu perioada:

\[ T= 4\,\mathrm s. \]

Viteza:

\[ v= \frac{2\pi r}{T}. \]

Pentru:

\[ \pi\approx3{,}14, \]

avem:

\[ v= \frac{ 2\cdot3{,}14\cdot2 }{ 4 } = 3{,}14\,\mathrm{m/s}. \]

Apoi:

\[ F_c= \frac{mv^2}{r}. \] \[ F_c \approx \frac{ 1\cdot3{,}14^2 }{ 2 }. \] \[ \boxed{ F_c \approx 4{,}93\,\mathrm N }. \]

Strategie pentru probleme

  1. identifică centrul traiectoriei;
  2. desenează toate forțele reale;
  3. stabilește care au componente radiale;
  4. alege sensul pozitiv spre centru;
  5. scrie \(\sum F_r=mv^2/r\);
  6. rezolvă ecuația pentru mărimea necunoscută.

Întrebare de control

Dacă rezultanta radială ar dispărea brusc, corpul nu ar continua să descrie cercul.

Conform principiului inerției, în acel moment corpul ar tinde să se deplaseze pe direcția tangentei la traiectorie.

Sinteză

Ce trebuie să reții

Viteza

Este tangentă la traiectorie.

\[ v=\text{constant ca modul} \]

Accelerația centripetă

\[ \boxed{ a_c= \frac{v^2}{r} } \]

Cu viteza unghiulară

\[ \boxed{ a_c= \omega^2r } \]

Rezultanta radială

\[ \boxed{ F_c= \frac{mv^2}{r} } \]

Altă formă

\[ \boxed{ F_c= m\omega^2r } \]

Ecuația de dinamică

\[ \boxed{ \sum F_r= \frac{mv^2}{r} } \]

Ideea fundamentală

Nu adăuga în diagrama corpului o forță suplimentară numită „forță centripetă”.

Desenează forțele reale și determină rezultanta componentelor lor radiale.

Bilă legată de fir

Tensiunea poate avea rol centripet.

Automobil în viraj

Frecarea statică poate avea rol centripet.

Satelit

Forța gravitațională poate avea rol centripet.

identific corpul → desenez forțele reale → aleg direcția radială → calculez \(\sum F_r\) → \(\sum F_r=mv^2/r\)

Relații utile din cinematică

\[ v= \omega r \] \[ \omega= \frac{2\pi}{T} \] \[ v= \frac{2\pi r}{T} \] \[ f= \frac{1}{T}. \]

Urmează: gravitația

Am văzut că pentru un satelit forța gravitațională poate furniza rezultanta orientată spre centrul orbitei.
