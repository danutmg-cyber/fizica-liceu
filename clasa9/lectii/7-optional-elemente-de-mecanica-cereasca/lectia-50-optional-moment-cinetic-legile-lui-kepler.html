Momentul cinetic. Legile lui Kepler

De ce planetele nu se deplasează cu aceeași viteză în toate punctele orbitei? De ce orbitele lor sunt elipse și ce legătură există între perioada de revoluție și distanța față de Soare?

🎯 Ce vei învăța

La final vei putea:

  • să definești momentul cinetic al unui punct material;
  • să explici conservarea momentului cinetic în cazul unei forțe centrale;
  • să descrii elementele principale ale unei orbite eliptice;
  • să formulezi cele trei legi ale lui Kepler;
  • să explici de ce o planetă se deplasează mai repede la periheliu;
  • să utilizezi legea a III-a pentru comparația perioadelor orbitale;
  • să interpretezi o simulare a unei orbite kepleriene.

Ideea centrală

Gravitația este o forță centrală: forța exercitată asupra planetei este orientată permanent spre corpul central.

Din această geometrie simplă rezultă o proprietate foarte puternică: momentul cinetic se conservă.

Legea a II-a a lui Kepler este o consecință directă a acestei conservări.

☀️ Situație-problemă

O planetă se deplasează în jurul Soarelui pe o orbită eliptică. Soarele nu se află în centrul elipsei, ci într-unul dintre focare.

periheliu
afeliu
Întrebări:

De ce planeta nu se deplasează cu viteză constantă?

De ce este mai rapidă atunci când se află mai aproape de Soare?

Și cum poate fi prezisă perioada orbitei fără a urmări planeta timp de un ciclu complet?

Răspunsurile sunt sintetizate în legile lui Kepler.

1. Atracția gravitațională ca forță centrală

Între două corpuri de mase \(M\) și \(m\), aflate la distanța \(r\), modulul forței gravitaționale este:

\[ \boxed{ F_g= G\frac{Mm}{r^2} } \]

Direcția acestei forțe coincide cu dreapta care unește centrele celor două corpuri.

O forță a cărei linie de acțiune trece permanent printr-un punct fix se numește forță centrală. În modelul în care masa Soarelui este mult mai mare decât masa planetei, punctul central este aproximativ centrul Soarelui.

2. Momentul cinetic

Am definit impulsul mecanic prin:

\[ \vec p=m\vec v \]

Pentru mișcările de rotație sau pentru mișcarea unui corp în jurul unui punct \(O\), introducem momentul cinetic.

\[ \boxed{ \vec L= \vec r\times\vec p } \]

unde:

  • \(\vec r\) este vectorul de poziție față de punctul \(O\);
  • \(\vec p=m\vec v\) este impulsul mecanic;
  • \(\vec L\) este momentul cinetic față de \(O\).

Modulul său este:

\[ \boxed{ L= rp\sin\alpha } \]
adică:
\[ \boxed{ L= mrv\sin\alpha } \]

\(\alpha\) este unghiul dintre \(\vec r\) și \(\vec v\).

3. Cazul mișcării circulare

În mișcarea circulară, viteza este tangentă la traiectorie, iar raza este perpendiculară pe tangentă:

\[ \alpha=90^\circ \]
Cum:
\[ \sin90^\circ=1 \]
rezultă:
\[ \boxed{ L=mrv } \]
Momentul cinetic joacă în studiul rotației un rol asemănător celui jucat de impulsul mecanic în studiul translației.

4. Legătura cu momentul forței

În lecțiile despre echilibru am întâlnit momentul unei forțe.

În formă vectorială:

\[ \vec M= \vec r\times\vec F \]

Momentul rezultant al forțelor determină variația momentului cinetic:

\[ \boxed{ \frac{\Delta\vec L}{\Delta t} \approx \vec M } \]

În formă exactă, pentru variații continue:

\[ \boxed{ \frac{d\vec L}{dt} = \vec M } \]

5. Conservarea momentului cinetic

În cazul forței gravitaționale, \(\vec F_g\) este paralelă cu \(\vec r\).

Prin urmare:
\[ \vec r\times\vec F_g=0 \]
deci:
\[ \vec M=0 \]
Din:
\[ \frac{d\vec L}{dt} = \vec M \]
rezultă:
\[ \boxed{ \vec L= \text{constant} } \]
Conservarea momentului cinetic: în mișcarea sub acțiunea unei forțe centrale, momentul cinetic față de centrul forței rămâne constant.

6. Ce înseamnă fizic această conservare?

Pentru o orbită plană:

\[ L= mrv_\perp \]
unde \(v_\perp\) este componenta vitezei perpendiculară pe vectorul de poziție.

Dacă \(L\) rămâne constant:

\[ \boxed{ rv_\perp= \text{constant} } \]
Când planeta se apropie de Soare, \(r\) scade. Pentru ca momentul cinetic să rămână constant, componenta tangențială a vitezei trebuie să crească. De aceea planeta se deplasează mai repede în apropierea Soarelui.

7. Orbita eliptică

Elipsa este o curbă definită prin două puncte fixe, numite focare.

Pentru orice punct \(P\) al elipsei:

\[ \boxed{ PF_1+PF_2= \text{constant} } \]

Elemente importante

Semiaxa mare \(a\)

Reprezintă jumătate din lungimea axei mari a elipsei.

Excentricitatea \(e\)

Caracterizează cât de alungită este elipsa.

\[ 0\le e<1 \]

Focarele

Pentru o orbită planetară, Soarele se află într-un focar.

Pentru o elipsă:

\[ c=ae \]
unde \(c\) este distanța dintre centrul elipsei și un focar.

8. Periheliu și afeliu

Pentru o planetă care orbitează Soarele:

PERIHELIU

Distanța minimă

\[ \boxed{ r_p= a(1-e) } \]

Planeta este cel mai aproape de Soare.

AFELIU

Distanța maximă

\[ \boxed{ r_a= a(1+e) } \]

Planeta este cel mai departe de Soare.

Pentru un satelit care orbitează Pământul folosim termenii perigeu și apogeu. Termenii generali sunt periapsidă și apoapsidă.

9. Legea I a lui Kepler – legea orbitelor

Legea I: Planetele se deplasează în jurul Soarelui pe orbite eliptice, Soarele aflându-se într-unul dintre focarele elipsei.
\[ \boxed{ \text{orbită eliptică} \quad+\quad \text{Soarele într-un focar} } \]
Greșeală frecventă: Soarele nu se află, în general, în centrul geometric al orbitei eliptice. Se află într-unul dintre focare.

10. Legea a II-a a lui Kepler – legea ariilor

Legea a II-a: Raza vectoare care unește Soarele de planetă mătură arii egale în intervale de timp egale.
\[ \boxed{ \frac{\Delta A}{\Delta t} = \text{constant} } \]

Mărimea:

\[ \frac{dA}{dt} \]
se numește viteză areolară.

11. De ce rezultă legea ariilor din conservarea momentului cinetic?

Într-un interval foarte scurt \(\Delta t\), planeta se deplasează aproximativ cu:

\[ \Delta s \approx v_\perp\Delta t \]

Aria mică măturată de raza vectoare poate fi aproximată cu aria unui triunghi:

\[ \Delta A \approx \frac12 r\, v_\perp\Delta t \]
Împărțim la \(\Delta t\):
\[ \frac{\Delta A}{\Delta t} \approx \frac12 rv_\perp \]
Dar:
\[ L= mrv_\perp \]
deci:
\[ \boxed{ \frac{dA}{dt} = \frac{L}{2m} } \]
Cum \(L\) este constant:
\[ \boxed{ \frac{dA}{dt} = \text{constant} } \]
Legea a II-a a lui Kepler nu este doar o regulă geometrică. Ea exprimă direct conservarea momentului cinetic într-un câmp central.

12. Periheliu: rapid. Afeliu: lent.

În periheliu și afeliu, viteza este perpendiculară pe raza vectoare.

Conservarea momentului cinetic dă:
\[ m r_p v_p = m r_a v_a \]
Simplificăm masa:
\[ \boxed{ r_pv_p= r_av_a } \]
de unde:
\[ \boxed{ \frac{v_p}{v_a} = \frac{r_a}{r_p} } \]
Cum:
\[ r_a>r_p \]
rezultă:
\[ \boxed{ v_p>v_a } \]

🧮 Exemplul 1 – Raportul vitezelor

O planetă are o orbită cu:

\[ a=10 \] unități astronomice și: \[ e=0,40 \]

1. Distanța la periheliu

\[ r_p= a(1-e) \] \[ r_p= 10(1-0,40) = 6 \]

2. Distanța la afeliu

\[ r_a= a(1+e) \] \[ r_a= 10(1+0,40) = 14 \]

3. Raportul vitezelor

\[ \frac{v_p}{v_a} = \frac{r_a}{r_p} = \frac{14}{6} \] \[ \boxed{ \frac{v_p}{v_a} \approx2,33 } \]
În acest model, viteza la periheliu este de aproximativ 2,33 ori mai mare decât viteza la afeliu.

13. Legea a III-a a lui Kepler – legea perioadelor

Legea a III-a: Pentru corpuri care orbitează același corp central, pătratul perioadei de revoluție este proporțional cu cubul semiaxei mari a orbitei.
\[ \boxed{ T^2\sim a^3 } \]
sau:
\[ \boxed{ \frac{T^2}{a^3} = \text{constant} } \]
Pentru două planete care orbitează același corp central:
\[ \boxed{ \frac{T_1^2}{a_1^3} = \frac{T_2^2}{a_2^3} } \]

14. Forma newtoniană a legii a III-a

Pentru un corp de masă neglijabilă față de corpul central de masă \(M\), legea a III-a poate fi scrisă:

\[ \boxed{ T^2 = \frac{4\pi^2}{GM} a^3 } \]

Observăm că perioada depinde de:

  • semiaxa mare \(a\);
  • masa corpului central \(M\).
Pentru două corpuri care orbitează același corp central, \(G\) și \(M\) sunt aceleași. De aceea: \[ \frac{T^2}{a^3} = \text{constant} \]

15. Cum putem intui legea a III-a?

Pentru o orbită circulară, gravitația furnizează forța cu rol centripet:

\[ G\frac{Mm}{r^2} = m\frac{v^2}{r} \]
Simplificăm \(m\):
\[ v^2= \frac{GM}{r} \]
Dar:
\[ v= \frac{2\pi r}{T} \]
Înlocuim:
\[ \frac{4\pi^2r^2}{T^2} = \frac{GM}{r} \]
și rezultă:
\[ \boxed{ T^2= \frac{4\pi^2}{GM}r^3 } \]
Pentru orbitele eliptice, raza \(r\) nu este constantă. În forma generală a legii a III-a, în locul razei folosim semiaxa mare \(a\).

16. O formă foarte utilă pentru Sistemul Solar

Dacă folosim:

  • perioada \(T\) în ani;
  • semiaxa mare \(a\) în unități astronomice (UA);
  • masa Soarelui ca masă centrală,
atunci pentru planetele Sistemului Solar:
\[ \boxed{ T^2\approx a^3 } \]
sau:
\[ \boxed{ T\approx a^{3/2} } \]

Pământul oferă chiar unitățile de referință:

\[ a_{\oplus}=1\,\mathrm{UA} \] \[ T_{\oplus}=1\,\text{an} \]

🧮 Exemplul 2 – O planetă la 4 UA

O planetă orbitează o stea cu masa Soarelui și are:

\[ a=4\,\mathrm{UA} \]
Folosim:
\[ T^2=a^3 \]
deci:
\[ T^2= 4^3 = 64 \]
Prin urmare:
\[ \boxed{ T=8\,\text{ani} } \]
Dacă semiaxa mare este de 4 ori mai mare decât cea a Pământului, perioada nu este de 4 ori mai mare, ci de 8 ori mai mare.

🧮 Exemplul 3 – Determinarea semiaxei mari

Un corp are perioada orbitală:

\[ T=27\,\text{ani} \]
în jurul unei stele cu masa Soarelui.

Din:
\[ T^2=a^3 \]
rezultă:
\[ a= \sqrt[3]{T^2} \] \[ a= \sqrt[3]{27^2} \] \[ a= \sqrt[3]{729} \]
Prin urmare:
\[ \boxed{ a=9\,\mathrm{UA} } \]

17. Cele trei legi ale lui Kepler

LEGEA I

Orbitele

Planetele se deplasează pe elipse, iar Soarele se află într-un focar.

LEGEA II

Ariile

Arii egale sunt măturate în intervale de timp egale.

\[ \frac{dA}{dt} = \text{constant} \]
LEGEA III

Perioadele

\[ \frac{T^2}{a^3} = \text{constant} \]

🔬 Activitate – Desenează o orbită eliptică

Materiale

  • o foaie de hârtie;
  • două pioneze;
  • o bucată de ață;
  • un creion;
  • o bucată de carton ca suport.

Scop

Construirea geometrică a unei elipse și observarea proprietății focarelor.

  1. Fixează cele două pioneze în două puncte \(F_1\) și \(F_2\).
  2. Leagă capetele firului astfel încât să formeze o buclă.
  3. Așază bucla în jurul celor două pioneze.
  4. Întinde firul cu vârful creionului.
  5. Menține firul întins și deplasează creionul.
  6. Vei obține o elipsă.
În orice punct al curbei, suma distanțelor până la cele două focare rămâne constantă: \[ PF_1+PF_2=\text{constant} \]

🔎 Investigație conceptuală – Arii egale

Imaginează-ți două intervale de timp egale:

  • unul în apropierea periheliului;
  • unul în apropierea afeliului.

În apropierea periheliului, distanța \(r\) este mai mică, dar planeta parcurge un arc mai lung.

În apropierea afeliului, distanța \(r\) este mai mare, dar planeta parcurge un arc mai scurt.

\[ \Delta A_1= \Delta A_2 \]
Aceasta este esența legii a II-a: planeta „compensează” raza mai mică printr-o viteză mai mare.

19. Kepler descrie, Newton explică

Legile lui Kepler au fost formulate pe baza analizei observațiilor astronomice.

Ele descriu foarte precis comportamentul orbitelor:

  • forma;
  • variația vitezei;
  • relația dintre perioadă și dimensiunea orbitei.

Mecanica newtoniană explică de ce aceste legi apar, pornind de la atracția gravitațională.

Kepler: descrierea regularităților mișcării planetelor.

Newton: explicația dinamică prin legea gravitației și principiile mecanicii.

⚠️ Idei greșite frecvente

1. „Soarele este în centrul elipsei.”

Nu. În modelul keplerian, Soarele se află într-unul dintre focare.

2. „Planeta are viteză constantă.”

Nu pe o orbită eliptică. Viteza este mai mare în apropierea periheliului.

3. „Dacă planeta este mai aproape, gravitația o încetinește.”

În apropierea periheliului, viteza orbitală este mai mare.

4. „Legea a II-a spune că arcurile sunt egale.”

Nu. În intervale egale de timp sunt egale ariile măturate, nu lungimile arcurilor.

5. „\(T^2/a^3\) este aceeași constantă pentru orice orbită din Univers.”

Nu. Constanta depinde de masa corpului central.

6. „Momentul cinetic este același lucru cu impulsul.”

Nu.

\[ \vec p=m\vec v \] dar \[ \vec L= \vec r\times\vec p \]

📌 De reținut

Moment cinetic

\[ \boxed{ \vec L= \vec r\times\vec p } \]

Modul

\[ \boxed{ L= mrv\sin\alpha } \]

Forță centrală

\[ \boxed{ \vec M=0 \Rightarrow \vec L=\text{constant} } \]

Legea I

Orbită eliptică, corpul central într-un focar.

Legea II

\[ \boxed{ \frac{dA}{dt} = \text{constant} } \]

Legea III

\[ \boxed{ \frac{T^2}{a^3} = \text{constant} } \]
Ideea esențială: gravitația este o forță centrală, deci momentul ei față de corpul central este nul. Momentul cinetic se conservă, iar această conservare apare geometric în legea ariilor a lui Kepler.

🔗 Legătura cu lecția următoare

Legile lui Kepler descriu orbitele și perioadele. Dar putem determina și viteza unui satelit pe o orbită circulară?

Dacă gravitația furnizează exact forța centripetă: \[ G\frac{Mm}{r^2} = m\frac{v^2}{r} \] ce expresie obținem pentru viteza orbitală?

Aceasta este legătura naturală spre studiul mișcării planetelor și sateliților, vitezelor orbitale și vitezelor cosmice.
