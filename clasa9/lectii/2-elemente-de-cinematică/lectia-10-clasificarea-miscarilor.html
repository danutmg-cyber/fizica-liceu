Clasificarea mișcărilor

După traiectorie • După modulul vitezei • După accelerație

Prof. Dănuț Andronie e-Mail: danutmg@gmail.com

O mișcare poate fi în același timp circulară și uniformă?

Da.

De exemplu, un punct de pe marginea unui disc care se rotește uniform descrie o traiectorie circulară, iar modulul vitezei sale poate rămâne constant.

Totuși, vectorul viteză își schimbă permanent direcția.

Consecință: o mișcare nu trebuie clasificată folosind un singur cuvânt.

Trebuie să precizăm criteriul de clasificare.

La finalul lecției vei putea:

  • să clasifici mișcările după forma traiectoriei;
  • să diferențiezi mișcarea rectilinie de cea curbilinie;
  • să recunoști mișcarea circulară ca un caz particular de mișcare curbilinie;
  • să diferențiezi mișcarea uniformă de cea variată;
  • să identifici mișcarea cu accelerație constantă;
  • să diferențiezi creșterea modulului vitezei de accelerația pozitivă;
  • să combini corect mai multe criterii de clasificare;
  • să clasifici situații concrete din viața reală.

1. Criterii de clasificare

Aceeași mișcare poate primi mai multe caracterizări

Mișcările pot fi clasificate folosind criterii diferite. Cele mai importante pentru această etapă sunt:

Forma traiectoriei

rectilinie sau curbilinie

Modulul vitezei

uniformă sau variată

Accelerația

nulă, constantă sau variabilă

Aceste criterii sunt independente.

De exemplu, o mișcare poate fi:

rectilinie și uniformă

sau:

circulară și uniformă.

„Uniformă” nu înseamnă automat „rectilinie”

Termenul uniformă se referă la constanța modulului vitezei.

Forma traiectoriei este un criteriu separat.

Criteriu Întrebarea pe care o punem Exemple de răspuns
Traiectorie Ce formă are drumul? rectilinie, circulară, curbilinie
Modulul vitezei Se modifică rapiditatea? uniformă, variată
Accelerație Cum se modifică vectorul viteză? \(a=0\), \(a=\text{constantă}\), \(a=\text{variabilă}\)

2. Clasificarea după traiectorie

Rectilinie sau curbilinie?

Mișcare rectilinie

Traiectoria este o linie dreaptă.

Exemple: liftul, tren pe un segment drept, corp pe un plan înclinat drept.

Mișcare curbilinie

Traiectoria este o linie curbă.

Exemple: minge aruncată, automobil într-o curbă, satelit pe orbită.

Mișcarea circulară

Mișcarea este circulară atunci când traiectoria este un cerc.

Orice mișcare circulară este curbilinie.

Dar nu orice mișcare curbilinie este circulară.

3. Clasificarea după modulul vitezei

Mișcare uniformă sau variată?

Mișcare uniformă

Modulul vitezei rămâne constant:

\[ \boxed{ |\vec v| = \text{constant} } \]

Mișcare variată

Modulul vitezei se modifică în timp:

\[ \boxed{ |\vec v| \neq \text{constant} } \]

Exemplu – mișcare uniformă

Un automobil parcurge:

\[ 10\,\text{m} \] în fiecare secundă succesivă, fără schimbarea modulului vitezei.

Exemplu – mișcare variată

În intervale succesive de câte o secundă, un corp parcurge:

\[ 2\,\text{m}, \quad 4\,\text{m}, \quad 6\,\text{m}. \]

Modulul vitezei nu rămâne constant.

Atenție la mișcarea circulară uniformă

În mișcarea circulară uniformă:

\[ |\vec v| = \text{constant}, \]

dar direcția vectorului viteză se modifică permanent.

Prin urmare:

\[ \vec v \neq \text{constant}. \]
Modul constant al vitezei nu înseamnă neapărat vector viteză constant.

Pagina 4 din 9
4. Clasificarea după accelerație

Cum se modifică vectorul viteză?

Accelerație nulă

\[ \vec a=\vec0 \]

Vectorul viteză este constant.

Accelerație constantă

\[ \vec a= \text{constant} \]

Viteza se modifică regulat în timp.

Accelerație variabilă

\[ \vec a= \vec a(t) \]

Accelerația se modifică în timp.

Mișcarea rectilinie uniformă

Dacă traiectoria este dreaptă și vectorul viteză este constant:

\[ \boxed{ \vec a=\vec0 } \]

Mișcarea rectilinie uniform variată

Dacă mișcarea este rectilinie și accelerația este constantă: \[ \boxed{ a= \text{constant} } \] vorbim despre mișcare rectilinie uniform variată.

Pentru această mișcare:

\[ v(t)=v_0+at. \]

„Uniform variată” nu înseamnă „uniformă”

În mișcarea uniformă:

\[ |\vec v|= \text{constant}. \]

În mișcarea uniform variată:

\[ \vec a= \text{constant}, \]

iar viteza se modifică.

Accelerare sau încetinire?

Modulul vitezei crește

Viteza și accelerația au același sens.

Modulul vitezei scade

Viteza și accelerația au sensuri opuse.

Nu identificăm „încetinirea” doar după semnul negativ al accelerației.

Trebuie comparate sensurile lui \(\vec v\) și \(\vec a\).

5. Combinarea criteriilor

O descriere completă folosește mai multe criterii

Situație Traiectorie Modulul vitezei Accelerație
Tren pe linie dreaptă cu viteză constantă rectilinie constant nulă
Automobil care accelerează pe drum drept rectilinie crește nenulă
Punct pe un disc ce se rotește uniform circulară constant nenulă
Automobil într-o curbă, accelerând curbilinie crește nenulă

Cazul important: mișcarea rectilinie uniformă

\[ \boxed{ \text{traiectorie dreaptă} + \vec v=\text{constant} } \] \[ \boxed{ \vec a=\vec0 } \]

Cazul important: mișcarea circulară uniformă

\[ \boxed{ \text{traiectorie circulară} + |\vec v|=\text{constant} } \]

dar:

\[ \boxed{ \vec a\neq\vec0 } \]

De ce există accelerație?

Pentru că direcția vectorului viteză se modifică permanent, chiar dacă modulul vitezei este constant.

\[ |\vec v_1| = |\vec v_2|, \] dar: \[ \vec v_1 \neq \vec v_2. \]
Pagina 6 din 9
6. Cum clasificăm o mișcare?

Folosește trei întrebări

1. Ce formă are traiectoria?
2. Modulul vitezei este constant?
3. Cum se comportă accelerația?

Exemplul 1

Un tren se deplasează pe o porțiune dreaptă de cale ferată cu:

\[ v=20\,\text{m/s} \] constant.

Pasul 1 – traiectoria

Calea este dreaptă:

\[ \boxed{ \text{mișcare rectilinie} } \]

Pasul 2 – modulul vitezei

Viteza rămâne constantă:

\[ \boxed{ \text{mișcare uniformă} } \]

Pasul 3 – accelerația

Direcția, sensul și modulul vitezei nu se modifică:

\[ \boxed{ a=0 } \]

Mișcarea este:

rectilinie uniformă.

Exemplul 2

Un punct se deplasează pe un cerc cu:

\[ |\vec v|=5\,\text{m/s} \] constant.

Traiectoria: circulară.

Modulul vitezei: constant.

Clasificare: mișcare circulară uniformă.

Accelerația: nenulă, deoarece direcția vitezei se modifică.

Un automobil se deplasează pe un drum drept, iar modulul vitezei sale crește constant în timp. Care descriere este cea mai potrivită?

Nu deduce mai mult decât permit datele

Dacă știm doar că viteza crește, nu putem afirma automat că accelerația este constantă.

Pentru „uniform variată” trebuie să știm că:

\[ a=\text{constant}. \]

Sinteză

De reținut

După traiectorie

rectilinie

curbilinie

circulară – caz particular

După modulul vitezei

uniformă:

\[ |\vec v| = \text{constant} \]

variată:

\[ |\vec v| \neq \text{constant} \]

După accelerație

\[ \vec a=\vec0 \] \[ \vec a=\text{constant} \] \[ \vec a=\vec a(t) \]

Rectilinie uniformă

\[ \vec v= \text{constant} \] \[ \vec a=\vec0 \]

Rectilinie uniform variată

\[ \vec a= \text{constant} \]

Circulară uniformă

\[ |\vec v|= \text{constant} \]

dar:

\[ \vec a\neq\vec0 \]
\[ \boxed{ \text{traiectorie} + \text{viteză} + \text{accelerație} \rightarrow \text{clasificarea mișcării} } \]

Regula de lucru

Nu spune doar:

„mișcarea este uniformă”

înainte să verifici și forma traiectoriei.

Întreabă întotdeauna:

„După ce criteriu clasific mișcarea?”

Lecția următoare

Vom studia în detaliu cel mai simplu model cinematic:

mișcarea rectilinie uniformă.

Vom deduce legea:

\[ \boxed{ x(t)=x_0+vt } \]

și vom interpreta graficele:

\[ x(t) \quad\text{și}\quad v(t). \]
