Mișcarea rectilinie uniformă. Legea mișcării

1. Definiție și mărimi

În MRU, traiectoria este dreaptă și vectorul viteză este constant. Mobilul parcurge distanțe egale în intervale de timp egale.

vₓ = constant; aₓ = 0

2. Legea mișcării

x = x₀ + vₓ(t − t₀)

x₀ este poziția la momentul t₀; x este poziția la momentul t. Manualul utilizează și S, S₀ pentru coordonata de-a lungul traiectoriei. Aici x păstrează explicit semnul pe axă.

Exemplu: x₀ = 2 m, vₓ = 3 m/s, t₀ = 0

x(4 s) = 2 + 3 × 4 = 14 m. Deplasarea este 12 m; distanța este tot 12 m, deoarece sensul nu se schimbă.

3. Cum arată graficul?

Graficul x(t) este o dreaptă cu panta vₓ. Ordonata la t = 0 este x₀ când t₀ = 0.

Coordonata poate fi negativă. Distanța parcursă într-un interval este d = |vₓ|Δt.
