Accelerația centripetă

Mișcare circulară uniformă • Modificarea direcției vitezei • Accelerație orientată spre centru

Prof. Dănuț Andronie e-Mail: danutmg@gmail.com

Dacă viteza este constantă, de ce există accelerație?

În mișcarea circulară uniformă:

\[ |\vec v|=\text{constant}. \]

Totuși, corpul nu se deplasează pe o dreaptă. Vectorul viteză își schimbă permanent direcția.

Cauză: direcția vectorului viteză se modifică.

Efect: vectorul viteză se modifică, deci corpul are accelerație.

\[ \boxed{ a_c=\frac{v^2}{r} } \] \[ \boxed{ a_c=\omega^2r } \]

La finalul lecției vei putea:

  • să explici de ce MCU este o mișcare accelerată;
  • să descrii direcția accelerației centripete;
  • să explici sensul accelerației spre centrul cercului;
  • să utilizezi relația \(a_c=v^2/r\);
  • să deduci relația \(a_c=\omega^2r\);
  • să exprimi accelerația prin perioadă și frecvență;
  • să analizezi influența razei și vitezei;
  • să diferențiezi accelerația centripetă de o forță.

1. Vectorul viteză se modifică

Accelerația nu înseamnă numai modificarea modulului vitezei

Accelerația descrie modificarea vectorului viteză:

\[ \vec a= \frac{\Delta\vec v}{\Delta t}. \]

Un vector se poate modifica prin:

Modul

viteza devine mai mare sau mai mică

Direcție

vectorul își schimbă orientarea

Sens

vectorul poate ajunge să fie orientat în sens opus

În mișcarea circulară uniformă:

\[ |\vec v_1| = |\vec v_2| = v, \]

dar:

\[ \vec v_1 \neq \vec v_2. \]
Chiar dacă modulul vitezei este constant, schimbarea direcției vectorului \(\vec v\) înseamnă: \[ \boxed{ \Delta\vec v\neq0 } \] și deci: \[ \boxed{ \vec a\neq0 }. \]

2. Direcția accelerației centripete

Accelerația este orientată spre centrul cercului

În orice punct al traiectoriei:

  • vectorul viteză este tangent la cerc;
  • accelerația centripetă este orientată radial;
  • sensul accelerației este spre centrul cercului.
\[ \boxed{ \vec a_c \text{ este orientată spre centrul cercului} } \]

Dacă accelerația centripetă ar dispărea, vectorul viteză nu și-ar mai schimba direcția.

Corpul ar continua instantaneu pe direcția tangentei, conform stării sale de mișcare din acel moment.

„Centripet” descrie sensul accelerației

Termenul provine din ideea de orientare spre centru.

Accelerația centripetă nu este orientată în sensul deplasării și nici spre exteriorul cercului.

3. Modulul accelerației centripete

De ce depinde accelerația centripetă?

Pentru un corp care se deplasează uniform pe un cerc de rază \(r\), modulul accelerației centripete este:

\[ \boxed{ a_c= \frac{v^2}{r} } \]

Analiza relației

Dacă \(v\) crește

\[ a_c\propto v^2 \]

Accelerația crește cu pătratul vitezei.

Dacă \(r\) crește

pentru aceeași viteză liniară:

\[ a_c\propto\frac1r \]

Dacă viteza se dublează și raza rămâne aceeași:

\[ v\rightarrow2v \]

atunci:

\[ a_c \rightarrow \frac{(2v)^2}{r} = 4a_c. \]
Dublarea vitezei produce o accelerație centripetă de patru ori mai mare, dacă raza rămâne aceeași.

Exemplu

Un corp se deplasează cu:

\[ v=4\,\text{m/s} \] pe un cerc de rază: \[ r=0{,}50\,\text{m}. \]

Accelerația centripetă:

\[ a_c= \frac{4^2}{0{,}50} \] \[ a_c= \frac{16}{0{,}50} \] \[ \boxed{ a_c=32\,\text{m/s}^2 }. \]

Verificarea unității

\[ [a_c] = \frac{ (\text{m/s})^2 }{ \text{m} } \] \[ [a_c] = \frac{ \text{m}^2/\text{s}^2 }{ \text{m} } \] \[ \boxed{ [a_c]=\text{m/s}^2 }. \]

Un corp are \(v=4\,\text{m/s}\) și se deplasează pe un cerc cu \(r=0{,}50\,\text{m}\). Calculează \(a_c\).

4. Accelerația și viteza unghiulară

Folosim relația dintre viteza liniară și viteza unghiulară

Din lecția precedentă:

\[ v=\omega r. \]

Înlocuim în:

\[ a_c= \frac{v^2}{r}. \]

Pasul 1

\[ a_c= \frac{ (\omega r)^2 }{ r }. \]

Pasul 2

\[ a_c= \frac{ \omega^2r^2 }{ r }. \]

Rezultatul

\[ \boxed{ a_c= \omega^2r } \]
Pentru aceeași viteză unghiulară: \[ a_c\propto r. \]

Pe același disc rigid, punctele mai îndepărtate de axă au accelerație centripetă mai mare.

Exemplu

Pentru:

\[ \omega= 6\,\text{rad/s}, \] \[ r= 0{,}25\,\text{m}, \] avem: \[ a_c= \omega^2r \] \[ a_c= 6^2\cdot0{,}25 \] \[ a_c= 36\cdot0{,}25 \] \[ \boxed{ a_c= 9\,\text{m/s}^2 }. \]

Pentru \(\omega=5\,\text{rad/s}\) și \(r=0{,}20\,\text{m}\), calculează \(a_c\).

5. Accelerația, perioada și frecvența

Folosim viteza unghiulară

Știm că:

\[ a_c= \omega^2r. \]

Dar:

\[ \omega= \frac{2\pi}{T}. \]

Atunci:

\[ a_c= \left( \frac{2\pi}{T} \right)^2r. \]
\[ \boxed{ a_c= \frac{ 4\pi^2r }{ T^2 } } \]

Folosim frecvența

Deoarece:

\[ \omega= 2\pi f, \] rezultă: \[ a_c= (2\pi f)^2r. \]
\[ \boxed{ a_c= 4\pi^2rf^2 } \]
Date cunoscute Relație utilă
\(v,r\) \[ a_c=\frac{v^2}{r} \]
\(\omega,r\) \[ a_c=\omega^2r \]
\(T,r\) \[ a_c= \frac{4\pi^2r}{T^2} \]
\(f,r\) \[ a_c= 4\pi^2rf^2 \]

Exemplu

Un punct se rotește pe un cerc de rază:

\[ r=0{,}50\,\text{m} \] cu perioada: \[ T=1\,\text{s}. \]

Atunci:

\[ a_c= \frac{ 4\pi^2\cdot0{,}50 }{ 1^2 } \] \[ a_c= 2\pi^2\,\text{m/s}^2 \] \[ \boxed{ a_c\approx19{,}74\,\text{m/s}^2 }. \]

Frecvența dublă:

\[ f\rightarrow2f \]

produce, la aceeași rază:

\[ a_c\rightarrow4a_c. \]

6. Exemplu rezolvat

De la frecvență la accelerația centripetă

Problemă

Un punct aflat la marginea unui disc se deplasează pe un cerc de rază:

\[ r=0{,}50\,\text{m}. \]

Discul se rotește uniform cu frecvența:

\[ f=1\,\text{Hz}. \]

Determină:

  1. perioada;
  2. viteza unghiulară;
  3. viteza liniară;
  4. accelerația centripetă;
  5. direcția și sensul accelerației.

1. Perioada

\[ T= \frac{1}{f} \] \[ \boxed{ T=1\,\text{s} }. \]

2. Viteza unghiulară

\[ \omega= 2\pi f \] \[ \boxed{ \omega= 2\pi\,\text{rad/s} }. \]

3. Viteza liniară

\[ v= \omega r \] \[ v= 2\pi\cdot0{,}50 \] \[ \boxed{ v= \pi\,\text{m/s} } \] \[ v\approx3{,}14\,\text{m/s}. \]

4. Accelerația centripetă

Putem folosi:

\[ a_c= \omega^2r. \] \[ a_c= (2\pi)^2\cdot0{,}50. \] \[ a_c= 2\pi^2\,\text{m/s}^2. \] \[ \boxed{ a_c\approx19{,}74\,\text{m/s}^2 }. \]

5. Direcția și sensul

Accelerația este radială și orientată:

de la punctul aflat pe cerc spre centrul traiectoriei.

Verificare prin a doua formulă

\[ a_c= \frac{v^2}{r} \] \[ a_c= \frac{ \pi^2 }{ 0{,}50 } \] \[ a_c= 2\pi^2\,\text{m/s}^2. \]

Rezultatul este același.
