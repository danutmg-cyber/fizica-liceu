Graficele mișcării rectilinii uniform variate

\(x(t)\) • \(v(t)\) • \(a(t)\) • Pantă • Arie • Interpretare fizică

Prof. Dănuț Andronie e-Mail: danutmg@gmail.com

Trei grafice. O singură mișcare.

Pentru același mobil putem reprezenta:

\[ x(t), \qquad v(t), \qquad a(t). \]

Cele trei grafice nu descriu trei mișcări diferite. Ele descriu aceeași mișcare din trei perspective.

\[ \boxed{ a=\text{constant} } \] \[ \boxed{ v(t)=v_0+at } \] \[ \boxed{ x(t)= x_0+v_0t+\frac{at^2}{2} } \]

Accelerația ne arată cum se modifică viteza.

Viteza ne arată cum se modifică poziția.

La finalul lecției vei putea:

  • să construiești graficele \(x(t)\), \(v(t)\) și \(a(t)\);
  • să identifici \(x_0\), \(v_0\) și \(a\) din grafice;
  • să determini viteza din panta graficului \(x(t)\);
  • să determini accelerația din panta graficului \(v(t)\);
  • să determini deplasarea din aria de sub \(v(t)\);
  • să determini variația vitezei din aria de sub \(a(t)\);
  • să recunoști momentul schimbării sensului;
  • să treci corect de la un grafic cinematic la altul.

2. Graficul poziție–timp

\(x(t)\) este o funcție de gradul al doilea

\[ x(t) = x_0+v_0t+\frac{at^2}{2}. \]

Pentru \(a\neq0\), graficul este o parabolă.

Ce citim din grafic?

Poziția inițială

La:

\[ t=0 \] avem: \[ \boxed{ x=x_0 } \]

Viteza

Este dată de panta tangentei:

\[ \boxed{ v= \text{panta tangentei la }x(t) } \]

Accelerația

Influențează concavitatea graficului.

Panta tangentei se modifică

Dacă panta tangentei crește, viteza crește.

Dacă panta tangentei scade, viteza scade.

Graficul nu este traiectoria

Mișcarea este rectilinie.

Forma parabolică reprezintă dependența poziției de timp.

3. Graficul viteză–timp

Graficul \(v(t)\) este o dreaptă

\[ \boxed{ v(t)=v_0+at } \]

Coeficientul lui \(t\) este accelerația.

Panta graficului

\[ \boxed{ a= \frac{\Delta v}{\Delta t} } \]
\[ \boxed{ \text{panta graficului }v(t)=a } \]

Aria de sub grafic

Aria algebrică dintre grafic și axa timpului reprezintă:

\[ \boxed{ \Delta x }. \]

Exemplu

Pentru:

\[ v_0=2\,\text{m/s}, \] \[ a=3\,\text{m/s}^2, \] \[ t=4\,\text{s}, \] viteza finală este: \[ v=2+3\cdot4 = 14\,\text{m/s}. \]

Aria trapezului:

\[ \Delta x = \frac{ v_0+v }{2}t \] \[ \Delta x = \frac{ 2+14 }{2} \cdot4 \] \[ \boxed{ \Delta x=32\,\text{m} }. \]

Pentru \(v_0=2\,\text{m/s}\), \(a=3\,\text{m/s}^2\) și \(t=4\,\text{s}\), determină deplasarea.

4. Graficul accelerație–timp

În MRUV accelerația este constantă

\[ \boxed{ a(t)=a=\text{constant} } \]

Graficul \(a(t)\) este o dreaptă paralelă cu axa timpului.

Ce reprezintă aria?

Din definiția accelerației:

\[ a= \frac{\Delta v}{\Delta t}. \]

Pentru accelerație constantă:

\[ \Delta v=a\Delta t. \]
\[ \boxed{ \Delta v = \text{aria algebrică de sub graficul }a(t) } \]

Exemplu

Dacă:

\[ a=-2\,\text{m/s}^2 \] timp de: \[ 5\,\text{s}, \] atunci: \[ \Delta v = -2\cdot5 \] \[ \boxed{ \Delta v=-10\,\text{m/s} }. \]

Accelerație negativă

Graficul \(a(t)\) este sub axa timpului.

Aceasta înseamnă:

\[ a<0, \]

nu automat că mobilul încetinește.

5. Cum trecem de la un grafic la altul?

Două operații fundamentale

Pantă

Arată cât de repede se modifică mărimea de pe axa verticală.

Arie

Acumulează efectul unei mărimi pe un interval de timp.

\[ \boxed{ x(t) \xrightarrow{\text{pantă}} v(t) } \] \[ \boxed{ v(t) \xrightarrow{\text{pantă}} a(t) } \]
\[ \boxed{ a(t) \xrightarrow{\text{arie}} \Delta v } \] \[ \boxed{ v(t) \xrightarrow{\text{arie}} \Delta x } \]
Grafic Panta reprezintă Aria reprezintă
\(x(t)\) viteza nu folosim o interpretare cinematică elementară directă
\(v(t)\) accelerația deplasarea
\(a(t)\) variația accelerației, nu o mărime studiată aici variația vitezei

Exemplu cauză–efect

Dacă \(a>0\) constantă, graficul \(a(t)\) este orizontal deasupra axei timpului.

Atunci \(v(t)\) are pantă pozitivă și este o dreaptă crescătoare.

Dacă și \(v>0\), graficul \(x(t)\) devine din ce în ce mai înclinat.

Nu memora numai forma

Un grafic trebuie interpretat prin mărimile de pe axe, semnul valorilor, pantă și arie.

6. Exemplu complet

De la \(v(t)\) la \(a(t)\) și \(x(t)\)

Problemă

Viteza unui mobil scade liniar de la:

\[ 8\,\text{m/s} \] la: \[ 0\,\text{m/s} \] în: \[ 4\,\text{s}. \]

Poziția inițială este:

\[ x_0=5\,\text{m}. \]

Determină accelerația, legea vitezei, deplasarea, legea poziției și poziția la oprire.

1. Accelerația

\[ a= \frac{ 0-8 }{ 4-0 } \] \[ \boxed{ a=-2\,\text{m/s}^2 }. \]

2. Legea vitezei

\[ v(t)=v_0+at \] \[ \boxed{ v(t)=8-2t }. \]

3. Deplasarea până la oprire

Din aria triunghiului/trapezului de sub \(v(t)\):

\[ \Delta x = \frac{ 8+0 }{2} \cdot4 \] \[ \boxed{ \Delta x=16\,\text{m} }. \]

4. Legea poziției

\[ x= x_0+v_0t+ \frac{at^2}{2} \] \[ x= 5+8t- t^2. \]
\[ \boxed{ x(t)=5+8t-t^2 } \]

5. Poziția la oprire

\[ x(4) = 5+8\cdot4-4^2 \] \[ x(4) = 5+32-16 \] \[ \boxed{ x(4)=21\,\text{m} }. \]
La \(t=4\,\text{s}\): \[ v=0. \]

Prin urmare, tangenta la graficul \(x(t)\) este orizontală.

Dacă accelerația \(-2\,\text{m/s}^2\) continuă după \(t=4\,\text{s}\), viteza devine negativă.

Mobilul își schimbă sensul, iar coordonata începe să scadă.

panta lui \(v(t)\) → \(a\)
aria lui \(v(t)\) → \(\Delta x\)
reconstruiesc \(x(t)\)

Regula graficelor cinematice

Nu încerca să memorezi numai desenele.

Leagă întotdeauna graficul de relațiile:

\[ a= \frac{\Delta v}{\Delta t}, \] \[ v= \frac{\Delta x}{\Delta t}, \] și de semnificația fizică a ariei.
