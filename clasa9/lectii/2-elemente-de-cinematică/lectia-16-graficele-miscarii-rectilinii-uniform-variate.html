Graficele mișcării rectilinii uniform variate

1. Poziție, viteză și accelerație

Pentru x₀ = 0, v₀ₓ = 0 și aₓ = +2 m/s²:

x = t²; vₓ = 2t; aₓ = 2

x(t) este o parabolă. Panta tangentei arată vₓ; nu este nevoie de calculul unei limite pentru a interpreta desenul.

2. Graficul vitezei

Panta reprezintă accelerația. Aria cu semn dintre vₓ(t) și axa timpului reprezintă deplasarea. La viteză pozitivă, aria triunghiului este și distanța parcursă.

Δx = (v₀ₓ + vₓ)Δt/2

3. Graficul accelerației

O linie orizontală nenulă înseamnă accelerație constantă. Aria cu semn reprezintă variația componentei vitezei: Δvₓ = aₓΔt.

La schimbarea sensului

Când vₓ trece prin zero, mobilul își schimbă sensul. Graficul poziției are atunci un maxim sau minim. Pentru distanță, adunăm modulele deplasărilor de pe intervalele cu sens constant.

Aplică noțiunile

Scrie formulele înaintea înlocuirilor numerice și verifică unitățile și semnele.
