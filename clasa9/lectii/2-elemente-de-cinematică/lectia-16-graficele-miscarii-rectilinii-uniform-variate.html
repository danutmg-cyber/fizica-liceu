Graficele mișcării rectilinii uniform variate

Aceeași mișcare poate fi descrisă prin trei grafice; fiecare răspunde altei întrebări.

1. Legile și aceleași date2. Graficul poziției x(t)3. Graficul vitezei vₓ(t)4. Graficul accelerației aₓ(t)

1. Legile și aceleași date

Considerăm t₀ = 0, x₀ = 0, v₀ₓ = 0, aₓ = 2 m/s². Aplicând legile MRUV obținem x = t², vₓ = 2t, aₓ = 2.

Timpul este comun tuturor graficelor. Valorile verticale au însă alte mărimi și alte unități; aceeași înălțime pe ecran nu reprezintă același fenomen.

2. Graficul poziției x(t)

Poziția crește din ce în ce mai repede. Panta tangentei crește, deci și viteza crește. O parabolă cu deschiderea în sus indică aₓ > 0; cu deschiderea în jos indică aₓ < 0. Sensul mișcării este dat de semnul pantei, nu de semnul poziției.

Ce arată un maxim sau un minim?

La un vârf atins în interiorul intervalului, tangenta este orizontală și viteza este nulă. Dacă panta își schimbă semnul, mobilul își schimbă sensul. Accelerația poate rămâne nenulă.

3. Graficul vitezei vₓ(t)

aₓ = Δvₓ/Δt; Δx = aria cu semn

Panta este 6/3 = 2 m/s². Aria triunghiului pentru 0–3 s este 3 × 6/2 = 9 m, aceeași deplasare obținută din x = t². Fiind viteza nenegativă, aceasta este și distanța.

Dacă dreapta traversează zero

Pentru o viteză de la +4 m/s la −4 m/s în 4 s, schimbarea sensului are loc la 2 s. Cele două arii au valori +4 m și −4 m: deplasarea totală este 0, dar distanța este 8 m.

4. Graficul accelerației aₓ(t)

Δvₓ = aₓΔt = aria cu semn

O orizontală nenulă arată accelerație constantă. Aria dintre 0 și 3 s este 2 × 3 = 6 m/s: variația vitezei, nu distanța. Pentru viteza finală trebuie cunoscută și viteza inițială.

La grafice pe etape, capătul unei etape furnizează datele inițiale ale următoarei. La frângeri analizăm separat intervalele vecine, fără a atribui automat o singură valoare instantanee.

Ce trebuie să poți explica și aplica?

Corelăm graficele: poziție → viteză → accelerație. Unitățile arată ce reprezintă fiecare pantă și arie.
