Fizică · clasa a IX-a · Elemente de cinematică

Mișcarea rectilinie uniform variată. Legea mișcării

1. Legea poziției

x = x₀ + v₀ₓτ + aₓτ²/2; τ = t − t₀

La t₀ = 0, τ = t. Viteza este vₓ = v₀ₓ + aₓτ. Pentru pornire din repaus și x₀ = 0: x = aₓτ²/2.

2. Deplasarea și relația lui Galilei

Δx = (v₀ₓ + vₓ)τ/2
vₓ² = v₀ₓ² + 2aₓΔx

Prima relație folosește viteza medie în MRUV. A doua elimină timpul. Componentele și deplasarea se introduc cu semn.

Cum aleg formula?

Cu timp cunoscut: legea poziției. Fără timp, dar cu viteze și accelerație: relația lui Galilei. Modulul vitezei obținut din radical nu stabilește singur sensul.

3. Oprire și distanță de frânare

τopr = −v₀ₓ/aₓ
dopr = v₀ₓ²/(2|aₓ|)

Relațiile de frânare presupun accelerație constantă, opusă vitezei inițiale, până la oprire. Distanța este pozitivă.

Dacă sensul se schimbă, distanța se calculează adunând lungimile porțiunilor; nu este întotdeauna |Δx|.

Aplică noțiunile

Scrie formulele înaintea înlocuirilor numerice și verifică unitățile și semnele.
