Mișcarea circulară uniformă

Radian • Perioadă • Frecvență • Viteză unghiulară • Viteză liniară

Prof. Dănuț Andronie e-Mail: danutmg@gmail.com

Ce au în comun un ventilator, o roată și un carusel?

Un punct de pe marginea lor poate descrie o traiectorie circulară.

Dacă parcurge arce egale în intervale egale de timp, mișcarea este circulară uniformă.

Modulul vitezei poate rămâne constant, dar direcția vectorului viteză se modifică permanent.

Din această cauză, vectorul viteză nu este constant.

La finalul lecției vei putea:

  • să definești mișcarea circulară uniformă;
  • să identifici raza și unghiul de rotație;
  • să explici ce este radianul;
  • să transformi grade în radiani și invers;
  • să definești perioada și frecvența;
  • să utilizezi relația \(f=1/T\);
  • să calculezi viteza unghiulară;
  • să folosești relația \(v=\omega r\).

1. Mișcarea circulară uniformă

Traiectoria este un cerc

Mișcarea circulară uniformă este mișcarea pe o traiectorie circulară în care modulul vitezei rămâne constant.
\[ \boxed{ |\vec v|=\text{constant} } \]

Direcția vitezei

În fiecare punct al cercului, vectorul viteză este tangent la traiectorie.

Chiar dacă:

\[ |\vec v|=\text{constant}, \]

direcția vectorului se schimbă permanent.

Modul constant nu înseamnă vector constant

În mișcarea circulară uniformă:

\[ |\vec v|=\text{constant}, \]

dar:

\[ \boxed{ \vec v\neq\text{constant} }. \]

Prin urmare, există accelerație chiar dacă modulul vitezei nu se modifică.

2. Unghiul în radiani

Cum măsurăm rotația?

Considerăm un punct care se deplasează pe un cerc de rază \(r\) și parcurge un arc de lungime \(s\).

Unghiul la centru, exprimat în radiani, este:

\[ \boxed{ \theta= \frac{s}{r} } \]

Ce este un radian?

Unghiul are măsura de 1 radian atunci când lungimea arcului este egală cu raza: \[ s=r. \] Atunci: \[ \theta= \frac{r}{r} = 1\,\text{rad}. \]

O rotație completă

Lungimea cercului este:

\[ s=2\pi r. \]

Deci:

\[ \theta= \frac{2\pi r}{r} = 2\pi\,\text{rad}. \]
\[ \boxed{ 360^\circ=2\pi\,\text{rad} } \] \[ \boxed{ 180^\circ=\pi\,\text{rad} } \]
Grade Radiani

\(90^\circ\) \(\frac{\pi}{2}\)
\(60^\circ\) \(\frac{\pi}{3}\)
\(45^\circ\) \(\frac{\pi}{4}\)
\(30^\circ\) \(\frac{\pi}{6}\)

3. Perioada și frecvența

Cât durează o rotație?

Perioada \(T\)

Timpul necesar pentru efectuarea unei rotații complete.

\[ \boxed{ T= \frac{\Delta t}{N} } \]

Unitatea SI:

\[ [T]=\text{s} \]

Frecvența \(f\)

Numărul de rotații efectuate în unitatea de timp.

\[ \boxed{ f= \frac{N}{\Delta t} } \]

Unitatea SI:

\[ [f]=\text{Hz} \]

Din cele două definiții:

\[ T= \frac{\Delta t}{N} \] și: \[ f= \frac{N}{\Delta t}, \] rezultă: \[ \boxed{ f=\frac{1}{T} } \] și: \[ \boxed{ T=\frac{1}{f} }. \]

Exemplu

O roată efectuează 30 de rotații în 15 s.

Frecvența:

\[ f= \frac{30}{15} = \boxed{ 2\,\text{Hz} }. \]

Perioada:

\[ T= \frac{1}{2} = \boxed{ 0{,}5\,\text{s} }. \]

Ce înseamnă 2 Hz?

\[ f=2\,\text{Hz} \] înseamnă că sistemul efectuează 2 rotații în fiecare secundă.

Nu confunda perioada cu frecvența

Perioada spune: câte secunde durează o rotație.

Frecvența spune: câte rotații au loc într-o secundă.

Un sistem are frecvența:

\[ f=4\,\text{Hz}. \]

Calculează perioada.

4. Viteza unghiulară

Cât de repede se modifică unghiul?

Viteza unghiulară medie este:

\[ \boxed{ \omega= \frac{\Delta\theta}{\Delta t} } \]

unde unghiul este exprimat în radiani.

Unitatea uzuală:

\[ \boxed{ [\omega]=\text{rad/s} }. \]

Pentru o rotație completă

Avem:

\[ \Delta\theta=2\pi\,\text{rad} \] și: \[ \Delta t=T. \]

Deci:

\[ \boxed{ \omega= \frac{2\pi}{T} } \]

Cum:

\[ f=\frac{1}{T}, \] rezultă: \[ \boxed{ \omega=2\pi f }. \]
În mișcarea circulară uniformă: \[ \boxed{ \omega=\text{constant} } \]

Exemplu

Un disc se rotește cu:

\[ f=5\,\text{Hz}. \]

Viteza unghiulară:

\[ \omega= 2\pi f \] \[ \omega= 2\pi\cdot5 \] \[ \boxed{ \omega=10\pi\,\text{rad/s} }. \]

Numeric:

\[ \omega\approx31{,}4\,\text{rad/s}. \]
Mărime Simbol Unitate Relație
perioadă \(T\) s \(T=1/f\)
frecvență \(f\) Hz \(f=1/T\)
viteză unghiulară \(\omega\) rad/s \(\omega=2\pi f\)

Un corp se rotește cu frecvența:

\[ f=2\,\text{Hz}. \]

Calculează numeric viteza unghiulară folosind \(\pi\approx3{,}1416\).

5. Legătura dintre mișcarea unghiulară și cea liniară

De la unghi la arc

Din definiția radianului:

\[ \theta= \frac{s}{r}. \]

Rezultă:

\[ \boxed{ s=r\theta }. \]

Împărțim la timp

\[ \frac{s}{\Delta t} = r \frac{\theta}{\Delta t}. \]

Dar:

\[ v= \frac{s}{\Delta t} \] și: \[ \omega= \frac{\theta}{\Delta t}. \]

Prin urmare:

\[ \boxed{ v=\omega r } \]

Alte forme utile

Pentru o rotație:

\[ s=2\pi r. \]

În timpul unei perioade \(T\):

\[ \boxed{ v= \frac{2\pi r}{T} } \] și, deoarece \(f=1/T\): \[ \boxed{ v=2\pi rf }. \]
Pe același corp rigid care se rotește: toate punctele au aceeași viteză unghiulară.

Dar:

\[ v=\omega r. \]

Punctele mai depărtate de axă au viteză liniară mai mare.

Un punct se află la:

\[ r=0{,}30\,\text{m} \] pe un disc cu: \[ \omega=10\,\text{rad/s}. \]

Calculează viteza liniară.

6. Exemplu rezolvat

O roată care efectuează 120 rotații/minut

Problemă

O roată de rază:

\[ r=0{,}25\,\text{m} \] se rotește uniform cu: \[ n=120\,\text{rotații/minut}. \]

Determină:

  1. frecvența;
  2. perioada;
  3. viteza unghiulară;
  4. viteza liniară a unui punct de pe margine.

1. Transformăm rotațiile pe minut

Un minut are 60 s:

\[ f= \frac{120}{60} \] \[ \boxed{ f=2\,\text{Hz} }. \]

2. Perioada

\[ T= \frac{1}{f} \] \[ T= \frac{1}{2} \] \[ \boxed{ T=0{,}5\,\text{s} }. \]

3. Viteza unghiulară

\[ \omega= 2\pi f \] \[ \omega= 2\pi\cdot2 \] \[ \boxed{ \omega=4\pi\,\text{rad/s} } \] \[ \omega\approx 12{,}57\,\text{rad/s}. \]

4. Viteza liniară

\[ v= \omega r. \] \[ v= 4\pi\cdot0{,}25. \] \[ v=\pi\,\text{m/s}. \] \[ \boxed{ v\approx3{,}14\,\text{m/s} }. \]

Rezultatele:

\[ \boxed{ f=2\,\text{Hz} } \] \[ \boxed{ T=0{,}5\,\text{s} } \] \[ \boxed{ \omega=4\pi\,\text{rad/s} } \] \[ \boxed{ v\approx3{,}14\,\text{m/s} }. \]

Verificarea prin circumferință

Într-o rotație punctul parcurge:

\[ 2\pi r. \]

Deci:

\[ v= \frac{2\pi r}{T}. \] \[ v= \frac{ 2\pi\cdot0{,}25 }{ 0{,}5 } = \pi\,\text{m/s}. \]

Obținem același rezultat.

rotații/min → \(f\)
\(f\) → \(T,\omega\)
\(\omega,r\) → \(v\)

Întrebarea-cheie

Când studiezi o rotație, întreabă:

„Cât durează o rotație, câte rotații se fac într-o secundă și ce unghi se parcurge într-o secundă?”

Aceste întrebări conduc natural la:

\[ T,\qquad f,\qquad\omega. \]

Următorul pas experimental

Mișcarea circulară uniformă poate fi studiată experimental măsurând timpul necesar pentru mai multe rotații.

Din măsurări se pot determina:

\[ T, \qquad f, \qquad \omega. \]

Repetarea determinărilor permite compararea rezultatelor și analiza incertitudinilor experimentale.
