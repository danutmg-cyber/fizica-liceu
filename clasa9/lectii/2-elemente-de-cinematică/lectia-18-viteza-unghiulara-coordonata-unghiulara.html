Viteza unghiulară și coordonata unghiulară

Poziție unghiulară • Deplasare unghiulară • Legea mișcării circulare uniforme

Prof. Dănuț Andronie e-Mail: danutmg@gmail.com

Cum precizăm poziția unui punct pe un cerc?

Pe o dreaptă folosim coordonata:

\[ x. \]

Pe un cerc este mai natural să folosim un unghi:

\[ \theta. \]

Dacă rotația este uniformă, coordonata unghiulară se modifică liniar cu timpul.

\[ \boxed{ \theta(t) = \theta_0+\omega t } \]

În MRU:

\[ x=x_0+vt. \]

În mișcarea circulară uniformă:

\[ \theta=\theta_0+\omega t. \]

La finalul lecției vei putea:

  • să definești coordonata unghiulară;
  • să alegi un sens pozitiv de rotație;
  • să calculezi deplasarea unghiulară;
  • să explici semnul lui \(\Delta\theta\);
  • să definești viteza unghiulară;
  • să utilizezi legea \(\theta=\theta_0+\omega t\);
  • să legi \(\omega\) de \(T\) și \(f\);
  • să distingi unghiul acumulat de orientarea geometrică finală pe cerc.

1. Coordonata unghiulară

Alegem o direcție de referință

Considerăm un punct \(P\) aflat pe un cerc cu centrul în \(O\).

Alegem o semidreaptă de referință, de exemplu axa pozitivă \(Ox\).

Poziția punctului poate fi indicată prin unghiul dintre direcția de referință și raza \(OP\).

Coordonata unghiulară \(\theta\) indică poziția unghiulară a punctului față de direcția de referință aleasă.

2. Deplasarea unghiulară

Din poziția inițială în poziția finală

Dacă punctul are inițial coordonata:

\[ \theta_0 \] și ajunge la: \[ \theta, \] atunci deplasarea unghiulară este: \[ \boxed{ \Delta\theta= \theta-\theta_0 }. \]

Legătura cu arcul parcurs

Pentru un unghi exprimat în radiani:

\[ s=r|\Delta\theta|. \]
\[ \boxed{ s= r|\Delta\theta| } \]

Deplasare unghiulară și lungime de arc

\(\Delta\theta\) poate fi pozitivă sau negativă deoarece conține informația despre sens.

Lungimea arcului parcurs \(s\) este o mărime scalară nenegativă:

\[ s\geq0. \]

Exemplu

Un punct se rotește pe un cerc de rază:

\[ r=0{,}40\,\text{m} \] și realizează: \[ \Delta\theta= \frac{3\pi}{2}\,\text{rad}. \]

Lungimea arcului parcurs este:

\[ s= r|\Delta\theta| \] \[ s= 0{,}40\cdot \frac{3\pi}{2} \] \[ \boxed{ s=0{,}6\pi\,\text{m} } \] \[ s\approx1{,}88\,\text{m}. \]

Un punct se rotește cu:

\[ \Delta\theta=2\,\text{rad} \]

pe un cerc cu:

\[ r=0{,}50\,\text{m}. \]

Calculează lungimea arcului.

3. Viteza unghiulară

Cât de repede se modifică unghiul?

Dacă într-un interval \(\Delta t\) coordonata unghiulară se modifică cu \(\Delta\theta\), definim:

\[ \boxed{ \omega= \frac{\Delta\theta}{\Delta t} } \]

În mișcarea circulară uniformă:

\[ \boxed{ \omega=\text{constant} }. \]

Unitatea de măsură

\[ \boxed{ [\omega]=\text{rad/s} } \]

Radianul este adimensional din punct de vedere matematic, dar simbolul „rad” este păstrat pentru a arăta că mărimea descrie o rotație.

Semnul lui \(\omega\)

\(\omega>0\)

Rotație în sensul ales pozitiv.

\(\omega<0\)

Rotație în sens opus sensului pozitiv.

Observație vectorială

În descrierea completă, viteza unghiulară este o mărime vectorială.

Pentru mișcare într-un plan fix, putem lucra la acest nivel cu valoarea sa algebrică \(\omega\), semnul indicând sensul rotației.

Exemplu

Un punct realizează:

\[ \Delta\theta= 3\pi\,\text{rad} \] în: \[ \Delta t= 1{,}5\,\text{s}. \]

Atunci:

\[ \omega= \frac{3\pi}{1{,}5} \] \[ \boxed{ \omega= 2\pi\,\text{rad/s} }. \]

Un corp se rotește cu:

\[ \Delta\theta=8\,\text{rad} \]

în 2 s. Calculează viteza unghiulară.

4. Legea coordonatei unghiulare

Deducerea legii

Pentru mișcare circulară uniformă:

\[ \omega= \frac{\Delta\theta}{\Delta t}. \]

Dacă la momentul \(t_0\) coordonata unghiulară este \(\theta_0\), iar la momentul \(t\) este \(\theta\), atunci:

\[ \omega= \frac{ \theta-\theta_0 }{ t-t_0 }. \]

Izolăm coordonata unghiulară

\[ \theta-\theta_0 = \omega(t-t_0). \]
\[ \boxed{ \theta(t) = \theta_0+ \omega(t-t_0) } \]

Pentru \(t_0=0\)

\[ \boxed{ \theta(t) = \theta_0+\omega t } \]

Analogia cu MRU

Mișcare rectilinie uniformă Mișcare circulară uniformă
\(x\) \(\theta\)
\(x_0\) \(\theta_0\)
\(\Delta x\) \(\Delta\theta\)
\(v\) \(\omega\)
\(x=x_0+vt\) \(\theta=\theta_0+\omega t\)
\[ \boxed{ x=x_0+vt } \] și: \[ \boxed{ \theta=\theta_0+\omega t } \] au aceeași structură matematică.

Exemplu

Inițial:

\[ \theta_0= \frac{\pi}{4}\,\text{rad}. \]

Viteza unghiulară:

\[ \omega= 2\,\text{rad/s}. \]

După 3 s:

\[ \theta= \frac{\pi}{4}+2\cdot3 \] \[ \boxed{ \theta= \frac{\pi}{4}+6 }. \]

Pentru:

\[ \theta_0=1\,\text{rad}, \qquad \omega=2\,\text{rad/s}, \]

determină coordonata unghiulară după 3 s.

5. Legătura cu perioada și frecvența

O rotație completă

În timpul unei perioade \(T\), deplasarea unghiulară este:

\[ \Delta\theta= 2\pi\,\text{rad}. \]

Din:

\[ \omega= \frac{\Delta\theta}{\Delta t}, \] rezultă: \[ \boxed{ \omega= \frac{2\pi}{T} }. \]

Deoarece:

\[ f= \frac{1}{T}, \] avem: \[ \boxed{ \omega= 2\pi f }. \]

Numărul de rotații

Dacă un corp efectuează \(N\) rotații:

\[ |\Delta\theta| = 2\pi N. \]

Pentru rotație în sens pozitiv:

\[ \boxed{ \Delta\theta= 2\pi N }. \]

Rezultă:

\[ \boxed{ N= \frac{ |\Delta\theta| }{ 2\pi } }. \]
\[ \boxed{ \omega= \frac{2\pi}{T} = 2\pi f } \]

Exemplu

Un disc are:

\[ f=3\,\text{Hz}. \]

În 2 s efectuează:

\[ N=ft \] \[ N=3\cdot2 \] \[ \boxed{ N=6 } \] rotații.

Deplasarea unghiulară:

\[ \Delta\theta= 2\pi N \] \[ \boxed{ \Delta\theta= 12\pi\,\text{rad} }. \]

Frecvență mai mare \(\Rightarrow\) mai multe rotații pe secundă.

Mai multe rotații pe secundă \(\Rightarrow\) viteză unghiulară mai mare.

Un disc se rotește cu:

\[ f=2{,}5\,\text{Hz}. \]

Câte rotații efectuează în 2 s?

6. Exemplu rezolvat

Coordonata unghiulară poate depăși \(2\pi\)

Problemă

Un punct se rotește uniform în sens trigonometric.

La \(t=0\):

\[ \theta_0= \frac{\pi}{6}\,\text{rad}. \]

Frecvența este:

\[ f=2\,\text{Hz}. \]

Determină după:

\[ t=0{,}75\,\text{s} \] următoarele:

  1. viteza unghiulară;
  2. deplasarea unghiulară;
  3. numărul de rotații;
  4. coordonata unghiulară acumulată;
  5. orientarea geometrică finală pe cerc.

1. Viteza unghiulară

\[ \omega= 2\pi f \] \[ \omega= 2\pi\cdot2 \] \[ \boxed{ \omega= 4\pi\,\text{rad/s} }. \]

2. Deplasarea unghiulară

\[ \Delta\theta= \omega t \] \[ \Delta\theta= 4\pi\cdot0{,}75 \] \[ \boxed{ \Delta\theta= 3\pi\,\text{rad} }. \]

3. Numărul de rotații

\[ N= \frac{ \Delta\theta }{ 2\pi } \] \[ N= \frac{ 3\pi }{ 2\pi } \] \[ \boxed{ N=1{,}5 }. \]

4. Coordonata unghiulară acumulată

\[ \theta= \theta_0+\Delta\theta \] \[ \theta= \frac{\pi}{6}+3\pi. \] \[ \theta= \frac{\pi}{6}+ \frac{18\pi}{6}. \] \[ \boxed{ \theta= \frac{19\pi}{6}\,\text{rad} }. \]

5. Unde este punctul efectiv pe cerc?

O rotație completă:

\[ 2\pi= \frac{12\pi}{6}. \]

Scădem o rotație completă:

\[ \frac{19\pi}{6} - \frac{12\pi}{6} = \frac{7\pi}{6}. \]

Coordonata unghiulară acumulată:

\[ \boxed{ \theta= \frac{19\pi}{6}\,\text{rad} } \]

Orientarea geometrică echivalentă pe cerc:

\[ \boxed{ \theta_{\text{geom}}= \frac{7\pi}{6}\,\text{rad} = 210^\circ }. \]
Unghiurile care diferă cu un număr întreg de rotații complete indică aceeași direcție geometrică: \[ \boxed{ \theta \quad\text{și}\quad \theta+2k\pi } \] unde \(k\) este număr întreg.

Nu reduce automat orice unghi la intervalul \(0\)–\(2\pi\)

Dacă problema cere deplasarea unghiulară totală sau numărul de rotații, trebuie păstrată informația despre unghiul acumulat.

\(f\rightarrow\omega\)
\(\omega t\rightarrow\Delta\theta\)
\(\theta_0+\Delta\theta\rightarrow\theta\)

Întrebarea-cheie

Într-o problemă de mișcare circulară uniformă, identifică:

coordonata inițială \(\theta_0\), sensul pozitiv, viteza unghiulară \(\omega\) și timpul \(t\).

Apoi folosește:

\[ \theta= \theta_0+\omega t. \]

Legătura cu experimentul

Prin măsurarea timpului pentru mai multe rotații putem determina:

\[ T=\frac{\Delta t}{N}, \] apoi: \[ f=\frac1T \] și: \[ \omega= \frac{2\pi}{T}. \]

Aceasta permite verificarea experimentală a modelului mișcării circulare uniforme.
