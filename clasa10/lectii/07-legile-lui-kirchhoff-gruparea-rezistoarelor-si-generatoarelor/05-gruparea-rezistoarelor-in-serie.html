Lecția 5 Clasa a X-a Gruparea rezistoarelor

Gruparea rezistoarelor în serie

Când mai multe rezistoare sunt conectate succesiv, fără ramificații între ele, același curent le străbate pe toate. Folosind legea lui Ohm și Legea a II-a a lui Kirchhoff vom determina rezistența echivalentă a întregii grupări.

🎯 Ce vei învăța

La final vei putea:

  • să recunoști o grupare de rezistoare în serie;
  • să explici de ce intensitatea este aceeași prin toate rezistoarele;
  • să explici cum se distribuie tensiunea pe rezistoare;
  • să deduci formula rezistenței echivalente;
  • să calculezi rezistența echivalentă a unei grupări în serie;
  • să determini tensiunea pe fiecare rezistor;
  • să folosești raportul de divizare a tensiunii;
  • să verifici experimental proprietățile grupării în serie.

Relațiile esențiale

\[ \boxed{ I=I_1=I_2=\ldots=I_n } \]
\[ \boxed{ U=U_1+U_2+\ldots+U_n } \]
\[ \boxed{ R_s= R_1+R_2+\ldots+R_n } \]

1. Situație-problemă

Avem trei rezistoare:

\[ R_1=2\,\Omega, \qquad R_2=3\,\Omega, \qquad R_3=5\,\Omega \]

conectate unul după altul la o sursă.

Întrebarea acestei lecții: Putem înlocui cele trei rezistoare cu un singur rezistor astfel încât sursa să furnizeze același curent?

2. Când sunt rezistoarele conectate în serie?

Două sau mai multe rezistoare sunt conectate în serie dacă sunt așezate succesiv pe aceeași latură, iar între ele nu există ramificații prin care curentul să se poată împărți.

Conectare în serie

\[ A -R_1- R_2- R_3- B \]

Există un singur traseu al curentului prin grupare.

Nu este suficient...

...ca rezistoarele să fie desenate unul lângă altul.

Trebuie analizate conexiunile electrice, nu poziția lor geometrică pe schemă.

Un criteriu foarte util: dacă între două rezistoare apare un nod din care pleacă o altă latură, ele nu mai formează singure o grupare pur serie.

3. Cele trei proprietăți fundamentale

I

Același curent

\[ \boxed{ I=I_1=I_2=I_3 } \]

Nu există ramificații între rezistoare.

U

Tensiunile se adună

\[ \boxed{ U=U_1+U_2+U_3 } \]

Rezultă din bilanțul variațiilor de potențial.

R

Rezistențele se adună

\[ \boxed{ R_s=R_1+R_2+R_3 } \]

Rezistorul echivalent opune aceeași rezistență totală.

4. De ce este aceeași intensitate?

Privim punctul de legătură dintre \(R_1\) și \(R_2\).

În acel punct nu există nicio ramificație. Sarcina electrică nu are două trasee pe care să se împartă.

Prin urmare:

\[ I_1=I_2 \]

La fel:

\[ I_2=I_3 \]
deci:

\[ \boxed{ I_1=I_2=I_3=I } \]
Aceasta este consecința directă a faptului că toate rezistoarele fac parte din aceeași latură.

5. De ce tensiunile se adună?

Aplicăm Legea a II-a a lui Kirchhoff circuitului care conține sursa și cele trei rezistoare.

\[ +U -U_1 -U_2 -U_3 =0 \]
de unde:

\[ \boxed{ U= U_1+U_2+U_3 } \]

Pentru \(n\) rezistoare:

\[ \boxed{ U= \sum_{k=1}^{n}U_k } \]

6. Deducerea rezistenței echivalente

Nu memorăm formula. O deducem din relațiile deja cunoscute.

1. Tensiunea totală
\[ U= U_1+U_2+U_3 \]
2. Aplicăm legea lui Ohm fiecărui rezistor
\[ U_1=IR_1 \] \[ U_2=IR_2 \] \[ U_3=IR_3 \]
3. Înlocuim
\[ U= IR_1+ IR_2+ IR_3 \]
4. Factorizăm intensitatea
\[ U= I(R_1+R_2+R_3) \]
5. Rezistorul echivalent trebuie să respecte
\[ U=IR_s \]
6. Comparăm
\[ \boxed{ R_s= R_1+R_2+R_3 } \]

General:

\[ \boxed{ R_s= R_1+R_2+\ldots+R_n = \sum_{k=1}^{n}R_k } \]

7. Ce înseamnă „rezistor echivalent”?

Gruparea originală

\[ A -R_1- R_2- R_3- B \]

Gruparea echivalentă

\[ A -R_s- B \]

Cele două configurații sunt echivalente din punctul de vedere al bornelor \(A\) și \(B\) dacă pentru aceeași tensiune:

\[ U_{AB} \]
produc același curent:

\[ I \]
Rezistorul echivalent nu reproduce neapărat toate detaliile interne ale grupării. El reproduce comportarea electrică văzută de la bornele externe.

8. O consecință imediată

Pentru rezistoare cu rezistențe pozitive:

\[ R_s= R_1+R_2+\ldots \]
deci:

\[ \boxed{ R_s> R_k } \]

pentru fiecare rezistor individual din grupare, dacă există cel puțin două rezistențe nenule.

Într-o grupare în serie, rezistența echivalentă este mai mare decât fiecare rezistență componentă luată separat.

9. Caz particular – rezistoare identice

Dacă avem \(n\) rezistoare identice:

\[ R_1=R_2=\ldots=R_n=R \]
atunci:

\[ R_s= \underbrace{ R+R+\ldots+R }_{n\text{ termeni}} \]
și:

\[ \boxed{ R_s=nR } \]

Exemplu

Patru rezistoare de:

\[ R=10\,\Omega \]
au:

\[ R_s= 4\cdot10 \]
\[ \boxed{ R_s=40\,\Omega } \]

10. Cum se distribuie tensiunea?

Pentru fiecare rezistor:

\[ U_k=IR_k \]
iar pentru întreaga grupare:

\[ I= \frac{U}{R_s} \]
Înlocuim:

\[ U_k= \frac{U}{R_s} R_k \]
deci:

\[ \boxed{ U_k= U \frac{R_k}{R_s} } \]

Pentru două rezistoare:

\[ \frac{U_1}{U_2} = \frac{R_1}{R_2} \]
În serie, rezistorul cu rezistența mai mare are și căderea de tensiune mai mare, deoarece același curent străbate toate rezistoarele.
Această relație este valabilă pentru rezistoare ohmice în condițiile în care rezistențele lor pot fi considerate constante.

🧮 Exemple rezolvate

Nivel 1

Exemplul 1 – Rezistența echivalentă

Se conectează în serie:

\[ R_1=4\,\Omega, \quad R_2=6\,\Omega, \quad R_3=10\,\Omega \]
Vezi rezolvarea
\[ R_s= R_1+R_2+R_3 \] \[ R_s= 4+6+10 \] \[ \boxed{ R_s=20\,\Omega } \]
Nivel 1

Exemplul 2 – Curentul prin grupare

Gruparea anterioară este conectată la:

\[ U=10\,V \]

Determină intensitatea.

Vezi rezolvarea
\[ R_s=20\,\Omega \] \[ I= \frac{U}{R_s} \] \[ I= \frac{10}{20} \] \[ \boxed{ I=0,50\,A } \] Același curent străbate fiecare rezistor.
Nivel 2

Exemplul 3 – Tensiunile pe rezistoare

Pentru:

\[ I=0,50\,A \]
și:

\[ R_1=4\,\Omega, \quad R_2=6\,\Omega, \quad R_3=10\,\Omega \]

determină \(U_1,U_2,U_3\).

Vezi rezolvarea
\[ U_1= IR_1= 0,5\cdot4= 2\,V \] \[ U_2= 0,5\cdot6= 3\,V \] \[ U_3= 0,5\cdot10= 5\,V \] Verificare: \[ 2+3+5= 10\,V \] \[ \boxed{ U_1=2\,V,\quad U_2=3\,V,\quad U_3=5\,V } \]
Nivel 2

Exemplul 4 – Rezistență necunoscută

Trei rezistoare sunt conectate în serie:

\[ R_s=30\,\Omega \] \[ R_1=8\,\Omega \] \[ R_2=12\,\Omega \] \[ R_3=? \]
Vezi rezolvarea
\[ R_s= R_1+R_2+R_3 \] \[ 30= 8+12+R_3 \] \[ 30= 20+R_3 \] \[ \boxed{ R_3=10\,\Omega } \]
Nivel 2

Exemplul 5 – Divizor de tensiune

Două rezistoare:

\[ R_1=2\,k\Omega \] \[ R_2=4\,k\Omega \]
sunt conectate în serie la:

\[ U=12\,V \]

Determină tensiunea pe \(R_2\).

Vezi rezolvarea
\[ R_s= 2+4= 6\,k\Omega \] Folosim raportul:

\[ U_2= U \frac{R_2}{R_s} \] \[ U_2= 12 \frac{4}{6} \] \[ \boxed{ U_2=8\,V } \]
Nivel 3

Exemplul 6 – Determină raportul rezistențelor

Pe două rezistoare conectate în serie se măsoară:

\[ U_1=3\,V \] \[ U_2=9\,V \]

Determină:

\[ \frac{R_1}{R_2} \]
Vezi rezolvarea
În serie:

\[ \frac{U_1}{U_2} = \frac{R_1}{R_2} \] deci:

\[ \frac{R_1}{R_2} = \frac39 = \frac13 \] \[ \boxed{ R_1:R_2=1:3 } \]

🔬 Experiment – verificarea grupării în serie

Materiale

  • sursă didactică de joasă tensiune;
  • 2–3 rezistoare;
  • ampermetru sau multimetru;
  • voltmetru sau multimetru;
  • conductoare;
  • întrerupător.

Ce verificăm?

\[ I_1\approx I_2\approx I_3 \]
\[ U\approx U_1+U_2+U_3 \]
  1. Montează două sau trei rezistoare succesiv, fără ramificații între ele.
  2. Conectează sursa numai după verificarea circuitului.
  3. Măsoară intensitatea înaintea primului rezistor: \[ I_1 \]
  4. Oprește alimentarea înainte de modificarea conexiunilor, apoi măsoară intensitatea într-un alt punct al aceleiași laturi: \[ I_2 \]
  5. Compară valorile: \[ I_1 \quad\text{și}\quad I_2 \]
  6. Conectează voltmetrul succesiv la bornele fiecărui rezistor și măsoară: \[ U_1,\ U_2,\ U_3 \]
  7. Măsoară tensiunea la bornele întregii grupări: \[ U \]
  8. Compară: \[ U \quad\text{cu}\quad U_1+U_2+U_3 \]
În limitele erorilor experimentale, te aștepți la:

\[ \boxed{ I_1\approx I_2\approx I_3 } \]
și:

\[ \boxed{ U\approx U_1+U_2+U_3 } \]
Reguli de lucru: ampermetrul se conectează în serie, voltmetrul în paralel cu porțiunea măsurată, iar conexiunile se modifică cu sursa oprită. Nu utiliza funcția de ohmmetru pe un circuit alimentat.

⚠️ Greșeli frecvente

1. „Curentul scade după fiecare rezistor.”

Nu.

Într-o grupare serie fără ramificații:

\[ I_1=I_2=I_3 \]

2. „Rezistoarele consumă curent.”

Rezistorul transferă energie electrică, dar sarcina electrică nu este „consumată”.

3. „Tensiunea este aceeași pe toate rezistoarele.”

Numai în cazul particular al unor rezistențe egale.

În general:

\[ U_k=IR_k \]

4. „În serie se adună tensiunile pentru că așa spune formula.”

Relația provine din bilanțul variațiilor de potențial, adică din Legea a II-a a lui Kirchhoff.

5. „Orice rezistoare desenate unul după altul sunt în serie.”

Nu. Trebuie să nu existe ramificații între ele.

6. „Rezistența echivalentă este media rezistențelor.”

Pentru serie:

\[ R_s= R_1+R_2+\ldots \]

7. „Rezistența echivalentă poate fi mai mică decât toate rezistențele.”

Nu pentru o grupare serie de rezistențe pozitive. Suma este mai mare decât fiecare termen individual.

8. „Rezistorul echivalent trebuie să fie identic fizic cu gruparea.”

Nu. Echivalența se referă la comportarea electrică văzută de la bornele externe.

📌 De reținut

Curent

\[ \boxed{ I_1=I_2=\ldots=I } \]

Tensiune

\[ \boxed{ U= U_1+U_2+\ldots } \]

Rezistență

\[ \boxed{ R_s= R_1+R_2+\ldots } \]
Pentru \(n\) rezistoare identice:

\[ \boxed{ R_s=nR } \]
Pentru divizarea tensiunii:

\[ \boxed{ U_k= U \frac{R_k}{R_s} } \]

și, pentru două rezistoare:

\[ \boxed{ \frac{U_1}{U_2} = \frac{R_1}{R_2} } \]

🔗 Ce urmează?

În serie există un singur traseu pentru curent.

Dar ce se întâmplă când fiecare rezistor este conectat între aceleași două noduri?

În lecția următoare: Gruparea rezistoarelor în paralel vom descoperi că:
  • tensiunea devine aceeași pe fiecare ramură;
  • curentul se ramifică;
  • rezistența echivalentă devine mai mică decât fiecare rezistență individuală.
