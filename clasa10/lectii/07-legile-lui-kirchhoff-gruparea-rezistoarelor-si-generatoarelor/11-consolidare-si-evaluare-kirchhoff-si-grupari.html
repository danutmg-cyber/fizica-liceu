Lecția 11 Evaluare Remediere

Consolidare și evaluare – Kirchhoff și grupări

O evaluare diagnostică a întregului capitol: rețele electrice, legile lui Kirchhoff, grupări de rezistoare și generatoare și adaptarea domeniului aparatelor de măsură. La final primești un profil pe teme și un plan de remediere.

🎯 Scopul evaluării

Nu evaluăm doar memoria

Itemii verifică dacă poți:

  • recunoaște structura unei rețele;
  • aplica legile lui Kirchhoff;
  • alege corect relațiile serie/paralel;
  • interpreta semnul unui curent;
  • calcula parametri echivalenți;
  • verifica dacă un rezultat este fizic plauzibil.

După test

Pagina va genera:

  • scor din 100 de puncte;
  • procent pentru fiecare temă;
  • explicația fiecărui item;
  • lecțiile recomandate pentru recapitulare;
  • un mini-retest numai pentru domeniile care necesită consolidare.
Pentru o evaluare diagnostică utilă, rezolvă mai întâi testul fără a consulta lecțiile anterioare. Explicațiile și fișa de recapitulare apar după finalizarea evaluării.

📚 Fișă de recapitulare după evaluare

Legea I a lui Kirchhoff

\[ \boxed{ \sum I_{\text{intră}} = \sum I_{\text{ies}} } \]

Consecință a conservării sarcinii electrice.

Legea a II-a a lui Kirchhoff

\[ \boxed{ \sum \mathcal E = \sum IR } \]

Pentru un ochi și o convenție de semne coerentă.

Rezistoare în serie

\[ \boxed{ R_s= R_1+R_2+\ldots } \]
\[ I_1=I_2=\ldots \]

Rezistoare în paralel

\[ \boxed{ \frac1{R_p} = \frac1{R_1} + \frac1{R_2} +\ldots } \]
\[ U_1=U_2=\ldots \]

Generatoare în serie

\[ \boxed{ \mathcal E_{eq} = \sum s_k\mathcal E_k } \]
\[ \boxed{ r_{eq} = \sum r_k } \]

Generatoare identice în paralel

\[ \boxed{ \mathcal E_{eq}=\mathcal E } \]
\[ \boxed{ r_{eq}=\frac rn } \]

Ampermetru – șunt

\[ \boxed{ R_{sh} = \frac{R_A}{n-1} } \]

Șuntul se conectează în paralel.

Voltmetru – rezistență adițională

\[ \boxed{ R_{ad} = (n-1)R_V } \]

Rezistența adițională se conectează în serie.

În problemele de rețea, nu începe prin a căuta o formulă. Începe prin a identifica: nodurile → ramurile → sensurile de referință → conexiunile serie/paralel → ecuațiile necesare.

✅ Checklist de final de capitol

Capitolul este bine consolidat dacă poți răspunde afirmativ la majoritatea întrebărilor următoare:

  • Pot identifica nodurile și laturile?
  • Pot scrie Legea I într-un nod?
  • Pot alege un sens de parcurgere pentru un ochi?
  • Pot interpreta un curent calculat negativ?
  • Pot recunoaște dacă două rezistoare sunt cu adevărat în paralel?
  • Pot reduce o grupare mixtă pas cu pas?
  • Pot calcula parametrii unei grupări de generatoare?
  • Știu diferența dintre serie și paralel la generatoare?
  • Pot dimensiona un șunt?
  • Pot dimensiona o rezistență adițională pentru voltmetru?
