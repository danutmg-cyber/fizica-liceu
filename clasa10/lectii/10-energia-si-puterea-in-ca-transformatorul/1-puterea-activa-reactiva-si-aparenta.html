Lecția 1 Clasa a X-a Puteri în curent alternativ

Puterea activă, reactivă și aparentă

Într-un circuit de curent alternativ, produsul valorilor efective \(UI\) nu reprezintă întotdeauna puterea transformată efectiv în alte forme de energie. Diferența de fază dintre tensiune și curent conduce la trei mărimi: puterea activă \(P\), puterea reactivă \(Q\) și puterea aparentă \(S\).

🎯 Ce vei învăța

La final vei putea:

  • să explici de ce puterea instantanee variază în curent alternativ;
  • să definești puterea activă;
  • să definești puterea reactivă;
  • să definești puterea aparentă;
  • să folosești relațiile \(P=UI\cos\varphi\), \(Q=UI\sin\varphi\) și \(S=UI\);
  • să construiești triunghiul puterilor;
  • să folosești relația \(S^2=P^2+Q^2\);
  • să interpretezi semnul puterii reactive;
  • să recunoști sarcini rezistive, inductive și capacitive;
  • să explici rolul factorului de putere.

Relațiile centrale

\[ \boxed{ P=UI\cos\varphi } \]
\[ \boxed{ Q=UI\sin\varphi } \]
\[ \boxed{ S=UI } \]
\[ \boxed{ S^2=P^2+Q^2 } \]

1. De unde pornim?

În capitolul anterior am folosit pentru un circuit sinusoidal:

\[ \boxed{ P=UI\cos\varphi } \]

unde:

  • \(U\) este valoarea efectivă a tensiunii;
  • \(I\) este valoarea efectivă a curentului;
  • \(\varphi=\varphi_U-\varphi_I\) este diferența de fază;
  • \(\cos\varphi\) este factorul de putere.
Dacă tensiunea și curentul sunt în fază: \[ \varphi=0 \] și: \[ P=UI \] Dar dacă există un decalaj de fază, numai o parte din produsul \(UI\) reprezintă putere activă.

2. Puterea instantanee

Considerăm tensiunea:

\[ u(t)=U_m\sin(\omega t) \]

și curentul:

\[ i(t)=I_m\sin(\omega t-\varphi) \]

unde folosim convenția:

\[ \boxed{ \varphi=\varphi_U-\varphi_I } \]

Puterea instantanee este:

\[ p(t)=u(t)i(t) \]

Folosind identitatea:

\[ \sin a\sin b= \frac12 \left[ \cos(a-b)-\cos(a+b) \right] \]

obținem:

\[ \boxed{ p(t)= UI \left[ \cos\varphi- \cos(2\omega t-\varphi) \right] } \]
Puterea instantanee are:
  • o componentă constantă, \(UI\cos\varphi\);
  • o componentă oscilantă, cu pulsația \(2\omega\).

3. Puterea activă \(P\)

Media pe o perioadă a termenului oscilant este zero. Prin urmare, puterea medie transferată efectiv receptorului este:

\[ \boxed{ P=UI\cos\varphi } \]

Aceasta se numește putere activă.

Unitatea de măsură

\[ \boxed{ [P]=W } \]

Unitatea este wattul.

Puterea activă descrie ritmul mediu în care energia electrică este transformată în alte forme de energie:
  • energie internă;
  • energie mecanică;
  • energie luminoasă;
  • alte forme utile sau disipative.

4. Cazul pur rezistiv

Pentru un rezistor ideal:

\[ \varphi=0 \]

deci:

\[ \cos\varphi=1 \]

și:

\[ \boxed{ P=UI } \]

Cum:

\[ U=RI \]

rezultă și:

\[ \boxed{ P=I^2R } \]

respectiv:

\[ \boxed{ P=\frac{U^2}{R} } \]

5. Puterea reactivă \(Q\)

Bobina și condensatorul ideale nu consumă putere activă în medie, dar schimbă periodic energie cu sursa.

Pentru descrierea acestei componente reactive definim:

\[ \boxed{ Q=UI\sin\varphi } \]

Unitatea de măsură

\[ \boxed{ [Q]=var } \]

Unitatea se numește volt-amper reactiv, simbol \(var\).

Puterea reactivă nu reprezintă o energie consumată ireversibil în fiecare secundă. Ea caracterizează schimbul periodic de energie dintre sursă și elementele reactive: bobine și condensatoare.

6. Semnul puterii reactive

Folosim convenția:

\[ \varphi= \varphi_U-\varphi_I \]

Sarcină inductivă

Curentul este în urmă față de tensiune:

\[ \varphi>0 \]

deci:

\[ \boxed{ Q>0 } \]

Sarcină capacitivă

Curentul conduce tensiunea:

\[ \varphi<0 \]

deci:

\[ \boxed{ Q<0 } \]

Sarcină rezistivă

\[ \varphi=0 \]
\[ \boxed{ Q=0 } \]
Convenția uzuală folosită aici este: \[ \boxed{ Q>0 \text{ pentru caracter inductiv} } \] și: \[ \boxed{ Q<0 \text{ pentru caracter capacitiv} } \]

7. Bobina și condensatorul ideale

Bobină ideală

\[ \varphi=+90^\circ \]
\[ P= UI\cos90^\circ = 0 \]
\[ \boxed{ Q=+UI } \]

Condensator ideal

\[ \varphi=-90^\circ \]
\[ P= UI\cos(-90^\circ) = 0 \]
\[ \boxed{ Q=-UI } \]
Pentru ambele elemente ideale: \[ \boxed{ P=0 } \] dar puterea instantanee nu este permanent zero. Energia este absorbită și apoi restituită circuitului.

8. Puterea aparentă \(S\)

Produsul valorilor efective ale tensiunii și curentului definește puterea aparentă:

\[ \boxed{ S=UI } \]

Unitatea de măsură

\[ \boxed{ [S]=VA } \]

Unitatea este volt-amperul.

Deși dimensional: \[ 1\,VA=1\,V\cdot A \] și wattul poate fi scris tot ca \(V\cdot A\), se folosesc denumiri diferite pentru a evidenția semnificația fizică diferită:
  • \(P\) în W – putere activă;
  • \(Q\) în var – putere reactivă;
  • \(S\) în VA – putere aparentă.

9. Legătura dintre \(P\), \(Q\) și \(S\)

Avem:

\[ P=S\cos\varphi \]

și:

\[ Q=S\sin\varphi \]

Ridicăm la pătrat și adunăm:

\[ P^2+Q^2 = S^2 \left( \cos^2\varphi+ \sin^2\varphi \right) \]

Cum:

\[ \cos^2\varphi+ \sin^2\varphi=1 \]

rezultă:

\[ \boxed{ S^2=P^2+Q^2 } \]

sau:

\[ \boxed{ S= \sqrt{ P^2+Q^2 } } \]

10. Triunghiul puterilor

Relația:

\[ S^2=P^2+Q^2 \]

poate fi reprezentată printr-un triunghi dreptunghic.

Latură Mărime Unitate
orizontală puterea activă \(P\) W
verticală puterea reactivă \(Q\) var
ipotenuză puterea aparentă \(S\) VA
\[ \boxed{ \cos\varphi= \frac PS } \]
\[ \boxed{ \sin\varphi= \frac QS } \]
\[ \boxed{ \tan\varphi= \frac QP } \]

11. Factorul de putere

Din:

\[ P=UI\cos\varphi \]

și:

\[ S=UI \]

rezultă:

\[ \boxed{ \cos\varphi= \frac PS } \]
Factorul de putere arată ce fracție din puterea aparentă corespunde puterii active: \[ \boxed{ P=S\cos\varphi } \] Cu cât \(|\varphi|\) este mai mic, cu atât \(\cos\varphi\) este mai apropiat de 1.

12. De ce contează factorul de putere?

Din:

\[ P= UI\cos\varphi \]

rezultă:

\[ \boxed{ I= \frac{ P }{ U\cos\varphi } } \]

Dacă dorim aceeași putere activă \(P\) la aceeași tensiune \(U\), un factor de putere mai mic necesită un curent mai mare.

\[ \cos\varphi\downarrow \]
→
\[ I\uparrow \]
→
pierderi Joule mai mari în conductoare
Pentru o rezistență a liniei \(R_{linie}\): \[ P_{pierderi} = I^2R_{linie} \] Deci creșterea curentului poate mări semnificativ pierderile termice.

13. Puterile într-un circuit RLC serie

Pentru:

\[ Z= \sqrt{ R^2+ (X_L-X_C)^2 } \]

avem:

\[ \cos\varphi= \frac RZ \]

și:

\[ \sin\varphi= \frac{ X_L-X_C }{ Z } \]

Puterea activă

\[ P= UI\cos\varphi \]

Cum \(U=ZI\):

\[ \boxed{ P=I^2R } \]

Puterea reactivă

\[ Q= UI\sin\varphi \]

de unde:

\[ \boxed{ Q= I^2 (X_L-X_C) } \]

Puterea aparentă

\[ \boxed{ S=UI=I^2Z } \]

14. Semnul lui \(Q\) într-un circuit RLC

\(X_L>X_C\)

\[ Q>0 \]

Circuit cu caracter inductiv.

\(X_C>X_L\)

\[ Q<0 \]

Circuit cu caracter capacitiv.

\(X_L=X_C\)

\[ Q=0 \]

Rezonanță serie.

La rezonanță: \[ \varphi=0 \] \[ Q=0 \] \[ S=P \] \[ \cos\varphi=1 \] Circuitul este global rezistiv.

15. Tabel comparativ

Mărime Simbol Relație Unitate Semnificație
Putere activă \(P\) \(UI\cos\varphi\) W transfer mediu net de energie către receptor
Putere reactivă \(Q\) \(UI\sin\varphi\) var descrie componenta asociată schimbului periodic de energie
Putere aparentă \(S\) \(UI\) VA produsul valorilor efective \(U\) și \(I\)

🧮 Exemple rezolvate

Nivel 1

Exemplul 1 – Puterea aparentă

Un receptor este alimentat la:

\[ U=230\,V \]

și este parcurs de:

\[ I=2\,A \]

Determinați puterea aparentă.

Vezi rezolvarea
\[ S=UI \] \[ S= 230\cdot2 \] \[ \boxed{ S=460\,VA } \]
Nivel 1

Exemplul 2 – Puterea activă

Pentru receptorul anterior:

\[ \cos\varphi=0,80 \]

Determinați puterea activă.

Vezi rezolvarea
\[ P= S\cos\varphi \] \[ P= 460\cdot0,80 \] \[ \boxed{ P=368\,W } \]
Nivel 1

Exemplul 3 – Puterea reactivă

Se dau:

\[ U=100\,V, \quad I=2\,A, \quad \varphi=60^\circ \]

Determinați \(Q\).

Vezi rezolvarea
\[ Q= UI\sin\varphi \] \[ Q= 100\cdot2\cdot \sin60^\circ \] \[ Q= 200\cdot0,866 \] \[ \boxed{ Q\approx173,2\,var } \] Dacă \(\varphi=+60^\circ\), sarcina are caracter inductiv.
Nivel 2

Exemplul 4 – Din \(P\) și \(Q\)

Un receptor are:

\[ P=800\,W \]
\[ Q=600\,var \]

Determinați puterea aparentă.

Vezi rezolvarea
\[ S= \sqrt{ P^2+Q^2 } \] \[ S= \sqrt{ 800^2+ 600^2 } \] \[ S= \sqrt{ 640000+ 360000 } \] \[ S= 1000\,VA \] \[ \boxed{ S=1000\,VA } \]
Nivel 2

Exemplul 5 – Factorul de putere

Pentru:

\[ P=800\,W, \quad S=1000\,VA \]

determinați factorul de putere.

Vezi rezolvarea
\[ \cos\varphi= \frac PS \] \[ \cos\varphi= \frac{800}{1000} \] \[ \boxed{ \cos\varphi=0,80 } \]
Nivel 2

Exemplul 6 – Unghiul de fază

Un circuit are:

\[ P=300\,W, \quad Q=400\,var \]

Determinați \(\varphi\).

Vezi rezolvarea
\[ \tan\varphi= \frac QP \] \[ \tan\varphi= \frac{400}{300} = \frac43 \] \[ \boxed{ \varphi\approx53,1^\circ } \] Cum \(Q>0\), caracterul este inductiv.
Nivel 2

Exemplul 7 – Sarcină capacitivă

Se dau:

\[ U=120\,V, \quad I=3\,A, \quad \varphi=-30^\circ \]

Determinați \(P\), \(Q\) și \(S\).

Vezi rezolvarea
Puterea aparentă:

\[ S= UI= 120\cdot3 = 360\,VA \] Puterea activă:

\[ P= 360\cos(-30^\circ) \] \[ P\approx 360\cdot0,866 \] \[ P\approx311,8\,W \] Puterea reactivă:

\[ Q= 360\sin(-30^\circ) \] \[ Q= 360\cdot(-0,5) \] \[ Q=-180\,var \] Rezultă:

\[ \boxed{ P\approx311,8\,W } \] \[ \boxed{ Q=-180\,var } \] \[ \boxed{ S=360\,VA } \] Semnul negativ al lui \(Q\) indică un caracter capacitiv.
Nivel 3

Exemplul 8 – Curent pentru aceeași putere activă

Un receptor consumă:

\[ P=1000\,W \]

la:

\[ U=200\,V \]

Comparați curentul pentru \(\cos\varphi=1\) și pentru \(\cos\varphi=0,5\).

Vezi rezolvarea
Folosim:

\[ I= \frac{ P }{ U\cos\varphi } \] Pentru:

\[ \cos\varphi=1 \] obținem:

\[ I_1= \frac{1000}{200} = 5\,A \] Pentru:

\[ \cos\varphi=0,5 \] obținem:

\[ I_2= \frac{ 1000 }{ 200\cdot0,5 } = 10\,A \] Deci:

\[ \boxed{ I_2=2I_1 } \] Dacă rezistența liniei rămâne aceeași, pierderile Joule devin de patru ori mai mari:

\[ P_{pierderi}\propto I^2 \]
Nivel 3

Exemplul 9 – Circuit RLC serie

Se dau:

\[ I=2\,A, \quad R=30\,\Omega, \quad X_L=50\,\Omega, \quad X_C=10\,\Omega \]

Determinați \(P\), \(Q\) și \(S\).

Vezi rezolvarea
Puterea activă:

\[ P= I^2R \] \[ P= 2^2\cdot30 \] \[ P=120\,W \] Puterea reactivă:

\[ Q= I^2 (X_L-X_C) \] \[ Q= 4(50-10) \] \[ Q=160\,var \] Puterea aparentă:

\[ S= \sqrt{ 120^2+ 160^2 } \] \[ S= 200\,VA \] Prin urmare:

\[ \boxed{ P=120\,W, \quad Q=160\,var, \quad S=200\,VA } \]
Nivel 3

Exemplul 10 – Rezonanța

Ce valori au \(Q\) și factorul de putere pentru un circuit RLC serie la rezonanță?

Vezi rezolvarea
La rezonanță:

\[ X_L=X_C \] deci:

\[ \varphi=0 \] Prin urmare:

\[ Q= UI\sin0 = 0 \] și:

\[ \cos\varphi= 1 \] Deci:

\[ \boxed{ Q=0 } \] \[ \boxed{ \cos\varphi=1 } \] iar:

\[ \boxed{ S=P } \]

18. Ce înseamnă \(p(t)<0\)?

Când:

\[ p(t)>0 \]

energia circulă, în convenția receptorului, de la sursă către circuit.

Când:

\[ p(t)<0 \]

circuitul restituie temporar energie către sursă.

Această alternanță apare din cauza elementelor reactive. Bobina și condensatorul pot stoca temporar energie în: \[ W_m= \frac12Li^2 \] respectiv: \[ W_e= \frac12Cu^2 \] și o pot restitui ulterior circuitului.

⚠️ 20. Greșeli frecvente

1. „\(P=UI\) pentru orice receptor.”

Nu.

\[ \boxed{ P=UI\cos\varphi } \]

Relația \(P=UI\) apare când \(\cos\varphi=1\).

2. „Puterea aparentă este puterea consumată.”

Nu.

\[ S=UI \]

este puterea aparentă, nu puterea activă.

3. „Puterea reactivă se măsoară în W.”

În notația tehnică:

\[ \boxed{ [Q]=var } \]

4. „Puterea aparentă se măsoară în var.”

Nu.

\[ \boxed{ [S]=VA } \]

5. „\(S=P+Q\).”

Nu.

\[ \boxed{ S^2=P^2+Q^2 } \]

6. „\(Q\) este mereu pozitiv.”

Nu cu convenția utilizată aici.

\[ Q>0 \]

pentru caracter inductiv, iar:

\[ Q<0 \]

pentru caracter capacitiv.

7. „Bobina ideală nu schimbă energie cu sursa.”

Schimbă energie periodic, dar energia netă transferată într-o perioadă este zero.

8. „Dacă \(P=0\), atunci \(I=0\).”

Nu.

O bobină sau un condensator ideal poate fi parcurs de curent, deși puterea activă medie este zero.

9. „Factorul de putere are unitate.”

Nu.

\[ \cos\varphi= \frac PS \]

este adimensional.

10. „La rezonanță există putere reactivă totală mare.”

Pentru circuitul RLC ideal analizat global:

\[ \boxed{ Q=0 } \]

chiar dacă bobina și condensatorul schimbă energie între ele și cu circuitul.
