Lecția 3 Clasa a X-a Transformatorul

Transformatorul. Construcție și principiu de funcționare. Raport de transformare

Transformatorul folosește inducția electromagnetică pentru a modifica valoarea tensiunii alternative fără a modifica frecvența. În modelul ideal, raportul tensiunilor este determinat de raportul numerelor de spire, iar curenții se transformă în raport invers.

🎯 Ce vei învăța

La final vei putea:

  • să identifici părțile principale ale unui transformator;
  • să diferențiezi înfășurarea primară de cea secundară;
  • să explici rolul miezului magnetic;
  • să explici funcționarea prin inducție electromagnetică;
  • să folosești raportul de transformare;
  • să recunoști un transformator ridicător sau coborâtor de tensiune;
  • să explici relația dintre curenții primar și secundar;
  • să aplici conservarea puterii în modelul ideal;
  • să diferențiezi transformatorul ideal de cel real;
  • să explici de ce transformatorul necesită flux magnetic variabil.

Relațiile centrale

\[ \boxed{ \frac{U_1}{U_2} = \frac{N_1}{N_2} } \]
\[ \boxed{ k= \frac{N_1}{N_2} = \frac{U_1}{U_2} } \]
\[ \boxed{ \frac{I_2}{I_1} = \frac{N_1}{N_2} = k } \]
\[ \boxed{ P_1=P_2 } \]

pentru transformatorul ideal.

1. De ce avem nevoie de transformatoare?

În lecția precedentă am observat că, pentru o anumită putere activă, creșterea tensiunii permite reducerea curentului:

\[ I= \frac{ P }{ U\cos\varphi } \]

Iar pierderile Joule pe conductoare sunt:

\[ P_J= I^2R \]
tensiune mai mare
→
curent mai mic
→
pierderi Joule mai mici
Transformatorul este dispozitivul care permite creșterea sau micșorarea tensiunii alternative prin inducție electromagnetică.

2. Ce este transformatorul?

Transformatorul este un aparat electromagnetic static care transferă energie electrică între două circuite prin intermediul unui câmp magnetic variabil.

În forma sa de bază conține:

  • o înfășurare primară;
  • o înfășurare secundară;
  • un miez magnetic comun.
Transformatorul nu are nevoie de contact electric direct între înfășurarea primară și cea secundară în modelul obișnuit cu înfășurări separate. Transferul energiei se realizează prin cuplaj magnetic.

3. Construcția transformatorului

Înfășurarea primară

Are:

\[ N_1 \]

spire și este conectată la sursa de tensiune alternativă:

\[ U_1 \]

Înfășurarea secundară

Are:

\[ N_2 \]

spire și alimentează receptorul cu tensiunea:

\[ U_2 \]

Miezul magnetic

Asigură o cale de reluctanță magnetică mică și favorizează cuplarea fluxului magnetic între cele două înfășurări.

4. De ce miez feromagnetic?

Curentul alternativ din primar produce un câmp magnetic variabil. Miezul feromagnetic concentrează o mare parte din fluxul magnetic astfel încât acesta să străbată și înfășurarea secundară.

Rolul miezului este să realizeze un cuplaj magnetic eficient între înfășurări.

De ce este adesea realizat din tole?

Într-un miez conductor supus unui flux magnetic variabil se pot induce curenți turbionari. Aceștia încălzesc inutil miezul.

Construirea miezului din foi subțiri izolate electric între ele reduce intensitatea acestor curenți.

Laminarea miezului reduce pierderile prin curenți turbionari.

5. Principiul de funcționare

  1. Aplicăm o tensiune alternativă la înfășurarea primară.
  2. Prin primar circulă un curent alternativ.
  3. Curentul produce în miez un flux magnetic variabil.
  4. Fluxul variabil străbate și spirele înfășurării secundare.
  5. Prin inducție electromagnetică apare o tensiune electromotoare în secundar.
  6. Dacă secundarul este conectat la un receptor, prin el circulă curent și se transferă energie către receptor.

6. Legătura cu legea inducției electromagnetice

Pentru o bobină cu \(N\) spire, tensiunea electromotoare indusă este descrisă de:

\[ \boxed{ e= -N \frac{d\Phi}{dt} } \]

În transformator, ambele înfășurări sunt străbătute aproximativ de același flux magnetic variabil în modelul ideal.

De aceea amplitudinea tensiunii induse este proporțională cu numărul de spire:

\[ E\propto N \]

iar pentru cele două înfășurări:

\[ \boxed{ \frac{U_1}{U_2} = \frac{N_1}{N_2} } \]

7. Raportul de transformare

În această lecție definim:

\[ \boxed{ k= \frac{N_1}{N_2} = \frac{U_1}{U_2} } \]
În unele surse, raportul de transformare poate fi definit invers. De aceea, înainte de rezolvarea unei probleme, verifică întotdeauna definiția lui \(k\). În această lecție folosim: \[ \boxed{ k= \frac{U_1}{U_2} = \frac{N_1}{N_2} } \]

8. Ridicător sau coborâtor de tensiune?

Ridicător

\[ N_2>N_1 \]

deci:

\[ U_2>U_1 \]

și, cu definiția noastră:

\[ \boxed{ k<1 } \]

Coborâtor

\[ N_2

deci:

\[ U_2

și:

\[ \boxed{ k>1 } \]

Raport 1:1

\[ N_2=N_1 \]

deci:

\[ U_2=U_1 \]

și:

\[ \boxed{ k=1 } \]

9. Cum calculăm tensiunea secundară?

Din:

\[ \frac{U_1}{U_2} = \frac{N_1}{N_2} \]

rezultă:

\[ \boxed{ U_2= U_1 \frac{N_2}{N_1} } \]

Exemplu rapid

Dacă:

\[ U_1=12\,V, \quad N_1=400, \quad N_2=800 \]

atunci:

\[ U_2= 12 \frac{800}{400} \]
\[ \boxed{ U_2=24\,V } \]

Transformatorul este ridicător de tensiune.

10. Puterea într-un transformator ideal

Un transformator ideal nu are pierderi de energie. Prin urmare:

\[ \boxed{ P_1=P_2 } \]

În modelul simplificat:

\[ \boxed{ U_1I_1= U_2I_2 } \]

Această relație arată că transformatorul nu „creează putere”.

Dacă transformatorul mărește tensiunea, curentul disponibil pe secundar scade în raport corespunzător. Dacă micșorează tensiunea, curentul secundar poate fi mai mare.

11. Raportul curenților

Pornim de la:

\[ U_1I_1= U_2I_2 \]

de unde:

\[ \frac{I_2}{I_1} = \frac{U_1}{U_2} \]

dar:

\[ \frac{U_1}{U_2} = \frac{N_1}{N_2} = k \]

Deci:

\[ \boxed{ \frac{I_2}{I_1} = \frac{N_1}{N_2} = k } \]

sau echivalent:

\[ \boxed{ \frac{I_1}{I_2} = \frac{N_2}{N_1} } \]
Tensiunile se transformă în același raport cu numărul de spire. Curenții se transformă în raport invers.

13. Transformatorul modifică frecvența?

Nu. În funcționarea ideală:

\[ \boxed{ f_2=f_1 } \]

Dacă primarul este alimentat sinusoidal la \(50\,Hz\), tensiunea secundară are aceeași frecvență:

\[ \boxed{ f_2=50\,Hz } \]
Transformatorul poate modifica tensiunea și curentul, dar nu modifică frecvența semnalului alternativ.

14. De ce un transformator nu funcționează normal în curent continuu?

Principiul transformatorului necesită:

\[ \frac{d\Phi}{dt}\neq0 \]

adică un flux magnetic variabil.

După regimul tranzitoriu, un curent continuu constant ar produce un flux aproximativ constant:

\[ \frac{d\Phi}{dt}=0 \]

și tensiunea indusă în secundar ar deveni:

\[ e_2=0 \]
Un transformator proiectat pentru curent alternativ nu trebuie conectat la o sursă de curent continuu în regim normal. În primar poate apărea un curent foarte mare, limitat în principal de rezistența înfășurării, cu risc de încălzire și deteriorare.

15. Transformatorul real

Un transformator real are pierderi, deci:

\[ P_2

Definim randamentul:

\[ \boxed{ \eta= \frac{P_2}{P_1} } \]

sau procentual:

\[ \boxed{ \eta[\%] = \frac{P_2}{P_1} \cdot100 } \]

Surse principale de pierderi

În înfășurări

Efect Joule:

\[ P_J= I^2R \]

În miez

Curenți turbionari și pierderi asociate magnetizării ciclice.

Flux de dispersie

Nu întregul flux produs de o înfășurare străbate perfect cealaltă înfășurare.

16. Puterea în cazul real

Pentru un receptor general în curent alternativ:

\[ P_2= U_2I_2\cos\varphi_2 \]

iar la intrare:

\[ P_1= U_1I_1\cos\varphi_1 \]

Randamentul este:

\[ \boxed{ \eta= \frac{ U_2I_2\cos\varphi_2 }{ U_1I_1\cos\varphi_1 } } \]
Relația simplă: \[ U_1I_1=U_2I_2 \] se folosește pentru transformatorul ideal sau ca aproximație atunci când pierderile pot fi neglijate.

🧮 Exemple rezolvate

Nivel 1

Exemplul 1 – Tensiunea secundară

Se dau:

\[ N_1=500, \quad N_2=100, \quad U_1=20\,V \]

Determinați \(U_2\).

Vezi rezolvarea

Folosim:

\[ \frac{U_1}{U_2} = \frac{N_1}{N_2} \]

deci:

\[ U_2= U_1 \frac{N_2}{N_1} \] \[ U_2= 20 \frac{100}{500} \] \[ \boxed{ U_2=4\,V } \]

Transformatorul este coborâtor de tensiune.

Nivel 1

Exemplul 2 – Numărul de spire secundare

Se dau:

\[ U_1=12\,V, \quad U_2=36\,V, \quad N_1=200 \]

Determinați \(N_2\).

Vezi rezolvarea
\[ \frac{U_1}{U_2} = \frac{N_1}{N_2} \]

de unde:

\[ N_2= N_1 \frac{U_2}{U_1} \] \[ N_2= 200 \frac{36}{12} \] \[ \boxed{ N_2=600 } \]

Secundarul are de trei ori mai multe spire decât primarul.

Nivel 1

Exemplul 3 – Raportul de transformare

Un transformator are:

\[ N_1=1000, \quad N_2=250 \]

Determinați \(k\).

Vezi rezolvarea

În convenția utilizată în această lecție:

\[ k= \frac{N_1}{N_2} \] \[ k= \frac{1000}{250} \] \[ \boxed{ k=4 } \]

Cum \(k>1\), transformatorul este coborâtor de tensiune.

Nivel 2

Exemplul 4 – Curentul secundar

Un transformator ideal are:

\[ N_1=600, \quad N_2=200 \]

iar curentul primar este:

\[ I_1=0,5\,A \]

Determinați \(I_2\).

Vezi rezolvarea
\[ \frac{I_2}{I_1} = \frac{N_1}{N_2} \] \[ I_2= I_1 \frac{N_1}{N_2} \] \[ I_2= 0,5 \frac{600}{200} \] \[ \boxed{ I_2=1,5\,A } \]
Nivel 2

Exemplul 5 – Puterea ideală

Un transformator ideal are:

\[ U_1=120\,V, \quad I_1=0,40\,A \]

și:

\[ U_2=24\,V \]

Determinați \(I_2\).

Vezi rezolvarea

Pentru transformatorul ideal:

\[ U_1I_1= U_2I_2 \]

deci:

\[ I_2= \frac{ U_1I_1 }{ U_2 } \] \[ I_2= \frac{ 120\cdot0,40 }{ 24 } \] \[ \boxed{ I_2=2\,A } \]
Nivel 2

Exemplul 6 – Transformator ridicător

Un transformator are:

\[ U_1=10\,V, \quad U_2=50\,V \]

iar secundarul are:

\[ N_2=1000 \]

Determinați \(N_1\).

Vezi rezolvarea
\[ \frac{U_1}{U_2} = \frac{N_1}{N_2} \] \[ N_1= N_2 \frac{U_1}{U_2} \] \[ N_1= 1000 \frac{10}{50} \] \[ \boxed{ N_1=200 } \]

Deoarece:

\[ N_2>N_1 \]

transformatorul este ridicător de tensiune.

Nivel 2

Exemplul 7 – Randament

Un transformator real primește:

\[ P_1=500\,W \]

și furnizează:

\[ P_2=450\,W \]

Determinați randamentul.

Vezi rezolvarea
\[ \eta= \frac{P_2}{P_1} \] \[ \eta= \frac{450}{500} = 0,90 \] \[ \boxed{ \eta=90\% } \]

Puterea pierdută este:

\[ P_{pierderi} = 500-450 = 50\,W \]
Nivel 3

Exemplul 8 – Receptor rezistiv pe secundar

Un transformator ideal are:

\[ U_1=12\,V, \quad N_1=400, \quad N_2=200 \]

La secundar se conectează:

\[ R=10\,\Omega \]

Determinați \(U_2\), \(I_2\), \(P_2\) și \(I_1\).

Vezi rezolvarea

Tensiunea secundară:

\[ U_2= 12 \frac{200}{400} = 6\,V \]

Curentul prin receptor:

\[ I_2= \frac{U_2}{R} = \frac6{10} = 0,6\,A \]

Puterea secundară:

\[ P_2= U_2I_2 = 6\cdot0,6 = 3,6\,W \]

Pentru transformatorul ideal:

\[ P_1=P_2 \]

deci:

\[ I_1= \frac{P_1}{U_1} = \frac{3,6}{12} = 0,30\,A \]

Rezultă:

\[ \boxed{ U_2=6\,V } \] \[ \boxed{ I_2=0,6\,A } \] \[ \boxed{ P_2=3,6\,W } \] \[ \boxed{ I_1=0,30\,A } \]
Nivel 3

Exemplul 9 – Frecvența secundară

Primarul unui transformator este alimentat la:

\[ f_1=50\,Hz \]

iar transformatorul ridică tensiunea de cinci ori. Care este frecvența secundară?

Vezi rezolvarea

Transformatorul nu modifică frecvența:

\[ f_2=f_1 \]

Prin urmare:

\[ \boxed{ f_2=50\,Hz } \]

Faptul că tensiunea se modifică de cinci ori nu schimbă frecvența.

🔬 17. Activitate demonstrativă – transformator didactic

Se poate utiliza un transformator didactic cu miez demontabil și două bobine cu numere de spire cunoscute.

Materiale

  • sursă alternativă izolată de joasă tensiune;
  • miez feromagnetic didactic;
  • două bobine;
  • două voltmetre pentru c.a.;
  • conductoare de legătură.

Ce verificăm?

Măsurăm:

\[ U_1 \]

și:

\[ U_2 \]

apoi comparăm:

\[ \frac{U_1}{U_2} \]

cu:

\[ \frac{N_1}{N_2} \]

Procedură

  1. Notează numărul de spire \(N_1\) și \(N_2\).
  2. Montează bobinele pe miezul magnetic.
  3. Conectează primarul la sursa alternativă de joasă tensiune.
  4. Măsoară \(U_1\).
  5. Măsoară tensiunea secundară în gol \(U_2\).
  6. Calculează raportul \(U_1/U_2\).
  7. Compară-l cu raportul \(N_1/N_2\).
  8. Inversează rolurile bobinelor și observă schimbarea tensiunii secundare.
Activitatea se realizează numai cu sursă didactică alternativă izolată și tensiune joasă. Nu conectați bobine experimentale direct la rețeaua de 230 V.

⚠️ 20. Greșeli frecvente

1. „Transformatorul funcționează numai prin contact electric între bobine.”

Nu.

Transferul dintre înfășurările separate se realizează prin câmpul magnetic variabil.

2. „Mai multe spire în secundar înseamnă tensiune mai mică.”

Nu.

\[ N_2>N_1 \Rightarrow U_2>U_1 \]

3. „Transformatorul mărește puterea.”

Nu.

În modelul ideal:

\[ P_1=P_2 \]

iar în realitate:

\[ P_2

4. „Dacă tensiunea crește, crește obligatoriu și curentul.”

Nu în transformarea ideală a aceleiași puteri.

Curenții se transformă invers.

5. „Transformatorul schimbă frecvența.”

Nu.

\[ \boxed{ f_1=f_2 } \]

6. „Raportul de transformare este definit identic în toate sursele.”

Nu neapărat.

În această lecție:

\[ k= \frac{U_1}{U_2} = \frac{N_1}{N_2} \]

7. „La curent continuu transformatorul funcționează la fel.”

Nu.

Este necesar un flux magnetic variabil.

8. „Dacă \(k>1\), transformatorul este ridicător.”

Nu cu definiția folosită aici.

\[ k>1 \Rightarrow U_1>U_2 \]

deci este coborâtor de tensiune.

9. „Miezul laminat mărește curenții turbionari.”

Nu.

Laminarea este folosită tocmai pentru reducerea lor.

10. „Randamentul unui transformator real este 100%.”

Nu.

\[ \eta<1 \]

din cauza pierderilor reale.
