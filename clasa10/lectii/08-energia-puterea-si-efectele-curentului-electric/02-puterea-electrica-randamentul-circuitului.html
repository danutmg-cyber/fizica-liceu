Lecția 2 Clasa a X-a Putere și randament

Puterea electrică. Randamentul circuitului

Energia arată cât s-a transferat într-un anumit interval de timp. Puterea arată cât de rapid are loc transferul energetic. Pentru o sursă reală, puterea furnizată se împarte între circuitul exterior și procesele disipative din interiorul generatorului.

🎯 Ce vei învăța

La final vei putea:

  • să definești puterea prin energia transferată în unitatea de timp;
  • să utilizezi relația \(P=UI\);
  • să deduci formele \(P=I^2R\) și \(P=U^2/R\);
  • să calculezi puterea totală furnizată de generator;
  • să calculezi puterea utilă din circuitul exterior;
  • să calculezi puterea disipată în rezistența internă;
  • să verifici bilanțul puterilor;
  • să definești și să calculezi randamentul circuitului;
  • să explici diferența dintre randament mare și putere utilă mare.

Relațiile centrale

\[ \boxed{ P=\frac{W}{t} } \]
\[ \boxed{ P=UI } \]
\[ \boxed{ \eta= \frac{P_{util}}{P_s} } \]

🔁 Pornim de la energia electrică

În lecția precedentă am stabilit:

\[ W_s= \mathcal E It \]
\[ W_{ext}=UIt \]
\[ W_{int}=I^2rt \]
și bilanțul:

\[ \boxed{ W_s= W_{ext}+W_{int} } \]
Puterea nu introduce un nou tip de energie. Ea descrie ritmul transferului de energie.

1. Ce este puterea?

Dacă într-un interval:

\[ \Delta t \]

se transferă energia:

\[ \Delta W \]

puterea medie este:

\[ \boxed{ P= \frac{\Delta W}{\Delta t} } \]

Pentru un regim constant:

\[ \boxed{ P= \frac{W}{t} } \]

Unitatea SI

\[ [P]= \frac{J}{s} \]
\[ \boxed{ 1\,W=1\,\frac{J}{s} } \]
Un dispozitiv cu puterea de \(1\,W\) transferă sau transformă, în condițiile considerate, aproximativ \(1\,J\) de energie în fiecare secundă.

2. Puterea electrică \(P=UI\)

Pentru un receptor:

\[ W=UIt \]

iar:

\[ P= \frac{W}{t} \]

Prin urmare:

\[ \boxed{ P=UI } \]

Verificarea unităților

\[ V\cdot A = \frac{J}{C} \cdot \frac{C}{s} = \frac{J}{s} = W \]
Relația: \[ P=UI \] arată că puterea transferată electric depinde simultan de tensiunea dintre bornele receptorului și de intensitatea curentului care îl străbate.

3. Puterea disipată de un rezistor ohmic

Pentru un rezistor:

\[ U=IR \]

În:

\[ P=UI \]

înlocuim \(U=IR\):

\[ P= (IR)I \]
\[ \boxed{ P=I^2R } \]

Sau, folosind:

\[ I= \frac UR \]

obținem:

\[ \boxed{ P= \frac{U^2}{R} } \]
Pentru un rezistor ohmic, în aceleași condiții: \[ \boxed{ P= UI= I^2R= \frac{U^2}{R} } \] Formulele sunt echivalente. Alegi forma în funcție de mărimile cunoscute.

4. Atenție la interpretarea lui \(P=I^2R\) și \(P=U^2/R\)

Dacă \(I\) rămâne constant

\[ P=I^2R \]

Atunci:

\[ P\propto R \]

Creșterea rezistenței crește puterea disipată, dacă intensitatea este menținută constantă.

Dacă \(U\) rămâne constant

\[ P= \frac{U^2}{R} \]

Atunci:

\[ P\propto\frac1R \]

Creșterea rezistenței reduce puterea, dacă tensiunea este menținută constantă.

Nu există contradicție. Cele două afirmații descriu condiții diferite: într-un caz este menținut constant curentul, în celălalt tensiunea.

5. Puterea totală furnizată de generator

Energia furnizată de generator este:

\[ W_s= \mathcal E It \]

Împărțim la timp:

\[ P_s= \frac{W_s}{t} \]

și obținem:

\[ \boxed{ P_s= \mathcal E I } \]
Generator
\[ P_s= \mathcal E I \]
→
Circuit exterior
\[ P_{ext}=UI \]
+
Interiorul sursei
\[ P_{int}=I^2r \]

6. Cele trei puteri ale circuitului real

\(P_s\)

Putere totală

Furnizată de generator:

\[ \boxed{ P_s= \mathcal E I } \]
\(P_u\)

Putere utilă

Transferată circuitului exterior:

\[ \boxed{ P_u= UI } \]

Pentru \(R\) ohmic:

\[ P_u=I^2R \]
\(P_i\)

Putere disipată intern

\[ \boxed{ P_i= I^2r } \]

7. Bilanțul puterilor

Din bilanțul energetic:

\[ W_s= W_{ext}+W_{int} \]

împărțim prin același interval \(t\):

\[ \frac{W_s}{t} = \frac{W_{ext}}{t} + \frac{W_{int}}{t} \]
\[ \boxed{ P_s= P_u+P_i } \]

Adică:

\[ \boxed{ \mathcal E I = UI+ I^2r } \]

Împărțind cu \(I\neq0\):

\[ \boxed{ \mathcal E= U+Ir } \]
Bilanțul puterilor și bilanțul tensiunilor sunt două exprimări ale aceleiași conservări energetice. Relația: \[ P_s=P_u+P_i \] este forma „pe secundă” a relației: \[ W_s=W_{ext}+W_{int} \]

8. Puterile exprimate prin \(R\) și \(r\)

Pentru circuitul simplu:

\[ I= \frac{\mathcal E}{R+r} \]

Puterea totală a generatorului

\[ P_s= \mathcal E I \]
\[ \boxed{ P_s= \frac{\mathcal E^2}{R+r} } \]

Puterea utilă pe rezistența exterioară

\[ P_u= I^2R \]
\[ \boxed{ P_u= \frac{ \mathcal E^2R }{ (R+r)^2 } } \]

Puterea disipată intern

\[ P_i= I^2r \]
\[ \boxed{ P_i= \frac{ \mathcal E^2r }{ (R+r)^2 } } \]
Observă că puterea utilă depinde de \(R\) în două moduri simultan: \(R\) apare atât la numărător, cât și prin curent în numitor. De aceea, dependența puterii utile de rezistența receptorului nu este una simplu crescătoare sau descrescătoare. Aceasta va fi tema lecției următoare.

9. Randamentul circuitului

Randamentul arată ce fracție din energia furnizată de generator ajunge în circuitul exterior.

\[ \boxed{ \eta= \frac{W_{util}}{W_s} } \]

Pentru același interval:

\[ W=P t \]

deci:

\[ \boxed{ \eta= \frac{P_u}{P_s} } \]

Randamentul este adimensional:

\[ 0\le\eta\le1 \]

și se exprimă frecvent în procente:

\[ \boxed{ \eta_{\%} = 100\eta } \]

10. Randamentul generatorului real

Pentru circuitul simplu în regim de generator:

\[ P_u=UI \]
\[ P_s= \mathcal E I \]

Prin urmare:

1. Definiția randamentului
\[ \eta= \frac{P_u}{P_s} \]
2. Înlocuim puterile
\[ \eta= \frac{UI}{\mathcal E I} \]
3. Simplificăm
\[ \boxed{ \eta= \frac{U}{\mathcal E} } \]
4. Pentru receptor rezistiv

Deoarece:

\[ U=IR \]
și:

\[ \mathcal E= I(R+r) \]
rezultă:

\[ \boxed{ \eta= \frac{R}{R+r} } \]

11. Interpretarea randamentului

\(R\gg r\)

\[ \eta\rightarrow1 \]

O fracție mare din puterea furnizată ajunge în exterior.

\(R=r\)

\[ \eta= \frac12 \]
\[ \boxed{ \eta=50\% } \]

Puterea utilă și puterea internă sunt egale.

\(R\ll r\)

\[ \eta\rightarrow0 \]

O fracție mare din putere se disipă în interiorul sursei.

12. Randament mare ≠ putere utilă mare

Aceasta este una dintre cele mai importante idei ale lecției: un randament mai mare nu înseamnă automat o putere utilă mai mare.

Pentru:

\[ R\rightarrow\infty \]
avem:

\[ \frac{R}{R+r} \rightarrow1 \]

dar:

\[ I= \frac{\mathcal E}{R+r} \rightarrow0 \]

și, în consecință:

\[ P_u=I^2R \rightarrow0 \]
Așadar, un circuit poate avea un randament foarte apropiat de \(100\%\), dar să transfere foarte puțină putere receptorului. În lecția următoare vom cerceta întrebarea: pentru ce valoare a rezistenței exterioare puterea transferată receptorului devine maximă?

13. Precizare importantă – circuitul deschis

În circuit deschis:

\[ I=0 \]

deci:

\[ P_s=0 \]
\[ P_u=0 \]
\[ P_i=0 \]
Pentru circuitul exact deschis, raportul: \[ \eta= \frac{P_u}{P_s} \] devine formal: \[ \frac00 \] și nu definește un randament. Afirmația corectă este: \[ \boxed{ R\rightarrow\infty \quad\Longrightarrow\quad \eta\rightarrow1 } \] pentru o succesiune de circuite încă străbătute de un curent nenul, dar foarte mic.

14. Scurtcircuitul din perspectiva puterii

În modelul idealizat:

\[ R=0 \]

și:

\[ I_{sc}= \frac{\mathcal E}{r} \]

Puterea utilă:

\[ P_u= I^2R = 0 \]

Puterea disipată intern:

\[ P_i= I_{sc}^2r \]
\[ P_i= \frac{\mathcal E^2}{r} \]

Puterea furnizată:

\[ P_s= \mathcal E I_{sc} = \frac{\mathcal E^2}{r} \]
\[ \boxed{ P_s=P_i, \qquad P_u=0, \qquad \eta=0 } \]
Scurtcircuitul poate produce o putere internă foarte mare și o încălzire rapidă a sursei și conductorilor reali. Nu se realizează experimental prin scurtcircuitarea bateriilor.

15. Exemplu complet – sursă reală

Se dau:

\[ \mathcal E=12\,V \]
\[ r=1\,\Omega \]
\[ R=5\,\Omega \]

Pasul 1 – curentul

\[ I= \frac{12}{5+1} \]
\[ \boxed{ I=2\,A } \]

Pasul 2 – tensiunea la borne

\[ U=IR \]
\[ \boxed{ U=10\,V } \]

Pasul 3 – puterea furnizată

\[ P_s= \mathcal E I \]
\[ P_s= 12\cdot2 \]
\[ \boxed{ P_s=24\,W } \]

Pasul 4 – puterea utilă

\[ P_u= UI \]
\[ P_u= 10\cdot2 \]
\[ \boxed{ P_u=20\,W } \]

Pasul 5 – puterea internă

\[ P_i= I^2r \]
\[ P_i= 2^2\cdot1 \]
\[ \boxed{ P_i=4\,W } \]

Pasul 6 – verificare

\[ 24=20+4 \]

Pasul 7 – randamentul

\[ \eta= \frac{20}{24} \]
\[ \boxed{ \eta\approx0,833 } \]
adică:

\[ \boxed{ \eta\approx83,3\% } \]

Verificare alternativă

\[ \eta= \frac R{R+r} = \frac5{6} \approx83,3\% \]

🔬 Activitate experimentală – estimarea puterii unui receptor

Materiale

  • sursă de joasă tensiune;
  • rezistor didactic sau bec de joasă tensiune;
  • ampermetru;
  • voltmetru;
  • conductoare și întrerupător.

Scop

Măsurarea:

\[ U \quad\text{și}\quad I \]

și calcularea:

\[ \boxed{ P=UI } \]
  1. Construiește montajul cu ampermetrul în serie și voltmetrul în paralel pe receptor.
  2. Profesorul verifică montajul înainte de alimentare.
  3. Măsoară tensiunea la bornele receptorului.
  4. Măsoară intensitatea curentului prin receptor.
  5. Calculează puterea: \[ P=UI \]
  6. Pentru un rezistor cunoscut, compară cu: \[ P=I^2R \]
  7. Dacă măsurătorile se repetă la alte tensiuni, compară valorile puterii obținute.
Activitatea se realizează numai la joasă tensiune și în limitele de putere admise de componente. Nu utiliza rețeaua de 230 V pentru această activitate.

⚠️ Greșeli frecvente

1. „Puterea este energia.”

Nu.

\[ P= \frac{W}{t} \]

Puterea descrie ritmul transferului de energie.

2. „W și Wh sunt aceeași unitate.”

Nu.

Wattul măsoară puterea, iar watt-ora măsoară energia.

3. „Puterea generatorului este întotdeauna \(UI\).”

Pentru sursa reală:

\[ P_s= \mathcal E I \]

iar:

\[ UI \]
este puterea transferată circuitului exterior.

4. „Dacă randamentul este 80%, se pierd 80%.”

Nu.

Dacă:

\[ \eta=80\% \]
atunci 80% reprezintă fracția utilă, iar 20% fracția disipată intern în modelul studiat.

5. „Randamentul poate fi 120%.”

Nu pentru sistemul energetic definit aici.

\[ 0\le\eta\le1 \]

6. „Randament mare înseamnă întotdeauna putere utilă mare.”

Fals. La \(R\) foarte mare, randamentul tinde spre 1, dar curentul și puterea utilă tind spre zero.

7. „În circuit deschis randamentul este exact 100%.”

În circuit exact deschis:

\[ P_s=P_u=0 \]

deci raportul \(P_u/P_s\) nu definește un randament.

8. „\(P=I^2R\) spune că un R mai mare produce mereu putere mai mare.”

Numai dacă \(I\) este menținut constant. Într-un circuit alimentat de o sursă reală, curentul se schimbă când modificăm \(R\).

🔗 Ce urmează?

Am constatat două lucruri:

  • randamentul crește când \(R/r\) crește;
  • puterea utilă nu crește neapărat odată cu randamentul.
În lecția următoare: Transferul maxim de putere vom studia funcția:

\[ \boxed{ P_u(R)= \frac{ \mathcal E^2R }{ (R+r)^2 } } \]
și vom căuta răspunsul la întrebarea:

\[ \boxed{ \text{Pentru ce valoare a lui }R \text{ primește receptorul putere maximă?} } \]
