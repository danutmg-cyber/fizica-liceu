Lecția 6 Clasa a X-a Efect magnetic

Câmpul magnetic produs de un conductor liniar parcurs de curent

Un conductor străbătut de curent modifică spațiul din jurul său: produce un câmp magnetic. Vom observa efectul cu ajutorul unui ac magnetic, vom reprezenta liniile de câmp, vom determina sensul lor prin regula mâinii drepte și vom analiza dependența inducției magnetice de curent și distanță.

🎯 Ce vei învăța

La final vei putea:

  • să explici experimental efectul magnetic al curentului;
  • să descrii experiența de tip Oersted;
  • să reprezinți liniile câmpului magnetic în jurul unui conductor liniar;
  • să stabilești sensul câmpului cu regula mâinii drepte;
  • să utilizezi simbolurile \(\odot\) și \(\otimes\);
  • să definești vectorul inducție magnetică \(\vec B\);
  • să aplici relația \(B=\mu_0I/(2\pi r)\);
  • să explici dependența \(B\propto I\);
  • să explici dependența \(B\propto1/r\);
  • să interpretezi orientarea unui ac magnetic în câmp.

Ideile centrale

\[ \boxed{ I\neq0 \Longrightarrow \text{câmp magnetic} } \]
\[ \boxed{ B= \frac{\mu_0I}{2\pi r} } \]

pentru un conductor rectiliniu foarte lung, în aer sau vid, la distanța perpendiculară \(r\) față de axa conductorului.

🔗 Un nou efect al curentului electric

În lecția precedentă am observat că un conductor parcurs de curent poate produce un efect termic:

\[ I \Longrightarrow Q=I^2Rt \]

Dar curentul electric produce și un efect care poate fi observat fără ca conductorul să devină vizibil incandescent: efectul magnetic.

Întrebarea experimentală este simplă: Ce se întâmplă cu un ac magnetic aflat lângă un conductor atunci când prin conductor începe să circule curent?

1. Experiența de tip Oersted

Așezăm un conductor rectiliniu în apropierea unui ac magnetic și observăm orientarea acului înainte și după închiderea circuitului.

Circuit deschis

Acul are orientarea determinată de câmpul magnetic ambiental.

Circuit închis

Acul se abate: în spațiul din jurul conductorului există un câmp magnetic.

Curent inversat

Sensul abaterii se schimbă. Sensul câmpului depinde de sensul curentului.

Concluzia experimentală: \[ \boxed{ \text{un curent electric produce un câmp magnetic} } \] iar inversarea sensului curentului inversează sensul câmpului magnetic.

2. Câmpul magnetic

Câmpul magnetic este descris prin mărimea vectorială:

\[ \boxed{ \vec B } \]

numită inducție magnetică.

Modul

Modulul vectorului se notează:

\[ B \]

și exprimă intensitatea locală a câmpului magnetic.

Unitate SI

\[ \boxed{ [B]=T } \]

Unitatea este tesla, simbol \(T\).

Un câmp magnetic există într-o regiune a spațiului independent de faptul că plasăm sau nu acolo un ac magnetic. Acul magnetic este doar un instrument de evidențiere a câmpului.

3. Liniile câmpului magnetic

Pentru un conductor rectiliniu foarte lung, liniile câmpului magnetic sunt:

\[ \boxed{ \text{cercuri concentrice în jurul conductorului} } \]

Cercurile sunt situate în plane perpendiculare pe conductor.

Geometria câmpului

  • centrul cercurilor este pe axa conductorului;
  • vectorul \(\vec B\) este tangent la linia de câmp;
  • sensul tangentei depinde de sensul curentului;
  • câmpul este mai intens aproape de conductor.

La aceeași distanță

Pentru conductorul ideal foarte lung, toate punctele aflate la aceeași distanță perpendiculară \(r\) au același modul \(B\).

\[ B=B(r) \]

4. Cum reprezentăm un conductor perpendicular pe pagină?

⊙

Curent spre observator

\[ \boxed{\odot} \]

Imaginează-ți vârful unei săgeți care vine către tine.

⊗

Curent înspre pagină

\[ \boxed{\otimes} \]

Imaginează-ți coada unei săgeți care se îndepărtează de tine.

↻

Sensul liniilor

Se determină prin regula mâinii drepte.

5. Regula mâinii drepte

Pentru conductor rectiliniu

  1. Apucă imaginar conductorul cu mâna dreaptă.
  2. Orientează degetul mare în sensul curentului convențional.
  3. Degetele curbate indică sensul liniilor câmpului magnetic.
Pentru:

\[ I:\ \odot \]

câmpul este orientat antiorar în planul paginii.

Pentru:

\[ I:\ \otimes \]

câmpul este orientat orar.

6. Cum găsești direcția lui \(\vec B\) într-un punct?

Presupunem că firul este perpendicular pe pagină și curentul iese spre observator:

\[ I:\odot \]

Liniile sunt antiorare. În fiecare punct, vectorul \(\vec B\) este tangent la cerc.

Poziția punctului față de fir Sensul lui \(\vec B\)
la dreapta firului în sus
deasupra firului spre stânga
la stânga firului în jos
sub fir spre dreapta
Dacă sensul curentului se inversează, toate sensurile vectorilor \(\vec B\) se inversează, dar forma liniilor de câmp rămâne aceeași: cercuri concentrice.

7. Modulul inducției magnetice

Pentru un conductor rectiliniu foarte lung, străbătut de curentul \(I\), în aer sau vid, modulul inducției magnetice la distanța perpendiculară \(r\) față de axa conductorului este:

\[ \boxed{ B= \frac{\mu_0 I}{2\pi r} } \]

unde:

\[ \boxed{ \mu_0= 4\pi\cdot10^{-7} \ \frac{T\cdot m}{A} } \]
Distanța \(r\) se măsoară perpendicular pe conductor. Nu reprezintă distanța măsurată de-a lungul firului.
Relația este modelul pentru un conductor rectiliniu foarte lung. În apropierea capetelor unui conductor finit, geometria câmpului diferă de modelul ideal.

8. De ce depinde câmpul?

Dependența de curent

La distanță constantă:

\[ \boxed{ B\propto I } \]

Dacă:

\[ I\rightarrow2I \]
atunci:

\[ \boxed{ B\rightarrow2B } \]

Dependența de distanță

La curent constant:

\[ \boxed{ B\propto\frac1r } \]

Dacă:

\[ r\rightarrow2r \]
atunci:

\[ \boxed{ B\rightarrow\frac B2 } \]
Câmpul conductorului nu scade cu \(1/r^2\) în acest model. Pentru conductorul rectiliniu foarte lung: \[ \boxed{ B\propto\frac1r } \]

9. O formă practică pentru calcule

Din:

\[ B= \frac{ 4\pi\cdot10^{-7}I }{ 2\pi r } \]
rezultă:

\[ \boxed{ B= 2\cdot10^{-7} \frac Ir } \]

cu:

\[ I\text{ în A}, \qquad r\text{ în m}, \qquad B\text{ în T} \]

Exemplu rapid

Dacă:

\[ I=5\,A, \qquad r=5\,cm=0,05\,m \]
atunci:

\[ B= 2\cdot10^{-7} \cdot \frac5{0,05} \]
\[ B= 2\cdot10^{-5}\,T \]
adică:

\[ \boxed{ B=20\,\mu T } \]

10. Ce indică acul magnetic?

Un ac magnetic liber se orientează după câmpul magnetic rezultant din locul în care este plasat.

Dacă avem simultan:

  • câmpul conductorului;
  • câmpul magnetic ambiental;

acul nu indică neapărat exact direcția câmpului conductorului singur. El se orientează după suma vectorială:

\[ \boxed{ \vec B_{rez} = \vec B_{fir} + \vec B_{amb} } \]
Această observație este importantă în experimentul de tip Oersted: abaterea acului depinde atât de câmpul produs de conductor, cât și de câmpurile magnetice deja prezente.

🔬 Experiment demonstrativ – conductor și busolă

Materiale

  • sursă de joasă tensiune;
  • conductor rectiliniu izolat;
  • busolă;
  • întrerupător;
  • rezistor pentru limitarea curentului, dacă este necesar;
  • conductoare de legătură.

Întrebări

  • Ce se întâmplă când închidem circuitul?
  • Ce se întâmplă când inversăm polaritatea sursei?
  • Ce se întâmplă când apropiem busola de conductor?
  • Ce se întâmplă dacă intensitatea crește?
  1. Așază conductorul rectiliniu în apropierea busolei.
  2. Cu circuitul deschis, observă direcția inițială a acului magnetic.
  3. Închide circuitul pentru un interval scurt.
  4. Observă abaterea acului.
  5. Deschide circuitul.
  6. Inversează polaritatea sursei, fără a modifica poziția conductorului și a busolei.
  7. Închide din nou circuitul și compară sensul abaterii.
  8. Dacă montajul permite în siguranță, modifică distanța dintre busolă și conductor și compară abaterea.
Nu scurtcircuita sursa pentru a obține un curent mare. Folosește o sursă de joasă tensiune, iar curentul trebuie limitat la valori compatibile cu conductorul și sursa. Conductorul se poate încălzi prin efect Joule.

11. Predicții înainte de experiment

Modificare Predicție pentru câmp Motiv
dublăm \(I\) \(B\) se dublează \[ B\propto I \]
înjumătățim \(I\) \(B\) se înjumătățește dependență liniară de \(I\)
dublăm \(r\) \(B\) se înjumătățește \[ B\propto1/r \]
inversăm \(I\) modulul rămâne același, sensul se inversează regula mâinii drepte
\(I=0\) câmpul produs de conductor este nul \[ B\propto I \]

🧮 Exemple rezolvate

Nivel 1

Exemplul 1 – Calculul inducției magnetice

Un conductor rectiliniu foarte lung este parcurs de:

\[ I=4\,A \]

Calculați \(B\) la:

\[ r=2\,cm \]
Vezi rezolvarea
Transformăm: \[ r=0,02\,m \] Folosim: \[ B= 2\cdot10^{-7} \frac Ir \] \[ B= 2\cdot10^{-7} \frac4{0,02} \] \[ B= 4\cdot10^{-5}\,T \] deci: \[ \boxed{ B=40\,\mu T } \]
Nivel 1

Exemplul 2 – Dublarea distanței

La distanța \(r\), câmpul are:

\[ B_1=60\,\mu T \]

Ce valoare are la \(2r\)?

Vezi rezolvarea
\[ B\propto\frac1r \] deci: \[ B_2= \frac{B_1}{2} \] \[ \boxed{ B_2=30\,\mu T } \]
Nivel 1

Exemplul 3 – Dublarea curentului

La \(I=2\,A\), un punct are:

\[ B=15\,\mu T \]

Ce valoare obținem la \(4\,A\), în același punct?

Vezi rezolvarea
La distanță constantă: \[ B\propto I \] Curentul se dublează, deci: \[ \boxed{ B=30\,\mu T } \]
Nivel 2

Exemplul 4 – Determinarea distanței

Se dau:

\[ I=5\,A \]
și:

\[ B=25\,\mu T \]

Determinați distanța față de conductor.

Vezi rezolvarea
\[ r= \frac{ 2\cdot10^{-7}I }{ B } \] Transformăm: \[ B= 25\cdot10^{-6}\,T \] \[ r= \frac{ 2\cdot10^{-7}\cdot5 }{ 25\cdot10^{-6} } \] \[ r=0,04\,m \] \[ \boxed{ r=4\,cm } \]
Nivel 2

Exemplul 5 – Determinarea curentului

La:

\[ r=5\,cm \]

se măsoară:

\[ B=12\,\mu T \]

Determinați \(I\).

Vezi rezolvarea
\[ I= \frac{2\pi rB}{\mu_0} \] sau: \[ I= \frac{Br}{2\cdot10^{-7}} \] \[ I= \frac{ 12\cdot10^{-6}\cdot0,05 }{ 2\cdot10^{-7} } \] \[ \boxed{ I=3\,A } \]
Nivel 2

Exemplul 6 – Sensul câmpului

Curentul este orientat spre observator:

\[ I:\odot \]

Care este sensul lui \(\vec B\) într-un punct situat la dreapta conductorului?

Vezi rezolvarea
Pentru: \[ \odot \] regula mâinii drepte indică un sens antiorar. În punctul aflat la dreapta conductorului, tangenta antiorară este orientată în sus. \[ \boxed{ \vec B\text{ este orientat în sus} } \]
Nivel 3

Exemplul 7 – Modificarea simultană a lui \(I\) și \(r\)

Curentul se triplează, iar distanța se dublează. Cum se modifică \(B\)?

Vezi rezolvarea
\[ B\propto\frac Ir \] Prin urmare: \[ \frac{B_2}{B_1} = \frac{3I}{2r} \cdot \frac rI \] \[ \boxed{ \frac{B_2}{B_1} = \frac32 } \] Deci câmpul crește de \(1,5\) ori.

13. Cum trebuie să arate graficele?

\(B=f(I)\), cu \(r\) constant

\[ B= \frac{\mu_0}{2\pi r}I \]

Este o funcție liniară. Graficul este o dreaptă care trece prin origine.

\(B=f(r)\), cu \(I\) constant

\[ B= \frac{\mu_0I}{2\pi} \frac1r \]

Este o dependență invers proporțională. Graficul este o curbă descrescătoare.

⚠️ Greșeli frecvente

1. „Liniile de câmp sunt radiale.”

Nu. În jurul conductorului rectiliniu foarte lung ele sunt cercuri concentrice.

2. „\(\vec B\) este orientat spre conductor.”

Nu. Vectorul \(\vec B\) este tangent la cercul liniei de câmp.

3. „\(\odot\) înseamnă curent în pagină.”

Este invers:

\[ \odot \]

înseamnă curent spre observator.

4. „Dublarea distanței reduce câmpul de patru ori.”

Nu pentru conductorul liniar foarte lung:

\[ B\propto\frac1r \]

5. „Inversarea curentului schimbă modulul lui B.”

Dacă \(|I|\) rămâne același, modulul lui \(B\) rămâne același. Se inversează sensul.

6. „Acul magnetic arată numai câmpul firului.”

Acul se orientează după câmpul magnetic rezultant din poziția sa.

7. „Distanța r se măsoară de-a lungul firului.”

Nu. \(r\) este distanța perpendiculară față de axa conductorului.

8. „Formula este exactă pentru orice fir finit.”

Relația utilizată aici descrie conductorul rectiliniu foarte lung. În apropierea capetelor unui fir finit apar efecte geometrice suplimentare.

📌 De reținut

Efect magnetic

\[ \boxed{ I\neq0 \Rightarrow \text{câmp magnetic} } \]

Linii de câmp

Pentru conductorul rectiliniu foarte lung:

\[ \boxed{ \text{cercuri concentrice} } \]

Sens

Se determină cu:

\[ \boxed{ \text{regula mâinii drepte} } \]

Modul

\[ \boxed{ B= \frac{\mu_0I}{2\pi r} } \]

Dependența de curent

\[ \boxed{ B\propto I } \]

Dependența de distanță

\[ \boxed{ B\propto\frac1r } \]
Schema mentală: sensul curentului → regula mâinii drepte → sensul liniilor circulare; modulul curentului și distanța → valoarea lui \(B\).

🧭 Ce se întâmplă dacă înfășurăm conductorul?

Un singur conductor produce linii circulare de câmp. Dar putem îndoi conductorul într-o spiră și apoi putem grupa mai multe spire.

Câmpurile produse de diferitele porțiuni ale conductorului se pot combina, iar în interiorul ansamblului poate apărea un câmp mult mai bine organizat.

În lecția următoare: Câmpul magnetic al bobinei parcurse de curent vom studia cum se modifică efectul magnetic atunci când conductorul este înfășurat în mai multe spire.

\[ \boxed{ \text{conductor liniar} \longrightarrow \text{spiră} \longrightarrow \text{bobină} } \]
