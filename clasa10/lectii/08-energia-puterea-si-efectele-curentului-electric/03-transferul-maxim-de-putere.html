Lecția 3 Clasa a X-a Transfer de putere

Transferul maxim de putere

Puterea primită de un receptor nu crește continuu nici când îi micșorăm rezistența, nici când o mărim. Pentru un generator real există o valoare specială a rezistenței exterioare pentru care puterea transferată receptorului este maximă. O vom determina și interpreta fizic.

🎯 Ce vei învăța

La final vei putea:

  • să scrii puterea utilă în funcție de \(R\);
  • să explici de ce \(P_u(R)\) are un maxim;
  • să demonstrezi condiția transferului maxim de putere;
  • să utilizezi condiția \(R=r\);
  • să calculezi puterea utilă maximă;
  • să calculezi curentul și tensiunea la transfer maxim;
  • să determini randamentul în acest regim;
  • să diferențiezi puterea maximă de randamentul maxim;
  • să interpretezi grafic dependența \(P_u(R)\).

Rezultatul central

\[ \boxed{ R=r } \]

la transfer maxim de putere.

\[ \boxed{ P_{u,max} = \frac{\mathcal E^2}{4r} } \]
\[ \boxed{ \eta=50\% } \]

🔁 De unde pornim?

Pentru generatorul real:

\[ I= \frac{\mathcal E}{R+r} \]

Puterea transferată rezistenței exterioare este:

\[ P_u= I^2R \]

Înlocuind curentul:

\[ \boxed{ P_u(R)= \frac{ \mathcal E^2R }{ (R+r)^2 } } \]
În această lecție, \(\mathcal E\) și \(r\) sunt considerate constante. Variabila este: \[ R \] adică rezistența receptorului conectat la sursă.

1. Situația-problemă

Ce trebuie să facem pentru ca receptorul să primească cea mai mare putere?

\(R\ll r\)

Rezistență foarte mică

Curentul este mare, dar:

\[ P_u=I^2R \]

conține un \(R\) foarte mic.

\(R=r\)

Valoare intermediară

Curentul nu este maxim, dar nici rezistența receptorului nu este prea mică.

Aici apare echilibrul optim pentru putere.

\(R\gg r\)

Rezistență foarte mare

Randamentul este mare, dar curentul devine foarte mic.

\[ I\rightarrow0 \]

2. Ce se întâmplă la extreme?

Când \(R=0\)

\[ P_u= \frac{ \mathcal E^2\cdot0 }{ r^2 } = 0 \]

Când \(R\rightarrow\infty\)

Putem scrie:

\[ P_u= \frac{ \mathcal E^2R }{ (R+r)^2 } \]

iar pentru \(R\) foarte mare, numitorul crește aproximativ ca \(R^2\), în timp ce numărătorul crește numai ca \(R\).

\[ \boxed{ P_u\rightarrow0 } \]
Puterea utilă este nulă la ambele extreme: \[ R=0 \] și:

\[ R\rightarrow\infty \]
Prin urmare, între cele două extreme trebuie să existe o zonă în care puterea devine mai mare.

3. Demonstrarea condiției de maxim – fără derivate

Pornim de la o proprietate simplă:

\[ (R-r)^2\ge0 \]
1. Dezvoltăm pătratul
\[ R^2-2Rr+r^2\ge0 \]
2. Adunăm \(4Rr\)
\[ R^2+2Rr+r^2 \ge 4Rr \]
3. Recunoaștem un pătrat perfect
\[ \boxed{ (R+r)^2 \ge 4Rr } \]
4. Împărțim la cantități pozitive

Pentru:

\[ R>0, \qquad r>0 \]
rezultă:

\[ \frac{R}{(R+r)^2} \le \frac1{4r} \]
5. Înmulțim cu \(\mathcal E^2\)
\[ \frac{ \mathcal E^2R }{ (R+r)^2 } \le \frac{ \mathcal E^2 }{ 4r } \]
6. Identificăm puterea utilă
\[ \boxed{ P_u \le \frac{ \mathcal E^2 }{ 4r } } \]

Egalitatea apare numai când:

\[ (R-r)^2=0 \]
adică:

\[ \boxed{ R=r } \]
Condiția transferului maxim de putere: pentru un generator real cu t.e.m. și rezistență internă constante, puterea transferată unui receptor rezistiv este maximă atunci când: \[ \boxed{ R=r } \]

4. Puterea utilă maximă

În formula:

\[ P_u= \frac{ \mathcal E^2R }{ (R+r)^2 } \]

punem:

\[ R=r \]
\[ P_{u,max} = \frac{ \mathcal E^2r }{ (r+r)^2 } \]
\[ P_{u,max} = \frac{ \mathcal E^2r }{ 4r^2 } \]
\[ \boxed{ P_{u,max} = \frac{ \mathcal E^2 }{ 4r } } \]

5. Curentul la transfer maxim

Curentul general este:

\[ I= \frac{ \mathcal E }{ R+r } \]

Pentru:

\[ R=r \]
obținem:

\[ \boxed{ I_{maxP} = \frac{ \mathcal E }{ 2r } } \]
Indicele „maxP” înseamnă curentul în regimul de putere utilă maximă. Nu înseamnă curent maxim al sursei. Curentul maxim al modelului apare la scurtcircuit: \[ I_{sc} = \frac{\mathcal E}{r} \] Prin urmare: \[ \boxed{ I_{maxP} = \frac{I_{sc}}{2} } \]

6. Tensiunea la borne în regimul optim

Tensiunea pe receptor este:

\[ U=IR \]

La transfer maxim:

\[ I= \frac{\mathcal E}{2r}, \qquad R=r \]
deci:

\[ U= \frac{\mathcal E}{2r} \cdot r \]
\[ \boxed{ U= \frac{\mathcal E}{2} } \]

Căderea internă este:

\[ u=Ir = \frac{\mathcal E}{2} \]
La transfer maxim de putere: \[ \boxed{ U=u=\frac{\mathcal E}{2} } \] Tensiunea electromotoare se „împarte” egal, în sensul bilanțului de tensiune, între rezistența exterioară și rezistența internă.

7. Bilanțul puterilor la \(R=r\)

Puterea utilă este:

\[ P_u= I^2R \]

Puterea disipată intern:

\[ P_i= I^2r \]

Dacă:

\[ R=r \]
atunci:

\[ \boxed{ P_u=P_i } \]

Fiecare are valoarea:

\[ \boxed{ P_u=P_i= \frac{ \mathcal E^2 }{ 4r } } \]

Puterea totală furnizată este:

\[ P_s= P_u+P_i \]
adică:

\[ \boxed{ P_s= \frac{ \mathcal E^2 }{ 2r } } \]

8. Randamentul la transfer maxim

Din lecția precedentă:

\[ \eta= \frac{R}{R+r} \]

Pentru:

\[ R=r \]
rezultă:

\[ \eta= \frac r{r+r} = \frac12 \]
\[ \boxed{ \eta=50\% } \]
Transferul maxim de putere nu coincide cu randamentul maxim. La punctul de putere maximă: \[ 50\% \] din puterea furnizată ajunge receptorului, iar: \[ 50\% \] se disipă în rezistența internă a modelului.

9. Putere maximă sau randament mare?

Regim Curent Putere utilă Randament
\[ R\ll r \] mare mică mic
\[ R=r \] \[ \frac{\mathcal E}{2r} \] maximă 50%
\[ R\gg r \] mic tinde spre 0 tinde spre 100%
Cele două obiective sunt diferite: maximizarea puterii transferate și maximizarea randamentului. Un sistem proiectat pentru economie de energie nu este neapărat proiectat în punctul de transfer maxim de putere.

10. O formă universală a problemei

Definim raportul:

\[ x= \frac Rr \]

și raportăm puterea utilă la puterea maximă:

\[ \frac{P_u}{P_{u,max}} \]

Din:

\[ P_u= \frac{ \mathcal E^2R }{ (R+r)^2 } \]
și:

\[ P_{u,max} = \frac{ \mathcal E^2 }{ 4r } \]
rezultă:

\[ \boxed{ \frac{P_u}{P_{u,max}} = \frac{4x}{(1+x)^2} } \]

Randamentul devine:

\[ \boxed{ \eta= \frac{x}{1+x} } \]
Aceste relații nu mai conțin explicit nici \(\mathcal E\), nici \(r\). Forma curbei este aceeași pentru orice generator descris de model, dacă reprezentăm rezultatul în funcție de raportul: \[ R/r \]

11. Cum evoluează puterea și randamentul?

\[ R/r \] \[ P_u/P_{u,max} \] \[ \eta \]
0,25 64% 20%
0,50 88,9% 33,3%
1 100% 50%
2 88,9% 66,7%
4 64% 80%
Observă perechile: \[ R/r=0,5 \] și:

\[ R/r=2 \]
Ele dau aceeași fracție din puterea maximă, dar randamente diferite. Aceasta arată din nou că puterea și randamentul nu descriu același lucru.

12. Extensie – două rezistențe pot primi aceeași putere

Pentru aceeași sursă, două rezistențe:

\[ R_1 \quad\text{și}\quad R_2 \]

situate de o parte și de alta a valorii optime pot primi aceeași putere.

Condiția este:

\[ \boxed{ R_1R_2=r^2 } \]

Exemplu

Dacă:

\[ r=2\,\Omega \]
atunci:

\[ R_1=1\,\Omega \]
și:

\[ R_2=4\,\Omega \]
satisfac:

\[ 1\cdot4=2^2 \]
și primesc aceeași putere utilă.

Dar randamentele lor sunt diferite:

\[ \eta_1= \frac1{1+2} = 33,3\% \]
\[ \eta_2= \frac4{4+2} = 66,7\% \]

13. Extensie matematică – demonstrația prin derivată

Această metodă este opțională și poate fi folosită acolo unde elevii cunosc derivarea funcțiilor. Demonstrația algebrică anterioară este suficientă pentru concluzia fizică.

Considerăm:

\[ P_u(R) = \frac{ \mathcal E^2R }{ (R+r)^2 } \]

Derivata este:

\[ \boxed{ \frac{dP_u}{dR} = \frac{ \mathcal E^2(r-R) }{ (R+r)^3 } } \]

Pentru extrem:

\[ \frac{dP_u}{dR}=0 \]
deci:

\[ r-R=0 \]
și:

\[ \boxed{ R=r } \]

Semnul derivatei arată:

  • pentru \(R0\) – puterea crește;
  • pentru \(R>r\), \(dP_u/dR<0\) – puterea scade.

Prin urmare, punctul \(R=r\) este un maxim.

14. Exemplu complet

Un generator are:

\[ \mathcal E=12\,V \]
\[ r=2\,\Omega \]

a) Rezistența pentru putere maximă

\[ \boxed{ R=r=2\,\Omega } \]

b) Curentul

\[ I= \frac{12}{2+2} \]
\[ \boxed{ I=3\,A } \]

c) Tensiunea la borne

\[ U=IR \]
\[ U=3\cdot2 \]
\[ \boxed{ U=6\,V } \]

d) Puterea utilă maximă

\[ P_{u,max} = \frac{ 12^2 }{ 4\cdot2 } \]
\[ P_{u,max} = \frac{144}{8} \]
\[ \boxed{ P_{u,max}=18\,W } \]

e) Puterea internă

\[ P_i= I^2r = 3^2\cdot2 \]
\[ \boxed{ P_i=18\,W } \]

f) Puterea furnizată

\[ P_s= \mathcal E I = 12\cdot3 \]
\[ \boxed{ P_s=36\,W } \]

g) Randamentul

\[ \eta= \frac{18}{36} \]
\[ \boxed{ \eta=50\% } \]

15. Același generator, trei sarcini diferite

Pentru:

\[ \mathcal E=12\,V, \qquad r=2\,\Omega \]
\(R\) \(I\) \(P_u\) \(\eta\)
\(1\,\Omega\) \(4\,A\) \(16\,W\) 33,3%
\(2\,\Omega\) \(3\,A\) \(18\,W\) 50%
\(4\,\Omega\) \(2\,A\) \(16\,W\) 66,7%
\(8\,\Omega\) \(1,2\,A\) \(11,52\,W\) 80%
Observă: \[ R=4\,\Omega \] are randament mai mare decât:

\[ R=2\,\Omega \]
dar primește o putere mai mică. Din nou: randament maxim și transfer maxim de putere sunt obiective diferite.

16. Unde este utilă ideea?

Modelarea unei surse reale

O baterie sau o sursă poate fi reprezentată, într-un model simplificat, prin:

  • t.e.m. \(\mathcal E\);
  • rezistență internă \(r\).

Sarcina \(R\) poate fi aleasă sau modificată, iar puterea primită de aceasta depinde de raportul \(R/r\).

Circuite de semnal – extensie

În anumite sisteme electronice, transferul de putere și adaptarea dintre sursă și sarcină sunt importante.

Pentru curent alternativ, situația generală implică impedanțe, nu doar rezistențe. Aceasta depășește modelul rezistiv al lecției.

În instalațiile de transport și utilizare a energiei electrice, obiectivul obișnuit nu este funcționarea permanentă la: \[ R=r \] deoarece atunci randamentul este doar 50%. Transferul maxim de putere este o condiție matematică și fizică precisă, dar nu reprezintă automat punctul optim pentru orice aplicație practică.

🔬 Experiment – căutarea experimentală a puterii maxime

Materiale

  • sursă didactică de joasă tensiune;
  • rezistor serie cunoscut \(r_m\), care modelează rezistența internă;
  • cutie de rezistențe sau reostat adecvat;
  • ampermetru;
  • voltmetru;
  • conductoare;
  • întrerupător.

Ideea experimentului

Nu este necesar să folosim rezistența internă reală a unei baterii.

Construim o sursă-model cu o rezistență serie cunoscută:

\[ r_m \]

și variem sarcina \(R\).

  1. Alege o sursă de joasă tensiune și conectează în serie rezistorul \(r_m\).
  2. Conectează sarcina variabilă \(R\).
  3. Pentru fiecare valoare a lui \(R\), măsoară tensiunea \(U\) pe sarcină.
  4. Măsoară intensitatea \(I\).
  5. Calculează: \[ P_u=UI \]
  6. Repetă pentru valori ale lui \(R\) atât mai mici, cât și mai mari decât \(r_m\).
  7. Construiește un tabel: \[ R,\quad U,\quad I,\quad P_u \]
  8. Identifică valoarea lui \(R\) pentru care \(P_u\) este cea mai mare.
  9. Compară experimental cu predicția: \[ R=r_m \]
Folosește numai surse de joasă tensiune, rezistoare cu putere nominală adecvată și evită valorile de sarcină care produc curenți excesivi. Nu căuta „puterea maximă” prin scurtcircuitarea unei baterii.

⚠️ Greșeli frecvente

1. „Puterea maximă apare la \(R=0\).”

Nu.

La:

\[ R=0 \]
avem:

\[ P_u=0 \]

2. „Curent maxim = putere utilă maximă.”

Nu. Curentul maxim apare la sarcină foarte mică, dar puterea utilă conține și factorul \(R\).

3. „Puterea maximă apare când randamentul este maxim.”

Nu.

La putere maximă:

\[ \boxed{ \eta=50\% } \]

4. „Dacă măresc mereu \(R\), puterea crește.”

Numai pentru:

\[ R

După:

\[ R=r \]
puterea începe să scadă.

5. „La \(R=r\), tensiunea la borne este \(\mathcal E\).”

Nu.

\[ \boxed{ U=\frac{\mathcal E}{2} } \]

6. „La maxim, pierderile interne dispar.”

Dimpotrivă:

\[ P_i=P_u \]

7. „\(R=r\) este întotdeauna regimul cel mai economic.”

Nu. Este condiția pentru putere transferată maximă, nu pentru randament maxim.

8. „Formula este valabilă pentru orice sistem electric fără condiții.”

În lecție folosim un model de curent continuu cu generator liniar și receptor rezistiv. Alte sisteme pot necesita modele mai complexe.
