Lecția 8 Clasa a X-a Interacțiuni magnetice

Interacțiunea dintre conductoare paralele parcurse de curent

Fiecare conductor parcurs de curent produce un câmp magnetic. Dacă apropiem două conductoare paralele, fiecare se află în câmpul magnetic produs de celălalt. Rezultatul este o pereche de forțe: curenții în același sens produc atracție, iar curenții în sensuri opuse produc respingere.

🎯 Ce vei învăța

La final vei putea:

  • să explici originea interacțiunii dintre două conductoare paralele;
  • să identifici câmpul produs de primul conductor la poziția celui de-al doilea;
  • să stabilești sensul forței magnetice;
  • să explici atracția pentru curenți în același sens;
  • să explici respingerea pentru curenți în sensuri opuse;
  • să aplici relația pentru forța magnetică asupra unui conductor;
  • să deduci forța dintre două conductoare paralele;
  • să utilizezi forța pe unitatea de lungime;
  • să analizezi dependența de \(I_1\), \(I_2\) și \(d\);
  • să recunoști limitele modelului conductorilor foarte lungi.

Rezultatul central

\[ \boxed{ \frac FL = \frac{ \mu_0|I_1I_2| }{ 2\pi d } } \]

pentru două conductoare rectilinii, paralele și suficient de lungi, în aer sau vid.

\[ \boxed{ \text{același sens}\Rightarrow\text{atracție} } \]
\[ \boxed{ \text{sensuri opuse}\Rightarrow\text{respingere} } \]

1. Legătura cu lecțiile precedente

Știm deja că un conductor parcurs de curent produce, la distanța \(d\), un câmp magnetic:

\[ B= \frac{\mu_0I}{2\pi d} \]

Știm și că sensul câmpului se determină prin regula mâinii drepte.

Conductorul 1
\[ I_1 \]
→
Câmp magnetic
\[ \vec B_1 \]

la conductorul 2

→
Forță magnetică
\[ \vec F_2 \]

asupra conductorului 2

Interacțiunea nu trebuie memorată ca un fenomen separat. Ea rezultă din două idei deja cunoscute: un curent produce câmp magnetic, iar un conductor parcurs de curent poate fi supus unei forțe într-un câmp magnetic.

2. Forța magnetică asupra unui conductor parcurs de curent

Pentru un segment rectiliniu de conductor de lungime \(L\), parcurs de curentul \(I\), aflat într-un câmp magnetic uniform, modulul forței magnetice este:

\[ \boxed{ F=BIL\sin\alpha } \]

unde \(\alpha\) este unghiul dintre direcția curentului și vectorul \(\vec B\).

\(\alpha=0^\circ\)

\[ F=0 \]

Curentul este paralel cu câmpul.

\(\alpha=90^\circ\)

\[ \boxed{ F=BIL } \]

Forța are modul maxim pentru aceleași \(B,I,L\).

Direcția

Forța este perpendiculară atât pe direcția curentului, cât și pe câmp.

În cazul celor două conductoare paralele, câmpul produs de unul la poziția celuilalt este perpendicular pe direcția curentului din celălalt conductor. Prin urmare: \[ \alpha=90^\circ \] și: \[ F=BIL \]

3. Curenți în același sens → atracție

Conductorul 1

\[ \uparrow I_1 \qquad F_1\rightarrow \]

Forța asupra conductorului 1 este orientată către conductorul 2.

Conductorul 2

\[ \leftarrow F_2 \qquad I_2\uparrow \]

Forța asupra conductorului 2 este orientată către conductorul 1.

\[ \boxed{ I_1\uparrow \quad I_2\uparrow \quad \Longrightarrow \quad \text{atracție} } \]

De ce?

Presupunem că primul conductor este în stânga, iar al doilea în dreapta. Ambele curente sunt orientate în sus.

La poziția conductorului 2, câmpul produs de conductorul 1 este orientat înspre planul paginii:

\[ \vec B_1:\otimes \]

Forța magnetică asupra conductorului 2 este orientată spre stânga, adică spre conductorul 1.

Analog, conductorul 1 este împins spre dreapta, către conductorul 2.

4. Curenți în sensuri opuse → respingere

Conductorul 1

\[ \leftarrow F_1 \qquad I_1\uparrow \]

Forța este orientată în exterior, departe de celălalt conductor.

Conductorul 2

\[ I_2\downarrow \qquad F_2\rightarrow \]

Și al doilea conductor este împins în exterior.

\[ \boxed{ I_1\uparrow \quad I_2\downarrow \quad \Longrightarrow \quad \text{respingere} } \]
Inversarea ambilor curenți simultan nu schimbă tipul interacțiunii. Dacă ambii curenți au în continuare același sens unul față de celălalt, conductoarele se atrag.

5. Regula practică

Curenți paraleli cu același sens:
\[ \uparrow\quad\uparrow \]
\[ \boxed{ \text{ATRACȚIE} } \]
Curenți paraleli cu sensuri opuse:
\[ \uparrow\quad\downarrow \]
\[ \boxed{ \text{RESPINGERE} } \]
Regula este utilă pentru verificare, dar la probleme mai complexe este mai sigur să urmezi traseul: sensul curentului → sensul câmpului → sensul forței.

6. Deducerea forței dintre două conductoare

Considerăm două conductoare rectilinii, paralele, suficient de lungi, separate prin distanța \(d\).

Curentul prin primul conductor este \(I_1\), iar prin al doilea este \(I_2\). Analizăm o lungime comună \(L\).

1. Câmpul produs de conductorul 1 la conductorul 2
\[ B_1= \frac{ \mu_0|I_1| }{ 2\pi d } \]
2. Forța asupra conductorului 2

Deoarece direcția curentului din conductorul 2 este perpendiculară pe \(\vec B_1\):

\[ F_2= B_1|I_2|L \]
3. Înlocuim \(B_1\)
\[ F= \frac{ \mu_0|I_1| }{ 2\pi d } |I_2|L \]
4. Rezultă
\[ \boxed{ F= \frac{ \mu_0|I_1I_2|L }{ 2\pi d } } \]
Formula de mai sus dă modulul forței. Semnul curentului nu se introduce mecanic în formula modulului. Sensul forței se stabilește separat, din sensurile curenților și regulile câmpului magnetic.

7. Forța pe unitatea de lungime

Împărțim relația anterioară la \(L\):

\[ \boxed{ \frac FL = \frac{ \mu_0|I_1I_2| }{ 2\pi d } } \]

În aer sau vid:

\[ \mu_0= 4\pi\cdot10^{-7} \frac{T\cdot m}{A} \]

deci:

\[ \boxed{ \frac FL = 2\cdot10^{-7} \frac{ |I_1I_2| }{ d } } \]

cu:

\[ I_1,I_2\text{ în A}, \qquad d\text{ în m} \]

iar rezultatul:

\[ \frac FL \]

se exprimă în:

\[ \boxed{ N/m } \]

8. Cele două forțe

Conductorul 1 exercită o forță asupra conductorului 2, iar conductorul 2 exercită o forță asupra conductorului 1.

\[ \boxed{ \vec F_{12} = -\vec F_{21} } \]

Prin urmare:

  • forțele au același modul;
  • au aceeași direcție;
  • au sensuri opuse;
  • acționează asupra unor corpuri diferite.
Chiar dacă: \[ I_1\neq I_2 \] modulele celor două forțe de interacțiune sunt egale, deoarece ambele conțin produsul: \[ |I_1I_2| \]

9. De ce depinde interacțiunea?

De \(I_1\)

\[ \frac FL \propto |I_1| \]

Dublarea lui \(I_1\) dublează forța.

De \(I_2\)

\[ \frac FL \propto |I_2| \]

Dublarea lui \(I_2\) dublează forța.

De distanță

\[ \frac FL \propto \frac1d \]

Dublarea distanței înjumătățește forța pe unitatea de lungime.

Dacă ambii curenți se dublează simultan:

\[ I_1\rightarrow2I_1 \]
\[ I_2\rightarrow2I_2 \]
atunci:

\[ |I_1I_2| \rightarrow 4|I_1I_2| \]
și forța crește de patru ori.

10. Efectul distanței

La curenți constanți:

\[ \frac FL = C\frac1d \]

unde:

\[ C= \frac{ \mu_0|I_1I_2| }{ 2\pi } \]
Distanță Forță pe unitatea de lungime
\(d\) \(f\)
\(2d\) \(f/2\)
\(3d\) \(f/3\)
\(d/2\) \(2f\)
În acest model, interacțiunea scade ca: \[ \boxed{ 1/d } \] nu ca \(1/d^2\).

11. Exemplu complet

Două conductoare paralele sunt separate prin:

\[ d=5\,cm=0,05\,m \]

și sunt străbătute în același sens de curenții:

\[ I_1=10\,A \]
\[ I_2=15\,A \]

Calculăm forța pe o lungime:

\[ L=2\,m \]

a) Forța pe unitatea de lungime

\[ \frac FL = 2\cdot10^{-7} \frac{ I_1I_2 }{ d } \]
\[ \frac FL = 2\cdot10^{-7} \frac{ 10\cdot15 }{ 0,05 } \]
\[ \boxed{ \frac FL = 6\cdot10^{-4}\,N/m } \]

b) Forța pe lungimea de 2 m

\[ F= \frac FL \cdot L \]
\[ F= 6\cdot10^{-4} \cdot2 \]
\[ \boxed{ F= 1,2\cdot10^{-3}\,N } \]

c) Sensul

Curenții au același sens, deci conductoarele:

\[ \boxed{ \text{se atrag} } \]

🔬 Experiment demonstrativ – două conductoare flexibile

Scop

Observarea calitativă a interacțiunii dintre două conductoare paralele parcurse de curent.

Se urmărește diferența dintre:

  • curenți în același sens;
  • curenți în sensuri opuse.

Montaj posibil

  • sursă didactică de joasă tensiune cu limitare de curent;
  • două conductoare flexibile și ușoare;
  • întrerupător;
  • suport izolator;
  • ampermetru, dacă este necesar.
  1. Așază două porțiuni de conductor cât mai paralele și suficient de mobile.
  2. Pregătește circuitul astfel încât curentul să circule în același sens prin cele două porțiuni.
  3. Închide circuitul numai pentru intervale scurte.
  4. Observă tendința de apropiere.
  5. Deschide circuitul.
  6. Modifică legăturile astfel încât curenții prin porțiunile paralele să aibă sensuri opuse.
  7. Închide din nou circuitul și urmărește tendința de îndepărtare.
  8. Compară observația cu predicția realizată prin regula câmp–forță.
Forțele magnetice vizibile între conductoare necesită adesea curenți relativ mari. Nu improviza experimentul prin scurtcircuitarea bateriilor sau acumulatorilor. Pentru demonstrația fizică se folosește numai aparatură de laborator cu joasă tensiune și limitare controlată a curentului. Dacă un asemenea montaj nu este disponibil, simulatorul este alternativa recomandată.

Exemplul 3 – Dublarea unui curent

\(I_1\) se dublează, iar \(I_2\) și \(d\) rămân constante. Cum se modifică \(F/L\)?

Vezi rezolvarea
\[ \frac FL \propto I_1 \] deci: \[ \boxed{ \frac FL \text{ se dublează} } \]
Nivel 1

Exemplul 4 – Dublarea distanței

Distanța dintre conductoare se dublează, iar curenții rămân constanți.

Vezi rezolvarea
\[ \frac FL \propto \frac1d \] Prin urmare: \[ \boxed{ \left( \frac FL \right)_2 = \frac12 \left( \frac FL \right)_1 } \]
Nivel 2

Exemplul 5 – Calcul numeric

Se dau:

\[ I_1=5\,A, \qquad I_2=8\,A, \qquad d=4\,cm \]

Determinați \(F/L\).

Vezi rezolvarea
Transformăm: \[ d=0,04\,m \] Apoi: \[ \frac FL = 2\cdot10^{-7} \frac{ 5\cdot8 }{ 0,04 } \] \[ \frac FL = 2\cdot10^{-7} \cdot1000 \] \[ \boxed{ \frac FL = 2\cdot10^{-4}\,N/m } \]
Nivel 2

Exemplul 6 – Determinarea distanței

Pentru:

\[ I_1=10\,A, \qquad I_2=20\,A \]

forța pe unitatea de lungime este:

\[ \frac FL = 8\cdot10^{-4}\,N/m \]

Determinați distanța.

Vezi rezolvarea
\[ d= \frac{ 2\cdot10^{-7}I_1I_2 }{ F/L } \] \[ d= \frac{ 2\cdot10^{-7}\cdot10\cdot20 }{ 8\cdot10^{-4} } \] \[ d= 0,05\,m \] \[ \boxed{ d=5\,cm } \]
Nivel 2

Exemplul 7 – Ambii curenți se dublează

Ce se întâmplă cu forța dacă:

\[ I_1\rightarrow2I_1 \]
și:

\[ I_2\rightarrow2I_2 \]
iar \(d,L\) rămân constante?

Vezi rezolvarea
\[ F\propto I_1I_2 \] deci: \[ F' \propto (2I_1)(2I_2) = 4I_1I_2 \] \[ \boxed{ F'=4F } \]
Nivel 3

Exemplul 8 – Modificări simultane

\(I_1\) se triplează, \(I_2\) se înjumătățește, iar distanța se dublează. Cum se modifică forța?

Vezi rezolvarea
\[ F\propto \frac{ I_1I_2 }{ d } \] deci: \[ \frac{F'}F = \frac{ 3\cdot\frac12 }{ 2 } \] \[ \frac{F'}F = \frac34 \] Prin urmare: \[ \boxed{ F'=0,75F } \]

⚠️ Greșeli frecvente

1. „Curenții în același sens se resping.”

Este invers:

\[ \boxed{ \text{același sens}\Rightarrow\text{atracție} } \]

2. „Curenții opuși se atrag.”

Pentru conductoare paralele:

\[ \boxed{ \text{sensuri opuse}\Rightarrow\text{respingere} } \]

3. „Conductorul cu curent mai mare suportă forța mai mare.”

Nu. Forțele de interacțiune au module egale:

\[ F_{12}=F_{21} \]

4. „Forța scade cu \(1/d^2\).”

Pentru modelul studiat:

\[ \boxed{ F/L\propto1/d } \]

5. „Formula cu \(I_1I_2\) stabilește singură sensul.”

Formula pentru modul folosește:

\[ |I_1I_2| \]

Sensul se stabilește separat.

6. „Dacă unul dintre curenți este zero, rămâne aceeași interacțiune.”

Nu:

\[ I_1I_2=0 \Rightarrow F=0 \]

pentru interacțiunea magnetică modelată aici.

7. „Un conductor este împins de propriul său câmp spre celălalt.”

În explicația utilizată aici, forța asupra fiecărui conductor rezultă din câmpul produs de celălalt conductor.

8. „Formula este exactă pentru orice două fire.”

Relația folosită presupune conductoare rectilinii, paralele și suficient de lungi, cu distanța mică în raport cu lungimea relevantă.

📌 De reținut

Același sens

\[ \boxed{ \uparrow\uparrow \Rightarrow \text{atracție} } \]

Sensuri opuse

\[ \boxed{ \uparrow\downarrow \Rightarrow \text{respingere} } \]

Forță

\[ \boxed{ F= \frac{ \mu_0|I_1I_2|L }{ 2\pi d } } \]

Forță pe unitatea de lungime

\[ \boxed{ \frac FL= \frac{ \mu_0|I_1I_2| }{ 2\pi d } } \]

Dependențe

\[ F\propto|I_1| \] \[ F\propto|I_2| \] \[ F\propto\frac1d \]

Acțiune și reacțiune

\[ \boxed{ \vec F_{12} = -\vec F_{21} } \]
Schema mentală: \(I_1\) produce \(B_1\) → \(B_1\) acționează asupra lui \(I_2\) → apare \(F_2\) → sensurile curenților stabilesc atracția sau respingerea.

🧭 Ce urmează?

Am întâlnit până acum mai multe efecte ale curentului electric:

  • efectul termic;
  • producerea câmpului magnetic;
  • forțe magnetice între conductoare parcurse de curent.

Aceste fenomene nu sunt doar rezultate de laborator. Ele stau la baza multor dispozitive și sisteme tehnice.

În lecția următoare: Aplicații tehnice ale efectelor curentului electric vom conecta legile studiate cu funcționarea unor dispozitive reale care utilizează efectele termice și magnetice ale curentului.
