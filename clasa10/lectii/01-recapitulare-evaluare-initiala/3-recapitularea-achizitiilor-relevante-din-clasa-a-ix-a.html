Reactualizare 1 aproximativ 7 minute

Impulsul mecanic

\[ \boxed{ \vec p=m\vec v } \]

Impulsul este o mărime vectorială.

Direcția și sensul impulsului sunt aceleași cu direcția și sensul vitezei.

Mărime Simbol Unitate SI
masă \(m\) kg
viteză \(v\) m/s
impuls \(p\) kg·m/s

Forța modifică impulsul

\[ \boxed{ \Delta\vec p = \vec F_{\mathrm{med}}\Delta t } \]

De ce sunt utile centura și airbagul?

Pentru aceeași variație a impulsului, mărirea duratei în care corpul este oprit reduce modulul forței medii:

\[ F_{\mathrm{med}} = \frac{\Delta p}{\Delta t}. \]

Exemplu

Un corp cu masa:

\[ m=0{,}50\,\mathrm{kg} \]

se deplasează cu:

\[ v=4\,\mathrm{m/s}. \]

Modulul impulsului este:

\[ p=mv. \] \[ p= 0{,}50\cdot4. \] \[ \boxed{ p=2\,\mathrm{kg\cdot m/s} }. \]

Reactualizare 2 aproximativ 13 minute

Conservarea impulsului

Pentru un sistem izolat, impulsul total se conservă:

\[ \boxed{ \vec p_{\mathrm{inițial}} = \vec p_{\mathrm{final}} } \]

Ciocnire perfect inelastică – exemplu

Un corp de:

\[ m_1=0{,}20\,\mathrm{kg} \]

se deplasează cu:

\[ v_1=4\,\mathrm{m/s}. \]

El lovește un corp aflat în repaus:

\[ m_2=0{,}30\,\mathrm{kg}. \]

După ciocnire, corpurile rămân împreună.

\[ m_1v_1 = (m_1+m_2)v. \] \[ 0{,}20\cdot4 = 0{,}50v. \] \[ \boxed{ v=1{,}6\,\mathrm{m/s} }. \]

Atenție

Într-o ciocnire perfect inelastică se conservă impulsul total, dar energia cinetică nu se conservă.

Echilibrul mecanic

Echilibru de translație

\[ \boxed{ \sum\vec F=\vec 0 } \]

Momentul unei forțe

Capacitatea unei forțe de a produce rotație depinde de forță și de brațul acesteia.

\[ \boxed{ M=Fd } \]

unde \(d\) este distanța perpendiculară de la axa de rotație la dreapta suport a forței.

Echilibru de rotație

\[ \boxed{ \sum M=0 } \]

O forță de \(10\,\mathrm N\) acționează perpendicular la \(2\,\mathrm m\) de axa de rotație. Determină momentul forței.

Reflexia și refracția luminii

Reflexia

\[ \boxed{ i=r } \]

Unghiul de incidență și unghiul de reflexie se măsoară față de normală, nu față de suprafață.

Refracția

\[ \boxed{ n_1\sin i = n_2\sin r } \]

Dacă lumina trece într-un mediu cu indice de refracție mai mare, raza refractată se apropie de normală.

Dacă trece într-un mediu cu indice mai mic, raza se îndepărtează de normală.

Explorează refracția

\(i\) 40,0°
\(r\) 25,4°
Fenomen refracție
Lumina intră într-un mediu cu indice mai mare și se apropie de normală.

Reflexia totală

Poate apărea când lumina trece dintr-un mediu cu indice mai mare spre un mediu cu indice mai mic și unghiul de incidență depășește unghiul limită.

Reactualizare 4 aproximativ 8 minute

Lentile subțiri

Lentilă convergentă

Este mai groasă în zona centrală decât la margini.

Un fascicul paralel cu axa optică este convergent către focarul imagine.

Lentilă divergentă

Este mai subțire în zona centrală.

Un fascicul paralel devine divergent după traversarea lentilei.

Construcția geometrică a imaginii

Două raze principale

1. O rază paralelă cu axa optică trece, după lentila convergentă, prin focarul imagine.

2. Raza care trece prin centrul optic al lentilei subțiri își păstrează aproximativ direcția.

Vergenta lentilei

\[ \boxed{ C= \frac{1}{f} } \]

unde \(f\) se exprimă în metri.

Unitatea pentru vergentă este dioptria:

\[ 1\,\mathrm{dpt} = 1\,\mathrm{m^{-1}}. \]
