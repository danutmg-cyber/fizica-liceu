Mărime scalară

Este caracterizată prin valoare numerică și unitate.

Exemple: masă, timp, energie, temperatură.

Mărime vectorială

Poziție, distanță, deplasare și viteză

Poziție

Este descrisă prin coordonate față de un sistem de referință.

Distanță parcursă

Este lungimea traiectoriei parcurse.

Este o mărime scalară.

Deplasare

Leagă poziția inițială de poziția finală.

Este o mărime vectorială.

Distanța nu este același lucru cu deplasarea

Un elev merge 3 m spre est și apoi 3 m spre vest.

Distanța parcursă: \(6\,\mathrm m\).

Deplasarea: \(0\,\mathrm m\).

Forțe și legile lui Newton

Mișcarea nu se schimbă pentru că „un corp are forță”.

Mișcarea se modifică atunci când asupra corpului acționează o rezultantă nenulă a forțelor.

Principiul I

\[ \boxed{ \vec F_{\mathrm{rez}}=\vec 0 \Rightarrow \vec v=\text{constantă} } \]

Corpul poate fi în repaus sau se poate deplasa rectiliniu și uniform.

Principiul al II-lea

\[ \boxed{ \vec F_{\mathrm{rez}} = m\vec a } \]

Principiul al III-lea

Dacă un corp A exercită o forță asupra corpului B, corpul B exercită asupra corpului A o forță:

\[ \boxed{ \vec F_{AB} = -\vec F_{BA} }. \]

Acțiunea și reacțiunea nu se anulează

Ele acționează asupra unor corpuri diferite.

Simulator: forța rezultantă și accelerația

\(F_{\mathrm{rez}}\) +4,00 N
\(a\) +2,00 m/s²
Sens spre dreapta
Rezultanta este spre dreapta, deci și accelerația este spre dreapta.

Asupra unui corp de \(3\,\mathrm{kg}\) acționează o rezultantă de \(6\,\mathrm N\). Determină accelerația.

m/s²

Forțe uzuale: greutate, reacțiune, elasticitate și frecare

Greutatea

\[ \boxed{ G=mg } \]

Forța elastică

\[ \boxed{ F_e=-kx } \]

Frecare la alunecare

\[ \boxed{ F_f=\mu N } \]

Forța elastică

Semnul minus din: \(F_e=-kx\) arată că forța elastică este orientată în sens opus deformării.

Exemplu 1 – resort

Pentru:

\[ k= 100\,\mathrm{N/m}, \qquad x= 3\,\mathrm{cm} = 0{,}03\,\mathrm m, \] modulul forței elastice este: \[ |F_e|= k|x|. \] \[ |F_e|= 100\cdot0{,}03. \] \[ \boxed{ |F_e|=3\,\mathrm N }. \]

Un resort este alungit spre dreapta. În ce sens este orientată forța elastică?

Exemplu 2 – frecare

Un corp alunecă pe o suprafață orizontală.

Pentru:

\[ m=2\,\mathrm{kg}, \qquad \mu=0{,}20, \qquad g\approx10\,\mathrm{m/s^2}, \] avem: \[ N=mg=20\,\mathrm N. \] \[ F_f= \mu N = 0{,}20\cdot20. \] \[ \boxed{ F_f=4\,\mathrm N }. \]

Sensul frecării

Forța de frecare la alunecare este orientată în sens opus mișcării relative dintre suprafețele aflate în contact.

Conservarea energiei mecanice

Într-un sistem în care putem neglija forțele disipative:

\[ \boxed{ E_m= E_c+E_p= \text{constantă} } \]

Ideea fizică

Energia nu „se consumă” pur și simplu.

Ea poate fi transferată sau transformată dintr-o formă în alta.

\[ E_c= \frac12 \cdot2 \cdot4^2. \] \[ \boxed{ E_c=16\,\mathrm J }. \]

Cele cinci idei esențiale

  1. Unitățile trebuie transformate corect în SI.
  2. Viteza descrie mișcarea, iar accelerația descrie modificarea vitezei.
  3. Accelerația are direcția rezultantei forțelor.
  4. Forțele pot modifica mișcarea și pot efectua lucru mecanic.
  5. Energia se poate transfera și transforma dintr-o formă în alta.
mișcare → forțe → lucru mecanic → energie
