Sistem termodinamic. Parametri de stare. Grade de libertate

Cum alegem sistemul pe care îl studiem, cum îi descriem starea și de ce nu toți parametrii de stare pot fi aleși independent?

Prof. Dănuț Andronie

O încăpere plină cu aer conține enorm de multe molecule. Trebuie să le urmărim pe fiecare?

Nu. Termodinamica descrie sistemul macroscopic, prin câteva mărimi măsurabile: presiune, temperatură, volum, masă, densitate etc.

1. Sistemul termodinamic

Ce parte din Univers studiem?

Într-o problemă de termodinamică nu studiem tot ceea ce există. Alegem o parte bine precizată, pe care o separăm conceptual de restul mediului.

🔵 Definiție

Sistemul termodinamic este un sistem fizic finit, format dintr-un număr foarte mare de particule microscopice care pot interacționa între ele.

🟢 De reținut

Termodinamica descrie comportarea colectivă a unui număr foarte mare de particule, nu mișcarea individuală a fiecărei molecule.

foarte multe particule microscopice
→
comportare colectivă
→
descriere macroscopică

Exemple de sisteme termodinamice

💧

Apa dintr-un vas

Sistemul poate fi chiar apa, fără a include vasul.

🌬️

Aerul dintr-o încăpere

Este format dintr-un număr enorm de molecule și din mai multe componente.

⚙️

Gazul din cilindrul unui motor

Presiunea, temperatura și volumul se pot modifica în timp.

💦

Apă + vapori

Un sistem poate conține mai multe faze.

🧍

Un organism viu

Este un sistem termodinamic foarte complex.

🔬

Un singur atom

Nu reprezintă sistemul macroscopic avut în vedere în această definiție.

Sistem, frontieră, mediu

🔵 Definiție

Frontiera sistemului separă sistemul ales pentru studiu de mediul înconjurător.

Exemplu – aerul dintr-o seringă

Alegem pentru studiu numai aerul din seringă.

  • sistem: aerul din seringă;
  • frontieră: pereții seringii și suprafața pistonului;
  • mediu înconjurător: seringa, mâna, aerul exterior etc.
🟡 Cauză → efect

Alegem altă frontieră → se poate modifica ceea ce numim sistem → se modifică și interacțiunile pe care trebuie să le analizăm.

🟠 Atenție

Sistemul termodinamic nu este obligatoriu recipientul.

În multe probleme, sistemul este chiar substanța din recipient.

Dacă studiem aerul aflat într-o seringă, ce putem alege drept sistem?

2. Starea sistemului. Parametri de stare

Cum descriem un sistem la un moment dat?

Presupunem că privim un gaz aflat într-un recipient. Putem măsura presiunea, temperatura, volumul, masa și alte mărimi macroscopice.

🔵 Definiție

Starea unui sistem termodinamic este descrisă prin totalitatea caracteristicilor sale la un moment dat.

🔵 Definiție

Mărimile fizice care descriu starea unui sistem se numesc:

\[ \boxed{ \text{parametri de stare} } \]

Ele se mai numesc și mărimi de stare.

Exemple importante

\(p\)

Presiune

\[ [p]=\mathrm{Pa} \]
\(V\)

Volum

\[ [V]=\mathrm{m^3} \]
\(T\)

Temperatură

\[ [T]=\mathrm K \]
\(m\)

Masă

\[ [m]=\mathrm{kg} \]
\(\nu\)

Cantitate de substanță

\[ [\nu]=\mathrm{mol} \]
\(\rho\)

Densitate

\[ [\rho]=\mathrm{kg/m^3} \]
🟢 De reținut

O singură mărime, de exemplu temperatura, nu descrie în general complet starea unui sistem termodinamic.

🟡 Cauză → efect

Încălzim un gaz → temperatura se modifică → în funcție de condițiile impuse, se pot modifica și presiunea sau volumul.

Prin urmare, parametrii de stare pot fi legați între ei.

Exemplu de stare

Un gaz poate avea la un moment dat:

\[ p= 1{,}0\cdot10^5\,\mathrm{Pa} \] \[ V= 2{,}0\cdot10^{-3}\,\mathrm{m^3} \] \[ T= 300\,\mathrm K \]

Aceste valori contribuie la precizarea stării macroscopice a sistemului.

🟠 Atenție

„Stare” nu înseamnă poziția corpului în spațiu.

Este vorba despre starea termodinamică, descrisă prin valorile parametrilor macroscopici.

3. Parametri intensivi și extensivi

Două categorii importante

🔵 Parametri intensivi

Pot descrie local sistemul și pot avea valori diferite în puncte diferite.

Exemple:

\[ \boxed{ p,\quad T,\quad\rho } \]

🟢 Parametri extensivi

Caracterizează sistemul ca întreg și depind de cantitatea de materie considerată.

Exemple:

\[ \boxed{ m,\quad V,\quad\nu,\quad U } \]
🔵 Definiție

Parametrii intensivi pot fi considerați funcții de punct: valoarea lor poate varia de la o zonă la alta a sistemului.

🔵 Definiție

Parametrii extensivi caracterizează întregul sistem și sunt legați de mărimea sau cantitatea de materie a acestuia.

Testul dublării sistemului

Luăm două sisteme identice, aflate în aceleași condiții, și le considerăm împreună.

\[ m_{total}=m_1+m_2 \] \[ V_{total}=V_1+V_2 \] \[ \nu_{total}=\nu_1+\nu_2 \]

Pentru două sisteme identice:

\[ m_{total}=2m \] \[ V_{total}=2V \] \[ \nu_{total}=2\nu \]

Dar nu scriem:

\[ T_{total}=2T \]

sau:

\[ p_{total}=2p \]
🟢 De reținut

Parametrii extensivi sunt aditivi.

\[ \boxed{ X_{ext,total} = \sum_i X_{ext,i} } \]
🟡 Cauză → efect

Dublăm cantitatea de materie în aceleași condiții → masa și volumul se dublează → temperatura, presiunea și densitatea nu trebuie să se dubleze.

🟠 Atenție

Intensiv nu înseamnă „mic”.

Extensiv nu înseamnă „mare”.

Clasificarea se referă la modul în care parametrul depinde de mărimea sistemului.

Care grup conține numai parametri intensivi?

4. Parametri independenți. Grade de libertate

Sunt toți parametrii independenți?

Nu. Între parametrii de stare există numeroase relații. De aceea, dacă unii parametri sunt cunoscuți, alții pot fi calculați.

Exemplul cel mai simplu

Masa, volumul și densitatea sunt legate prin:

\[ \boxed{ \rho= \frac{m}{V} } \]

sau:

\[ \boxed{ m= \rho V } \]
🟡 Cauză → efect

Cunoaștem \(m\) și \(V\) → putem calcula \(\rho\) → densitatea nu mai reprezintă o informație independentă.

🔵 Definiție

Parametrii care pot fi aleși pentru a preciza independent starea se numesc parametri independenți.

Parametrii determinați din aceștia prin relații fizice se numesc parametri dependenți.

🔵 Definiție esențială

Numărul parametrilor de stare necesari și suficienți pentru cunoașterea stării sistemului se numește:

\[ \boxed{ \text{numărul gradelor de libertate} } \]
🟢 De reținut

Grad de libertate nu înseamnă că sistemul „se mișcă liber”.

În contextul acestei lecții, el reprezintă o informație independentă necesară pentru descrierea stării.

Exemplul \(m\), \(V\), \(\rho\)

Parametri aleși independent Parametru dependent Relația de calcul
\(m,\ V\) \(\rho\) \(\rho=m/V\)
\(\rho,\ V\) \(m\) \(m=\rho V\)
\(m,\ \rho\) \(V\) \(V=m/\rho\)
🟠 Atenție

Nu putem declara automat că \(m\), \(V\) și \(\rho\) sunt trei parametri independenți.

Relația:

\[ m=\rho V \]

arată că oricare dintre ei poate fi calculat dacă ceilalți doi sunt cunoscuți.

🟢 Regula practică

Pentru a verifica dacă un set de parametri este independent, întreabă-te:

„Pot calcula unul dintre ei folosindu-i numai pe ceilalți?”

Dacă răspunsul este „da”, atunci setul nu este complet independent.

Documentare – cazul unui sistem cu mai multe componente

În caseta de documentare din manual este prezentat, pentru modelul considerat acolo, un sistem format din \(K\) componente. Numărul parametrilor independenți este asociat numărului tipurilor independente de contacte pe care sistemul le poate avea cu mediul.

Pentru nivelul acestei lecții este mai importantă ideea:

\[ \boxed{ \text{grade de libertate} = \text{număr de parametri independenți necesari} } \]

5. Stare staționară și stare nestaționară

Ce se întâmplă cu parametrii în timp?

⏸️ Stare staționară

Parametrii macroscopici considerați nu se modifică în timp.

\[ \boxed{ X(t)=\mathrm{constant} } \]

▶️ Stare nestaționară

Cel puțin un parametru de stare se modifică în timp.

\[ \boxed{ X=X(t) } \]
🔵 Definiție

O stare este staționară dacă parametrii macroscopici care o descriu rămân constanți în timp.

🔵 Definiție

O stare este nestaționară dacă cel puțin unul dintre parametrii de stare se modifică în timp.

Exemplu – aerul dintr-o încăpere

În apropierea caloriferului:

\[ T_1=24^\circ C \]

iar lângă fereastră:

\[ T_2=20^\circ C \]

Dacă aceste valori rămân aceleași în timp, situația poate fi staționară, deși temperatura nu este uniformă în spațiu.

🟠 Atenție importantă

Constant în timp nu înseamnă obligatoriu constant în spațiu.

Aceasta este una dintre confuziile cele mai frecvente.

🟡 Cauză → efect

Parametrii nu se modifică în timp → starea este staționară.

Dar dacă temperatura diferă de la un punct la altul, sistemul poate avea totuși neuniformități spațiale.

Manualul leagă starea de echilibru termodinamic de o stare staționară a unui sistem aflat în condiții de izolare față de mediul înconjurător.

Cum poate interacționa sistemul cu mediul?

↔️

Contact mecanic

Permite interacțiuni mecanice între sistem și mediu.

🌡️

Contact termic

Permite schimb energetic determinat de diferențe de temperatură.

⚛️

Schimb de substanță

Particulele pot traversa frontiera sistemului.

🟠 Atenție

Izolarea termică, izolarea mecanică și împiedicarea schimbului de substanță sunt condiții distincte.

Un recipient închis pentru materie nu este automat și izolator termic.

Reprezentarea unei stări

Dacă alegem doi parametri independenți, o stare poate fi reprezentată printr-un punct într-o diagramă.

\[ \boxed{ A(V_A,p_A) } \]

într-o diagramă:

\[ \boxed{ p-V } \]
🟢 De reținut

Punctul \(A\) din diagrama \(p-V\) reprezintă o stare termodinamică, nu poziția geometrică a sistemului în laborator.

📌 Sinteza vizuală

🔵 Definiții

Sistem termodinamic = sistem fizic finit format din foarte multe particule microscopice.

Parametri de stare = mărimi fizice care descriu starea sistemului.

Grade de libertate = numărul parametrilor independenți necesari și suficienți pentru descrierea stării.

🟢 De reținut
\[ \boxed{ \text{intensivi: } p,\ T,\ \rho } \] \[ \boxed{ \text{extensivi: } m,\ V,\ \nu,\ U } \]

Parametrii extensivi sunt aditivi.

🟡 Cauză → efect

Există o relație între parametri → nu toți sunt independenți → avem nevoie numai de un anumit număr de parametri independenți → acest număr este numărul gradelor de libertate.

🟠 Nu confunda
  • intensiv cu „mic”;
  • extensiv cu „mare”;
  • staționar cu „uniform în spațiu”;
  • parametru independent cu „parametru care nu influențează nimic”;
  • punct într-o diagramă de stare cu poziția fizică a sistemului.
