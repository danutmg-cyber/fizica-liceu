1. Temperatura

Parametru de stare

Temperatura este un parametru de stare care caracterizează starea termică a unui sistem și permite stabilirea sensului spontan al transferului termic între sisteme.

Pentru temperatura termodinamică folosim simbolul:

\[ T. \]

Unitatea SI este:

\[ \boxed{ [T]=\mathrm K } \]

unitatea se numește kelvin.

Sensul transferului termic

Dacă două corpuri pot schimba energie prin contact termic și:

\[ T_1>T_2, \]

atunci transferul termic spontan net are loc:

\[ \boxed{ 1\longrightarrow2 } \]

de la temperatura mai mare către temperatura mai mică.

La echilibru termic:

\[ \boxed{ T_1=T_2 }. \]

Temperatură ≠ căldură

Temperatura este parametru de stare.

Căldura descrie un transfer de energie determinat de o diferență de temperatură.

Nu spunem că un corp „conține o anumită cantitate de căldură”.

„De două ori mai cald” cere atenție

Temperatura de:

\[ 20^\circ\mathrm C \]

nu este „de două ori mai mare” fizic decât:

\[ 10^\circ\mathrm C. \]

Pentru comparații prin rapoarte de temperatură se utilizează temperatura termodinamică exprimată în kelvini.

2. Termometria

Cum măsurăm o temperatură?

Termometria este domeniul care se ocupă cu măsurarea temperaturii și cu realizarea practică a scărilor de temperatură.

Temperatura nu este, în majoritatea termometrelor uzuale, „văzută” direct.

Măsurăm o altă proprietate fizică ce depinde în mod reproductibil de temperatură.

Proprietatea termometrică

\[ \boxed{ X=X(T) } \]

unde \(X\) este o proprietate fizică măsurabilă care variază într-un mod cunoscut cu temperatura.

Volum

volumul unui lichid se poate modifica odată cu temperatura

Rezistență electrică

\[ R=R(T) \]

Tensiune electrică

poate fi folosită în termocupluri

Radiație termică

permite măsurări fără contact direct

Ce cerem unei proprietăți termometrice?

  • să poată fi măsurată;
  • să depindă reproductibil de temperatură;
  • să varieze suficient de sensibil în domeniul dorit;
  • să permită asocierea unei valori de temperatură prin etalonare.

3. Termometrul

Un instrument bazat pe o proprietate termometrică

Termometrul este un instrument utilizat pentru măsurarea temperaturii pe baza variației unei proprietăți fizice cu temperatura.

Măsurarea prin contact

Pentru un termometru de contact:

Etalonarea

Pentru ca o valoare a proprietății termometrice să poată fi transformată într-o temperatură, instrumentul trebuie etalonat.

\[ X \longrightarrow \text{etalonare} \longrightarrow T \]

Etalonarea stabilește corespondența dintre valorile proprietății termometrice și valorile temperaturii.

Nu toate termometrele funcționează prin contact

Termometrele în infraroșu determină temperatura analizând radiația electromagnetică emisă de suprafața corpului.

Ele nu trebuie confundate cu termometrele de contact care necesită atingerea aproximativă a echilibrului termic cu sistemul măsurat.

4. Scara Celsius

Temperatura Celsius

Pentru temperatura exprimată pe scara Celsius folosim frecvent simbolul:

\[ t. \]

Unitatea este:

\[ \boxed{ [t]=^\circ\mathrm C } \]

Repere familiare

În condiții apropiate de presiunea atmosferică standard:

Topirea gheții

\[ t\approx0^\circ\mathrm C \]

Fierberea apei

\[ t\approx100^\circ\mathrm C \]

la presiune atmosferică standard

Temperatura de fierbere depinde de presiune

Apa nu fierbe la \(100^\circ\mathrm C\) în orice condiții.

La presiuni diferite, temperatura de fierbere se modifică.

Temperaturi negative pe scara Celsius

Scara Celsius permite valori negative:

\[ -10^\circ\mathrm C, \qquad -20^\circ\mathrm C, \qquad \ldots \]

Aceste valori nu reprezintă temperaturi termodinamice negative.

\(0^\circ\mathrm C\) nu este temperatura minimă posibilă.

Este doar originea aleasă pentru scara Celsius.

5. Scara Kelvin

Scara temperaturii termodinamice

Unitatea SI a temperaturii termodinamice este kelvinul, cu simbolul: \[ \boxed{ \mathrm K }. \]

Se scrie K, nu °K

Corect:

\[ 300\,\mathrm K \]

Nu:

\[ 300^\circ\mathrm K. \]

Zero absolut

Originea scării Kelvin este:

\[ \boxed{ T=0\,\mathrm K } \]

numită zero absolut.

Aceasta corespunde pe scara Celsius valorii:

\[ \boxed{ -273{,}15^\circ\mathrm C }. \]

Legătura Celsius–Kelvin

\[ \boxed{ T(\mathrm K) = t(^\circ\mathrm C) + 273{,}15 } \]

Invers:

\[ \boxed{ t(^\circ\mathrm C) = T(\mathrm K) - 273{,}15 } \]

Exemplul 1

\[ t=20^\circ\mathrm C \] \[ T= 20+273{,}15 \] \[ \boxed{ T=293{,}15\,\mathrm K }. \]

Exemplul 2

\[ T=300\,\mathrm K \] \[ t= 300-273{,}15 \] \[ \boxed{ t=26{,}85^\circ\mathrm C }. \]

Transformă în kelvini:

\[ -20^\circ\mathrm C. \]

6. Intervale de temperatură și alte scări

Un kelvin și un grad Celsius au aceeași mărime ca interval

Diferența dintre:

\[ 20^\circ\mathrm C \quad\text{și}\quad 30^\circ\mathrm C \] este: \[ \Delta t=10^\circ\mathrm C. \]

În kelvini:

\[ 293{,}15\,\mathrm K \quad\text{și}\quad 303{,}15\,\mathrm K, \] deci: \[ \Delta T=10\,\mathrm K. \]
\[ \boxed{ \Delta T(\mathrm K) = \Delta t(^\circ\mathrm C) } \]

numeric, pentru același interval de temperatură.

Temperatura și intervalul de temperatură nu se convertesc la fel

Pentru o temperatură:

\[ T=t+273{,}15. \]

Pentru o diferență:

\[ \Delta T=\Delta t. \]

Scara Fahrenheit

Scara Fahrenheit este utilizată în special în Statele Unite. Unitatea este gradul Fahrenheit:

\[ ^\circ\mathrm F. \]

Relația cu scara Celsius este:

\[ \boxed{ t_F= \frac{9}{5}t_C+32 } \]

Invers:

\[ \boxed{ t_C= \frac{5}{9} \left( t_F-32 \right) }. \]
