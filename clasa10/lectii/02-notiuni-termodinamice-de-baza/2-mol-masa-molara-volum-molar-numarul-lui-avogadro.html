Mol. Masa molară. Volumul molar. Numărul lui Avogadro

De la masa unei singure molecule la cantități macroscopice pe care le putem măsura în laborator.

Prof. Dănuț Andronie

Cum „numărăm” \(10^{23}\) molecule?

Într-o cantitate obișnuită de apă există un număr enorm de molecule. Nu le putem număra una câte una.

Folosim o mărime macroscopică, cantitatea de substanță, care face legătura dintre lumea microscopică și cea macroscopică.

\[ \boxed{ 1\,\mathrm{mol} \longleftrightarrow 6{,}022\,140\,76 \cdot10^{23} \text{ entități} } \]

Microscopic: atomi, molecule, ioni și alte entități elementare.

Macroscopic: măsurăm masa \(m\), volumul \(V\) și alte mărimi ale probei.

Legătura: cantitatea de substanță \(\nu\), măsurată în moli.

Notațiile folosite în manual

\(m_0\)
masa unei molecule
\(m_r\)
masa moleculară relativă
\(\nu\)
cantitatea de substanță
\(\mu\)
masa molară
\(V_\mu\)
volumul molar
\(N_A\)
numărul / constanta lui Avogadro

La finalul lecției vei putea:

  • să explici semnificația molului;
  • să folosești notația \(\nu\) pentru cantitatea de substanță;
  • să utilizezi relația \(N=\nu N_A\);
  • să definești masa molară \(\mu\);
  • să calculezi \(\nu=m/\mu\);
  • să definești volumul molar \(V_\mu\);
  • să aplici relația \(V=\nu V_\mu\);
  • să diferențiezi \(m_0\), \(m_r\), \(m\), \(\mu\), \(\nu\) și \(n\).

1. Cantitatea de substanță și molul

Cantitatea de substanță \(\nu\)

Cantitatea de substanță este o mărime fizică fundamentală care caracterizează numărul de entități elementare dintr-un sistem.

\[ \boxed{ [\nu]=\mathrm{mol} } \]

Atenție la notație

În această lecție, conform manualului, cantitatea de substanță este notată:

\[ \boxed{\nu} \]

Simbolul \(n\) îl vom păstra pentru numărul volumic.

Ce este molul?

Molul este unitatea SI pentru cantitatea de substanță. Un mol conține exact: \[ \boxed{ 6{,}022\,140\,76 \cdot10^{23} } \] entități elementare specificate.

Entitățile trebuie întotdeauna precizate. Pot fi atomi, molecule, ioni, electroni sau alte particule ori grupări definite.

Atomi

De exemplu: \(1\,\mathrm{mol}\) de atomi de fier.

Molecule

De exemplu: \(1\,\mathrm{mol}\) de molecule de apă.

Ioni

De exemplu: \(1\,\mathrm{mol}\) de ioni \(\mathrm{Na^+}\).

Electroni

Putem preciza și un mol de electroni.

\[ 1\,\mathrm{kmol} = 10^3\,\mathrm{mol} \]

Exemplu

Un mol de molecule de apă conține:

\[ \boxed{ 6{,}022\,140\,76 \cdot10^{23} \text{ molecule de } \mathrm{H_2O} } \]

Ce trebuie specificat când folosim molul?

2. Numărul lui Avogadro

De la mol la numărul de particule

Numărul lui Avogadro este raportul dintre numărul \(N\) de entități elementare și cantitatea de substanță \(\nu\):

\[ \boxed{ N_A= \frac{N}{\nu} } \]

În SI:

\[ \boxed{ N_A= 6{,}022\,140\,76 \cdot10^{23} \,\mathrm{mol^{-1}} } \]

\(N\) și \(N_A\) nu înseamnă același lucru

\(N\) este numărul de entități din proba studiată.

\(N_A\) este constanta lui Avogadro.

Relațiile de calcul

Din definiție rezultă:

\[ \boxed{ N= \nu N_A } \]

și invers:

\[ \boxed{ \nu= \frac{N}{N_A} } \]

Exemplul 1

Câte molecule se află în \(2\,\mathrm{mol}\) de apă?

\[ N= \nu N_A \] \[ N= 2\cdot 6{,}022\,140\,76 \cdot10^{23} \] \[ \boxed{ N\approx 1{,}2044\cdot10^{24} \text{ molecule} } \]

Exemplul 2

Câte molecule conține \(0{,}5\,\mathrm{mol}\) de \(\mathrm{O_2}\)?

\[ N= 0{,}5N_A \] \[ \boxed{ N\approx 3{,}011\cdot10^{23} \text{ molecule} } \]

Dacă \(\nu\) se dublează, numărul de molecule \(N\) se dublează.

Dacă \(\nu\) se înjumătățește, și \(N\) se înjumătățește.

Prin urmare: \[ N\propto\nu \] pentru același tip de entități.

3. Masa molară

Masa molară \(\mu\)

Masa molară este raportul dintre masa \(m\) a unui sistem și cantitatea de substanță \(\nu\) pe care acesta o conține.

\[ \boxed{ \mu= \frac{m}{\nu} } \]

Unitatea SI este:

\[ \boxed{ [\mu] = \mathrm{kg/mol} } \]

În calculele școlare este foarte comodă și unitatea:

\[ \mathrm{g/mol} \]

Legătura cu masa moleculară relativă

În aproximația utilizată în problemele școlare, valoarea numerică a masei molare exprimată în \(\mathrm{g/mol}\) este egală numeric cu masa moleculară relativă \(m_r\):

\[ \boxed{ \mu = m_r\, \mathrm{g/mol} } \]

Echivalent:

\[ \boxed{ \mu = m_r\, \mathrm{kg/kmol} } \]
Substanță \(m_r\) \(\mu\)
\(\mathrm{H_2}\) 2 2 g/mol
\(\mathrm{H_2O}\) 18 18 g/mol
\(\mathrm{N_2}\) 28 28 g/mol
\(\mathrm{O_2}\) 32 32 g/mol
\(\mathrm{CO_2}\) 44 44 g/mol

Cantitatea de substanță din masa probei

Din definiția masei molare:

\[ \mu= \frac{m}{\nu} \]

obținem:

\[ \boxed{ \nu= \frac{m}{\mu} } \]

și:

\[ \boxed{ m= \mu\nu } \]

Exemplu

Câți moli de apă se află în \(36\,\mathrm g\) de apă?

Pentru apă:

\[ \mu= 18\,\mathrm{g/mol} \]

Atunci:

\[ \nu= \frac{36}{18} \] \[ \boxed{ \nu=2\,\mathrm{mol} } \]

4. Masa unei molecule și masa moleculară relativă

Masa unei molecule \(m_0\)

Masa unei molecule este notată în manual cu:

\[ \boxed{ m_0 } \]

Unitatea SI este kilogramul. Deoarece valorile sunt extrem de mici, se folosește unitatea unificată de masă atomică:

\[ \boxed{ 1u \approx 1{,}6605\cdot10^{-27}\,\mathrm{kg} } \]

Masa moleculară relativă \(m_r\)

Masa moleculară relativă este definită prin raportul:

\[ \boxed{ m_r= \frac{m_0}{u} } \]

Este o mărime adimensională:

\[ [m_r]=1 \]

Din definiție:

\[ \boxed{ m_0= m_r u } \]

Exemplu – apa

Pentru apă:

\[ m_r=18 \]

deci:

\[ m_0= 18u \] \[ m_0 \approx 18\cdot 1{,}6605\cdot10^{-27}\,\mathrm{kg} \] \[ \boxed{ m_0 \approx 2{,}99\cdot10^{-26}\,\mathrm{kg} } \]

Nu confunda

\(m_0\) = masa unei singure molecule.

\(m\) = masa întregii probe.

\(m_r\) = număr adimensional.

\(\mu\) = masa corespunzătoare unui mol.

5. Volumul molar

Volumul molar \(V_\mu\)

Volumul molar reprezintă raportul dintre volumul \(V\) al sistemului și cantitatea de substanță \(\nu\):

\[ \boxed{ V_\mu= \frac{V}{\nu} } \]

Unitatea SI:

\[ \boxed{ [V_\mu] = \mathrm{m^3/mol} } \]

Din definiție:

\[ \boxed{ V= \nu V_\mu } \]
\[ \boxed{ \nu= \frac{V}{V_\mu} } \]

Gaz ideal în condiții normale

Pentru condițiile normale utilizate în manual:

\[ T_0= 273{,}15\,\mathrm K \] \[ p_0= 1{,}01325\cdot10^5\,\mathrm{Pa} \]

volumul molar al gazului ideal este aproximativ:

\[ \boxed{ V_{\mu0} \approx 22{,}4\cdot10^{-3}\, \mathrm{m^3/mol} } \]

adică:

\[ \boxed{ V_{\mu0} \approx 22{,}4\, \mathrm{L/mol} } \]

Valoarea \(22{,}4\,\mathrm{L/mol}\) nu este universală

Pentru gaze, volumul molar depinde de temperatură și presiune.

Valoarea de mai sus se folosește numai pentru condițiile normale precizate.

Legătura cu densitatea

Deoarece:

\[ \rho= \frac{m}{V} \] \[ m= \mu\nu \] \[ V= V_\mu\nu \]

rezultă:

\[ \boxed{ \rho= \frac{\mu}{V_\mu} } \]

sau:

\[ \boxed{ \mu= \rho V_\mu } \]

Exemplu

Ce volum ocupă \(2\,\mathrm{mol}\) de gaz ideal în condiții normale?

\[ V= \nu V_{\mu0} \] \[ V= 2\cdot22{,}4 \] \[ \boxed{ V=44{,}8\,\mathrm L } \]

6. Relații utile și probleme

Harta relațiilor

\[ \boxed{ \nu = \frac{m}{\mu} = \frac{N}{N_A} = \frac{V}{V_\mu} } \]

Dacă ai masa, folosești: \[ \nu=\frac{m}{\mu}. \]

Dacă ai numărul de particule, folosești: \[ \nu=\frac{N}{N_A}. \]

Dacă ai volumul și cunoști volumul molar corespunzător stării: \[ \nu=\frac{V}{V_\mu}. \]

Numărul volumic \(n\)

Manualul folosește simbolul \(n\) pentru numărul volumic:

\[ \boxed{ n= \frac{N}{V} } \]

Unitatea:

\[ [n]=\mathrm{m^{-3}} \]

Pentru un gaz:

\[ N= \nu N_A \] \[ V= \nu V_\mu \]

deci:

\[ \boxed{ n= \frac{N_A}{V_\mu} } \]

Problema 1 – apă

Calculați cantitatea de substanță și numărul de molecule din \(36\,\mathrm g\) de apă.

Vezi rezolvarea

Pentru apă:

\[ \mu= 18\,\mathrm{g/mol} \] \[ \nu= \frac{36}{18} = 2\,\mathrm{mol} \] \[ N= 2N_A \] \[ \boxed{ N\approx 1{,}2044\cdot10^{24} } \]

Problema 2 – oxigen

Calculați volumul ocupat în condiții normale de \(64\,\mathrm g\) de \(\mathrm{O_2}\).

Vezi rezolvarea
\[ \mu(\mathrm{O_2}) = 32\,\mathrm{g/mol} \] \[ \nu= \frac{64}{32} = 2\,\mathrm{mol} \] \[ V= 2\cdot22{,}4 \] \[ \boxed{ V=44{,}8\,\mathrm L } \]

Problema 3 – dioxid de carbon

O probă conține \(22\,\mathrm g\) de \(\mathrm{CO_2}\). Calculați \(\nu\), \(N\) și volumul la c.n.

Vezi rezolvarea
\[ \mu= 44\,\mathrm{g/mol} \] \[ \nu= \frac{22}{44} = 0{,}5\,\mathrm{mol} \] \[ N= 0{,}5N_A \approx 3{,}011\cdot10^{23} \] \[ V= 0{,}5\cdot22{,}4 = 11{,}2\,\mathrm L \]

Problema 4 – masa molară din densitate

Un gaz are în condiții normale densitatea aproximativă:

\[ \rho= 1{,}29\,\mathrm{kg/m^3}. \]

Estimați masa molară.

Vezi rezolvarea
\[ \mu= \rho V_{\mu0} \] \[ \mu= 1{,}29 \cdot 22{,}4\cdot10^{-3} \] \[ \mu \approx 2{,}89\cdot10^{-2} \,\mathrm{kg/mol} \] \[ \boxed{ \mu \approx 28{,}9\,\mathrm{g/mol} } \]
