Mol. Masa molară. Volumul molar. Numărul lui Avogadro

Trecerea de la masa unei molecule \(m_0\) și masa moleculară relativă \(m_r\) la cantitatea de substanță \(\nu\), masa molară \(\mu\), volumul molar \(V_\mu\) și numărul lui Avogadro \(N_A\).

Pagina 1 din 9 Lecția 2
Introducere

De la particule microscopice la cantități macroscopice

Un corp conține un număr enorm de atomi, molecule sau ioni. În loc să lucrăm direct cu numere de ordinul lui \(10^{23}\), folosim o mărime macroscopică: cantitatea de substanță.

În această lecție păstrăm notațiile folosite în manual: \[ \boxed{ m_0,\quad m_r,\quad \nu,\quad \mu,\quad V_\mu,\quad N_A } \]

Nivel microscopic

  • \(m_0\) – masa unei molecule;
  • \(m_r\) – masa moleculară relativă;
  • \(N\) – numărul de entități elementare.

Nivel macroscopic

  • \(m\) – masa sistemului;
  • \(V\) – volumul sistemului;
  • \(\nu\) – cantitatea de substanță;
  • \(\mu\) – masa molară;
  • \(V_\mu\) – volumul molar.

Obiective

  • să utilizezi simbolul \(\nu\) pentru cantitatea de substanță;
  • să utilizezi simbolul \(\mu\) pentru masa molară;
  • să utilizezi simbolul \(V_\mu\) pentru volumul molar;
  • să legi masa moleculară \(m_0\) de masa moleculară relativă \(m_r\);
  • să folosești relația \(N=\nu N_A\);
  • să rezolvi probleme cu mase, volume și numere de molecule.
Important: simbolul \(n\) nu va fi folosit aici pentru cantitatea de substanță. Conform notațiilor manualului, cantitatea de substanță este notată cu: \[ \boxed{\nu} \] Astfel, simbolul \(n\) poate rămâne disponibil pentru numărul volumic: \[ n=\frac NV \]

1. Masa moleculară

Masa unei molecule \(m_0\)

Masa moleculară este masa unei molecule. În notația manualului:

\[ \boxed{ m_0 } \]

Unitatea SI este kilogramul:

\[ [m_0]=\mathrm{kg} \]

Deoarece masele atomice și moleculare sunt extrem de mici, se utilizează unitatea unificată de masă atomică, cu simbolul \(u\).

\[ \boxed{ 1u= \frac1{12} m(^{12}\mathrm C) } \]

Numeric:

\[ \boxed{ 1u \approx 1{,}6605\cdot10^{-27}\,\mathrm{kg} } \]

Masa moleculară relativă \(m_r\)

Masa moleculară relativă arată de câte ori masa unei molecule este mai mare decât unitatea de masă atomică.

\[ \boxed{ m_r= \frac{m_0}{u} } \]

Prin urmare:

\[ \boxed{ m_0=m_r u } \]
Masa moleculară relativă este adimensională: \[ \boxed{ [m_r]=1 } \]

Exemplu – apa

Pentru molecula de apă:

\[ m_r(\mathrm{H_2O}) = 2\cdot1+16 = 18 \]

deci:

\[ m_0= 18u \]
\[ m_0 \approx 18\cdot 1{,}6605\cdot10^{-27} \]
\[ \boxed{ m_0 \approx 2{,}99\cdot10^{-26}\,\mathrm{kg} } \]

2. Cantitatea de substanță

Cantitatea de substanță \(\nu\)

Cantitatea de substanță este o mărime fizică fundamentală care caracterizează numărul de entități elementare dintr-un sistem.

\[ \boxed{ [\nu]=\mathrm{mol} } \]
Conform notației manualului: \[ \boxed{ \nu = \text{cantitatea de substanță} } \] Nu folosim \(n\) pentru această mărime.

Molul

Molul este unitatea SI pentru cantitatea de substanță.

\[ \boxed{ 1\,\mathrm{mol} \longleftrightarrow 6{,}022\,140\,76\cdot10^{23} \text{ entități} } \]

Entitățile trebuie precizate. Ele pot fi:

Atomi

de exemplu Fe, He, Cu.

Molecule

de exemplu \(\mathrm{H_2O}\), \(\mathrm{O_2}\), \(\mathrm{CO_2}\).

Alte entități

ioni, electroni sau grupări de particule specificate.

Manualul reproduce definiția istorică a molului, adoptată în 1971, prin raportare la atomii existenți în \(0{,}012\,\mathrm{kg}\) de carbon-12. În SI actual, molul este definit direct prin numărul exact \(6{,}022\,140\,76\cdot10^{23}\) de entități elementare. Notațiile din manual rămân însă cele folosite în această lecție.

Mol și kilomol

\[ \boxed{ 1\,\mathrm{kmol} = 10^3\,\mathrm{mol} } \]

3. Numărul lui Avogadro

Numărul lui Avogadro \(N_A\)

În notația manualului, numărul lui Avogadro este definit prin:

\[ \boxed{ N_A= \frac N\nu } \]

unde:

  • \(N_A\) – numărul lui Avogadro;
  • \(N\) – numărul entităților elementare din sistem;
  • \(\nu\) – cantitatea de substanță.

Valoarea este:

\[ \boxed{ N_A= 6{,}022\,140\,76 \cdot10^{23}\, \mathrm{mol^{-1}} } \]

Echivalent:

\[ \boxed{ N_A= 6{,}022\,140\,76 \cdot10^{26}\, \mathrm{kmol^{-1}} } \]
\(N_A\) nu este o mărime adimensională. Unitatea sa este: \[ \boxed{ [N_A] = \mathrm{mol^{-1}} } \] Denumirea metrologică actuală este constanta lui Avogadro.

Numărul de particule

Din:

\[ N_A= \frac N\nu \]

rezultă:

\[ \boxed{ N= \nu N_A } \]

și:

\[ \boxed{ \nu= \frac N{N_A} } \]
Exemplu

Câte molecule sunt în \(2\,\mathrm{mol}\) de apă?

Vezi rezolvarea
\[ N= \nu N_A \] \[ N= 2\cdot 6{,}022\,140\,76 \cdot10^{23} \] \[ \boxed{ N\approx 1{,}2044\cdot10^{24} \text{ molecule} } \]

4. Masa molară

Masa molară \(\mu\)

Masa molară este raportul dintre masa \(m\) a unui sistem și cantitatea de substanță \(\nu\) conținută în acel sistem.

\[ \boxed{ \mu= \frac m\nu } \]

În SI:

\[ \boxed{ [\mu] = \frac{\mathrm{kg}}{\mathrm{mol}} } \]

În calculele școlare sunt foarte comode și:

\[ \boxed{ \frac{\mathrm g}{\mathrm{mol}} } \qquad \text{și} \qquad \boxed{ \frac{\mathrm{kg}}{\mathrm{kmol}} } \]

Legătura dintre \(\mu\) și \(m_r\)

În aproximația utilizată în manual și în problemele școlare:

\[ \boxed{ \mu = m_r\, \frac{\mathrm g}{\mathrm{mol}} } \]

sau:

\[ \boxed{ \mu = m_r\, \frac{\mathrm{kg}}{\mathrm{kmol}} } \]
Exemplu pentru apă: \[ m_r=18 \] deci: \[ \boxed{ \mu= 18\,\mathrm{g/mol} = 18\,\mathrm{kg/kmol} } \] iar în unitatea SI: \[ \boxed{ \mu= 18\cdot10^{-3}\, \mathrm{kg/mol} } \]

Cantitatea de substanță din masă

Din:

\[ \mu= \frac m\nu \]

obținem:

\[ \boxed{ \nu= \frac m\mu } \]

și:

\[ \boxed{ m= \mu\nu } \]

Relația directă dintre masă și numărul de molecule

Combinând:

\[ \nu= \frac m\mu \]

cu:

\[ N= \nu N_A \]

rezultă:

\[ \boxed{ N= \frac m\mu N_A } \]
Substanță \(m_r\) \(\mu\)
\(\mathrm{H_2}\) 2 2 g/mol
\(\mathrm{H_2O}\) 18 18 g/mol
\(\mathrm{N_2}\) 28 28 g/mol
\(\mathrm{O_2}\) 32 32 g/mol
\(\mathrm{CO_2}\) 44 44 g/mol

5. Volumul molar

Volumul molar \(V_\mu\)

Volumul molar este raportul dintre volumul \(V\) al sistemului și cantitatea de substanță \(\nu\):

\[ \boxed{ V_\mu= \frac V\nu } \]

Unitatea SI:

\[ \boxed{ [V_\mu] = \frac{\mathrm{m^3}}{\mathrm{mol}} } \]

Din definiție:

\[ \boxed{ V= \nu V_\mu } \]
\[ \boxed{ \nu= \frac V{V_\mu} } \]

Volumul molar al gazelor

Pentru gaze, volumul molar depinde puternic de presiune și temperatură.

Pentru condițiile normale utilizate în manual:

\[ T_0= 273{,}15\,\mathrm K \]
\[ p_0= 1{,}01325\cdot10^5\,\mathrm{Pa} \]

pentru gazul ideal:

\[ \boxed{ V_{\mu0} \approx 22{,}4\cdot10^{-3}\, \frac{\mathrm{m^3}}{\mathrm{mol}} } \]

sau:

\[ \boxed{ V_{\mu0} \approx 22{,}4\, \frac{\mathrm L}{\mathrm{mol}} } \]
Valoarea de \(22{,}4\,\mathrm{L/mol}\) este folosită pentru gaze ideale în condițiile normale indicate mai sus. Nu este o constantă universală valabilă la orice temperatură și presiune.

Legătura cu densitatea

Avem:

\[ \rho= \frac mV \]

iar:

\[ m=\mu\nu \]
\[ V=V_\mu\nu \]

Prin urmare:

\[ \boxed{ \rho= \frac{\mu}{V_\mu} } \]

sau:

\[ \boxed{ \mu= \rho V_\mu } \]
Exemplu

Volumul a \(2\,\mathrm{mol}\) de oxigen în condiții normale

Vezi rezolvarea
\[ V= \nu V_{\mu0} \] \[ V= 2\cdot22{,}4 \] \[ \boxed{ V=44{,}8\,\mathrm L } \]

6. Relații utile

Harta formulelor

Masă ↔ moli

\[ \boxed{ \nu= \frac m\mu } \]

Moli ↔ particule

\[ \boxed{ N= \nu N_A } \]

Moli ↔ volum

\[ \boxed{ V= \nu V_\mu } \]
Cele trei relații pot fi legate: \[ \boxed{ \frac m\mu = \frac N{N_A} = \frac V{V_\mu} = \nu } \] Ultimul raport, \(V/V_\mu\), se folosește atunci când volumul molar corespunzător stării sistemului este cunoscut.

Numărul volumic \(n\)

Manualul introduce și numărul volumic:

\[ \boxed{ n= \frac NV } \]

Unitatea:

\[ \boxed{ [n]=\mathrm{m^{-3}} } \]

Pentru un gaz:

\[ N= \nu N_A \]
\[ V= \nu V_\mu \]

deci:

\[ \boxed{ n= \frac{N_A}{V_\mu} } \]

În condiții normale:

\[ n_0 \approx \frac{ 6{,}022\cdot10^{23} }{ 22{,}4\cdot10^{-3} } \]
\[ \boxed{ n_0 \approx 2{,}69\cdot10^{25}\, \mathrm{m^{-3}} } \]
Acum se vede avantajul notației manualului: \[ \nu \] este cantitatea de substanță, iar: \[ n \] poate desemna fără ambiguitate numărul volumic.

Probleme rezolvate

Problema 1

\(36\,g\) de apă

Determinați \(\nu\) și \(N\).

Vezi rezolvarea

Pentru apă:

\[ \mu= 18\,\mathrm{g/mol} \] \[ \nu= \frac m\mu = \frac{36}{18} = 2\,\mathrm{mol} \] \[ N= \nu N_A \] \[ \boxed{ N\approx 1{,}2044\cdot10^{24} \text{ molecule} } \]
Problema 2

\(64\,g\) de oxigen

Calculați cantitatea de substanță și volumul în condiții normale.

Vezi rezolvarea
\[ \mu(\mathrm{O_2}) = 32\,\mathrm{g/mol} \] \[ \nu= \frac{64}{32} = 2\,\mathrm{mol} \] \[ V= \nu V_{\mu0} = 2\cdot22{,}4 \] \[ \boxed{ V=44{,}8\,\mathrm L } \]
Problema 3

\(22\,g\) de dioxid de carbon

Determinați \(\nu\), \(N\) și volumul în condiții normale.

Vezi rezolvarea
\[ \mu(\mathrm{CO_2}) = 44\,\mathrm{g/mol} \] \[ \nu= \frac{22}{44} = 0{,}5\,\mathrm{mol} \] \[ N= 0{,}5N_A \] \[ \boxed{ N\approx 3{,}011\cdot10^{23} } \] \[ V= 0{,}5\cdot22{,}4 \] \[ \boxed{ V=11{,}2\,\mathrm L } \]
Problema 4

Masa molară din densitate

Un gaz are în condiții normale densitatea aproximativă:

\[ \rho= 1{,}29\,\mathrm{kg/m^3} \]

Estimați masa molară.

Vezi rezolvarea
\[ \mu= \rho V_{\mu0} \] \[ \mu= 1{,}29 \cdot 22{,}4\cdot10^{-3} \] \[ \mu \approx 2{,}89\cdot10^{-2}\, \mathrm{kg/mol} \] \[ \boxed{ \mu\approx 28{,}9\,\mathrm{g/mol} } \]

Densitate

\[ \boxed{ \rho= \frac{\mu}{V_\mu} } \]
