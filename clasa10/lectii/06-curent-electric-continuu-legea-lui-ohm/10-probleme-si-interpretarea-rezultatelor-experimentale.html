Lecția 10 Consolidare

Probleme și interpretarea rezultatelor experimentale

Un rezultat experimental nu este doar un număr. Trebuie să verificăm unitățile, coerența datelor, graficul, dispersia valorilor, eventualele abateri și compatibilitatea cu modelul fizic studiat.

🎯 Ce vei învăța

Probleme

  • să alegi relația fizică potrivită;
  • să lucrezi corect cu \(V\), \(A\), \(mA\) și \(\Omega\);
  • să utilizezi legea lui Ohm;
  • să rezolvi probleme cu circuitul întreg;
  • să interpretezi efectul unui reostat;
  • să verifici fizic rezultatul obținut.

Date experimentale

  • să calculezi valorile \(R_i\);
  • să calculezi o valoare medie;
  • să interpretezi graficul \(U=f(I)\);
  • să identifici un punct suspect;
  • să diferențiezi dispersia de o eroare sistematică;
  • să formulezi o concluzie prudentă și argumentată.

1. De la „am calculat” la „am interpretat”

Într-o problemă de fizică, obținerea unui număr nu este ultimul pas.

1
Calculează

Aplică modelul fizic și obține rezultatul.

2
Verifică unitatea

Un rezultat fără unitate este incomplet.

3
Verifică ordinul de mărime

Este valoarea plauzibilă pentru situația analizată?

4
Interpretează

Ce spune rezultatul despre fenomen?

5
Compară

Este compatibil cu celelalte măsurări?

6
Reprezintă

Ce arată tabelul sau graficul?

7
Caută abateri

Există un punct suspect sau o tendință sistematică?

8
Concluzionează

Datele susțin sau nu modelul în domeniul investigat?

2. Trusa de formule

Legea lui Ohm

\[ \boxed{ U=RI } \] \[ \boxed{ I=\frac UR } \]

Rezistența

\[ \boxed{ R=\frac UI } \]

Conductor uniform

\[ \boxed{ R=\rho\frac{\ell}{S} } \]

Circuit întreg

\[ \boxed{ I= \frac{\mathcal E}{R+r} } \]

Tensiune la borne

\[ \boxed{ U= \mathcal E-Ir } \]

Grafic \(U(I)\)

\[ \boxed{ R= \frac{\Delta U}{\Delta I} } \]

3. Capcana unităților

Mărime Unitate SI Conversie frecventă
Intensitate A \[ 1\,mA=10^{-3}\,A \]
Tensiune V \[ 1\,mV=10^{-3}\,V \]
Rezistență \(\Omega\) \[ 1\,k\Omega=10^3\,\Omega \]
Secțiune \(m^2\) \[ 1\,mm^2=10^{-6}\,m^2 \]
Exemplu: \[ I=200\,mA \] înseamnă: \[ I=0,200\,A \] nu: \[ 200\,A \]

4. Cum interpretezi un tabel experimental?

Presupunem următorul set de măsurări:

Nr. \(I\,[A]\) \(U\,[V]\) \(R_i=U_i/I_i\,[\Omega]\)
1 0,050 1,02 20,4
2 0,100 1,99 19,9
3 0,150 3,04 20,3
4 0,200 3,98 19,9

Valorile nu sunt perfect identice, dar sunt apropiate.

O concluzie potrivită este: „În limitele dispersiei experimentale, raportul \(U/I\) rămâne aproximativ constant, iar datele sunt compatibile cu un comportament ohmic în domeniul investigat.”
O concluzie prea puternică ar fi: „Am demonstrat că acest rezistor respectă perfect legea lui Ohm în orice condiții.” Experimentul verifică doar domeniul de valori și condițiile efectiv investigate.

5. Media valorilor determinate

Pentru patru determinări:

\[ \boxed{ R_{med} = \frac{ R_1+R_2+R_3+R_4 }{4} } \]

Pentru datele precedente:

\[ R_{med} = \frac{ 20,4+19,9+20,3+19,9 }{4} \]
\[ \boxed{ R_{med} \approx20,1\,\Omega } \]
Media este utilă, dar nu trebuie să ascundă date neobișnuite. Dacă una dintre valori este foarte diferită, trebuie să investigăm cauza înainte de a o include automat în medie.

6. Interpretarea graficului \(U=f(I)\)

Pentru un rezistor ohmic menținut în condiții aproximativ constante:

\[ U=RI \]

Graficul ideal este o dreaptă prin origine.

\[ \boxed{ R= \frac{\Delta U}{\Delta I} } \]

Dreaptă prin origine

Este compatibilă cu:

\[ U\sim I \]

Dreaptă, dar nu prin origine

Poate sugera o abatere sistematică, un zero incorect sau un efect care trebuie investigat.

Curbură evidentă

Poate indica modificarea rezistenței cu punctul de funcționare, de exemplu prin încălzire.

7. Abatere aleatoare, sistematică sau greșeală grosieră?

Dispersie aleatoare

Valorile se împrăștie ușor de o parte și de alta a tendinței.

Exemple: citirea scalei, fluctuații mici, contacte imperfect repetabile.

Abatere sistematică

Rezultatele sunt deplasate într-un mod repetabil.

Exemple: zero incorect al aparatului, calibrare necorespunzătoare, o tensiune suplimentară constantă.

Greșeală grosieră

Un rezultat este incompatibil evident cu restul datelor.

Exemple: citire greșită, unitate greșită, valoare transcrisă incorect.

Un punct suspect nu se șterge doar pentru că „strică graficul”. Mai întâi trebuie căutată o cauză experimentală justificată.

8. Eroarea relativă față de o valoare de referință

Dacă este disponibilă o valoare de referință:

\[ R_{ref} \]
atunci:

\[ \boxed{ \varepsilon_r = \frac{ |R_{exp}-R_{ref}| }{ R_{ref} } \cdot100\% } \]

Exemplu

\[ R_{exp}=20,4\,\Omega \] \[ R_{ref}=20,0\,\Omega \]
\[ \varepsilon_r = \frac{0,4}{20} \cdot100\% \]
\[ \boxed{ \varepsilon_r=2\% } \]
Eroarea relativă spune cât de mare este abaterea în raport cu valoarea de referință. O diferență de \(1\,\Omega\) poate fi mică într-o măsurare de \(1000\,\Omega\), dar mare într-o măsurare de \(2\,\Omega\).

🧩 Probleme rezolvate și de interpretare

Nivel 1

Problema 1 – Legea lui Ohm

La bornele unui rezistor se măsoară:

\[ U=6\,V \] \[ I=300\,mA \]

Determină rezistența.

Vezi rezolvarea
Mai întâi: \[ 300\,mA = 0,300\,A \] Apoi: \[ R= \frac UI = \frac6{0,300} \] \[ \boxed{ R=20\,\Omega } \]
Nivel 1

Problema 2 – Predicție

Un rezistor ohmic de:

\[ R=30\,\Omega \]
este conectat la:

\[ U=9\,V \]

Ce curent este așteptat?

Vezi rezolvarea
\[ I= \frac UR = \frac9{30} \] \[ \boxed{ I=0,30\,A } \]
Nivel 2

Problema 3 – Analizează patru determinări

S-au obținut:

\[ R_1=39,6\,\Omega \] \[ R_2=40,2\,\Omega \] \[ R_3=40,0\,\Omega \] \[ R_4=40,4\,\Omega \]

Calculează media și formulează o concluzie.

Vezi rezolvarea
\[ R_{med} = \frac{ 39,6+40,2+40,0+40,4 }{4} \] \[ \boxed{ R_{med}=40,05\,\Omega } \] Valorile sunt foarte apropiate. O concluzie corectă: „Rezultatele sunt coerente între ele, iar rezistența determinată experimental este aproximativ \(40\,\Omega\).”
Nivel 2

Problema 4 – Punct suspect

Un elev obține:

\[ 19,8\,\Omega,\quad 20,1\,\Omega,\quad 31,4\,\Omega,\quad 20,0\,\Omega \]

Ce trebuie să facă?

Vezi interpretarea
Valoarea: \[ 31,4\,\Omega \] este mult diferită de celelalte trei. Nu trebuie eliminată automat. Elevul trebuie să verifice: - citirea lui \(U\); - citirea lui \(I\); - conversia unităților; - transcrierea; - conexiunile; - eventual repetarea determinării. Dacă se identifică o greșeală experimentală clară, măsurarea poate fi repetată și justificat exclusă.
Nivel 2

Problema 5 – Circuit întreg

O sursă are:

\[ \mathcal E=6\,V, \qquad r=1\,\Omega \]
și alimentează:

\[ R=11\,\Omega \]

Determină \(I\) și tensiunea la borne.

Vezi rezolvarea
\[ I= \frac{\mathcal E}{R+r} = \frac6{12} \] \[ \boxed{ I=0,50\,A } \] Tensiunea la borne: \[ U=IR \] \[ U= 0,50\cdot11 \] \[ \boxed{ U=5,5\,V } \] Verificare: \[ \mathcal E-Ir = 6-0,50 = 5,5\,V \]
Nivel 3

Problema 6 – Rezistența din grafic

Pe graficul \(U(I)\) se aleg două puncte ale dreptei de tendință:

\[ I_1=0,10\,A, \qquad U_1=2,1\,V \] \[ I_2=0,40\,A, \qquad U_2=8,1\,V \]

Determină panta.

Vezi rezolvarea
\[ R= \frac{\Delta U}{\Delta I} \] \[ R= \frac{ 8,1-2,1 }{ 0,40-0,10 } \] \[ R= \frac6{0,30} \] \[ \boxed{ R=20\,\Omega } \] Observă însă că dreapta definită de aceste puncte nu trece exact prin origine. Acest lucru trebuie observat și discutat, nu ascuns prin calculul pantei.

9. Cum interpretezi indicatorii analizorului?

\(R_{med}\)

Media valorilor:

\[ R_i= \frac{U_i}{I_i} \]

Este o estimare directă a rezistenței.

Panta \(a\)

Pentru ajustarea:

\[ U=aI+b \]

\(a\) are unitatea ohm și reprezintă panta dreptei de tendință.

Ordonata \(b\)

Pentru un rezistor ohmic ideal:

\[ b=0 \]

Un \(b\) semnificativ nenul poate indica o abatere sistematică sau un model incomplet.

\(R^2\)

Indică cât de bine este descris setul de o relație liniară.

O valoare apropiată de 1 indică linearitate bună.

Atenție: \[ R^2\approx1 \] nu demonstrează singur că datele respectă legea lui Ohm. De exemplu, o dreaptă foarte bună care nu trece prin apropierea originii poate indica o abatere sistematică.

10. Patru situații de diagnostic

A. Dispersie mică

Punctele sunt aproape de o dreaptă prin origine, iar valorile \(U/I\) sunt apropiate.

Concluzie: date compatibile cu modelul ohmic în domeniul investigat.

B. Un punct îndepărtat

Trei puncte urmează tendința, unul este foarte diferit.

Acțiune: verifică și, dacă este posibil, repetă măsurarea.

C. Dreaptă deplasată

Punctele sunt foarte liniare, dar dreapta nu trece prin origine.

Acțiune: caută o posibilă abatere sistematică.

D. Curbură

Raportul \(U/I\) crește treptat.

Interpretare posibilă: rezistența se modifică, de exemplu din cauza încălzirii conductorului.

🔎 Detectează greșeala

Cazul A

Un elev notează:

\[ U=6\,V \] \[ I=250\,mA \]
și calculează:

\[ R= \frac6{250} = 0,024\,\Omega \]
Care este greșeala?
Nu a transformat miliamperii în amperi. \[ 250\,mA= 0,250\,A \] Deci: \[ R= \frac6{0,250} = 24\,\Omega \]

Cazul B

Patru valori sunt:

\[ 30,1;\quad30,0;\quad45,8;\quad29,9\ \Omega \]

Elevul face imediat media tuturor și nu comentează nimic.

Ce lipsește?
Valoarea: \[ 45,8\,\Omega \] este suspectă. Înaintea mediei trebuie verificată citirea, transcrierea, unitatea și condițiile experimentale.

Cazul C

Un elev obține un grafic perfect liniar:

\[ U=20I+0,5 \]
și concluzionează doar: „legea lui Ohm este verificată perfect”.

Ce trebuie observat?
Panta este constantă, dar: \[ b=0,5\,V \] este semnificativ nenulă. Dreapta nu trece prin origine, deci trebuie investigată o posibilă abatere sistematică.

Concluzie

Trebuie să fie bazată pe: date, grafic, incertitudini și modelul fizic.

Ideea esențială: un elev care știe fizică nu întreabă doar: „Ce rezultat am obținut?” ci și: „Este coerent? Ce arată graficul? Care sunt limitele măsurării? Ce concluzie permit de fapt datele?”
