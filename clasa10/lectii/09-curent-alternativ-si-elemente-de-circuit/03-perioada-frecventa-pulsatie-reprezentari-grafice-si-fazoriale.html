Lecția 3 Clasa a X-a Descrierea sinusoidei

Perioada, frecvența și pulsația. Reprezentări grafice și fazoriale

O sinusoidă poate fi descrisă în două moduri complementare: prin graficul valorii instantanee în funcție de timp sau printr-un vector rotitor. Vom lega perioada \(T\), frecvența \(f\), pulsația \(\omega\) și faza într-o singură imagine fizică și matematică.

🎯 Ce vei învăța

La final vei putea:

  • să definești perioada unei mărimi sinusoidale;
  • să definești frecvența și unitatea sa;
  • să utilizezi relația \(f=1/T\);
  • să definești pulsația \(\omega\);
  • să utilizezi \(\omega=2\pi f=2\pi/T\);
  • să identifici faza instantanee și faza inițială;
  • să citești \(T\), \(U_m\) și faza dintr-un grafic;
  • să interpretezi o diferență de fază;
  • să transformi diferența de fază într-un decalaj temporal;
  • să asociezi unei sinusoide un vector rotitor;
  • să explici legătura dintre rotația fazorului și graficul sinusoidal;
  • să pregătești reprezentarea fazorială necesară circuitelor de curent alternativ.

Relațiile centrale

\[ \boxed{ f=\frac1T } \]
\[ \boxed{ \omega=2\pi f } \]
\[ \boxed{ \omega=\frac{2\pi}{T} } \]
\[ \boxed{ \varphi(t)=\omega t+\varphi_0 } \]
\[ \boxed{ \Delta t= \frac{\Delta\varphi}{\omega} = \frac{\Delta\varphi}{2\pi}T } \]

1. Ce știm deja despre sinusoidă?

În lecția precedentă am descris o tensiune alternativă prin:

\[ u(t) = U_m \sin(\omega t+\varphi_0) \]

Am identificat:

  • \(u(t)\) – valoarea instantanee;
  • \(U_m\) – amplitudinea;
  • \(U=U_m/\sqrt2\) – valoarea efectivă, pentru sinusoidă.

Au rămas însă trei întrebări:

Cât durează un ciclu?
\[ T \]
→
Câte cicluri au loc într-o secundă?
\[ f \]
→
Cât de repede evoluează faza?
\[ \omega \]

2. Perioada \(T\)

O mărime periodică revine după un anumit interval de timp în aceeași stare de variație.

Perioada \(T\) este cel mai mic interval de timp pozitiv după care mărimea periodică se repetă.

Matematic:

\[ \boxed{ u(t+T)=u(t) } \]

Unitatea de măsură

\[ \boxed{ [T]=s } \]

Un ciclu

Între două maxime pozitive consecutive:

\[ \Delta t=T \]

O semiperioadă

\[ \frac T2 \]

În acest interval, o sinusoidă trece într-o stare cu semn opus.

Un sfert de perioadă

\[ \frac T4 \]

corespunde unei variații de fază de \(90^\circ\).

3. Cum citim perioada dintr-un grafic?

Perioada poate fi măsurată între două puncte consecutive care se află în aceeași stare de variație.

Exemple:

  • maxim pozitiv → maxim pozitiv următor;
  • minim → minim următor;
  • trecere prin zero crescătoare → următoarea trecere prin zero crescătoare.
Nu orice două treceri consecutive prin zero sunt separate printr-o perioadă. Ele sunt separate prin: \[ \boxed{ \frac T2 } \] deoarece panta are sens opus la cele două treceri.

4. Frecvența \(f\)

Frecvența indică numărul de cicluri efectuate într-o secundă.

\[ \boxed{ f=\frac1T } \]

și reciproc:

\[ \boxed{ T=\frac1f } \]

Unitatea de măsură

\[ \boxed{ [f]=Hz } \]
\[ 1\,Hz=1\,s^{-1} \]

Frecvență mai mare

Mai multe oscilații în aceeași secundă.

\[ f\uparrow \Rightarrow T\downarrow \]

Perioadă mai mare

Fiecare oscilație durează mai mult.

\[ T\uparrow \Rightarrow f\downarrow \]

5. Exemplu fundamental: \(50\,Hz\)

Dacă o mărime sinusoidală are:

\[ f=50\,Hz \]

atunci:

\[ T= \frac1{50} \]
\[ \boxed{ T=0,020\,s=20\,ms } \]

O semiperioadă durează:

\[ \boxed{ \frac T2=10\,ms } \]

iar un sfert de perioadă:

\[ \boxed{ \frac T4=5\,ms } \]

6. Pulsația \(\omega\)

Într-o perioadă completă, argumentul sinusului crește cu:

\[ 2\pi\,rad \]

Dacă această variație are loc în timpul \(T\), ritmul de variație al fazei este:

\[ \omega= \frac{2\pi}{T} \]

Cum:

\[ f=\frac1T \]

rezultă:

\[ \boxed{ \omega= 2\pi f = \frac{2\pi}{T} } \]

Unitate

\[ \boxed{ [\omega]=rad/s } \]
Nu confunda: \[ \boxed{ f } \] cu: \[ \boxed{ \omega } \] Frecvența \(f\) spune câte cicluri au loc într-o secundă. Pulsația \(\omega\) spune cu câți radiani pe secundă evoluează faza.

8. Faza unei mărimi sinusoidale

În expresia:

\[ u= U_m \sin(\omega t+\varphi_0) \]

argumentul funcției sinus:

\[ \boxed{ \varphi(t) = \omega t+\varphi_0 } \]

se numește fază instantanee.

\(\omega t\)

Partea fazei acumulată prin evoluția în timp.

\(\varphi_0\)

Faza inițială:

\[ \varphi(0)=\varphi_0 \]
Faza indică unde ne aflăm în ciclul sinusoidal. Două semnale pot avea aceeași amplitudine și aceeași frecvență, dar valori instantanee diferite deoarece au faze diferite.

10. Diferența de fază

Considerăm două mărimi sinusoidale de aceeași frecvență:

\[ u_1= U_{1m} \sin(\omega t+\varphi_1) \]
\[ u_2= U_{2m} \sin(\omega t+\varphi_2) \]

Diferența lor de fază este:

\[ \boxed{ \Delta\varphi= \varphi_2-\varphi_1 } \]

În fază

\[ \Delta\varphi=0 \]

Maximele și trecerile prin zero apar simultan.

Cuadratură

\[ |\Delta\varphi| = \frac{\pi}{2} \]

Decalaj de un sfert de perioadă.

Opoziție de fază

\[ |\Delta\varphi| = \pi \]

Când una este maxim pozitiv, cealaltă este maxim negativ, dacă amplitudinile sunt comparabile.

11. Avans și întârziere de fază

Considerăm:

\[ u_1= U_m\sin(\omega t) \]

și:

\[ u_2= U_m \sin \left( \omega t+ \frac{\pi}{2} \right) \]

Semnalul \(u_2\) atinge aceeași fază caracteristică mai devreme decât \(u_1\).

Spunem că: \[ \boxed{ u_2 \text{ este în avans de fază față de } u_1 } \] cu: \[ \boxed{ \Delta\varphi= +\frac{\pi}{2} } \]

Dacă diferența este negativă, semnalul al doilea este în întârziere față de primul, conform convenției de mai sus.

12. Din diferență de fază în decalaj temporal

Deoarece faza crește cu viteza:

\[ \omega= \frac{\Delta\varphi}{\Delta t} \]

pentru două sinusoide de aceeași frecvență:

\[ \boxed{ \Delta t= \frac{\Delta\varphi}{\omega} } \]

Folosind:

\[ \omega= \frac{2\pi}{T} \]

obținem:

\[ \boxed{ \Delta t= \frac{\Delta\varphi}{2\pi} T } \]

\(90^\circ\)

\[ \Delta\varphi= \frac{\pi}{2} \]
\[ \boxed{ |\Delta t|=\frac T4 } \]

\(180^\circ\)

\[ \Delta\varphi= \pi \]
\[ \boxed{ |\Delta t|=\frac T2 } \]

\(360^\circ\)

\[ \Delta\varphi= 2\pi \]
\[ \boxed{ |\Delta t|=T } \]

13. De unde apare reprezentarea fazorială?

Imaginează-ți un vector de modul constant \(U_m\), care se rotește uniform cu viteza unghiulară \(\omega\).

La momentul \(t\), vectorul formează unghiul:

\[ \varphi= \omega t+\varphi_0 \]

față de axa de referință.

Dacă folosim proiecția sa pe axa verticală:

\[ \boxed{ u= U_m\sin\varphi } \]

obținem exact mărimea sinusoidală.

Vector rotitor
\[ |\vec U_m|=U_m \]
→
Proiecție verticală
\[ U_m\sin\varphi \]
→
Sinusoidă
\[ u(t) \]
Această construcție este puntea dintre graficul în timp și reprezentarea fazorială. În simulator folosim explicit convenția: unghiul se măsoară față de axa orizontală, iar valoarea sinusoidală este proiecția verticală a vectorului.

14. Fazorul – o reprezentare eficientă

Pentru mai multe mărimi sinusoidale cu aceeași frecvență, nu este necesar să desenăm mereu grafice complete.

Putem asocia fiecărei mărimi un vector caracterizat prin:

  • un modul proporțional cu amplitudinea sau cu valoarea efectivă;
  • un unghi care codifică faza;
  • aceeași viteză unghiulară \(\omega\) pentru toate mărimile de aceeași frecvență.
Într-o diagramă fazorială, diferența de unghi dintre fazori reprezintă diferența de fază dintre sinusoidele corespunzătoare.

Pentru circuitele de curent alternativ, această metodă va deveni foarte utilă deoarece vom compara permanent faza tensiunii cu faza curentului.

15. De ce comparăm fazorial mărimi de aceeași frecvență?

Dacă două mărimi au aceeași pulsație:

\[ \omega_1=\omega_2 \]

fazorii lor se rotesc cu aceeași viteză.

Atunci diferența unghiulară rămâne constantă:

\[ \Delta\varphi= constant \]
Aceasta face posibilă o diagramă fazorială „înghețată”: putem desena fazorii într-un anumit moment, iar diferența lor de fază rămâne aceeași în timp.

Dacă frecvențele sunt diferite, diferența de fază se modifică permanent, iar o diagramă fazorială simplă comună nu mai are aceeași interpretare.

16. Cum citim complet o sinusoidă din grafic?

  1. Identifică axa timpului și unitatea acesteia.
  2. Citește amplitudinea de la axa verticală: \[ U_m \]
  3. Alege două puncte echivalente consecutive, de exemplu două maxime pozitive.
  4. Măsoară distanța temporală: \[ T \]
  5. Calculează: \[ f=\frac1T \]
  6. Calculează: \[ \omega=2\pi f \]
  7. Observă starea la \(t=0\) pentru a deduce faza inițială.
  8. Dacă există două sinusoide, măsoară decalajul temporal și transformă-l în diferență de fază.

17. Faza din decalajul grafic

Dacă două sinusoide de aceeași perioadă sunt decalate cu \(\Delta t\), atunci modulul diferenței de fază este:

\[ \boxed{ |\Delta\varphi| = 2\pi \frac{|\Delta t|}{T} } \]

sau în grade:

\[ \boxed{ |\Delta\varphi|[^\circ] = 360^\circ \frac{|\Delta t|}{T} } \]

Exemplu

Dacă:

\[ \Delta t= \frac T4 \]

atunci:

\[ |\Delta\varphi| = 2\pi\cdot\frac14 = \frac{\pi}{2} \]
\[ \boxed{ |\Delta\varphi|=90^\circ } \]

Exemplul 6 – Diferență de fază

Se dau:

\[ u_1= 10\sin(\omega t) \]
\[ u_2= 8 \sin \left( \omega t+ \frac{\pi}{3} \right) \]

Determinați diferența de fază și precizați care semnal este în avans.

Vezi rezolvarea
\[ \varphi_1=0 \] \[ \varphi_2= \frac{\pi}{3} \] Prin urmare: \[ \Delta\varphi= \varphi_2-\varphi_1 = \frac{\pi}{3} \] \[ \boxed{ \Delta\varphi= 60^\circ } \] În convenția folosită: \[ \boxed{ u_2 \text{ este în avans de fază față de } u_1 } \]

Două tensiuni de:

Vezi rezolvarea

Exemplul 8 – Din decalaj temporal în fază

Două sinusoide au:

\[ T=16\,ms \]

iar maximele lor sunt decalate cu:

Determinați diferența de fază.

Vezi rezolvarea
\[ |\Delta\varphi| = 360^\circ \frac{|\Delta t|}{T} \] \[ |\Delta\varphi| = 360^\circ \frac2{16} \] \[ |\Delta\varphi| = 45^\circ \] Deci: \[ \boxed{ |\Delta\varphi| = 45^\circ = \frac{\pi}{4} } \]
Nivel 3

Exemplul 9 – Compararea frecvențelor

Semnalul A realizează 20 de oscilații în \(0,5\,s\), iar semnalul B are perioada \(T_B=0,04\,s\). Care are frecvența mai mare?

Vezi rezolvarea
Pentru A: \[ f_A= \frac{N}{t} = \frac{20}{0,5} \] \[ f_A=40\,Hz \] Pentru B: \[ f_B= \frac1{0,04} = 25\,Hz \] Prin urmare: \[ \boxed{ f_A>f_B } \]

⚠️ Greșeli frecvente

1. „Frecvența și pulsația sunt același lucru.”

Nu.

\[ \omega=2\pi f \]

Au și unități diferite.

2. „Două treceri consecutive prin zero sunt la o perioadă distanță.”

Pentru o sinusoidă sunt, în general, separate prin:

\[ \frac T2 \]

dacă au pante opuse.

3. „O perioadă înseamnă \(\pi\) rad.”

Nu. Un ciclu complet corespunde:

\[ \boxed{ 2\pi\,rad=360^\circ } \]

4. „Faza este măsurată în secunde.”

Nu. Faza este un unghi și se exprimă în radiani sau, uneori, în grade.

5. „Dacă schimb amplitudinea, schimb automat frecvența.”

Nu. Amplitudinea și frecvența sunt parametri independenți ai unei sinusoide.

6. „Două semnale de aceeași frecvență sunt automat în fază.”

Nu. Ele pot avea faze inițiale diferite.

7. „Un avans de \(90^\circ\) înseamnă un decalaj de \(90\,s\).”

Nu. Unghiul trebuie convertit într-un interval temporal folosind perioada.

8. „Fazorul este o săgeată fizică din circuit.”

Nu. Este o reprezentare matematică utilă pentru amplitudine și fază.

9. „Diferența de fază depinde de amplitudini.”

Nu. Două semnale pot avea amplitudini foarte diferite și totuși aceeași diferență de fază.

10. „Un fazor nu se leagă de graficul sinusoidal.”

Din contră: proiecția vectorului rotitor generează matematic sinusoida.

🧭 Ce urmează?

Acum putem reprezenta simultan o tensiune și un curent prin grafice și fazori.

Următoarea întrebare este:

Ce relație există între tensiune și curent atunci când elementul de circuit este un rezistor?

Vom constata că pentru un rezistor ideal:

\[ \boxed{ u=Ri } \]
