Lecția 6 Clasa a X-a Condensator ideal

Condensatorul. Reactanța capacitivă

Condensatorul ideal nu permite trecerea unui curent continuu staționar, dar într-un circuit de curent alternativ se încarcă și se descarcă periodic. Curentul este determinat de viteza cu care se modifică tensiunea, iar opoziția condensatorului la curent alternativ este descrisă prin reactanța capacitivă.

🎯 Ce vei învăța

La final vei putea:

  • să descrii modelul condensatorului ideal;
  • să folosești relația \(q=Cu\);
  • să deduci relația \(i=C\,du/dt\);
  • să explici de ce curentul este în avans cu \(90^\circ\) față de tensiune;
  • să definești reactanța capacitivă;
  • să utilizezi \(X_C=1/(\omega C)\);
  • să utilizezi \(U=X_CI\);
  • să explici dependența reactanței de frecvență și capacitate;
  • să interpretezi comportarea condensatorului la frecvențe mici și mari;
  • să calculezi energia câmpului electric;
  • să explici de ce puterea activă medie este nulă pentru condensatorul ideal.

Relațiile centrale

\[ \boxed{ q=Cu } \]
\[ \boxed{ i= C\frac{du}{dt} } \]
\[ \boxed{ X_C= \frac1{\omega C} = \frac1{2\pi fC} } \]
\[ \boxed{ U=X_CI } \]

1. De la bobină la condensator

Pentru bobina ideală am găsit:

\[ X_L=\omega L \]

și:

\[ \varphi_u-\varphi_i= +90^\circ \]

Reactanța inductivă crește când frecvența crește.

Condensatorul se va comporta complementar.

Pentru condensatorul ideal: \[ \boxed{ X_C= \frac1{\omega C} } \] iar curentul este în avans cu \(90^\circ\) față de tensiune.

2. Condensatorul ideal

Un condensator este format, în modelul simplificat, din două armături conductoare separate de un dielectric.

Mărimea care îl caracterizează este capacitatea electrică:

\[ C \]

Relația fundamentală este:

\[ \boxed{ q=Cu } \]

unde:

  • \(q\) este sarcina unei armături;
  • \(u\) este tensiunea dintre armături;
  • \(C\) este capacitatea.

Unitatea capacității

\[ \boxed{ [C]=F } \]

Unitatea se numește farad.

În practică sunt frecvente submultiplii: \[ 1\,\mu F=10^{-6}\,F \] \[ 1\,nF=10^{-9}\,F \] \[ 1\,pF=10^{-12}\,F \]

3. De ce apare curent când tensiunea se modifică?

Curentul electric este rata de variație a sarcinii:

\[ i= \frac{dq}{dt} \]

Cum:

\[ q=Cu \]

iar \(C\) este constantă pentru condensatorul ideal, rezultă:

\[ i= \frac{d(Cu)}{dt} \]
\[ \boxed{ i= C\frac{du}{dt} } \]
Curentul prin condensator este determinat de viteza de variație a tensiunii. Dacă tensiunea se modifică rapid, curentul poate avea o valoare mare. Dacă tensiunea este constantă, în regim staționar ideal: \[ \frac{du}{dt}=0 \Rightarrow i=0 \]

4. Tensiune sinusoidală aplicată condensatorului

Alegem tensiunea drept mărime de referință:

\[ u= U_m\sin(\omega t) \]

Pentru condensator:

\[ i= C\frac{du}{dt} \]

Derivăm:

\[ \frac{du}{dt} = \omega U_m \cos(\omega t) \]

deci:

\[ i= \omega C U_m \cos(\omega t) \]

Folosim:

\[ \cos x= \sin \left( x+\frac{\pi}{2} \right) \]

și obținem:

\[ \boxed{ i= \omega C U_m \sin \left( \omega t+ \frac{\pi}{2} \right) } \]

5. Relația de fază

Comparăm:

Tensiune

\[ u= U_m\sin(\omega t) \]

Curent

\[ i= I_m \sin \left( \omega t+ \frac{\pi}{2} \right) \]

Rezultă:

\[ \boxed{ \varphi_i-\varphi_u= +\frac{\pi}{2} = +90^\circ } \]
Pentru condensatorul ideal: curentul este în avans cu \(90^\circ\) față de tensiune. Echivalent: tensiunea este în întârziere cu \(90^\circ\) față de curent.

6. Momente importante într-o perioadă

Pentru:

\[ u= U_m\sin(\omega t) \]
Fază \(\omega t\) Tensiune \(u\) Ritmul variației \(du/dt\) Curent \(i\)
\(0\) 0 maxim pozitiv \(+I_m\)
\(\pi/2\) \(+U_m\) 0 0
\(\pi\) 0 maxim negativ \(-I_m\)
\(3\pi/2\) \(-U_m\) 0 0
Curentul este maxim ca modul atunci când tensiunea trece prin zero și se modifică cel mai rapid. Când tensiunea este maximă sau minimă, \(du/dt=0\), deci curentul instantaneu este zero.

7. Reactanța capacitivă

Din:

\[ I_m= \omega C U_m \]

rezultă:

\[ U_m= \frac{1}{\omega C} I_m \]

Definim:

\[ \boxed{ X_C= \frac1{\omega C} } \]

Mărimea \(X_C\) se numește reactanță capacitivă.

Cum:

\[ \omega=2\pi f \]

putem scrie:

\[ \boxed{ X_C= \frac1{2\pi fC} } \]

Unitatea de măsură

\[ \boxed{ [X_C]=\Omega } \]
Reactanța capacitivă se măsoară în ohmi, dar nu reprezintă o rezistență ohmică. Condensatorul ideal nu transformă continuu energia electrică în energie internă, ci stochează temporar energie în câmpul electric și o restituie circuitului.

8. Cum depinde reactanța capacitivă de frecvență?

\[ X_C= \frac1{2\pi fC} \]

Pentru capacitate constantă:

\[ \boxed{ X_C\propto\frac1f } \]

Frecvență mai mare

\[ f\uparrow \]
\[ X_C\downarrow \]

Capacitate mai mare

\[ C\uparrow \]
\[ X_C\downarrow \]

Frecvență foarte mică

\[ f\to0 \]
\[ X_C\to\infty \]
La aceeași tensiune efectivă: \[ I= \frac{U}{X_C} \] deci: \[ \boxed{ f\uparrow \Rightarrow X_C\downarrow \Rightarrow I\uparrow } \]

9. Condensatorul și curentul continuu

Pentru o tensiune continuă stabilă:

\[ \frac{du}{dt}=0 \]

deci:

\[ i= C\frac{du}{dt}=0 \]

În limbajul reactanței:

\[ f\to0 \Rightarrow X_C\to\infty \]
Un condensator ideal complet încărcat blochează curentul continuu staționar. Totuși, în timpul încărcării sau descărcării există curent, deoarece tensiunea se modifică.
Afirmația „condensatorul nu lasă curentul continuu să treacă” se referă la regimul staționar ideal, nu la intervalul tranzitoriu de încărcare sau descărcare.

10. Relația dintre valorile efective

Pentru amplitudini:

\[ U_m= X_CI_m \]

Împărțind cu \(\sqrt2\):

\[ \frac{U_m}{\sqrt2} = X_C \frac{I_m}{\sqrt2} \]

obținem:

\[ \boxed{ U=X_CI } \]

sau:

\[ \boxed{ I= \frac{U}{X_C} } \]
Pentru condensatorul ideal trebuie reținute împreună: \[ \boxed{ U=X_CI } \] și: \[ \boxed{ \varphi_i-\varphi_u= 90^\circ } \]

11. Diagrama fazorială

Alegem tensiunea drept fazor de referință.

Curentul este rotit cu \(+90^\circ\) față de tensiune.

\[ \boxed{ \vec I \text{ este în avans cu } 90^\circ \text{ față de } \vec U_C } \]
Regulă de memorare: la condensator, curentul conduce tensiunea. Matematic: \[ \boxed{ \varphi_I= \varphi_{U_C} + \frac{\pi}{2} } \]

12. Bobină ideală versus condensator ideal

Proprietate Bobină ideală Condensator ideal
Reactanță \[ X_L=\omega L \] \[ X_C=\frac1{\omega C} \]
Frecvență mai mare \[ X_L\uparrow \] \[ X_C\downarrow \]
Fază tensiunea conduce curentul cu \(90^\circ\) curentul conduce tensiunea cu \(90^\circ\)
Energia este stocată în câmp magnetic câmp electric
Putere activă medie ideală 0 0
Bobina și condensatorul au comportări opuse față de frecvență. Această opoziție va fi esențială în circuitul RLC și în fenomenul de rezonanță.

13. Energia electrică stocată în condensator

Energia stocată în câmpul electric al condensatorului este:

\[ \boxed{ W_e= \frac12Cu^2 } \]

Tensiune nulă

\[ u=0 \]
\[ W_e=0 \]

Tensiune maximă

\[ |u|=U_m \]

energia este maximă.

Energie maximă

\[ \boxed{ W_{e,max} = \frac12CU_m^2 } \]
Deoarece energia depinde de \(u^2\), ea este pozitivă atât pentru tensiune pozitivă, cât și pentru tensiune negativă.

14. Puterea instantanee

Considerăm:

\[ u= U_m\sin(\omega t) \]

și:

\[ i= I_m\cos(\omega t) \]

Puterea instantanee este:

\[ p= ui \]
\[ p= U_mI_m \sin(\omega t) \cos(\omega t) \]

Folosind:

\[ 2\sin x\cos x= \sin2x \]

obținem:

\[ \boxed{ p(t)= \frac{U_mI_m}{2} \sin(2\omega t) } \]

iar pentru valorile efective:

\[ \boxed{ p(t)= UI\sin(2\omega t) } \]

15. Ce semnifică semnul puterii?

\(p>0\)

Condensatorul absoarbe energie din circuit.

Energia câmpului electric crește.

\(p<0\)

Condensatorul restituie energie circuitului.

Energia câmpului electric scade.

Pe o perioadă completă:

\[ \boxed{ P_{med}=0 } \]
Puterea instantanee nu este nulă permanent. Ea alternează între valori pozitive și negative, dar energia netă transferată condensatorului ideal pe o perioadă completă este zero.

16. Puterea activă medie

În regim sinusoidal:

\[ P= UI\cos\varphi \]

Dacă definim:

\[ \varphi= \varphi_u-\varphi_i \]

pentru condensator:

\[ \varphi= -90^\circ \]

și:

\[ \cos(-90^\circ)=0 \]

deci:

\[ \boxed{ P=0 } \]
Condensatorul ideal nu consumă putere activă în medie. Energia circulă alternativ între sursă și câmpul electric al condensatorului.

\[ U=12\,V \]

Vezi rezolvarea

Pe un condensator de:

\[ C=100\,\mu F \]

\[ u= 20\sin(100\pi t)\,V \]

Vezi rezolvarea
\[ U_m=20\,V \] \[ \omega= 100\pi\,rad/s \] \[ C= 10^{-4}\,F \] Amplitudinea curentului:

\[ I_m= \omega C U_m \] \[ I_m= 100\pi \cdot 10^{-4} \cdot 20 \] \[ I_m= 0,2\pi\,A \] \[ I_m\approx0,628\,A \] Curentul este în avans cu \(\pi/2\):

\[ \boxed{ i= 0,2\pi \cos(100\pi t)\,A } \]
Nivel 2

Exemplul 5 – Dublarea frecvenței

Un condensator ideal este alimentat la aceeași tensiune efectivă. Frecvența se dublează. Cum se modifică reactanța și curentul?

Vezi rezolvarea
\[ X_C= \frac1{2\pi fC} \] Dacă:

\[ f'=2f \] atunci:

\[ X'_C= \frac{X_C}{2} \] La tensiune constantă:

\[ I= \frac{U}{X_C} \] deci:

\[ I'= \frac{U}{X_C/2} = 2I \] Rezultă:

\[ \boxed{ X'_C= \frac{X_C}{2}, \qquad I'=2I } \]

Vezi rezolvarea

Un condensator ideal este alimentat la:

\[ U=20\,V \]

și este parcurs de:

\[ I=0,50\,A \]

Vezi rezolvarea

\[ \varphi= -90^\circ \] \[ P= UI\cos\varphi \] \[ P= 20\cdot0,50 \cdot \cos(-90^\circ) \] \[ \boxed{ P=0 } \] Produsul:

\[ UI=10\,VA \] nu reprezintă putere activă consumată de condensatorul ideal.
Nivel 3

Exemplul 9 – Identificarea elementului

Într-un element ideal, curentul este maxim pozitiv exact când tensiunea trece prin zero și crește. Ce element este compatibil cu această comportare?

Vezi rezolvarea
Dacă tensiunea trece prin zero crescând:

\[ \frac{du}{dt} \] este maxim pozitiv. Pentru condensator:

\[ i= C\frac{du}{dt} \] deci curentul este maxim pozitiv. Prin urmare:

\[ \boxed{ \text{elementul poate fi un condensator ideal} } \]

Scopul activității este observarea faptului că, la aceeași amplitudine a tensiunii, curentul prin condensator crește când frecvența crește.

Materiale

  • generator sinusoidal de joasă tensiune;
  • condensator nepolarizat adecvat;
  • rezistor de protecție în serie;
  • multimetru sau sistem de achiziție;
  • opțional: osciloscop.

Predicție

\[ X_C= \frac1{2\pi fC} \]

Deci:

\[ f\uparrow \Rightarrow X_C\downarrow \Rightarrow I\uparrow \]
  1. Alege un condensator adecvat pentru semnal alternativ și tensiunea utilizată.
  2. Conectează în serie generatorul, rezistorul de protecție și condensatorul.
  3. Setează o tensiune sinusoidală mică.
  4. Măsoară curentul la o frecvență joasă.
  5. Mărește frecvența, păstrând pe cât posibil aceeași tensiune a sursei.
  6. Măsoară din nou curentul.
  7. Compară rezultatele cu predicția \(X_C\propto1/f\).

19. Condensator ideal și condensator real

Condensator ideal

  • fără pierderi;
  • reactanță \(X_C=1/(\omega C)\);
  • decalaj exact de \(90^\circ\);
  • putere activă medie zero;
  • energie stocată și restituită integral.

Condensator real

  • poate avea pierderi în dielectric;
  • poate avea rezistență serie echivalentă;
  • poate avea inductanțe parazite;
  • decalajul nu este perfect \(90^\circ\);
  • comportarea se modifică la frecvențe foarte mari.
Modelul ideal este baza pentru înțelegerea circuitelor de curent alternativ. În circuitele reale, parametrii paraziți devin importanți în funcție de frecvență și construcția componentei.

⚠️ Greșeli frecvente

1. „Tensiunea este în avans față de curent.”

Nu pentru condensatorul ideal.

\[ \boxed{ I \text{ este în avans cu } 90^\circ \text{ față de } U_C } \]

2. „\(X_C=\omega C\)”

Nu.

\[ \boxed{ X_C= \frac1{\omega C} } \]

3. „Reactanța capacitivă crește cu frecvența.”

Este invers:

\[ f\uparrow \Rightarrow X_C\downarrow \]

4. „La tensiune maximă și curentul este maxim.”

Nu. Când tensiunea are un extrem:

\[ \frac{du}{dt}=0 \]

deci:

\[ i=0 \]

5. „Condensatorul lasă curent continuu staționar să treacă.”

Pentru condensatorul ideal complet încărcat:

\[ i=0 \]

6. „Nu există deloc curent la alimentare continuă.”

Poate exista curent tranzitoriu în timpul încărcării sau descărcării.

7. „Condensatorul ideal consumă \(UI\) wați.”

Nu. Pentru condensatorul ideal:

\[ P= UI\cos(-90^\circ) = 0 \]

8. „Puterea instantanee este mereu zero.”

Nu.

\[ p(t)=UI\sin(2\omega t) \]

Ea alternează între valori pozitive și negative.

9. „Energia condensatorului poate fi negativă.”

Nu.

\[ W_e= \frac12Cu^2 \ge0 \]

10. „Orice condensator poate fi conectat la orice tensiune alternativă.”

Nu. Tipul condensatorului, polarizarea, tensiunea nominală și regimul de funcționare trebuie respectate.

Într-un circuit serie, curentul este același prin toate cele trei elemente, dar tensiunile nu sunt în fază între ele.

Nu vom putea aduna pur și simplu modulele: \[ U_R+U_L+U_C \] ca pe niște numere pozitive obișnuite. Va trebui să folosim diagrama fazorială.
În lecția următoare: Circuit RLC serie. Impedanța. Diagrama fazorială vom combina rezistorul, bobina și condensatorul și vom obține: \[ \boxed{ Z= \sqrt{ R^2+ (X_L-X_C)^2 } } \]
