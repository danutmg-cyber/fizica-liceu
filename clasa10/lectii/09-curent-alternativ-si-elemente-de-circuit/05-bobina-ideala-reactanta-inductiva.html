Lecția 5 Clasa a X-a Bobină ideală

Bobina ideală. Reactanța inductivă

O bobină ideală se opune variației curentului prin fenomenul de autoinducție. În curent alternativ această proprietate produce o opoziție dependentă de frecvență, numită reactanță inductivă. Tensiunea și curentul nu mai sunt în fază: tensiunea este în avans cu \(90^\circ\) față de curent.

🎯 Ce vei învăța

La final vei putea:

  • să descrii modelul bobinei ideale;
  • să explici rolul autoinducției;
  • să diferențiezi t.e.m. de autoinducție de tensiunea la borne;
  • să folosești relația \(u_L=L\,di/dt\);
  • să demonstrezi decalajul de fază de \(90^\circ\);
  • să definești reactanța inductivă;
  • să utilizezi \(X_L=\omega L=2\pi fL\);
  • să utilizezi \(U=X_LI\);
  • să interpretezi dependența curentului de frecvență;
  • să descrii schimbul periodic de energie dintre sursă și câmpul magnetic;
  • să explici de ce puterea activă medie este zero pentru bobina ideală.

Relațiile centrale

\[ \boxed{ u_L= L\frac{di}{dt} } \]
\[ \boxed{ X_L= \omega L= 2\pi fL } \]
\[ \boxed{ U=X_LI } \]
\[ \boxed{ \varphi_u-\varphi_i= +\frac{\pi}{2} } \]

1. De la rezistor la bobină

Pentru rezistorul ideal am obținut:

\[ u=Ri \]

și:

\[ \Delta\varphi=0 \]

Tensiunea și curentul erau în fază, iar rezistența ideală nu depindea de frecvență.

La bobină situația se schimbă fundamental.

Bobina nu se opune în primul rând valorii curentului, ci variației curentului. Cu cât curentul încearcă să varieze mai repede, cu atât efectul de autoinducție este mai puternic.

2. Modelul bobinei ideale

O bobină ideală este caracterizată prin inductanța:

\[ L \]

și are, în modelul ideal:

  • rezistența electrică a conductorului neglijabilă;
  • pierderi Joule nule;
  • pierderi magnetice neglijabile;
  • comportare descrisă numai prin inductanță.

Unitatea inductanței

\[ \boxed{ [L]=H } \]

Unitatea se numește henry.

O bobină reală are și rezistență electrică, iar dacă are miez magnetic pot exista pierderi suplimentare. În această lecție analizăm mai întâi bobina ideală.

3. Autoinducția

Curentul care străbate o bobină produce un câmp magnetic. Dacă intensitatea curentului se modifică, se modifică și fluxul magnetic asociat bobinei.

Prin inducție electromagnetică apare o tensiune electromotoare de autoinducție.

\[ \boxed{ \mathcal E_L= -L \frac{di}{dt} } \]
Semnul minus exprimă legea lui Lenz: efectul autoinducției se opune variației curentului care l-a produs.
Curent variabil
\[ \frac{di}{dt}\neq0 \]
→
Flux magnetic variabil
\[ \Phi(t) \]
→
Autoinducție
\[ \mathcal E_L \]

4. T.e.m. de autoinducție și tensiunea la borne

Această distincție este importantă.

Tensiunea electromotoare de autoinducție este:

\[ \mathcal E_L= -L\frac{di}{dt} \]

În convenția pasivă, tensiunea aplicată la bornele bobinei ideale este:

\[ \boxed{ u_L= L\frac{di}{dt} } \]
Cele două expresii au semne opuse deoarece descriu roluri diferite:
  • \(\mathcal E_L\) exprimă efectul de autoinducție care se opune variației curentului;
  • \(u_L\) este tensiunea aplicată la borne în convenția pasivă.

5. Curent sinusoidal prin bobină

Alegem curentul drept mărime de referință:

\[ i= I_m\sin(\omega t) \]

Tensiunea la borne este:

\[ u_L= L\frac{di}{dt} \]

Derivăm:

\[ \frac{di}{dt} = \omega I_m \cos(\omega t) \]

deci:

\[ u_L= \omega LI_m \cos(\omega t) \]

Dar:

\[ \cos x= \sin \left( x+\frac{\pi}{2} \right) \]

Prin urmare:

\[ \boxed{ u_L= \omega LI_m \sin \left( \omega t+ \frac{\pi}{2} \right) } \]

6. Relația de fază

Comparăm:

Curent

\[ i= I_m \sin(\omega t) \]

Tensiune

\[ u_L= U_m \sin \left( \omega t+ \frac{\pi}{2} \right) \]

Diferența de fază este:

\[ \boxed{ \varphi_u-\varphi_i= +\frac{\pi}{2} = +90^\circ } \]
Pentru bobina ideală: tensiunea este în avans cu \(90^\circ\) față de curent. Echivalent: curentul este în întârziere cu \(90^\circ\) față de tensiune.

7. Momente importante într-o perioadă

Pentru:

\[ i= I_m\sin(\omega t) \]
Fază \(\omega t\) Curent \(i\) Ritmul variației \(di/dt\) Tensiune \(u_L\)
\(0\) 0 maxim pozitiv \(+U_m\)
\(\pi/2\) \(+I_m\) 0 0
\(\pi\) 0 maxim negativ \(-U_m\)
\(3\pi/2\) \(-I_m\) 0 0
Tensiunea bobinei este maximă atunci când curentul se modifică cel mai rapid. Când curentul este maxim sau minim, variația sa instantanee este zero, deci tensiunea bobinei este zero.

8. Reactanța inductivă

Din expresia tensiunii rezultă pentru amplitudini:

\[ U_m= \omega LI_m \]

Definim:

\[ \boxed{ X_L= \omega L } \]

unde \(X_L\) se numește reactanță inductivă.

Cum:

\[ \omega= 2\pi f \]

rezultă și:

\[ \boxed{ X_L= 2\pi fL } \]

Unitatea de măsură

\[ \boxed{ [X_L]=\Omega } \]
Reactanța inductivă se măsoară în ohmi, dar nu este o rezistență ohmică. Un rezistor ideal disipă energie. O bobină ideală stochează temporar energie în câmpul magnetic și o restituie sursei.

9. Cum depinde reactanța de frecvență?

\[ X_L= 2\pi fL \]

Pentru inductanță constantă:

\[ \boxed{ X_L\propto f } \]

Frecvență mai mare

\[ f\uparrow \]
\[ X_L\uparrow \]

Inductanță mai mare

\[ L\uparrow \]
\[ X_L\uparrow \]

Frecvență foarte mică

\[ f\to0 \]
\[ X_L\to0 \]

pentru bobina ideală.

10. Ce se întâmplă la curent continuu?

Pentru curent continuu stabil:

\[ f=0 \]

deci:

\[ X_L= 2\pi fL=0 \]
Aceasta nu înseamnă că o bobină reală conectată la o sursă continuă are rezistență zero. Conductorul bobinei reale are o rezistență ohmică proprie. Afirmația \(X_L=0\) se referă numai la reactanța inductivă și la regimul staționar.
Conectarea directă a unei bobine reale la o sursă de tensiune continuă trebuie făcută numai în montaje didactice dimensionate corespunzător, deoarece curentul poate deveni mare dacă rezistența ohmică este mică.

11. Relația dintre valorile efective

Pentru amplitudini:

\[ U_m= X_LI_m \]

Împărțim cu \(\sqrt2\):

\[ \frac{U_m}{\sqrt2} = X_L \frac{I_m}{\sqrt2} \]

și obținem:

\[ \boxed{ U= X_LI } \]

sau:

\[ \boxed{ I= \frac{U}{X_L} } \]
Relația seamănă formal cu legea lui Ohm, dar trebuie reținut simultan și decalajul de fază: \[ \boxed{ U=X_LI \qquad \text{și} \qquad \varphi_u-\varphi_i= 90^\circ } \]

12. Diagrama fazorială

Alegem curentul drept fazor de referință.

Pentru bobina ideală, tensiunea este rotită cu \(+90^\circ\) față de curent.

\[ \boxed{ \vec U_L \text{ este în avans cu } 90^\circ \text{ față de } \vec I } \]
Regulă de memorare: L → tensiunea conduce curentul. Mai riguros: \[ \boxed{ \varphi_{U_L} = \varphi_I+ \frac{\pi}{2} } \]

14. Energia magnetică a bobinei

O bobină parcursă de curent stochează energie în câmpul magnetic.

Pentru bobina ideală:

\[ \boxed{ W_m= \frac12Li^2 } \]

Curent nul

\[ i=0 \]
\[ W_m=0 \]

Curent maxim

\[ |i|=I_m \]
\[ W_m=W_{m,max} \]

Energie maximă

\[ \boxed{ W_{m,max} = \frac12LI_m^2 } \]
Energia depinde de \(i^2\). De aceea energia câmpului magnetic este pozitivă atât pentru curent pozitiv, cât și pentru curent negativ.

15. Puterea instantanee

Considerăm:

\[ i= I_m\sin(\omega t) \]

și:

\[ u_L= U_m\cos(\omega t) \]

Puterea instantanee este:

\[ p= u_Li \]
\[ p= U_mI_m \sin(\omega t) \cos(\omega t) \]

Folosim:

\[ 2\sin x\cos x= \sin2x \]

și obținem:

\[ \boxed{ p(t)= \frac{U_mI_m}{2} \sin(2\omega t) } \]

Cum:

\[ UI= \frac{U_mI_m}{2} \]

putem scrie:

\[ \boxed{ p(t)= UI\sin(2\omega t) } \]

16. De ce puterea devine pozitivă și negativă?

\(p>0\)

Bobina absoarbe energie de la sursă.

Energia câmpului magnetic crește.

\(p<0\)

Bobina restituie energie circuitului.

Energia câmpului magnetic scade.

Pe o perioadă completă, energia absorbită și energia restituită sunt egale.

\[ \boxed{ P_{med}=0 } \]
Pentru bobina ideală, puterea activă medie este zero. Aceasta nu înseamnă că puterea instantanee este mereu zero. Există permanent un schimb periodic de energie între sursă și câmpul magnetic.

17. Legătura cu formula generală a puterii active

Pentru regim sinusoidal:

\[ P= UI\cos\varphi \]

Pentru bobina ideală:

\[ \varphi= \frac{\pi}{2} \]

și:

\[ \cos\frac{\pi}{2}=0 \]

deci:

\[ \boxed{ P=0 } \]
Rezultatul confirmă analiza energetică: bobina ideală nu consumă energie activă în medie; ea stochează temporar energie și o restituie.

Exemplul 5 – Dublarea frecvenței

O bobină ideală este alimentată la aceeași tensiune efectivă. Frecvența se dublează. Cum se modifică reactanța și curentul?

\[ X_L= 2\pi fL \] Dacă:

\[ f'=2f \] atunci:

\[ X'_L=2X_L \] Curentul:

\[ I= \frac{U}{X_L} \] deci la aceeași tensiune:

\[ \boxed{ X'_L=2X_L, \qquad I'=\frac I2 } \]

O bobină ideală este alimentată cu:

\[ U=40\,V \]

\[ I=2\,A \]

Vezi rezolvarea

\[ \varphi= 90^\circ \] \[ P= UI\cos\varphi \] \[ P= 40\cdot2\cdot \cos90^\circ \] \[ \boxed{ P=0 } \] Atenție: \[ UI=80\,VA \] nu reprezintă aici puterea activă consumată.
Nivel 3

Exemplul 9 – Identificarea elementului din fază

Într-un element ideal de circuit, tensiunea atinge maximul pozitiv exact când curentul trece prin zero și crește. Ce element poate fi?

Vezi rezolvarea
Dacă curentul trece prin zero crescând:

\[ \frac{di}{dt} \] este maxim pozitiv. Pentru bobină:

\[ u_L= L\frac{di}{dt} \] deci tensiunea este maxim pozitivă. Prin urmare:

\[ \boxed{ \text{elementul poate fi o bobină ideală} } \]

🔬 18. Activitate experimentală – efectul frecvenței

Scopul este observarea calitativă a faptului că o bobină se opune mai puternic curentului alternativ atunci când frecvența crește.

Materiale

  • generator sinusoidal de joasă tensiune;
  • bobină didactică;
  • rezistor de protecție în serie;
  • multimetru sau sistem de achiziție adecvat;
  • opțional: osciloscop.

Predicție

Dacă \(L\) este aproximativ constantă:

\[ X_L= 2\pi fL \]

deci frecvența mai mare conduce la o opoziție inductivă mai mare.

  1. Realizează un circuit serie cu generatorul, bobina și un rezistor de protecție.
  2. Folosește o tensiune alternativă mică și păstrează amplitudinea generatorului constantă.
  3. Măsoară sau estimează curentul la o frecvență joasă.
  4. Mărește frecvența fără a modifica intenționat amplitudinea tensiunii sursei.
  5. Compară curenții măsurați.
  6. Repetă pentru mai multe frecvențe.
  7. Discutați de ce bobina reală nu respectă perfect modelul \(I=U/X_L\).

20. Bobina ideală și bobina reală

Bobină ideală

  • rezistență ohmică nulă;
  • reactanță \(X_L=\omega L\);
  • decalaj exact de \(90^\circ\);
  • putere activă medie zero;
  • fără pierderi energetice.

Bobină reală

  • conductorul are rezistență;
  • există efect Joule;
  • decalajul este mai mic de \(90^\circ\);
  • poate absorbi putere activă;
  • miezul poate introduce pierderi suplimentare.
Modelul ideal este foarte util deoarece izolează efectul inductiv. Ulterior, în circuite mai complexe, vom combina efectele rezistive, inductive și capacitive.

⚠️ Greșeli frecvente

1. „Curentul este în avans față de tensiune.”

Nu pentru bobina ideală.

\[ \boxed{ U_L \text{ este în avans cu } 90^\circ \text{ față de } I } \]

2. „\(X_L=L/f\)”

Nu.

\[ \boxed{ X_L= 2\pi fL } \]

3. „Reactanța se măsoară în henry.”

Nu.

\[ [X_L]=\Omega \]

Inductanța se măsoară în henry.

4. „Bobina ideală consumă \(UI\) wați.”

Nu. Pentru bobina ideală:

\[ P= UI\cos90^\circ = 0 \]

5. „Puterea este zero în fiecare moment.”

Nu. Puterea instantanee alternează:

\[ p(t)= UI\sin(2\omega t) \]

Doar media pe o perioadă este zero.

6. „Bobina distruge energia absorbită.”

În modelul ideal, energia este stocată temporar în câmpul magnetic și apoi restituită.

7. „La curent maxim și tensiunea este maximă.”

Nu. Pentru bobina ideală, când \(i\) este extrem, \(di/dt=0\), deci:

\[ u_L=0 \]

8. „Frecvența mai mare înseamnă curent mai mare.”

La aceeași tensiune și aceeași inductanță:

\[ f\uparrow \Rightarrow X_L\uparrow \Rightarrow I\downarrow \]

9. „\(\mathcal E_L\) și \(u_L\) trebuie să aibă obligatoriu aceeași formulă cu același semn.”

Nu. T.e.m. de autoinducție exprimă opoziția conform legii lui Lenz:

\[ \mathcal E_L= -L\frac{di}{dt} \]

iar în convenția pasivă:

\[ u_L= L\frac{di}{dt} \]

10. „Bobina reală este identică cu bobina ideală.”

Nu. Bobina reală are rezistență și pierderi, deci faza și puterea diferă de modelul ideal.

\[ \boxed{ f\uparrow \Rightarrow X_L\uparrow \Rightarrow I\downarrow } \]
Schema mentală: curent variabil → autoinducție → tensiune în avans cu \(90^\circ\) → reactanță \(X_L=\omega L\) → energie stocată în câmpul magnetic → energie restituită sursei → putere activă medie nulă pentru bobina ideală.

🧭 Ce urmează?

Pentru bobina ideală am găsit:

\[ \boxed{ X_L= \omega L } \]

și:

\[ \boxed{ U_L \text{ este în avans cu } 90^\circ \text{ față de } I } \]

Următorul element reactiv, condensatorul, va avea o comportare complementară.

Pentru condensator vom obține o reactanță care scade când frecvența crește: \[ X_C= \frac1{\omega C} \] și vom constata că intensitatea curentului este în avans cu \(90^\circ\) față de tensiune.
În lecția următoare: Condensatorul. Reactanța capacitivă vom compara direct comportarea capacitivă cu cea inductivă și vom pregăti circuitul RLC serie.
