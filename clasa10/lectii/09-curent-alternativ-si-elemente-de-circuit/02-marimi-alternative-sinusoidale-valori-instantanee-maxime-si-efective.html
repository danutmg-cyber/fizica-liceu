Lecția 2 Clasa a X-a Mărimi sinusoidale

Mărimi alternative sinusoidale. Valori instantanee, maxime și efective

Tensiunea produsă de alternatorul idealizat nu are aceeași valoare în fiecare moment. Ea variază periodic, trece prin zero și își schimbă semnul. Pentru a descrie riguros o asemenea mărime vom diferenția valoarea instantanee, amplitudinea și valoarea efectivă.

🎯 Ce vei învăța

La final vei putea:

  • să recunoști o mărime alternativă sinusoidală;
  • să interpretezi semnul valorii instantanee;
  • să diferențiezi valoarea instantanee de valoarea maximă;
  • să identifici amplitudinea unei sinusoide;
  • să folosești relația \(u=U_m\sin(\omega t+\varphi_0)\);
  • să interpretezi noțiunea de fază instantanee;
  • să diferențiezi valoarea medie de valoarea efectivă;
  • să utilizezi \(U=U_m/\sqrt2\) pentru o tensiune sinusoidală;
  • să utilizezi \(I=I_m/\sqrt2\) pentru un curent sinusoidal;
  • să explici semnificația energetică a valorii efective.

Relațiile centrale

\[ \boxed{ u(t)= U_m \sin(\omega t+\varphi_0) } \]
\[ \boxed{ i(t)= I_m \sin(\omega t+\varphi_0) } \]
\[ \boxed{ U= \frac{U_m}{\sqrt2} } \]
\[ \boxed{ I= \frac{I_m}{\sqrt2} } \]

1. Legătura cu alternatorul

În lecția precedentă am obținut, pentru un alternator idealizat:

\[ \mathcal E(t) = \mathcal E_m \sin(\omega t) \]

Această expresie arată că tensiunea electromotoare nu este constantă.

Ea parcurge periodic valori:

\[ 0 \rightarrow +\mathcal E_m \rightarrow 0 \rightarrow -\mathcal E_m \rightarrow 0 \]
O mărime care își modifică periodic atât valoarea, cât și semnul poate fi o mărime alternativă. Dacă variația sa este descrisă printr-o funcție sinus sau cosinus, mărimea este alternativă sinusoidală.

2. Ce înseamnă „alternativ”?

Considerăm tensiunea:

\[ u(t)=U_m\sin(\omega t) \]

Pe durata unei perioade, tensiunea are atât valori pozitive, cât și valori negative.

Semialternanță pozitivă

\[ u>0 \]

Polaritatea este cea corespunzătoare sensului de referință ales.

Trecere prin zero

\[ u=0 \]

Valoarea instantanee este nulă numai în acel moment.

Semialternanță negativă

\[ u<0 \]

Polaritatea este inversă față de sensul de referință ales.

Semnul minus al valorii instantanee nu înseamnă că „tensiunea a dispărut”. El indică inversarea polarității față de convenția aleasă.

3. Ecuația unei mărimi alternative sinusoidale

O tensiune sinusoidală se poate scrie:

\[ \boxed{ u(t) = U_m \sin(\omega t+\varphi_0) } \]
Simbol Semnificație Unitate
\(u(t)\) valoarea instantanee a tensiunii V
\(U_m\) valoarea maximă sau amplitudinea V
\(\omega\) pulsația rad/s
\(t\) timpul s
\(\omega t+\varphi_0\) faza instantanee rad
\(\varphi_0\) faza inițială rad
În această lecție folosim faza doar pentru a citi o sinusoidă. Perioada, frecvența, pulsația și reprezentările fazoriale vor fi aprofundate în lecția următoare.

4. Curent sinusoidal

În mod analog, un curent alternativ sinusoidal poate fi exprimat:

\[ \boxed{ i(t)= I_m \sin(\omega t+\varphi_0) } \]

unde:

  • \(i(t)\) este intensitatea instantanee;
  • \(I_m\) este intensitatea maximă;
  • semnul lui \(i\) indică sensul instantaneu față de sensul de referință ales.
În curent alternativ trebuie să distingem atent: \[ \boxed{ i \neq I_m \neq I } \] unde:
  • \(i\) – valoare instantanee;
  • \(I_m\) – valoare maximă;
  • \(I\) – valoare efectivă.

5. Valoarea instantanee

Valoarea instantanee este valoarea mărimii la un anumit moment.

Dacă:

\[ u(t)= 20\sin(100\pi t) \]

atunci la:

\[ t=0 \]

avem:

\[ u(0)=0 \]

iar la un moment pentru care:

\[ 100\pi t= \frac{\pi}{2} \]

rezultă:

\[ u= 20\,V \]
Valoarea instantanee se poate modifica continuu. Prin urmare, un singur număr precum „20 V” nu descrie complet o tensiune sinusoidală decât dacă precizăm ce fel de valoare reprezintă.

6. Valoarea maximă – amplitudinea

Deoarece:

\[ -1\le \sin(\omega t+\varphi_0) \le1 \]

pentru:

\[ u= U_m \sin(\omega t+\varphi_0) \]

rezultă:

\[ \boxed{ -U_m \le u \le U_m } \]

\(U_m\) reprezintă amplitudinea sau modulul valorii maxime.

Maxim pozitiv

\[ u_{max}=+U_m \]

Minim

\[ u_{min}=-U_m \]

Modulul este tot \(U_m\).

7. Valoarea vârf-la-vârf

Pe un osciloscop poate fi utilă distanța dintre vârful pozitiv și vârful negativ.

\[ U_{pp} = U_m- (-U_m) \]
\[ \boxed{ U_{pp}=2U_m } \]

Exemplu

Dacă:

\[ U_{pp}=12\,V \]

atunci:

\[ U_m= \frac{U_{pp}}2 \]
\[ \boxed{ U_m=6\,V } \]

8. Valoarea medie pe o perioadă

Pentru o sinusoidă simetrică față de axa timpului, contribuția pozitivă dintr-o semiperioadă este compensată de contribuția negativă din cealaltă semiperioadă.

\[ \boxed{ u_{med}=0 } \]

pe o perioadă completă.

Valoarea medie nulă nu înseamnă că tensiunea sinusoidală nu poate transfera energie. Un rezistor conectat la o sursă alternativă sinusoidală se poate încălzi, deși media algebrică a tensiunii pe o perioadă este zero.

Această observație conduce la necesitatea unei alte mărimi: valoarea efectivă.

9. De ce avem nevoie de valoarea efectivă?

Considerăm un rezistor \(R\).

În curent continuu, energia transformată prin efect Joule într-un timp \(t\) este:

\[ Q_{cc} = I_{cc}^{\,2}Rt \]

Un curent alternativ își schimbă semnul, dar:

\[ i^2\ge0 \]

în fiecare moment.

Prin urmare, efectul termic nu se anulează atunci când curentul își schimbă sensul.

Valoarea efectivă a unui curent alternativ este valoarea curentului continuu care, trecând prin același rezistor în același interval de timp, produce același efect Joule.

10. Valoarea efectivă a unui curent sinusoidal

Pentru:

\[ i(t)=I_m\sin(\omega t) \]

puterea Joule instantanee într-un rezistor este:

\[ p(t)=i^2R \]

deci:

\[ p(t) = I_m^2R \sin^2(\omega t) \]

Pe o perioadă, valoarea medie a lui \(\sin^2\) este:

\[ \left\langle \sin^2 \right\rangle = \frac12 \]

Prin urmare:

\[ P_{med} = \frac{ I_m^2R }{ 2 } \]

Definim valoarea efectivă \(I\) astfel încât:

\[ P_{med}=I^2R \]

Comparând:

\[ I^2R= \frac{ I_m^2R }{ 2 } \]
\[ \boxed{ I= \frac{I_m}{\sqrt2} } \]

11. Valoarea efectivă a tensiunii sinusoidale

Pentru o tensiune sinusoidală:

\[ u= U_m \sin(\omega t+\varphi_0) \]

valoarea efectivă este:

\[ \boxed{ U= \frac{U_m}{\sqrt2} } \]

de unde:

\[ \boxed{ U_m= \sqrt2\,U } \]

Din maxim în efectiv

\[ U\approx0,707U_m \]

Din efectiv în maxim

\[ U_m\approx1,414U \]
Relațiile: \[ U= \frac{U_m}{\sqrt2}, \qquad I= \frac{I_m}{\sqrt2} \] sunt valabile pentru mărimi sinusoidale. Pentru alte forme de undă, valoarea efectivă trebuie determinată prin definiția RMS corespunzătoare.

12. Semnificația RMS

Denumirea internațională folosită frecvent este RMS:

\[ \text{Root Mean Square} \]

adică:

Square
\[ x^2 \]

ridicare la pătrat

→
Mean

media pe o perioadă

→
Root
\[ \sqrt{\phantom{x}} \]

rădăcina pătrată

Pentru o mărime periodică \(x(t)\), definiția generală este:

\[ \boxed{ X_{ef} = \sqrt{ \frac1T \int_0^T x^2(t)\,dt } } \]
Pentru o sinusoidă, această definiție conduce exact la: \[ X_{ef} = \frac{X_m}{\sqrt2} \]

13. O convenție de notație importantă

În studiul curentului alternativ, se folosesc frecvent:

Mărime Tensiune Curent
instantanee \(u\) \(i\)
maximă / amplitudine \(U_m\) \(I_m\)
efectivă \(U\) \(I\)
În probleme, verifică întotdeauna dacă valoarea numerică dată reprezintă: valoare instantanee, amplitudine sau valoare efectivă.

14. Exemplu: din valoare efectivă în amplitudine

O tensiune sinusoidală are valoarea efectivă:

\[ U=230\,V \]

Amplitudinea este:

\[ U_m= \sqrt2\,U \]
\[ U_m= 230\sqrt2 \]
\[ \boxed{ U_m\approx325\,V } \]
Acesta este un exemplu numeric pentru relația dintre valoarea efectivă și amplitudine. Nu se realizează experimente didactice direct la tensiuni de rețea. Pentru activități practice se folosesc exclusiv surse didactice de joasă tensiune.

🧮 Exemple rezolvate

Nivel 1

Exemplul 1 – Valoare instantanee

Se dă:

\[ u= 12\sin(\omega t) \]

Determinați \(u\) pentru:

\[ \omega t= \frac{\pi}{6} \]
Vezi rezolvarea
\[ u= 12 \sin \frac{\pi}{6} \] \[ u= 12\cdot\frac12 \] \[ \boxed{ u=6\,V } \]
Nivel 1

Exemplul 2 – Valoarea maximă

Pentru:

\[ i= 4\sin(100\pi t)\,A \]

determinați \(I_m\).

Vezi rezolvarea
Comparăm cu forma: \[ i= I_m\sin(\omega t) \] Prin urmare: \[ \boxed{ I_m=4\,A } \]
Nivel 1

Exemplul 3 – Valoarea efectivă

O tensiune sinusoidală are:

\[ U_m=24\,V \]

Determinați valoarea efectivă.

Vezi rezolvarea
\[ U= \frac{U_m}{\sqrt2} \] \[ U= \frac{24}{\sqrt2} \] \[ \boxed{ U\approx16,97\,V } \]
Nivel 1

Exemplul 4 – Din efectiv în maxim

Un curent sinusoidal are:

\[ I=2\,A \]

Determinați \(I_m\).

Vezi rezolvarea
\[ I_m= \sqrt2 I \] \[ I_m= 2\sqrt2 \] \[ \boxed{ I_m\approx2,83\,A } \]
Nivel 2

Exemplul 5 – Vârf-la-vârf

Pe un osciloscop se observă:

\[ U_{pp}=40\,V \]

Determinați amplitudinea și valoarea efectivă, presupunând o sinusoidă.

Vezi rezolvarea
\[ U_m= \frac{U_{pp}}2 = 20\,V \] Apoi: \[ U= \frac{20}{\sqrt2} \] \[ \boxed{ U\approx14,14\,V } \]
Nivel 2

Exemplul 6 – Valoare instantanee negativă

Pentru:

\[ u= 10\sin(\omega t) \]

se consideră:

\[ \omega t= \frac{7\pi}{6} \]
Vezi rezolvarea
\[ \sin \frac{7\pi}{6} = -\frac12 \] Deci: \[ u= 10 \left( -\frac12 \right) \] \[ \boxed{ u=-5\,V } \] Semnul negativ indică polaritatea opusă față de sensul de referință ales.
Nivel 2

Exemplul 7 – Efect Joule echivalent

Un curent sinusoidal are:

\[ I_m= 6\,A \]

Ce curent continuu ar produce același efect Joule în același rezistor?

Vezi rezolvarea
Curentul continuu echivalent termic are valoarea: \[ I= \frac{I_m}{\sqrt2} \] \[ I= \frac6{\sqrt2} \] \[ \boxed{ I\approx4,24\,A } \]
Nivel 3

Exemplul 8 – Puterea medie într-un rezistor

O tensiune sinusoidală cu:

\[ U_m=20\,V \]

este aplicată unui rezistor:

\[ R=10\,\Omega \]

Determinați puterea medie disipată.

Vezi rezolvarea
Mai întâi valoarea efectivă: \[ U= \frac{20}{\sqrt2} \] Apoi: \[ P_{med} = \frac{U^2}{R} \] Cum: \[ U^2= \frac{U_m^2}{2} \] rezultă: \[ P_{med} = \frac{ 20^2 }{ 2\cdot10 } \] \[ \boxed{ P_{med}=20\,W } \]

🔬 15. Activitate experimentală – amplitudine și valoare efectivă

Materiale posibile

  • generator de semnal didactic de joasă tensiune;
  • osciloscop;
  • multimetru adecvat măsurărilor de tensiune alternativă;
  • conductoare de legătură.

Scop

Compararea pentru o tensiune sinusoidală a:

  • amplitudinii \(U_m\), observată pe osciloscop;
  • valorii efective \(U\), măsurată cu aparatul corespunzător.
  1. Setează generatorul la o tensiune sinusoidală de joasă tensiune.
  2. Vizualizează semnalul pe osciloscop.
  3. Determină valoarea vârf-la-vârf \(U_{pp}\).
  4. Calculează: \[ U_m=\frac{U_{pp}}2 \]
  5. Determină valoarea efectivă: \[ U_{calc}=\frac{U_m}{\sqrt2} \]
  6. Compară această valoare cu indicația aparatului de măsură pentru tensiune alternativă.
  7. Discutați diferențele și incertitudinile experimentale.
Pentru o sinusoidă ideală ne așteptăm aproximativ la: \[ \frac{U_m}{U} = \sqrt2 \approx1,414 \]
Activitatea se realizează numai cu semnale didactice de joasă tensiune. Nu conectați osciloscopul sau montaje improvizate direct la rețeaua electrică.

17. Medie zero, efect Joule nenul

Această diferență merită reținută foarte clar.

Media algebrică a tensiunii

Pe o perioadă completă:

\[ \boxed{ u_{med}=0 } \]

Zona pozitivă și zona negativă se compensează.

Media lui \(u^2\)

În schimb:

\[ u^2\ge0 \]

și pentru sinusoidă:

\[ \boxed{ \left\langle u^2\right\rangle = \frac{U_m^2}{2} } \]
De aceea: \[ \boxed{ U_{ef} = \sqrt{ \left\langle u^2\right\rangle } = \frac{U_m}{\sqrt2} } \] și nu: \[ U_{ef}=u_{med} \]

⚠️ Greșeli frecvente

1. „\(u\), \(U_m\) și \(U\) sunt același lucru.”

Nu.

  • \(u\) – instantaneu;
  • \(U_m\) – maxim;
  • \(U\) – efectiv.

2. „Valoarea efectivă este media tensiunii.”

Nu. Pentru sinusoidă, media algebrică pe o perioadă este zero, dar valoarea efectivă este:

\[ U= \frac{U_m}{\sqrt2} \]

3. „O tensiune negativă are amplitudine negativă.”

Nu. Amplitudinea \(U_m\) este pozitivă. Valoarea instantanee \(u\) poate fi negativă.

4. „\(U_{pp}=U_m\).”

Nu:

\[ U_{pp}=2U_m \]

5. „Dacă media tensiunii este zero, nu există încălzire.”

Fals. Puterea Joule depinde de pătratul tensiunii sau al curentului.

6. „Relația \(U=U_m/\sqrt2\) este valabilă pentru orice semnal.”

Nu. Este relația specifică sinusoidei.

7. „Dublarea frecvenței dublează automat \(U_m\).”

Nu pentru o sinusoidă a cărei amplitudine este deja impusă independent. Frecvența și amplitudinea sunt parametri diferiți.

8. „Semnul lui \(u\) arată sensul în care curge energia.”

Nu în general. Semnul arată polaritatea instantanee față de convenția de referință. Analiza energiei necesită și curentul.
