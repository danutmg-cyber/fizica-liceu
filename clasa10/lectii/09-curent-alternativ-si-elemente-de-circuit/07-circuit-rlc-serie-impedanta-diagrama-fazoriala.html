Lecția 7 Clasa a X-a Circuit RLC serie

Circuit RLC serie. Impedanța. Diagrama fazorială

În circuitul RLC serie, același curent străbate rezistorul, bobina și condensatorul, dar tensiunile pe cele trei elemente nu sunt în fază. Pentru a determina tensiunea totală nu le putem aduna aritmetic: trebuie să folosim diagrama fazorială.

🎯 Ce vei învăța

La final vei putea:

  • să descrii un circuit RLC serie;
  • să explici de ce intensitatea curentului este aceeași prin toate elementele;
  • să reprezinți fazorial \(U_R\), \(U_L\) și \(U_C\);
  • să explici de ce \(U_L\) și \(U_C\) au sensuri fazoriale opuse;
  • să construiești fazorul tensiunii totale;
  • să deduci impedanța circuitului;
  • să utilizezi legea lui Ohm \(U=ZI\);
  • să calculezi unghiul de fază;
  • să recunoști un circuit cu caracter inductiv sau capacitiv;
  • să calculezi factorul de putere;
  • să calculezi puterea activă disipată în circuit.

Relațiile centrale

\[ \boxed{ X_L=\omega L } \]
\[ \boxed{ X_C=\frac1{\omega C} } \]
\[ \boxed{ Z= \sqrt{ R^2+ (X_L-X_C)^2 } } \]
\[ \boxed{ U=ZI } \]
\[ \boxed{ \tan\varphi= \frac{X_L-X_C}{R} } \]

1. Cele trei elemente studiate separat

Rezistor

\[ U_R=RI \]

Tensiunea și curentul sunt în fază:

\[ \varphi_R=0 \]

Bobină ideală

\[ U_L=X_LI \]
\[ X_L=\omega L \]

Tensiunea conduce curentul cu:

\[ +90^\circ \]

Condensator ideal

\[ U_C=X_CI \]
\[ X_C=\frac1{\omega C} \]

Tensiunea este în urmă față de curent cu:

\[ -90^\circ \]
În circuitul serie, intensitatea curentului este aceeași prin toate elementele. De aceea este natural să alegem fazorul curentului \(\vec I\) drept referință.

2. De ce curentul este același?

Rezistorul, bobina și condensatorul sunt conectate în serie. Prin urmare, în orice secțiune a circuitului curentul instantaneu are aceeași intensitate.

\[ \boxed{ i_R=i_L=i_C=i } \]

Pentru valorile efective:

\[ \boxed{ I_R=I_L=I_C=I } \]
Această proprietate face posibilă construirea unei diagrame fazoriale în care toate tensiunile sunt raportate la același fazor al curentului.

3. Fazorii tensiunilor

Alegem curentul pe axa orizontală.

Element Tensiune Poziție față de curent
Rezistor \[ U_R=RI \] \[ 0^\circ \]
Bobină \[ U_L=X_LI \] \[ +90^\circ \]
Condensator \[ U_C=X_CI \] \[ -90^\circ \]
Fazorii \(U_L\) și \(U_C\) se află pe aceeași direcție, dar au sensuri opuse. Prin urmare, efectul lor fazorial se combină prin diferență: \[ \boxed{ U_X=U_L-U_C } \]

4. De ce nu putem scrie \(U=U_R+U_L+U_C\)?

Valorile \(U_R\), \(U_L\) și \(U_C\) reprezintă module ale unor fazori cu direcții diferite.

Tensiunea totală se obține prin sumă vectorială:

\[ \boxed{ \vec U= \vec U_R+ \vec U_L+ \vec U_C } \]

Cum \(\vec U_L\) și \(\vec U_C\) sunt opuse, rezultanta lor este:

\[ \vec U_X= \vec U_L+ \vec U_C \]

cu modulul algebric vertical:

\[ \boxed{ U_X=U_L-U_C } \]
În general: \[ \boxed{ U\neq U_R+U_L+U_C } \] pentru modulele tensiunilor. Tensiunile trebuie adunate fazorial.

5. Triunghiul tensiunilor

Fazorul \(U_R\) este orizontal, iar rezultanta reactivă:

\[ U_L-U_C \]

este verticală.

Cele două componente sunt perpendiculare, deci:

\[ U^2= U_R^2+ (U_L-U_C)^2 \]
\[ \boxed{ U= \sqrt{ U_R^2+ (U_L-U_C)^2 } } \]

6. Deducerea impedanței

Știm că:

\[ U_R=RI \]
\[ U_L=X_LI \]
\[ U_C=X_CI \]

Înlocuim în:

\[ U^2= U_R^2+ (U_L-U_C)^2 \]

și obținem:

\[ U^2= (RI)^2+ (X_LI-X_CI)^2 \]

Factorizăm \(I^2\):

\[ U^2= I^2 \left[ R^2+ (X_L-X_C)^2 \right] \]

Prin urmare:

\[ U= I \sqrt{ R^2+ (X_L-X_C)^2 } \]

Definim impedanța circuitului:

\[ \boxed{ Z= \sqrt{ R^2+ (X_L-X_C)^2 } } \]

7. Legea lui Ohm pentru circuitul RLC serie

Cu ajutorul impedanței, relația dintre valorile efective ale tensiunii și curentului devine:

\[ \boxed{ U=ZI } \]

sau:

\[ \boxed{ I= \frac{U}{Z} } \]

Unitatea impedanței

\[ \boxed{ [Z]=\Omega } \]
Impedanța nu trebuie confundată cu rezistența. Rezistența \(R\) descrie componenta disipativă. Impedanța \(Z\) descrie opoziția totală a circuitului RLC față de curentul alternativ, incluzând și efectele inductiv și capacitiv.

8. Unghiul de fază al circuitului

În triunghiul fazorial:

\[ \tan\varphi= \frac{ U_L-U_C }{ U_R } \]

Folosind:

\[ U_L=X_LI, \quad U_C=X_CI, \quad U_R=RI \]

rezultă:

\[ \boxed{ \tan\varphi= \frac{ X_L-X_C }{ R } } \]

De asemenea:

\[ \boxed{ \cos\varphi= \frac{R}{Z} } \]
Folosim convenția: \[ \boxed{ \varphi= \varphi_U-\varphi_I } \] Astfel:
  • \(\varphi>0\) → tensiunea totală este în avans față de curent;
  • \(\varphi<0\) → curentul este în avans față de tensiunea totală;
  • \(\varphi=0\) → tensiunea și curentul sunt în fază.

9. Caracter inductiv, capacitiv sau rezistiv

Caracter inductiv

\[ X_L>X_C \]
\[ \varphi>0 \]

Tensiunea totală este în avans față de curent.

Caracter capacitiv

\[ X_C>X_L \]
\[ \varphi<0 \]

Curentul este în avans față de tensiunea totală.

Echilibru reactiv

\[ X_L=X_C \]
\[ \varphi=0 \]

Circuitul se comportă global ca unul rezistiv.

Cazul: \[ X_L=X_C \] este deosebit de important și va fi studiat separat în lecția despre rezonanță.

10. Cazul \(X_L=X_C\)

Dacă:

\[ X_L=X_C \]

atunci:

\[ X_L-X_C=0 \]

și:

\[ Z= \sqrt{R^2} \]
\[ \boxed{ Z=R } \]

În acest caz:

\[ \boxed{ \varphi=0 } \]

și:

\[ \boxed{ I=\frac UR } \]
Important: chiar dacă rezultanta fazorială a tensiunilor reactive este zero, \(U_L\) și \(U_C\) nu trebuie să fie individual zero. Ele pot avea module egale și sensuri fazoriale opuse.

11. Triunghiul impedanțelor

Relația:

\[ Z^2= R^2+ (X_L-X_C)^2 \]

poate fi reprezentată printr-un triunghi dreptunghic:

Latură Mărime
orizontală \[ R \]
verticală \[ X_L-X_C \]
ipotenuză \[ Z \]

Din triunghi:

\[ \boxed{ \cos\varphi= \frac RZ } \]
\[ \boxed{ \sin\varphi= \frac{ X_L-X_C }{ Z } } \]

12. Puterea activă în circuitul RLC serie

Puterea activă medie este:

\[ \boxed{ P= UI\cos\varphi } \]

Dar:

\[ U=ZI \]

și:

\[ \cos\varphi= \frac RZ \]

deci:

\[ P= ZI^2 \frac RZ \]
\[ \boxed{ P=I^2R } \]
În modelul ideal, numai rezistorul disipă putere activă. Bobina ideală și condensatorul ideal fac schimb periodic de energie cu sursa, dar nu consumă energie activă în medie.

13. Factorul de putere

Mărimea:

\[ \boxed{ \cos\varphi } \]

se numește factor de putere în regim sinusoidal.

Pentru circuitul RLC serie:

\[ \boxed{ \cos\varphi= \frac RZ } \]

Deoarece:

\[ Z\ge R \]

rezultă:

\[ 0\le \cos\varphi \le1 \]
Cu cât efectele reactive sunt mai reduse față de \(R\), cu atât: \[ |\varphi| \] este mai mic, iar factorul de putere este mai apropiat de 1.

14. Algoritm de rezolvare

  1. Transformă toate mărimile în unități SI: \(L\) în H, \(C\) în F, \(f\) în Hz.
  2. Calculează pulsația: \[ \omega=2\pi f \]
  3. Calculează reactanța inductivă: \[ X_L=\omega L \]
  4. Calculează reactanța capacitivă: \[ X_C=\frac1{\omega C} \]
  5. Determină reactanța rezultantă: \[ X=X_L-X_C \]
  6. Calculează impedanța: \[ Z= \sqrt{ R^2+X^2 } \]
  7. Calculează curentul: \[ I=\frac UZ \]
  8. Determină tensiunile: \[ U_R=RI, \quad U_L=X_LI, \quad U_C=X_CI \]
  9. Calculează unghiul de fază: \[ \tan\varphi=\frac XR \]
  10. Verifică: \[ U= \sqrt{ U_R^2+ (U_L-U_C)^2 } \]

🧮 Exemple rezolvate

Nivel 1

Exemplul 1 – Impedanță din reactanțe

Se dau:

\[ R=30\,\Omega, \quad X_L=50\,\Omega, \quad X_C=10\,\Omega \]

Determinați impedanța.

Vezi rezolvarea
Reactanța rezultantă:

\[ X= X_L-X_C = 50-10 = 40\,\Omega \] Impedanța:

\[ Z= \sqrt{ 30^2+ 40^2 } \] \[ Z= \sqrt{ 900+1600 } \] \[ \boxed{ Z=50\,\Omega } \]
Nivel 1

Exemplul 2 – Curentul

Pentru circuitul anterior:

\[ U=100\,V \]

Determinați curentul efectiv.

Vezi rezolvarea
\[ I= \frac UZ \] \[ I= \frac{100}{50} \] \[ \boxed{ I=2\,A } \]
Nivel 2

Exemplul 3 – Tensiunile pe elemente

Pentru:

\[ R=30\,\Omega, \quad X_L=50\,\Omega, \quad X_C=10\,\Omega, \quad I=2\,A \]

determinați \(U_R\), \(U_L\) și \(U_C\).

Vezi rezolvarea
\[ U_R= RI= 30\cdot2 = 60\,V \] \[ U_L= X_LI= 50\cdot2 = 100\,V \] \[ U_C= X_CI= 10\cdot2 = 20\,V \] Deci:

\[ \boxed{ U_R=60\,V } \] \[ \boxed{ U_L=100\,V } \] \[ \boxed{ U_C=20\,V } \] Tensiunea totală:

\[ U= \sqrt{ 60^2+ (100-20)^2 } \] \[ U= \sqrt{ 3600+6400 } \] \[ \boxed{ U=100\,V } \]
Nivel 2

Exemplul 4 – Unghiul de fază

Pentru circuitul:

\[ R=30\,\Omega, \quad X_L-X_C=40\,\Omega \]

determinați \(\varphi\).

Vezi rezolvarea
\[ \tan\varphi= \frac{40}{30} = \frac43 \] Prin urmare:

\[ \boxed{ \varphi\approx53,1^\circ } \] Semnul este pozitiv, deci circuitul are caracter inductiv.
Nivel 2

Exemplul 5 – Circuit capacitiv

Se dau:

\[ R=40\,\Omega, \quad X_L=20\,\Omega, \quad X_C=50\,\Omega \]

Precizați caracterul circuitului și calculați impedanța.

Vezi rezolvarea
\[ X_L-X_C= 20-50= -30\,\Omega \] Cum:

\[ X_C>X_L \] circuitul are caracter capacitiv. Impedanța:

\[ Z= \sqrt{ 40^2+ (-30)^2 } \] \[ Z= \sqrt{ 1600+900 } \] \[ \boxed{ Z=50\,\Omega } \]
Nivel 2

Exemplul 6 – Calcul complet din \(R,L,C,f\)

Se dau:

\[ R=20\,\Omega \] \[ L=0,10\,H \] \[ C=100\,\mu F \] \[ f=50\,Hz \]

Determinați \(X_L\), \(X_C\) și \(Z\).

Vezi rezolvarea
\[ \omega= 2\pi f = 100\pi\,rad/s \] Reactanța inductivă:

\[ X_L= \omega L = 100\pi\cdot0,10 \] \[ X_L= 10\pi \approx31,42\,\Omega \] Capacitatea:

\[ C= 100\,\mu F = 10^{-4}\,F \] Reactanța capacitivă:

\[ X_C= \frac1{ 100\pi\cdot10^{-4} } \] \[ X_C\approx31,83\,\Omega \] Rezultanta reactivă:

\[ X_L-X_C \approx -0,41\,\Omega \] Impedanța:

\[ Z= \sqrt{ 20^2+ (-0,41)^2 } \] \[ \boxed{ Z\approx20,00\,\Omega } \] Circuitul este foarte aproape de echilibrul reactanțelor.
Nivel 3

Exemplul 7 – Puterea activă

Un circuit RLC serie are:

\[ U=120\,V, \quad I=2\,A, \quad \cos\varphi=0,80 \]

Determinați puterea activă.

Vezi rezolvarea
\[ P= UI\cos\varphi \] \[ P= 120\cdot2\cdot0,80 \] \[ \boxed{ P=192\,W } \]
Nivel 3

Exemplul 8 – Determinarea rezistenței

Pentru un circuit RLC serie se cunosc:

\[ Z=50\,\Omega \]
\[ \cos\varphi=0,60 \]

Determinați \(R\).

Vezi rezolvarea
\[ \cos\varphi= \frac RZ \] deci:

\[ R= Z\cos\varphi \] \[ R= 50\cdot0,60 \] \[ \boxed{ R=30\,\Omega } \]
Nivel 3

Exemplul 9 – De ce tensiunile pot depăși tensiunea sursei?

Într-un circuit RLC se măsoară:

\[ U=40\,V, \quad U_L=100\,V, \quad U_C=80\,V \]

Este imposibil deoarece \(U_L>U\)?

Vezi explicația
Nu. Tensiunile nu se adună aritmetic. Rezultanta reactivă este:

\[ U_L-U_C= 100-80= 20\,V \] Dacă tensiunea rezistivă este:

\[ U_R= \sqrt{ 40^2- 20^2 } \] atunci:

\[ U_R\approx34,6\,V \] și:

\[ \sqrt{ 34,6^2+ 20^2 } \approx40\,V \] Prin urmare, tensiunile individuale pe elementele reactive pot fi mai mari decât tensiunea totală fără a încălca legea tensiunilor, deoarece trebuie tratate fazorial.

🔬 15. Activitate didactică – construirea diagramei fazoriale

Activitatea poate fi realizată fără conectarea unui circuit real, folosind hârtie milimetrică, riglă, raportor și valorile calculate.

Date propuse

\[ R=30\,\Omega \]
\[ X_L=50\,\Omega \]
\[ X_C=10\,\Omega \]
\[ I=2\,A \]

Calculați

  • \(U_R\);
  • \(U_L\);
  • \(U_C\);
  • \(U_L-U_C\);
  • \(U\);
  • \(\varphi\).
  1. Alege fazorul curentului pe orizontală.
  2. Desenează \(\vec U_R\) în aceeași direcție.
  3. Desenează \(\vec U_L\) vertical în sus.
  4. Desenează \(\vec U_C\) vertical în jos.
  5. Construiește rezultanta \(\vec U\).
  6. Măsoară unghiul \(\varphi\) cu raportorul.
  7. Compară valoarea măsurată cu: \[ \varphi= \arctan \left( \frac{X_L-X_C}{R} \right) \]
Această activitate este importantă deoarece transformă formula impedanței dintr-o expresie de memorat într-o consecință geometrică a diagramei fazoriale.

\[ X_C>X_L \]

și:

\[ \varphi<0 \]

\[ X_L\approx X_C \]

Observă că:

\[ Z\approx R \]

și:

\[ \varphi\approx0 \]

Observă simultan:

\[ X_L\uparrow \]
și:

\[ X_C\downarrow \]

Cum se modifică impedanța?

  • factorul de putere?

\[ U_L>U \]

⚠️ Greșeli frecvente

1. „Adun \(U_R+U_L+U_C\)”

Nu pentru module. Tensiunile au faze diferite.

\[ U= \sqrt{ U_R^2+ (U_L-U_C)^2 } \]

2. „Impedanța este \(R+X_L+X_C\)”

Nu.

\[ Z= \sqrt{ R^2+ (X_L-X_C)^2 } \]

3. „\(X_L\) și \(X_C\) se adună.”

Ele au efecte fazoriale opuse:

\[ X= X_L-X_C \]

4. „Dacă \(X_L>X_C\), curentul conduce.”

Este invers.

Pentru caracter inductiv, tensiunea totală conduce curentul.

5. „Dacă \(X_C>X_L\), \(\varphi\) este pozitiv.”

Nu. Cu convenția:

\[ \varphi= \varphi_U-\varphi_I \]

circuitul capacitiv are:

\[ \varphi<0 \]

6. „Impedanța poate fi mai mică decât \(R\).”

Nu în modelul RLC serie ideal:

\[ Z= \sqrt{ R^2+ (X_L-X_C)^2 } \ge R \]

7. „Bobina și condensatorul consumă putere activă ideal.”

Nu. Puterea activă medie este disipată în rezistor.

\[ P=I^2R \]

8. „Dacă \(X_L=X_C\), bobina și condensatorul dispar.”

Nu. Efectele lor asupra tensiunii totale se compensează fazorial, dar tensiunile individuale pot exista.

🧭 Ce urmează?

În circuitul RLC serie, curentul este comun, iar tensiunile se combină fazorial.

Într-un circuit RLC paralel, situația se inversează din punct de vedere structural:

tensiunea va fi comună ramurilor, iar curenții prin \(R\), \(L\) și \(C\) vor avea faze diferite.

Va trebui să construim o diagramă fazorială a curenților și să analizăm modul în care curenții inductiv și capacitiv se compensează.

În lecția următoare: Circuit RLC paralel vom trece de la suma fazorială a tensiunilor la suma fazorială a curenților.
