Lecția 8 Clasa a X-a Circuit RLC paralel

Circuit RLC paralel

În circuitul RLC paralel, tensiunea este aceeași pe toate cele trei ramuri, dar curenții prin rezistor, bobină și condensator au faze diferite. Curentul total se obține prin sumă fazorială, iar modul natural de descriere a circuitului devine admitanța.

🎯 Ce vei învăța

La final vei putea:

  • să descrii structura unui circuit RLC paralel;
  • să explici de ce tensiunea este aceeași pe toate ramurile;
  • să calculezi \(I_R\), \(I_L\) și \(I_C\);
  • să reprezinți fazorial curenții de ramură;
  • să calculezi curentul total;
  • să definești conductanța și admitanța;
  • să calculezi impedanța echivalentă;
  • să recunoști caracterul inductiv sau capacitiv al circuitului;
  • să calculezi unghiul de fază și factorul de putere;
  • să explici cazul \(I_L=I_C\);
  • să pregătești studiul rezonanței.

Relațiile centrale

\[ \boxed{ I_R=\frac UR } \]
\[ \boxed{ I_L=\frac U{X_L} } \]
\[ \boxed{ I_C=\frac U{X_C} } \]
\[ \boxed{ I= \sqrt{ I_R^2+ (I_C-I_L)^2 } } \]
\[ \boxed{ Y= \sqrt{ G^2+ (B_C-B_L)^2 } } \]

1. Serie versus paralel

RLC serie

Curentul este comun:

\[ I_R=I_L=I_C=I \]

Tensiunile se compun fazorial.

RLC paralel

Tensiunea este comună:

\[ U_R=U_L=U_C=U \]

Curenții se compun fazorial.

Ideea-cheie: în circuitul RLC paralel alegem tensiunea \(\vec U\) drept fazor de referință.

2. De ce tensiunea este aceeași?

Rezistorul, bobina și condensatorul sunt conectate între aceleași două noduri.

Prin urmare:

\[ \boxed{ u_R(t)=u_L(t)=u_C(t)=u(t) } \]

iar pentru valorile efective:

\[ \boxed{ U_R=U_L=U_C=U } \]
Aceeași tensiune produce trei curenți diferiți, deoarece fiecare ramură are o comportare diferită în curent alternativ.

3. Curenții prin cele trei ramuri

Ramura rezistivă

\[ \boxed{ I_R=\frac UR } \]

Curentul este în fază cu tensiunea.

\[ \Delta\varphi_R=0 \]

Ramura inductivă

\[ \boxed{ I_L=\frac U{X_L} } \]
\[ X_L=\omega L \]

Curentul este în urmă față de tensiune cu:

\[ 90^\circ \]

Ramura capacitivă

\[ \boxed{ I_C=\frac U{X_C} } \]
\[ X_C=\frac1{\omega C} \]

Curentul este în avans față de tensiune cu:

\[ 90^\circ \]

4. Diagrama fazorială a curenților

Alegem fazorul tensiunii pe direcția orizontală.

Curent Modul Poziție față de tensiune
\(I_R\) \[ \frac UR \] \[ 0^\circ \]
\(I_L\) \[ \frac U{X_L} \] \[ -90^\circ \]
\(I_C\) \[ \frac U{X_C} \] \[ +90^\circ \]
Fazorii \(I_L\) și \(I_C\) sunt pe aceeași direcție, dar au sensuri opuse. De aceea componenta reactivă a curentului total este: \[ \boxed{ I_X=I_C-I_L } \]

5. Legea I a lui Kirchhoff în regim sinusoidal

În nodul în care curentul sursei se separă în cele trei ramuri, legea I a lui Kirchhoff rămâne valabilă instantaneu:

\[ i=i_R+i_L+i_C \]

Pentru reprezentarea fazorială:

\[ \boxed{ \vec I= \vec I_R+ \vec I_L+ \vec I_C } \]
Nu putem scrie în general: \[ I=I_R+I_L+I_C \] pentru module, deoarece curenții nu sunt în fază. Ei trebuie adunați fazorial.

6. Curentul total

Componenta orizontală este:

\[ I_R \]

iar componenta verticală este:

\[ I_C-I_L \]

Aceste componente sunt perpendiculare, deci:

\[ I^2= I_R^2+ (I_C-I_L)^2 \]
\[ \boxed{ I= \sqrt{ I_R^2+ (I_C-I_L)^2 } } \]
Observă analogia cu circuitul RLC serie: serie: \[ U= \sqrt{ U_R^2+ (U_L-U_C)^2 } \] paralel: \[ I= \sqrt{ I_R^2+ (I_C-I_L)^2 } \]

7. Conductanța

Pentru ramura rezistivă:

\[ I_R= \frac UR \]

Definim conductanța:

\[ \boxed{ G= \frac1R } \]

Atunci:

\[ \boxed{ I_R=UG } \]

Unitatea conductanței

\[ \boxed{ [G]=S } \]

Unitatea se numește siemens.

8. Susceptanțele inductivă și capacitivă

Pentru bobină:

\[ I_L= \frac U{X_L} \]

definim modulul susceptanței inductive:

\[ \boxed{ B_L= \frac1{X_L} = \frac1{\omega L} } \]

astfel încât:

\[ I_L=UB_L \]

Pentru condensator:

\[ I_C= \frac U{X_C} \]

iar:

\[ \boxed{ B_C= \frac1{X_C} = \omega C } \]

deci:

\[ I_C=UB_C \]
Atât conductanța, cât și susceptanța se măsoară în siemens: \[ \boxed{ [G]=[B_L]=[B_C]=S } \]

9. Admitanța circuitului paralel

Înlocuim:

\[ I_R=UG \]
\[ I_C-I_L= U(B_C-B_L) \]

în expresia curentului total:

\[ I= \sqrt{ (UG)^2+ \left[ U(B_C-B_L) \right]^2 } \]

Factorizăm \(U\):

\[ I= U \sqrt{ G^2+ (B_C-B_L)^2 } \]

Definim admitanța:

\[ \boxed{ Y= \sqrt{ G^2+ (B_C-B_L)^2 } } \]

și obținem:

\[ \boxed{ I=UY } \]

Unitatea admitanței

\[ \boxed{ [Y]=S } \]

10. Admitanța exprimată prin \(R\), \(L\), \(C\) și \(f\)

Cum:

\[ G=\frac1R \]
\[ B_L= \frac1{\omega L} \]
\[ B_C= \omega C \]

rezultă:

\[ \boxed{ Y= \sqrt{ \frac1{R^2} + \left( \omega C- \frac1{\omega L} \right)^2 } } \]

Curentul total este:

\[ \boxed{ I= U \sqrt{ \frac1{R^2} + \left( \omega C- \frac1{\omega L} \right)^2 } } \]

11. Impedanța echivalentă

Prin definiție:

\[ Y= \frac IZ \cdot \frac ZU \]

mai simplu, deoarece:

\[ I=UY \]

și:

\[ I= \frac UZ \]

rezultă:

\[ \boxed{ Z= \frac1Y } \]

Deci:

\[ \boxed{ Z= \frac{ 1 }{ \sqrt{ \dfrac1{R^2} + \left( \omega C- \dfrac1{\omega L} \right)^2 } } } \]
Pentru circuitul paralel, admitanța este adesea mai ușor de calculat decât impedanța, deoarece contribuțiile ramurilor apar natural în expresia curentului total.

12. Unghiul de fază

Păstrăm convenția folosită în lecția anterioară:

\[ \boxed{ \varphi= \varphi_U-\varphi_I } \]

Din triunghiul curenților:

\[ \tan(-\varphi)= \frac{ I_C-I_L }{ I_R } \]

deci:

\[ \boxed{ \tan\varphi= \frac{ I_L-I_C }{ I_R } } \]

În termeni de admitanțe:

\[ \boxed{ \tan\varphi= \frac{ B_L-B_C }{ G } } \]

Factorul de putere este:

\[ \boxed{ \cos\varphi= \frac{I_R}{I} = \frac GY } \]

13. Caracter inductiv sau capacitiv

Caracter inductiv

\[ I_L>I_C \]

sau:

\[ B_L>B_C \]

Curentul total este în urmă față de tensiune:

\[ \boxed{ \varphi>0 } \]

Caracter capacitiv

\[ I_C>I_L \]

sau:

\[ B_C>B_L \]

Curentul conduce tensiunea:

\[ \boxed{ \varphi<0 } \]

Echilibru reactiv

\[ I_L=I_C \]
\[ \boxed{ \varphi=0 } \]

Curentul sursei este în fază cu tensiunea.

14. Cazul \(I_L=I_C\)

Dacă:

\[ I_L=I_C \]

atunci componenta reactivă a curentului total este nulă:

\[ I_C-I_L=0 \]

și:

\[ I= I_R \]

Prin urmare:

\[ \boxed{ Y=G=\frac1R } \]

iar:

\[ \boxed{ Z=R } \]
În circuitul RLC paralel ideal studiat aici, la compensarea curenților reactivi: \[ \boxed{ I=I_R } \] iar curentul absorbit de la sursă este minim pentru tensiunea dată. Curenții \(I_L\) și \(I_C\) pot fi însă nenuli și chiar mari.

15. Condiția de compensare a ramurilor reactive

Condiția:

\[ I_L=I_C \]

devine:

\[ \frac U{X_L} = \frac U{X_C} \]

deci:

\[ X_L=X_C \]

Înlocuim:

\[ \omega L= \frac1{\omega C} \]

și obținem:

\[ \omega^2LC=1 \]
\[ \boxed{ \omega_0= \frac1{\sqrt{LC}} } \]

respectiv:

\[ \boxed{ f_0= \frac{ 1 }{ 2\pi\sqrt{LC} } } \]
Aceasta este exact frecvența pe care o vom studia în lecția următoare: frecvența de rezonanță.

16. Ce este special la compensarea curenților?

Să presupunem că:

\[ I_L=I_C=2\,A \]

iar:

\[ I_R=0,5\,A \]

Curentul total nu este:

\[ 2+2+0,5=4,5\,A \]

deoarece curenții inductiv și capacitiv sunt în opoziție de fază.

Rezultanta este:

\[ I= \sqrt{ 0,5^2+ (2-2)^2 } \]
\[ \boxed{ I=0,5\,A } \]
Sursa poate furniza un curent relativ mic, în timp ce între ramurile reactive există curenți mai mari. Nu există contradicție: curenții se compun fazorial, nu aritmetic.

17. Puterea activă

Pentru întregul circuit:

\[ P= UI\cos\varphi \]

Dar:

\[ I_R= I\cos\varphi \]

deci:

\[ P= UI_R \]

iar cum:

\[ I_R= \frac UR \]

obținem:

\[ \boxed{ P= \frac{U^2}{R} } \]

sau:

\[ \boxed{ P= I_R^2R } \]
În modelul ideal, numai ramura rezistivă consumă putere activă medie. Bobina și condensatorul ideale fac schimb periodic de energie cu circuitul.

18. RLC serie versus RLC paralel

Aspect RLC serie RLC paralel
Mărime comună curentul \(I\) tensiunea \(U\)
Se compun fazorial tensiunile curenții
Componentă reactivă \[ X_L-X_C \] \[ B_C-B_L \]
Mărime convenabilă impedanța \(Z\) admitanța \(Y\)
La compensare \[ Z=R \] \[ Y=\frac1R \]
Fază la compensare \[ \varphi=0 \] \[ \varphi=0 \]

19. Algoritm de rezolvare

  1. Transformă \(L\) în henry și \(C\) în farad.
  2. Calculează: \[ \omega=2\pi f \]
  3. Calculează: \[ X_L=\omega L \]
  4. Calculează: \[ X_C=\frac1{\omega C} \]
  5. Determină curenții de ramură: \[ I_R=\frac UR, \quad I_L=\frac U{X_L}, \quad I_C=\frac U{X_C} \]
  6. Calculează componenta reactivă: \[ I_X=I_C-I_L \]
  7. Calculează curentul total: \[ I= \sqrt{ I_R^2+ I_X^2 } \]
  8. Dacă este necesar, calculează: \[ Y=\frac IU \] și: \[ Z=\frac1Y=\frac UI \]
  9. Determină caracterul circuitului din semnul lui \(I_C-I_L\).
  10. Calculează faza: \[ \tan\varphi= \frac{I_L-I_C}{I_R} \]

🧮 Exemple rezolvate

Nivel 1

Exemplul 1 – Curenții de ramură

Se dau:

\[ U=60\,V, \quad R=60\,\Omega, \quad X_L=30\,\Omega, \quad X_C=20\,\Omega \]

Determinați curenții de ramură.

Vezi rezolvarea
Pentru rezistor:

\[ I_R= \frac{60}{60} = 1\,A \] Pentru bobină:

\[ I_L= \frac{60}{30} = 2\,A \] Pentru condensator:

\[ I_C= \frac{60}{20} = 3\,A \] Prin urmare:

\[ \boxed{ I_R=1\,A, \quad I_L=2\,A, \quad I_C=3\,A } \]
Nivel 1

Exemplul 2 – Curentul total

Pentru circuitul anterior:

\[ I_R=1\,A, \quad I_L=2\,A, \quad I_C=3\,A \]

determinați curentul total.

Vezi rezolvarea
Componenta reactivă:

\[ I_C-I_L= 3-2= 1\,A \] Curentul total:

\[ I= \sqrt{ 1^2+ 1^2 } \] \[ \boxed{ I=\sqrt2\,A\approx1,41\,A } \] Circuitul are caracter capacitiv deoarece:

\[ I_C>I_L \]
Nivel 2

Exemplul 3 – Unghiul de fază

Pentru:

\[ I_R=1\,A, \quad I_L=2\,A, \quad I_C=3\,A \]

determinați \(\varphi\).

Vezi rezolvarea
\[ \tan\varphi= \frac{ I_L-I_C }{ I_R } \] \[ \tan\varphi= \frac{ 2-3 }{ 1 } = -1 \] Prin urmare:

\[ \boxed{ \varphi=-45^\circ } \] Semnul negativ arată caracterul capacitiv: curentul total conduce tensiunea.
Nivel 2

Exemplul 4 – Admitanța și impedanța

Un circuit paralel absoarbe:

\[ I=2\,A \]

la tensiunea:

\[ U=40\,V \]

Determinați admitanța și impedanța echivalentă.

Vezi rezolvarea
\[ Y= \frac IU \] \[ Y= \frac2{40} = 0,05\,S \] Apoi:

\[ Z= \frac1Y \] \[ Z= \frac1{0,05} \] \[ \boxed{ Y=0,05\,S } \] \[ \boxed{ Z=20\,\Omega } \]
Nivel 2

Exemplul 5 – Calcul din \(L\), \(C\) și \(f\)

Se dau:

\[ L=0,20\,H, \quad C=100\,\mu F, \quad f=50\,Hz \]

Determinați \(X_L\) și \(X_C\).

Vezi rezolvarea
\[ \omega= 2\pi f= 100\pi\,rad/s \] Pentru bobină:

\[ X_L= \omega L \] \[ X_L= 100\pi\cdot0,20 \] \[ \boxed{ X_L\approx62,8\,\Omega } \] Pentru condensator:

\[ C= 100\cdot10^{-6}\,F \] \[ X_C= \frac1{ 100\pi\cdot100\cdot10^{-6} } \] \[ \boxed{ X_C\approx31,8\,\Omega } \]
Nivel 2

Exemplul 6 – Efectul frecvenței

Frecvența sursei crește, în timp ce \(U\), \(R\), \(L\) și \(C\) rămân constante. Cum se modifică \(I_L\) și \(I_C\)?

Vezi rezolvarea
Pentru bobină:

\[ X_L=\omega L \] Deci:

\[ f\uparrow \Rightarrow X_L\uparrow \Rightarrow I_L= \frac U{X_L} \downarrow \] Pentru condensator:

\[ X_C= \frac1{\omega C} \] deci:

\[ f\uparrow \Rightarrow X_C\downarrow \Rightarrow I_C= \frac U{X_C} \uparrow \] Prin urmare:

\[ \boxed{ f\uparrow \Rightarrow I_L\downarrow, \quad I_C\uparrow } \]
Nivel 2

Exemplul 7 – Compensarea curenților reactivi

Se măsoară:

\[ I_R=0,80\,A, \quad I_L=2,5\,A, \quad I_C=2,5\,A \]

Determinați curentul sursei.

Vezi rezolvarea
\[ I_C-I_L=0 \] deci:

\[ I= \sqrt{ I_R^2+0^2 } \] \[ \boxed{ I=0,80\,A } \] Deși prin bobină și condensator circulă câte \(2,5\,A\), componentele lor reactive se compensează fazorial la sursă.
Nivel 3

Exemplul 8 – Puterea activă

Un circuit RLC paralel are:

\[ U=120\,V, \quad R=60\,\Omega \]

Determinați puterea activă în modelul ideal.

Vezi rezolvarea
\[ P= \frac{U^2}{R} \] \[ P= \frac{120^2}{60} \] \[ P= \frac{14400}{60} \] \[ \boxed{ P=240\,W } \] Bobina și condensatorul ideale nu contribuie la puterea activă medie.
Nivel 3

Exemplul 9 – Frecvența pentru compensare

Se dau:

\[ L=0,20\,H \]
\[ C=50\,\mu F \]

Determinați frecvența la care \(I_L=I_C\).

Vezi rezolvarea
Condiția este:

\[ f_0= \frac{ 1 }{ 2\pi\sqrt{LC} } \] Transformăm:

\[ C= 50\cdot10^{-6}\,F \] Calculăm:

\[ LC= 0,20\cdot50\cdot10^{-6} = 10^{-5} \] \[ \sqrt{LC} = \sqrt{10^{-5}} \approx 0,003162 \] Deci:

\[ f_0= \frac{ 1 }{ 2\pi\cdot0,003162 } \] \[ \boxed{ f_0\approx50,3\,Hz } \] Acesta este chiar cazul ce va conduce la studiul rezonanței.

🔬 20. Activitate practică – suma fazorială a curenților

Activitatea poate fi făcută pe hârtie, fără conectarea unui circuit real.

Date propuse

\[ I_R=2\,A \]
\[ I_L=3\,A \]
\[ I_C=1\,A \]

Sarcină

Alege o scară:

\[ 1\,A \longleftrightarrow 2\,cm \]

și construiește diagrama fazorială.

  1. Desenează fazorul tensiunii pe orizontală.
  2. Desenează \(I_R\) în aceeași direcție.
  3. Desenează \(I_C\) vertical în sus.
  4. Desenează \(I_L\) vertical în jos.
  5. Construiește componenta: \[ I_C-I_L \]
  6. Desenează curentul total \(\vec I\).
  7. Măsoară unghiul dintre \(\vec U\) și \(\vec I\).
  8. Compară cu valoarea calculată din: \[ \tan\varphi= \frac{I_L-I_C}{I_R} \]
Activitatea evidențiază de ce legea I a lui Kirchhoff este o sumă algebrică instantanee, dar modulele curenților sinusoidali trebuie combinate fazorial.

🔬 21. Extensie experimentală cu tensiune joasă

Dacă laboratorul dispune de generator sinusoidal, rezistor, bobină, condensator nepolarizat și aparate adecvate, se poate realiza un montaj paralel la tensiune joasă.

Se pot măsura:

  • tensiunea comună \(U\);
  • curentul \(I_R\);
  • curentul \(I_L\);
  • curentul \(I_C\);
  • curentul total furnizat de generator.
O bobină reală are rezistență proprie, iar condensatorul real are pierderi. Prin urmare, rezultatele experimentale nu vor reproduce perfect modelul ideal.
Experimentul se realizează exclusiv cu surse didactice izolate și tensiuni joase. Nu realizați montaje RLC improvizate direct la rețeaua electrică de 230 V.

\[ I_L>I \]

⚠️ Greșeli frecvente

1. „În paralel curentul este același în toate ramurile.”

Nu. În paralel, tensiunea este aceeași.

2. „Curentul total este \(I_R+I_L+I_C\).”

Nu pentru module.

\[ I= \sqrt{ I_R^2+ (I_C-I_L)^2 } \]

3. „\(I_L\) și \(I_C\) se adună.”

Fazorial au sensuri opuse:

\[ I_X= I_C-I_L \]

4. „Frecvența mai mare mărește \(I_L\).”

La tensiune constantă:

\[ f\uparrow \Rightarrow X_L\uparrow \Rightarrow I_L\downarrow \]

5. „Frecvența mai mare micșorează \(I_C\).”

Este invers:

\[ f\uparrow \Rightarrow X_C\downarrow \Rightarrow I_C\uparrow \]

6. „Dacă \(I_L=I_C\), ambii curenți sunt zero.”

Nu. Ei pot fi mari și egali, dar se compensează fazorial în curentul sursei.

7. „La compensare curentul sursei este zero.”

Nu dacă există ramura rezistivă.

\[ \boxed{ I=I_R } \]

8. „Admitanța se măsoară în ohmi.”

Nu.

\[ [Y]=S \]

Impedanța se măsoară în ohmi.

9. „Circuit inductiv înseamnă \(I_C>I_L\).”

Nu.

\[ \boxed{ I_L>I_C } \]

10. „Toate ramurile consumă putere activă.”

În modelul ideal, numai rezistorul disipă putere activă medie.

📌 De reținut

Tensiune comună

\[ \boxed{ U_R=U_L=U_C=U } \]

Curent rezistiv

\[ \boxed{ I_R=\frac UR } \]

Curenți reactivi

\[ \boxed{ I_L=\frac U{X_L}, \qquad I_C=\frac U{X_C} } \]

Curent total

\[ \boxed{ I= \sqrt{ I_R^2+ (I_C-I_L)^2 } } \]

Admitanță

\[ \boxed{ Y= \sqrt{ G^2+ (B_C-B_L)^2 } } \]

Impedanță

\[ \boxed{ Z=\frac1Y } \]

Unghi de fază

\[ \boxed{ \tan\varphi= \frac{ I_L-I_C }{ I_R } } \]

Factor de putere

\[ \boxed{ \cos\varphi= \frac{I_R}{I} } \]

Putere activă

\[ \boxed{ P= \frac{U^2}{R} } \]
Schema mentală: aceeași tensiune → \(I_R\) orizontal → \(I_C\) în sus → \(I_L\) în jos → diferența \(I_C-I_L\) → curent total → admitanță → impedanță → fază → compensarea curenților reactivi.

🧭 Ce urmează?

Atât în circuitul serie, cât și în circuitul paralel, am întâlnit condiția:

\[ \boxed{ X_L=X_C } \]

echivalentă cu:

\[ \omega L= \frac1{\omega C} \]

de unde:

\[ \boxed{ \omega_0= \frac1{\sqrt{LC}} } \]

și:

\[ \boxed{ f_0= \frac{ 1 }{ 2\pi\sqrt{LC} } } \]
În lecția următoare vom studia sistematic rezonanța:
  • condiția de rezonanță;
  • frecvența de rezonanță;
  • ce se întâmplă cu impedanța;
  • ce se întâmplă cu intensitatea curentului;
  • de ce circuitul devine global rezistiv la rezonanță.
